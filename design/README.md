# learn-ai · 页面设计

> 日期：2026-07-30
> 可运行原型：`index.html`（列表页）/ `episode.html`（详情页）
> **双击 `index.html` 就能打开，不需要起服务。**

数据不是假的。`data.js` 由 `extract.py` 从 `00_论文探索之旅/` 下的真实素材抽取而成：

| 来自 | 抽出来的东西 |
|---|---|
| `02-精校稿.md` | 46 节大纲、154 段发言、**48,831 字**正文、15 个三级小标题、9 处列表 |
| `03-资料索引.md` | 36 篇论文 + 36 位研究者 + 视频 9 / 演讲 7 / 访谈 5 / 书 9 / 延伸论文 9 / 技术报告 8 / 数据集工具 8 |
| `ppt/` 第 8 / 26 / 32 / 41 页 | 编年史四条轨道，35 个节点 |
| 节目 RSS | 5 条同系列访谈的小宇宙单集链接与完整标题 |
| 小宇宙 CDN | 这期节目的封面图（播放条左侧，走 CDN 缩略参数，18 KB） |
| 小宇宙 CDN | 真实音频地址（已实测支持 Range，无防盗链） |

只有一处是示意：列表页第二张虚线卡片，用来展示「以后条目多了长什么样」。

重新生成数据：`python3 design/extract.py`。
这个脚本里的解析规则就是正式构建脚本要用的规则（技术方案 §4.1–4.5），
先在原型里跑通，搬到 TypeScript 里是直译。

---

## 1. 这个站要解决的问题

不是做一个播客站，也不是做一个博客。是**把「读透了一件事」变成可以交付的东西**。

判断标准就一条：**别人打开这一页，能不能不靠我解释就把这件事学一遍。**

由此推出三个设计取舍：

| | 小宇宙原页 | 本设计 |
|---|---|---|
| 页面主体 | Shownotes + 播放器 | **文字稿**，Shownotes 不做（页头一个链接回原页） |
| 时间线 | 一列时间戳文字 | **可点的电路板走线图**，四条轨道，两种排布 |
| 论文 | PPT 右上角一个链接 | **36 篇成表** + 36 位研究者 + 七类延伸资料，全部带原文直链 |

---

## 2. 视觉：把 PPT 的电路板拿来当设计语言

嘉宾 PPT 从第 8 页开始，用的是一套很完整的**电路板走线**语言 ——
墨黑的线、45° 倒角、焊盘圆环、一颗 DIP 封装、点划线引出标注。

这套语言直接成了整站的视觉基础，连 logo 都是走线画的：

```
纸白 #FBFAF8   墨线 #14161A   阻焊青绿 #0F766E
```

强调色只用在**可点 / 当前 / 命中**三种状态上，正文一律中性色 —— 4.9 万字的长文里，
彩色越少越好。和慧客堂的橙色是刻意区分的：两个站不该看起来像同一个站的两个页面。

**只发亮色，不做深浅切换。** 颜色全部走 CSS 变量，哪天要暗色加一段媒体查询就行，
但一个内容站的主题开关是伪需求：占顶栏位置、要存状态、每个组件都要多测一遍。

## 3. 列表页

刻意做到几乎没有东西：

```
顶栏      ⌁ learn-ai │ 一篇一篇，跟上 AI 时代
条目列表  学习时间 | 主题标签 + 标题 + 一句话 + 产出物徽章
```

没有筛选条、没有站点统计、没有导语。一个只有几条内容的站，那些都是噪音，
等条目多到需要筛选时再加。

时间只有一个：**`2026.07`，我学它的时间**，精确到月。素材本身是哪年发布的，
进详情页看就够了 —— 这是学习史，不是发布史。

**产出物徽章**（`文稿 4.9 万字` `论文 36 篇` `PPT 51 页`）
是这个列表页和普通博客归档的区别 —— 它一眼说清**这一条学到了什么程度**，
所以只放能量化、且对读者有意义的东西。

**Logo 与 slogan** 围绕「跟上 AI 时代」出了 6 × 6 个候选（`pick.html` 里能直接看效果）。
定稿是 **`S1 一篇一篇，跟上 AI 时代`** + **`L1 追赶`** —— 一条虚线走在前面，
一条实线从后面追上来，末端一个实心焊盘。主题就写在图形里，也还在电路板这套语言里。

## 4. 详情页

三个 tab，**文稿是主角**：

```
文稿 4.9 万字 | 编年史 4 条轨道 | 资料 36 篇论文
```

底部播放器**常驻且跨 tab 不中断** —— 在编年史点「跳播」、在文稿里点时间码，
音频都会跳过去，文稿那边的高亮跟着走。控件照搬慧客堂：**−15 / ▶ / +30 三个图标按钮**
挨在一起，±秒在播放键左右；最左边是**这期节目在小宇宙上的封面图**
（走 CDN 缩略参数 `?imageMogr2/thumbnail/160x160`，18 KB，不是原图那 1.8 MB）。

### 4.1 文稿

- **左侧常驻大纲** 46 节按 Part 分组，播放时当前节高亮；窄屏收进「目录」全屏抽屉
- **正文占满大纲右边的整条列**（约 860px），不留空白栏
- **每段左边一个时间码**，`00:00:00` 定长格式，点一下跳播；播放时当前段整段高亮 +
  可跟随滚动（可关）
- **阅读设置**：字号三档（默认中）/ 黑体·宋体 / 时间码显隐，存 localStorage。
  4.9 万字是要坐下来读的量，宋体那一档不是装饰
- 正文按 Markdown 的语义渲染：15 个三级小标题、5 处无序表、4 处有序表都是真的
  `<h3>` `<ul>` `<ol>`，不是甩出来的纯文本
- 空格播放暂停，← → 前后跳

### 4.2 编年史 —— 这一页最花力气的地方

**没有直接贴 PPT 截图**，而是用数据重画了同一套视觉。原因：

1. PPT 是 960×540 位图，手机上那些 11 px 标注根本看不清
2. 图片是死的 —— 不能点、不能跳播、不能连到论文、搜不到
3. **它藏了信息**：等距排布把 2004→2012 那 8 年的空白、和 2014 年三篇论文挤在一个月里的密度，全抹平了

重画之后多出来的三件事：

- **可点**。点焊盘弹卡片 → 「读这一段」跳文稿章节 / 「▶ 跳播」跳音频那一秒 / 「原文 ↗」开论文。
  卡片**贴着被点的焊盘出现**：水平对齐焊盘中心，默认落在正下方 12px；下方装不下就自动翻到上方，
  永远不会被底部播放条盖住
- **两种排布**。「等距排布」还原 PPT；**「按真实年份」**换成真实时间刻度，
  四条轨道共用同一把尺子 —— 2014 和 2017 有多挤、2005–2011 有多空、
  多模态和语言模型两条线怎么在 2020 前后合流，一眼就看出来了。这是 PPT 给不了的
- **响应式换布局**。桌面横向走线、标签上下交错；窄屏转成竖向导轨、标签靠右。
  不是把大图缩小，是换一种画法

页面上不再提「看 PPT 原图」—— 重画的版本信息更全也更好用，把人引回一张看不清的位图没有意义。
PPT 完整版在页头「嘉宾 PPT ↗」和下载区里都拿得到。

### 4.3 资料

进 tab 第一眼是**下载区**，然后是一排锚点 chip，下面九块内容：

| 块 | 条数 | 说明 |
|---|---|---|
| 论文索引 | 36 | 点一行展开作者 / 机构 / 意义 |
| 人物索引 | 36 | **只有研究者**，按出现篇数排序，带机构、相关篇目、社交链接 |
| 视频教程 | 9 | 去掉了「状态」列 |
| 演讲 | 7 | 去掉了「Ian Buck 2009 GTC 分享」 |
| 访谈 | 5 | **已核到小宇宙单集链接与完整标题**（EP89 / 102 / 108 / 115 / 133），第三列从「备注」换成节目内容 |
| 书 / 文章 | 9 | 去掉了「扬·盖尔的城市规划论文和著作」 |
| 延伸论文 | 9 | 节目点名但没进 36 篇主线的 |
| 技术报告 | 8 | |
| 数据集 / 工具 | 8 | 去掉了 BooksCorpus、WebText —— 索引里明说没有可用镜像，列着也点不开 |

索引里那套「与 Shownotes 标注的核对结论」（⚠️ / ℹ️）**不在页面上出现**：
那是整理时的自查记录，读者不需要为几处月份差异分心，结论已经体现在页面给出的日期上。

**下载只有一个包，8.2 MB**：`精校稿.md` + `资料索引.md` + `AI演义-36篇论文.pdf`
+ `论文链接.txt`（构建期从索引生成，36 行原文地址，`wget -i` 一次全拉）。

论文 PDF 不打包 —— 服务器是 4 Mbps 上行，184 MB 的包一个人下 6 分钟就把全站拖垮，
而 36 篇的原文链接全都查证过，从 arXiv 官方站拉更快也更权威。资料区每篇也有「原文 ↗」。

文件名去掉了 `01-` `02-` 这类工作序号 —— 那是整理时的顺序，对下载的人没有意义。

## 5. 移动端

不是缩小，三处真的换了布局：

| | 桌面 | 窄屏 |
|---|---|---|
| 编年史 | 横向走线，标签上下交错 | **竖向导轨**，标签靠右 |
| 文稿大纲 | 左侧常驻侧栏 | **「目录」全屏抽屉** |
| 资料区 | 下载两栏 + 人物三列 | 单栏 |

播放器在窄屏让位给控件（封面缩小、时间码隐藏），用 `env(safe-area-inset-bottom)` 处理刘海屏。
编年史节点卡片在窄屏固定成贴底卡片。
阅读设置条在窄屏隐藏文字标签只留控件。标签条可横向滑动。

## 6. 文件

```
design/
├── index.html      列表页
├── episode.html    详情页（EP117）
├── app.css         设计系统 + 全部组件（三个断点）
├── app.js          交互：文稿渲染与同步、编年史 SVG 生成、播放器、tab
├── data.js         真实数据（195 KB，由 extract.py 生成，勿手改）
├── extract.py      抽取脚本：00_论文探索之旅/ → data.js
└── pick.html       Logo × 6 与 Slogan × 6 候选（已定 L1 + S1，留着备查）
```

`app.js` 里的编年史生成器 `trackSVG()` 可以直接搬进正式工程 ——
输入 `chronicle.json`、输出 SVG 字符串，纯函数，无依赖。

原型的播放器会真的去拉小宇宙的音频；如果本地网络拉不到，它会自动降级成模拟走时，
这样文稿高亮跟随的效果照样能看（播放器上会显示「音频源未直连，演示为模拟走时」）。
