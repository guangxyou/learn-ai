会算，但说不清为什么

作者举的几类「会算不懂」：矩阵乘法为什么是这样定义的，叉积为什么和行列式有关，特征值究竟代表什么。学生往往把矩阵的数值运算练得很熟，对背后的几何直觉只有模糊印象。

画面里想着行列式公式的 π 小人写的是 ac − bc，B 站译者加了一行注：应为 ad − bc。正确公式在第 6 章会讲到。

数值理解和几何理解各管一半

作者把理解分成两层：几何理解让你判断该用什么工具、感受它为什么有效、知道怎么解读结果；数值理解让你把这个工具算出来。两者都需要，但如果只有数值那一半，问题会潜伏一段时间，等你深入到计算机、工程、统计、经济这些领域才暴露出来。

到了默认你熟悉线性代数的课堂或工作里，老师和同事能很快看出该用哪个工具、答案大概长什么样。如果你以为他们在脑子里算完了所有数字，就会觉得那是魔法。

类比：只学过泰勒级数的正弦

设想你第一次学正弦函数时，看到的是这个无穷多项式：sin(x) = x − x³/3! + x⁵/5! − …。计算器就是这样算 sin 的。作业是代入不同的数、截断到某一项，练习近似计算。你隐约知道它和三角形有关，但具体怎么关联从来没讲清楚。

之后去上物理课，别人把 sin 和 cos 用得飞快，一眼就能看出某个值的正负。你会觉得只有脑子像计算机的人才适合学物理。作者说线性代数的情况差不多；好在和三角函数一样，线性代数背后也只有少数几个视觉直觉，而且它们和计算之间的联系比泰勒级数和三角形之间直接得多。

B 站 P2：01 - 向量究竟是什么？ ↗ YouTube 第 1 章 · 2016-08-06 ↗

三种看法

作者把关于向量的看法分成三种。物理专业的看法：向量是空间中的箭头，由长度和方向决定，只要这两样不变，箭头挪到哪里都是同一个向量；在平面上是二维，在我们生活的空间里是三维。

计算机专业的看法：向量是有序的数字列表。比如分析房价时只关心面积和价格，每套房子就可以用一对数来表示，第一个数是面积，第二个是价格，顺序不能换。这里「向量」基本就是「列表」的另一个叫法，列表长度是 2，就叫二维向量。

数学家的看法是把这两者都概括进去：只要有合理的「两个向量相加」和「向量乘一个数」，任何东西都可以叫向量。这种看法很抽象，作者建议先放着，等到最后一集（第 16 章，抽象向量空间）再谈。现在提它，是因为它暗示了一点：加法和数乘这两种运算会贯穿整个线性代数。

本系列的约定：起点在原点的箭头

一说到向量，先想一个箭头，而且是放在坐标系里、起点在原点的箭头。这和物理视角不太一样：物理里向量可以在空间里随便放，线性代数里向量几乎总是从原点出发。先在箭头的图像里理解一个新概念，再通过坐标翻译成数字列表的说法。

二维坐标系：水平的 x 轴、竖直的 y 轴，交点是原点，把它当作空间的中心和所有向量的根。任选一段长度当作 1，在两根轴上打刻度。想表达「整个二维空间」时，作者会把刻度延长成网格线。

坐标是一组走路的指令

向量的坐标是一对数，告诉你怎么从原点（箭头起点）走到箭头终点。第一个数表示沿 x 轴走多远，正数往右、负数往左；第二个数表示接着平行于 y 轴走多远，正数往上、负数往下。

为了和「点」区分，习惯上把这对数竖着写、外面加方括号，比如 −23。每一对数恰好对应一个向量，每个向量也恰好对应一对数。

三维再加一根同时垂直于 x、y 轴的 z 轴，每个向量对应一个有序三元组：前两个数和二维一样，第三个数表示再平行于 z 轴走多远。三元组和三维向量同样一一对应。

向量加法：首尾相接

线性代数的每个话题都围绕加法和数乘这两种运算。两个向量相加：把第二个向量平移，让它的起点落在第一个向量的终点，再从第一个向量的起点画到第二个向量的终点，这个新向量就是和。这几乎是线性代数里唯一允许向量离开原点的时候。

这样定义的理由：把每个向量看成一次移动，一步有确定的距离和方向。先沿第一个向量走一步，再沿第二个向量走一步，总效果和直接沿它们的和走一步一样。这是数轴上加法的推广：2 + 5 就是先往右走 2 步，再往右走 5 步，等于往右走 7 步。

数值上，12 加 3−1：首尾相接的路径可以拆成四步，右 1、上 2、右 3、下 1。把水平的步子放一起、竖直的放一起，就是右 1 + 3、上 2 − 1，和为 41。一般地，向量相加就是对应分量相加。

数乘：缩放

另一种基本运算是向量乘一个数。乘 2 就是把向量拉长到原来的 2 倍；乘 1/3 就是压缩到原来的 1/3；乘负数，比如 −1.8，先把向量反向，再拉长 1.8 倍。

这种拉伸、压缩、有时反向的过程叫缩放 (Scaling)，起这种作用的数（2、1/3、−1.8）叫标量 (Scalar)。线性代数里数的主要用途就是缩放向量，所以「标量」和「数」经常混着用。

数值上，向量乘以 2 就是每个分量都乘以 2。

箭头和数字之间来回翻译

把向量当成「恰好有方便数值表示的箭头」，还是「恰好有直观几何解释的数字列表」，无所谓。线性代数的价值在于能在这两种看法之间来回翻译。

对数据分析的人，它提供了把大量数字列表可视化的办法，能看清数据里的模式，也能看出某些运算整体上在做什么。反过来，对物理学家和图形程序员，它提供了一种用数字描述空间和空间变换的语言，可以交给计算机算。作者做数学动画时就是这样：先想清楚空间里发生了什么，再让计算机用数字表示，决定每个像素放在哪。

这一集记住这几条

  • 本系列里的向量默认是起点在原点的箭头，坐标是从原点走到终点的指令。
  • 向量加法是首尾相接，数值上对应分量相加。
  • 数乘是缩放，起缩放作用的数叫标量，数值上每个分量乘同一个数。
  • 线性代数的全部话题都围绕加法和数乘这两种运算。

B 站 P3：02 - 线性组合、张成的空间与基 ↗ YouTube 第 2 章 · 2016-08-07 ↗

坐标是两个标量

看到一对描述向量的数，比如 3−2，把每个数看成一个标量，也就是想它会怎样拉伸或压缩向量。

xy 坐标系里有两个特殊向量：指向右、长度为 1 的 î（读作 i-hat，x 方向的单位向量），指向上、长度为 1 的 ĵ（j-hat，y 方向的单位向量）。

x 坐标 3 是把 î 拉长 3 倍的标量，y 坐标 −2 是把 ĵ 反向并拉长 2 倍的标量。这对坐标描述的向量，就是这两个缩放后的向量之和：3î + (−2)ĵ。

î 和 ĵ 合起来叫这个坐标系的基 (Basis)。意思是：把坐标看成标量时，基向量就是这些标量缩放的对象。严格定义留到本集最后。

换一组基也可以

用基向量来描述坐标系，会带出一个微妙的点：完全可以选另一组基向量，得到一个同样合理的新坐标系。比如取一个指向右上的向量和一个指向右下的向量，用两个标量分别缩放再相加，能到达全部二维向量。

这组新基同样能在「一对数」和「二维向量」之间来回翻译，只是对应关系和标准的 î、ĵ 不同。所以每次用数字描述向量，背后都隐含了一个「用的是哪组基」的选择。不同坐标系之间的精确换算在第 13 章（基变换）讲。

思考题为什么这两个向量缩放再相加，能到达平面上的每一个向量？

只要两个向量不共线，就可以把平面铺成以它们为边的平行四边形网格：先沿第一个向量的方向走到目标所在的那条网格线（平行于第二个向量），再沿第二个向量的方向走到目标。两个方向各走多远，就是两个标量。共线的时候这一步做不到，因为两个方向是同一个方向。

线性组合与张成的空间

缩放两个向量再相加，叫这两个向量的线性组合 (Linear Combination)，写成 av + bw。「线性」这个词的一个理解方式（作者说明这不是词源）：固定其中一个标量，让另一个自由变化，结果向量的终点画出的是一条直线。

两个标量都自由变化时，有三种情况：大多数向量对能到达平面上的每一个点；两个向量恰好共线时，结果只能落在过原点的那条直线上；两个都是零向量时，只能停在原点。

给定一对向量，它们所有线性组合能到达的向量的集合，叫这两个向量张成的空间 (Span)。大多数二维向量对张成整个平面，共线的一对只张成一条直线。换句话说，span 问的是：只用加法和数乘这两种基本运算，能到达哪些向量。

单个向量想成箭头，一堆向量想成点

一条线上的所有向量、或者铺满平面的所有向量，全画成箭头会挤成一团。所以处理一批向量时，习惯只画每个向量的终点（起点仍然在原点）。这样「终点在某条直线上的所有向量」就直接想成那条直线，「所有二维向量」就想成整张无限大的平面。

经验规则：单独一个向量，想成箭头；一批向量，想成点。

三维里的张成

三维空间里取两个方向不同的向量，看它们张成什么：想象两个旋钮分别调两个标量，跟着结果向量的终点走，终点会扫出一张过原点的平面。这张平面上所有向量的集合，就是这两个向量张成的空间。

再加第三个向量。三个向量的线性组合同样是选三个标量、分别缩放、再相加。可能出现两种情况：第三个向量正好落在前两个张成的平面上，那么张成的空间不变，加进来的第三项带不来任何新向量；随便取一个第三向量，它几乎不可能落在那张平面上，于是它指向一个新方向，三个向量能到达所有三维向量。

作者给了两个画面：缩放第三个向量时，它带着前两个张成的那张平面来回移动，把平面扫过整个空间；或者说，你充分用上了三个可以自由变化的标量，去覆盖空间的三个维度。

线性相关与线性无关

第三个向量落在前两个的张成平面上，或者两个向量共线，这时至少有一个向量是多余的，对张成的空间没有贡献。只要一组向量里能去掉一个而不缩小张成的空间，就说它们线性相关 (Linearly Dependent)。另一种说法：其中某个向量可以写成其他向量的线性组合，因为它本来就在其他向量张成的空间里。

反过来，如果每个向量都给张成的空间增加了一个维度，就说它们线性无关 (Linearly Independent)。

基的严格定义

空间的一组基，是张成该空间的一个线性无关向量集。作者留的问题是：结合本集开头「基是坐标所缩放的对象」这个说法，以及你对「张成」「线性无关」的理解，想想这个定义为什么说得通。

思考题为什么「张成整个空间」加「线性无关」恰好是基该满足的条件？

基的用途是给每个向量分配坐标。「张成整个空间」保证每个向量都能写成基向量的线性组合，也就是坐标一定存在；「线性无关」保证没有多余的基向量，于是写法只有一种，坐标是唯一的。如果线性相关，某个基向量可以用别的基向量表示，同一个向量就会有不止一组坐标。

这一集记住这几条

  • 坐标是标量，缩放的是基向量；3−2 = 3î + (−2)ĵ。
  • 缩放再相加叫线性组合；所有线性组合的集合叫张成的空间。
  • 能去掉一个向量而不缩小张成的空间，就是线性相关；每个向量都贡献一个新维度，就是线性无关。
  • 基 = 张成整个空间的线性无关向量组；用哪组基决定了一个向量的坐标是什么。

变换 = 函数，用运动来想

「变换」就是函数的另一个叫法：接收输入，给出输出。在线性代数里，关心的是输入一个向量、输出另一个向量的变换。之所以叫变换而不叫函数，是为了暗示一种可视化方式：用运动。输入向量「移动」到输出向量的位置；要理解整个变换，就想象每一个输入向量都移动到对应的输出。

每个向量都画成箭头太挤，按上一集的办法把每个向量想成它终点那个点，于是变换就是空间里每个点移动到另一个点。二维的情况，作者用一整张无限网格上的点来演示，背景里再留一份原网格，方便对照每个点从哪来、到哪去。

什么叫「线性」

任意的变换可以很复杂，线性代数只研究一类好理解的：线性变换 (Linear Transformation)。从视觉上看，一个变换是线性的，要满足两条：所有直线变换后仍然是直线，不能弯曲；原点必须保持不动。

三个反例：把直线弄弯的不是线性变换；直线保持直的，但原点被挪走了，也不是；原点不动、横竖网格线看上去也还是直的，但看一条对角线就会发现它被弯成了曲线，同样不是。

一般来说，可以把线性变换理解为「保持网格线平行且等距分布」的变换。有些很好描述，比如绕原点旋转；有些很难用语言说清。

只要记住 î 和 ĵ 落在哪

如果要写程序做这种动画，给计算机什么公式，它才能根据一个向量的坐标算出变换后的坐标？答案是：只需要记录两个基向量 î 和 ĵ 各自落在哪，其余一切都跟着确定。

例子：v = −12，也就是 v = −1î + 2ĵ。播放某个变换，跟踪这三个向量。「网格线保持平行且等距」有一个重要推论：v 的落点等于 −1 乘 î 的落点，加上 2 乘 ĵ 的落点。变换前 v 是 î、ĵ 的某个线性组合，变换后它就是 î、ĵ 落点的同一个线性组合。

图中的变换把 î 送到 1−2，把 ĵ 送到 x 轴上的 30，所以 v 落在 −1·1−2 + 2·30 = 52。作者特意提醒这里值得暂停：关键在于不用看变换动画，只凭 î、ĵ 的落点就能推出任何向量的去向。

写成一般的 (x, y)：它落在 x·1−2 + y·30 = 1x+3y−2x+0y。所以一个二维线性变换完全由四个数决定：î 落点的两个坐标和 ĵ 落点的两个坐标。

矩阵：把两个落点排成两列

习惯上把这四个数排成一个 2×2 的数字网格，叫 2×2 矩阵 (Matrix)，两列分别是 î 和 ĵ 的落点。给定一个矩阵和一个向量，想知道变换后向量在哪：把向量的两个坐标分别乘矩阵的两列，再相加。这就是「把缩放后的新基向量加起来」。

一般情形，矩阵是 abcd。第一列 (a, c) 是第一个基向量的落点，第二列 (b, d) 是第二个基向量的落点。作用在 (x, y) 上：x·ac + y·bd = ax+bycx+dy。

把矩阵写在向量左边、像函数一样，这就是矩阵向量乘法的定义。你当然可以让学生背下这个公式，但作者认为更有意思的是把两列看成变换后的基向量，把结果看成这两个向量的线性组合。

几个例子

逆时针旋转 90°：î 落在 (0, 1)，ĵ 落在 (−1, 0)，所以矩阵是 0−110。想知道任何向量旋转 90° 后在哪，乘这个矩阵就行。

剪切 (Shear)：î 不动，第一列是 (1, 0)；ĵ 移到 (1, 1)，第二列是 (1, 1)，矩阵是 1101。

反过来，从矩阵想象变换。矩阵两列是 (1, 2) 和 (3, 1)：先把 î 移到 (1, 2)，再把 ĵ 移到 (3, 1)，其余空间跟着动，始终保持网格线平行等距。

如果 î、ĵ 的落点线性相关（一个是另一个的倍数），这个变换就把整个平面压到这两个向量所在的直线上，也就是它们张成的那条一维直线。第 6 章的行列式为零、第 7 章的秩为 1 说的都是这种情况。

每个矩阵都是一种空间变换

总结：线性变换是保持网格线平行等距、原点不动的空间运动。它只需要少数几个数来描述，就是每个基向量落点的坐标。矩阵是描述这些变换的语言，每一列是一个落点；矩阵向量乘法只是计算这个变换对某个向量做了什么。

最重要的一句：每当你看到一个矩阵，都可以把它解读为对空间的某种变换。后面的矩阵乘法、行列式、基变换、特征值，都建立在这个观点上。

回顾

线性变换是以向量为输入、向量为输出的函数，视觉上是让网格线保持平行等距、原点不动的空间挤压。它完全由基向量的落点决定，二维就是 î 和 ĵ：(x, y) = xî + yĵ 变换后落在 x 乘变换后的 î 加 y 乘变换后的 ĵ。把两个落点记成矩阵的两列，这种「按 x、y 缩放两列再相加」就定义为矩阵向量乘法。

复合变换：先旋转，再剪切

常常要描述「先做一个变换，再做另一个」的总效果。比如先把平面逆时针旋转 90°，再做一次剪切。从头到尾的总效果是另一个线性变换，和旋转、剪切都不同，叫这两个变换的复合 (Composition)。

它同样可以用一个矩阵描述，办法还是跟踪 î 和 ĵ。这个例子里，î 经过两次变换最终落在 (1, 1)，作为第一列；ĵ 最终落在 (−1, 0)，作为第二列。这个新矩阵把「先旋转后剪切」捕捉成了一个动作。

为什么叫「乘积」，为什么从右往左读

把一个向量先过旋转、再过剪切，笨办法是：先左乘旋转矩阵，再把结果左乘剪切矩阵。无论选哪个向量，结果都应该和直接左乘那个复合矩阵一样，因为它们描述的是同一个总效果。照这个写法，把复合矩阵叫作两个原矩阵的乘积很自然：剪切矩阵 × 旋转矩阵 = 复合矩阵。

一定要记住：两个矩阵相乘的几何意义，是先做一个变换，再做另一个。写法上有点别扭的是要从右往左读：先做右边矩阵代表的变换，再做左边的。这来自函数记号，函数写在变量左边，f(g(x)) 是先 g 后 f。

只用数字求复合矩阵

换个例子，这次不看动画，只用矩阵里的数。M₁ 的两列是 (1, 1) 和 (−2, 0)，M₂ 的两列是 (0, 1) 和 (2, 0)。求「先 M₁ 后 M₂」的矩阵，也就是 M₂M₁。

先看 î 去哪。做完 M₁，î 的新坐标按定义就是 M₁ 的第一列 (1, 1)。再做 M₂，就是用 M₂ 乘 (1, 1)：1·(0, 1) + 1·(2, 0) = (2, 1)，这就是复合矩阵的第一列。

同理跟踪 ĵ：M₁ 的第二列说明它先落在 (−2, 0)；再用 M₂ 乘它，得到 (0, −2)，这是复合矩阵的第二列。所以 M₂M₁ = 201−2。

一般公式

换成字母，推理完全一样。设 M₂ = abcd、M₁ = efgh。î 先落在右边矩阵的第一列 (e, g)，再用左边矩阵乘它，得到 e(a, c) + g(b, d) = (ae+bg, ce+dg)，所以复合矩阵的第一列永远等于左矩阵乘右矩阵的第一列。

同理，ĵ 先落在右矩阵第二列 (f, h)，左矩阵乘它得到 (af+bh, cf+dh)，就是复合矩阵的第二列。

通常这个公式是当作要背的东西教的，还配一套记忆口诀。作者建议在背之前，先养成习惯去想矩阵乘法代表什么：依次施加两个变换。这样矩阵乘法的各种性质都更容易理解。

顺序有关系：不满足交换律

两个矩阵相乘时，谁在左谁在右有没有影响，拿剪切（î 不动、ĵ 推到右边）和 90° 旋转来想：

先剪切再旋转，î 最后在 (0, 1)，ĵ 在 (−1, 1)，两个基向量挨得很近。先旋转再剪切，î 在 (1, 1)，ĵ 在 (−1, 0)，两个方向离得远。总效果明显不同，所以顺序有关系，AB ≠ BA。这种事在脑子里想象一下就能判断，不用算矩阵乘法。

结合律：没什么要证明的

作者回忆第一次学线性代数时，有道作业题要证明矩阵乘法满足结合律：三个矩阵 A、B、C 相乘，先算 AB 再乘 C，和先算 BC 再左乘 A，结果一样，括号放哪都行。用数字硬推很痛苦，也看不出道理。

从变换复合的角度看，这件事几乎是显然的：(AB)C 和 A(BC) 说的都是先做 C、再做 B、再做 A。同样三个变换、同样的顺序依次作用，没有什么需要证明的。作者强调这是一个正经的证明，而且比数值推导更能解释为什么这条性质成立。

最后的建议：多想象两个不同变换依次作用会怎样，再把矩阵乘积用数字算出来对照。

这一集记住这几条

  • M₂M₁ 表示先做 M₁ 再做 M₂，从右往左读。
  • 复合矩阵的第 k 列 = 左矩阵 × 右矩阵的第 k 列，因为那就是第 k 个基向量先后经过两个变换的落点。
  • 矩阵乘法一般不满足交换律：先剪切再旋转，和先旋转再剪切，结果不同。
  • 矩阵乘法满足结合律：(AB)C 和 A(BC) 都是先 C、再 B、再 A。

三维线性变换

考虑输入、输出都是三维向量的线性变换。可视化方式和二维一样：用网格代表三维空间里的所有点，让它们移动，同时保持网格线平行等距、原点不动。看到的每个点，仍然是「终点在那里的向量」的替身，要想的是输入向量移动到输出向量。

和二维一样，这种变换完全由基向量的去向描述。三维有三个标准基向量：x 方向的单位向量 î、y 方向的 ĵ，以及新来的 z 方向单位向量 k̂。整个三维网格画出来很乱，作者觉得只跟踪这三个基向量更容易看清变换，背景里保留一份原坐标轴，读出三个落点的坐标。

把三个落点的坐标记为一个 3×3 矩阵的三列，九个数就完整描述了这个变换。

例子：绕 y 轴旋转 90°

绕 y 轴把空间旋转 90°：î 被转到 z 轴上的 (0, 0, −1)；ĵ 在旋转轴上，不动，仍是 (0, 1, 0)；k̂ 被转到 x 轴上的 (1, 0, 0)。这三组坐标就是描述这次旋转的矩阵的三列：001010−100。

向量落在哪、两个矩阵相乘

一个坐标为 (x, y, z) 的向量落在哪，推理和二维几乎一样：三个坐标分别告诉你怎么缩放三个基向量、再加起来得到这个向量；关键是这个「缩放再相加」的关系在变换前后都成立。所以把三个坐标分别乘矩阵的对应列，再把三个结果相加。

矩阵乘法也一样：看到两个 3×3 矩阵相乘，想象先做右边那个矩阵编码的变换，再做左边那个。三维矩阵乘法在计算机图形学和机器人学里很重要：三维旋转很难直接描述，拆成几个更容易想的旋转的复合就好理解了。

行列式：面积的缩放倍数

有的线性变换把空间向外拉，有的往里压。理解一个变换时，一个很有用的量是它到底拉伸或压缩了多少，更具体地说，是给定区域的面积增大或减小的倍数。

例子：矩阵 3002 把 î 拉长 3 倍、ĵ 拉长 2 倍。看底边在 î 上、左边在 ĵ 上的 1×1 正方形，变换后它成了 3×2 的长方形，面积从 1 变成 6，所以这个变换把面积放大了 6 倍。

对比剪切 1101：î 不动，ĵ 移到 (1, 1)。同一个单位正方形被斜推成平行四边形，但底和高还是 1，面积仍然是 1。这个变换虽然把东西推歪了，面积却没变。

一个正方形就够了

只要知道那一个单位正方形的面积变了多少，就能知道任意区域的面积怎么变。第一，网格里任何一个方格，不管大小，遭遇和单位正方形一样，这是网格线保持平行等距的直接结果。第二，任何不是方格的形状都能用方格很好地近似，方格取得越小越准。所有小方格的面积都乘上同一个倍数，整块形状的面积也就乘上这个倍数。

这个特殊的倍数，即线性变换改变任意区域面积的比例，叫这个变换的行列式。作者强调理解它代表什么比会算重要得多。例子：行列式为 3，面积放大 3 倍；为 1/2，面积缩小一半。

行列式为零：压到更低维

二维变换的行列式为 0，意味着它把整个平面压到一条线上，甚至一个点上，此时任何区域的面积都变成 0。这个例子后面会很重要：检查一个矩阵的行列式是否为 0，就能判断它代表的变换是否把空间压到了更低的维度。下一集的逆矩阵、列空间都会用到这一点。

负的行列式：定向翻转

前面说的不完全对：行列式可以是负数。面积缩放负数倍，和定向 (Orientation) 有关。有的变换给人一种把空间翻过来的感觉：把二维平面想成一张纸，这个变换像是把纸翻到了背面。这样的变换叫作改变了空间的定向。

另一种判断方式看 î 和 ĵ：一开始 ĵ 在 î 的左边（逆时针方向）。变换后如果 ĵ 跑到了 î 的右边，定向就翻转了。

只要定向翻转，行列式就是负的；它的绝对值仍然是面积的缩放倍数。例：两列为 (1, 1) 和 (2, −1) 的矩阵，行列式是 −3，意思是空间翻了面，面积放大 3 倍。

用负数描述翻面是自然的，可以这样看：让 î 慢慢向 ĵ 靠拢的一系列变换。î 越靠近，空间被压得越扁，行列式越接近 0；两者完全重合时，行列式为 0；î 继续沿原方向走下去，行列式接着减小变成负数，就很顺理成章了。

三维：体积的缩放倍数

三维里，行列式告诉你体积被缩放了多少。和二维只看单位正方形一样，三维只看棱落在 î、ĵ、k̂ 上的 1×1×1 单位立方体。变换后它会被扭成一个斜斜的立方体，这种形状叫平行六面体 (Parallelepiped)。单位立方体体积是 1，行列式是体积缩放倍数，所以行列式就是这个平行六面体的体积。

行列式为 0，说明整个空间被压成体积为零的东西：一个平面、一条直线，或者极端情况下一个点。看过第 2 章的人会认出来，这意味着矩阵的各列线性相关。

思考题为什么三维行列式为 0 就说明矩阵的列线性相关？

三列是 î、ĵ、k̂ 的落点。行列式为 0 说明整个空间被压进了一个平面（或更低维），那么这三个落点也都在这个平面里。三个向量挤在一个平面内，至少有一个可以由另外两个线性组合出来，也就是线性相关。反过来也成立：列线性相关，三个落点张不满空间，单位立方体被压扁，体积为 0。

三维的定向：右手定则

三维的定向用右手定则描述：右手食指指向 î，中指指向 ĵ，这时竖起的大拇指正好指向 k̂。变换后如果还能这样用右手比出来，定向没变，行列式为正；如果变换后只能用左手比，定向翻转了，行列式为负。

怎么算：ad − bc

对 2×2 矩阵 abcd，公式是 ad − bc。一部分直觉：如果 b 和 c 都是 0，a 表示 î 在 x 方向拉伸了多少，d 表示 ĵ 在 y 方向拉伸了多少，单位正方形变成 a × d 的长方形，面积就是 ad。

b、c 中只有一个为 0 时，得到底为 a、高为 d 的平行四边形，面积还是 ad。粗略地说，b、c 都不为 0 时，bc 项表示这个平行四边形在对角方向被拉伸或压缩了多少。

想要精确理解 bc 项的，作者给了一张图可以暂停琢磨：把平行四边形放进一个 (a+b) × (c+d) 的大长方形里，大长方形面积减去四个角上的三角形和两个小长方形，(a+b)(c+d) − ac − bd − 2bc = ad − bc。

如果需要手算行列式，唯一的办法是多练几道。三阶行列式同样有公式，需要的话多练几个矩阵，或者去看 Sal Khan 的演示。作者认为这些计算不属于线性代数的本质，理解行列式代表什么才属于。

思考题

两个矩阵相乘，乘积的行列式等于两个矩阵行列式的乘积。用数字来证要写很久，试着用一句话解释为什么。

思考题为什么 det(M₁M₂) = det(M₁)det(M₂)？

M₁M₂ 是先做 M₂ 再做 M₁：先把面积缩放 det(M₂) 倍，再把得到的面积缩放 det(M₁) 倍，总共缩放两者乘积那么多倍。定向也一样，翻两次等于没翻，负负得正。

这一集记住这几条

  • 行列式 = 线性变换对面积（三维是体积）的缩放倍数，看单位正方形（单位立方体）变成了多大。
  • 行列式为负：定向翻转（二维里 ĵ 跑到 î 右边，三维里右手定则失效）；绝对值仍是缩放倍数。
  • 行列式为 0：空间被压到更低维，矩阵的列线性相关。
  • detabcd = ad − bc；det(M₁M₂) = det(M₁)det(M₂)。

线性方程组长什么样

「线性」方程组是一类很特殊的方程组：每个方程里，每个未知数只被一个常数缩放，缩放后的各项只做加法。没有指数，没有 sin 这类函数，也没有两个未知数相乘。整理时把未知数都放在等号左边、常数放在右边，同一个未知数上下对齐，某个方程里缺了哪个未知数就补一个系数 0。

这样排好之后，左边整体就是一个矩阵乘一个向量：系数排成矩阵 A，未知数排成向量 x，右边的常数是向量 v，整组方程写成一行 Ax = v。

几何图像：哪个向量会落在 v 上

A 代表一个线性变换，所以解 Ax = v 就是在找一个向量 x，它经过这个变换后恰好落在 v 上。多个未知数相互纠缠的代数问题，变成了一个可以想象的空间问题：空间被挤压、拉伸，盯住最后落在 v 上的那个向量。

先看两个方程两个未知数的情况，A 是 2×2 矩阵。答案取决于 A 有没有把平面压到更低的维度（一条线或一个点），用上一集的话说，就是 A 的行列式是不是 0。

行列式不为零：把变换倒放回去

随手取一个矩阵，行列式几乎总不为零，这是最常见的情况。平面没有被压扁，恰好有且只有一个向量落在 v 上。找它的办法是把变换倒着播放，跟着 v 往回走，停下的位置就是 x。

「倒放」本身也是一个线性变换，叫 A 的逆 (Inverse)，记作 A⁻¹。例子：A 是逆时针旋转 90°，A⁻¹ 就是顺时针旋转 90°；A 是把 ĵ 往右推一格的剪切，A⁻¹ 就是把 ĵ 往左推一格的剪切。

A⁻¹ 的定义性质是：先做 A 再做 A⁻¹，等于什么都没做。「先做一个再做一个」在代数上是矩阵乘法，「什么都不做」的变换叫恒等变换 (Identity Transformation)，它不动 î 和 ĵ，矩阵是 1001，所以 A⁻¹A = I。有了 A⁻¹，两边左乘它就得到 x = A⁻¹v。实际中求逆交给计算机。

方程数等于未知数个数时，高维也一样：只要变换不把空间压到更低维（行列式不为零），就有逆变换，解唯一，x = A⁻¹v。

行列式为零：没有逆，但可能有解

行列式为零时，变换把空间压到了更低维，这时没有逆变换。道理很直接：你没法把一条线「解压」回一个平面。要做到这一点，函数得把一个输入变成一整条线的输出，而函数只能一个输入对应一个输出。三维里也一样，压成平面、压成直线、压成一个点，体积都变成 0，都没有逆。

没有逆不等于没有解。平面被压成一条直线时，如果 v 恰好在这条线上，解就存在（而且不止一个）；v 不在线上就无解。

同样是行列式为零，情况的严重程度不一样。3×3 矩阵把空间压成平面时，v 落在那个平面上的机会还算大；压成一条直线时就苛刻得多。只说「行列式为零」区分不了这两种，需要更细的词。

秩与列空间

秩 (Rank) 就是变换后输出空间的维数。输出是一条线，秩为 1；输出是一个平面，秩为 2。对 2×2 矩阵，秩 2 已经是最高，说明基向量变换后仍然张成整个平面，行列式不为零。对 3×3 矩阵，秩 2 说明空间塌缩了，但没有塌到秩 1 那么狠；秩 3 就是行列式不为零、输出铺满三维空间。

所有可能的输出 Av 组成的集合，不管它是直线、平面还是整个三维空间，叫 A 的列空间 (Column Space)。名字的来历：矩阵的列告诉你基向量落在哪，这些落点的张成空间就是所有可能的输出。所以列空间就是矩阵各列张成的空间，秩更精确的定义是列空间的维数。

秩达到最大值（等于列数）时，叫满秩 (Full Rank)。

零空间：被压到原点的那些向量

线性变换必须保持原点不动，所以零向量一定在列空间里。满秩时，只有零向量自己会落到原点。不满秩时，会有一大批向量被压到原点：

2D 变换把平面压成一条线时，另有一条不同方向的直线整条落在原点；3D 变换把空间压成平面时，有一整条直线落在原点；3D 变换把空间压成直线时，有一整个平面落在原点。

这些落到原点的向量的集合叫零空间 (Null Space)，也叫核 (Kernel)，意思是这些向量都「变成了零」。放回方程组里看：当 v 恰好是零向量时，Ax = 0 的全部解就是零空间。

标准讲法：坐标相乘相加，几何上是投影

数值上，两个维数相同的向量做点积：把对应坐标配对相乘，再把结果相加。例：(1, 2)·(3, 4) = 1×3 + 2×4；(6, 2, 8, 3)·(1, 8, 5, 3) = 6×1 + 2×8 + 8×5 + 3×3。

几何解释：求 v·w，把 w 投影到过原点和 v 终点的那条直线上，用投影的长度乘以 v 的长度。投影方向和 v 相反时，点积是负的。所以两个向量大致同向时点积为正；垂直时（一个在另一个上的投影是零向量）点积为零；大致反向时为负。

B 站译者在这里加了注：视频里的投影指的是正交投影。

为什么顺序无关

这个几何解释很不对称，两个向量的地位完全不同。作者第一次学时很惊讶顺序居然无关：也可以把 v 投影到 w 上，用投影长度乘 w 的长度，结果一样。

直觉是这样的。如果 v 和 w 恰好一样长，可以用对称性：把 w 投影到 v 上再乘 v 的长度，和把 v 投影到 w 上再乘 w 的长度，是彼此的镜像。

现在把其中一个缩放，比如 v 乘 2，两者不再等长，对称被破坏。但看 2v·w 怎么变：如果把 w 投影到 v 上，投影长度不变，被投影到的向量长度翻倍，点积翻倍；如果把 v 投影到 w 上，被翻倍的是投影长度，w 的长度不变，点积同样翻倍。两种看法下，缩放对点积的影响一样，所以顺序无关。

到数轴的线性变换

还有一个更大的疑问：配对坐标、相乘、相加，这个数值过程为什么会和投影有关，要回答这个问题，得先讲从多维到一维（数轴）的线性变换。

这类函数接收二维向量、吐出一个数，而线性变换比一般的「二维进、一维出」函数受限得多。作者故意不讲形式化的定义，只用一个等价的视觉性质：一排等距的点，经过线性变换落到数轴上仍然等距；如果某排点变得不等距，这个变换就不是线性的。

和以前一样，这种变换完全由 î、ĵ 的去向决定。只是这次每个基向量都落在一个数上，记成矩阵的列，每列只有一个数，是个 1×2 矩阵。

例子：变换把 î 送到 1，把 ĵ 送到 −2。向量 (4, 3) = 4î + 3ĵ，由线性可知它落在 4 × 1 + 3 × (−2) = −2。纯数值地算，这就是矩阵向量乘法 1−243。

1×2 矩阵看起来就是躺倒的向量

1×2 矩阵乘一个向量，和两个向量做点积完全一样：那个 1×2 矩阵看起来就是一个放倒的向量。于是 1×2 矩阵和二维向量之间有一个很自然的对应：把向量的数字放倒就得到对应的矩阵，把矩阵立起来就得到对应的向量。

只看数字的话，这种来回翻转像是无聊的把戏。但它在几何上暗示了一件很棒的事：把向量变成数的线性变换，和向量本身之间有某种联系。

关键例子：投影到斜放的数轴上

先忘掉「点积和投影有关」这件事。把一条数轴斜着放进平面，0 放在原点。数轴上 1 那个位置对应一个二维单位向量，叫它 û。

把二维向量直接投影到这条斜数轴上，就定义了一个从二维向量到数的函数。而且它是线性的：任何一排等距的点投影到数轴上仍然等距。要注意：虽然数轴画在平面里，函数的输出是数，不是二维向量；û 是输入空间里的二维向量，只是位置恰好和数轴重叠。

既然是二维到数轴的线性变换，就一定有一个 1×2 矩阵描述它。它的两列是 î、ĵ 投影后落在的数。这里用到一个对称性：î 和 û 都是单位向量，所以把 î 投影到 û 所在的直线上，和把 û 投影到 x 轴上，是完全对称的。

后者就是 û 的 x 坐标。所以 î 落在的数就是 uₓ。同理，ĵ 落在的数是 û 的 y 坐标 uy。

于是这个投影变换的 1×2 矩阵就是 uₓuy。对任意向量做这个投影，就是用这个矩阵乘它，而这在计算上和与 û 做点积一模一样。这就解释了为什么和单位向量做点积，可以理解为把向量投影到这个单位向量所在的直线上、取投影长度。

非单位向量，以及对偶性

再看非单位向量：把 û 放大 3 倍，每个分量乘 3，对应的矩阵把 î、ĵ 送到原来 3 倍的位置。由线性，新矩阵的意思是：先投影到那条数轴上，再把结果乘 3。所以和一个非单位向量做点积，就是先投影到这个向量上，再乘以这个向量的长度。

回头看发生了什么：有一个从二维空间到数轴的线性变换，它不是用数值向量或点积定义的，只是把空间投影到一条斜数轴上。但因为它是线性的，就必然由某个 1×2 矩阵描述；而 1×2 矩阵乘二维向量，等于把矩阵立起来做点积，所以这个变换不可避免地和某个二维向量联系在一起。

一般结论：任何输出空间是数轴的线性变换，不管怎么定义的，都唯一对应一个向量 v，做这个变换就等于和 v 做点积。这是数学里所谓对偶性 (Duality) 的一个例子。

对偶性在数学里以各种形式出现，很难精确定义，粗略地说，指两类数学对象之间自然而又出人意料的对应。在这里：一个向量的对偶是它所编码的线性变换，一个到一维的线性变换的对偶是空间中的某个向量。

两层理解

表层：点积是理解投影、判断两个向量是否大致同向的几何工具，这是关于点积最该记住的。深一层：把两个向量点乘，是把其中一个翻译成变换的世界。

作者认为这件事之所以重要，是因为在数学里，当你熟悉一个向量的「脾气」，有时会发现把它理解为某个线性变换的实体化比理解为空间里的箭头更容易。向量像是某个变换的简写，因为想象一根箭头比想象整个空间被压到数轴上容易。

二维：平行四边形的有向面积

先从二维开始。两个向量 v、w，想它们张出的平行四边形：把 w 的副本起点挪到 v 的终点，把 v 的副本起点挪到 w 的终点，四个向量围成一个平行四边形。

v × w（用 × 形的乘号）就是这个平行四边形的面积，只是还要考虑定向：v 在 w 右侧时，v × w 为正，等于面积；v 在 w 左侧时，叉积为负，等于面积的相反数。所以顺序有关，w × v = −(v × w)。

作者记顺序的办法：两个基向量按顺序叉乘，î × ĵ 应该是正的。基向量的顺序本来就定义了定向，î 在 ĵ 右侧，所以 v 在 w 右侧时 v × w 为正。例：图中平行四边形面积是 7，v 在 w 左侧，所以 v × w = −7。

二维叉积就是行列式

不告诉你面积也要能算，这就要用到行列式。视频说「如果没看第五章（行列式）现在该去看」，那是 2016 年的旧编号，对应这里的第 6 章。

二维的 v × w：把 v 的坐标作为矩阵第一列，w 的坐标作为第二列，算行列式。原因是这个矩阵对应的线性变换把 î、ĵ 分别送到 v、w。

行列式衡量面积被缩放了多少倍，而最典型的区域就是 î、ĵ 上的单位正方形，它变换后正好成了我们关心的这个平行四边形。单位正方形面积是 1，所以行列式就是平行四边形的面积。v 在 w 左侧，意味着变换翻转了定向，这正是行列式为负的含义。

例：v = (−3, 1)，w = (2, 1)，行列式是 (−3)×1 − 2×1 = −5。所以面积是 5，v 在 w 左侧，结果为负。

作者建议在脑子里试几个性质：两个向量越接近垂直，叉积越大，因为边长相同时平行四边形越「正」面积越大；方向越接近，叉积越小。把其中一个向量放大 3 倍，面积也放大 3 倍，所以 (3v) × w = 3(v × w)。

三维叉积：结果是一个向量

严格说，上面描述的还不是叉积。叉积把两个三维向量组合成一个新的三维向量。仍然看两个向量张成的平行四边形，面积仍然起关键作用，比如这里面积是 2.5。

三维叉积的结果是一个向量：长度等于平行四边形的面积（2.5），方向垂直于这个平行四边形。垂直于一个平面、长度为 2.5 的向量有两个，选哪一个由右手定则决定：右手食指指向 v，中指指向 w，竖起的大拇指就是叉积的方向。

例子：v 长度 2、指向正 z 方向，w 长度 2、指向正 y 方向。它们垂直且等长，张成边长 2 的正方形，面积 4，所以叉积长度为 4。按右手定则，结果指向负 x 方向，所以 v × w = −4î。

计算：三阶行列式里塞进基向量

一般的计算有一个可以背的公式，但更常见也更容易的是记住一个涉及三阶行列式的过程。这个过程初看很怪：写一个 3×3 矩阵，第二、三列是 v 和 w 的坐标，第一列却填 î、ĵ、k̂ 三个基向量，然后算行列式。

向量当作矩阵元素，意思并不清楚，学生通常被告知这只是记号上的技巧。把 î、ĵ、k̂ 当成数照常展开，得到这三个基向量的某个线性组合：

v × w = î(v₂w₃ − v₃w₂) + ĵ(v₃w₁ − v₁w₃) + k̂(v₁w₂ − v₂w₁)

然后学生被告知要相信：这个线性组合定义的向量，恰好是垂直于 v 和 w、长度等于平行四边形面积、方向服从右手定则的那个唯一向量。

作者承认这是记号技巧，但它有来由：行列式再次出现不是巧合，把基向量塞进那一列也不是随便做的。要理解背后的原因，要用到上一集的对偶性。这部分有点重，放在单独的下一集，作者认为它严格说在线性代数的本质之外，最重要的是知道叉积向量在几何上代表什么。

问题：记号技巧为什么对

计算 v × w 的办法：写一个矩阵，第二列是 v 的坐标，第三列是 w 的坐标，第一列却是符号 î、ĵ、k̂，把它们当成数，算这个怪矩阵的行列式。照算下去，得到某个常数乘 î 加某个常数乘 ĵ 加某个常数乘 k̂。行列式具体怎么展开不重要，重要的是得到三个数，被解读为结果向量的坐标。

学生通常被告知要相信这个向量有以下几何性质：长度等于 v、w 张成的平行四边形面积；方向垂直于 v 和 w；方向服从右手定则。可以用暴力计算验证，作者要讲的是另一条推理。

回顾对偶性

对偶性的要点：任何从某个空间到数轴的线性变换，都对应该空间里唯一一个向量，做这个变换等于和那个向量做点积。数值上，这种变换由只有一行的矩阵描述，每列是一个基向量落到的数；用这个矩阵乘向量 v，和把矩阵立起来得到的向量与 v 做点积，计算上完全一样。

所以在数学的野外只要遇到一个到数轴的线性变换，就能把它配上一个向量，叫这个变换的对偶向量 (Dual Vector)。叉积就是这个过程的一个例子。

计划是：定义一个从三维到数轴的线性变换，它由 v、w 定义；然后找它在三维空间里的对偶向量，这个对偶向量就是 v × w。理解这个变换，就能看清叉积的计算和几何之间的联系。

构造那个线性变换

先回到二维：二维叉积就是把 v、w 当两列算行列式，普通的行列式，返回一个数，几何上是平行四边形的有向面积。

如果事先不知道三维叉积、试着类推，你可能会猜它是取三个三维向量 u、v、w，当作 3×3 矩阵的三列，算行列式。几何上这给出三个向量张成的平行六面体的体积，正负由右手定则下的定向决定。

但三维叉积是两个向量进、一个向量出，不是三个向量进、一个数出。但这个想法离真相很近：把第一个向量 u 换成变量 (x, y, z)，v、w 固定。

这样得到一个从三维到数轴的函数：输入 (x, y, z)，输出以 (x, y, z)、v、w 为三列的矩阵的行列式。几何意义：对任意输入向量，看它和 v、w 张成的平行六面体，返回其体积，正负取决于定向。

这个函数最重要的性质是它是线性的，作者留给观众根据行列式的性质自己验证。既然线性，就能用矩阵乘法描述；它从三维到一维，所以有一个 1×3 矩阵编码它。按对偶性，把这个矩阵立起来，整个变换就等于和某个特定向量做点积。

我们要找的就是这个三维向量 p：它和任意 (x, y, z) 的点积，等于把 (x, y, z) 放进 3×3 矩阵第一列、另两列为 v、w 坐标时的行列式。

思考题为什么这个函数 f(x, y, z) = det[(x, y, z), v, w] 是线性的？

行列式对每一列都是线性的：把第一列换成两个向量之和，行列式等于两个行列式之和；把第一列乘一个数，行列式也乘这个数（其他列不动）。几何上也看得出：固定底面 v、w，平行六面体的有向体积 = 底面积 × 第一个向量在底面法向上的分量，而「取法向分量」本身是线性的。

计算角度：得到那个记号技巧

先从计算上看。p 与 (x, y, z) 的点积是 p₁x + p₂y + p₃z，三个系数就是 p 的坐标。右边的行列式展开后，也能整理成「某个常数乘 x + 某个常数乘 y + 某个常数乘 z」，这些常数是 v、w 分量的特定组合：

x(v₂w₃ − v₃w₂) + y(v₃w₁ − v₁w₃) + z(v₁w₂ − v₂w₁)

所以这三个组合就是 p 的坐标。对做过叉积计算的人来说这很眼熟：把乘在 x、y、z 上的常数项收集起来，和在第一列填 î、ĵ、k̂、看哪些系数聚在哪个基向量上，是同一回事。填 î、ĵ、k̂ 只是提示我们：这些系数要解读成一个向量的坐标。

所以那个怪计算回答的问题是：什么样的向量 p，和任意 (x, y, z) 点积的结果，等于把 (x, y, z) 放进第一列、另两列是 v、w 时的行列式？

几何角度：得到叉积的几何性质

同一个问题，这次从几何上回答：什么三维向量 p，和任意 (x, y, z) 的点积，等于 (x, y, z)、v、w 张成的平行六面体的有向体积？

点积的几何意义是：把另一个向量投影到 p 上，投影长度乘 p 的长度。再看平行六面体的体积怎么算：先取 v、w 张成的平行四边形的面积，再乘 (x, y, z) 垂直于这个平行四边形的那个分量（而不是 (x, y, z) 的长度）。

换句话说，这个线性函数对一个向量做的事是：把它投影到同时垂直于 v 和 w 的直线上，再把投影长度乘以平行四边形的面积。这等于和一个「垂直于 v、w，长度等于平行四边形面积」的向量做点积。方向选对的话，点积为负的情形恰好和 (x, y, z)、v、w 在右手定则下定向为负的情形一致。

于是找到了一个向量 p，它和任意 (x, y, z) 的点积，就是那个三阶行列式。计算上用记号技巧得到的答案，几何上一定是这个向量。这就是叉积的计算和几何解释相关联的根本原因。

总结

从一个由 v、w 定义的、三维到数轴的线性变换出发，用两种方式找它的对偶向量（做这个变换 = 和这个向量点积）。

计算上，得到在第一列填 î、ĵ、k̂ 再算行列式的技巧；几何上，推出这个对偶向量必须垂直于 v 和 w、长度等于它们张成的平行四边形的面积。两种方法给出的是同一个变换的对偶向量，所以是同一个向量。

设定

一个线性方程组，两个未知数 x、y，两个方程。未知数更多、方程数相同时，下面的内容都成立，只是小例子更好想。

按第 7 章的看法，这是一个已知矩阵变换一个未知向量 (x, y)，并且知道输出是 (−4, −2)。矩阵的列告诉你输入空间的基向量落在哪。所以这是个谜题：要找的是落在这个输出上的那个输入向量。换一种说法：输出向量是矩阵各列的某个线性组合，x 乘 î 的落点加 y 乘 ĵ 的落点，我们要找的是这个组合的系数。

答案的类型取决于变换有没有把空间压到更低维，也就是行列式是不是 0；是 0 的话，要么没有输入落到这个输出，要么有一大堆。本集只考虑行列式不为零：每个输入对应唯一的输出，每个输出也只有唯一的输入。

一个方向对、但行不通的想法

先看一个错误但方向对的想法。未知向量的 x 坐标，是它和第一个基向量 (1, 0) 的点积；y 坐标是和 (0, 1) 的点积。也许可以指望：变换后，未知向量的像和基向量的像做点积，仍然等于 x 和 y。那就太好了，因为这些变换后的向量我们都知道。

问题是这一般不成立。多数线性变换前后，点积差别很大：两个大致同向、点积为正的向量，变换后可能被拉开，点积变负；原本垂直、点积为 0 的两个基向量，变换后常常不再垂直。这个例子里点积通常还会变大，因为多数向量被拉长了。

题外话：保持点积不变的变换有自己的名字，叫正交变换 (Orthonormal Transformation)：基向量变换后仍然互相垂直、仍然是单位长度，可以把它们想成旋转矩阵，对应没有拉伸、压缩、扭曲的刚体运动。

用正交矩阵解方程组很容易：点积不变，所以输出向量和矩阵各列的点积，等于未知输入和各基向量的点积，也就是输入的坐标。在这种特殊情况下，x 是第一列和输出的点积，y 是第二列和输出的点积。

换个办法描述坐标：有向面积

虽然这个想法对大多数方程组都不行，它指明了要找什么：有没有一种对输入向量坐标的几何描述，在变换后保持不变？

如果你一直在想行列式，可能会想到这个：取第一个基向量 î 和未知输入向量 (x, y) 张成的平行四边形。它的面积是底 1 乘以垂直于底的高，而高就是输入向量的 y 坐标。

所以这个平行四边形的面积是描述 y 坐标的一种古怪迂回的说法。更准确地说是有向面积：y 坐标为负时，面积也为负（把 î 当作两条边里的第一条）。

对称地，未知向量和第二个基向量 ĵ 张成的平行四边形，面积就是 x 坐标。

三维里也一样。通常 z 坐标是和 k̂ 的点积，另一种几何解释是看它和 î、ĵ 张成的平行六面体：把 î、ĵ 张成的面积为 1 的正方形当作底，体积就等于高，也就是 z 坐标。

其余坐标同理：用这个向量和「除了对应方向那个」的所有基向量组成平行六面体，体积就是那个坐标。这里说的是按右手定则的有向体积，所以三个向量的排列顺序有影响，负坐标也说得通。

关键一步：所有面积都乘 det(A)

用面积和体积描述坐标，好处在变换之后：施加矩阵变换时，这些平行四边形的面积不会保持不变，会变大或变小。但行列式的关键性质是：所有面积都按同一个比例缩放，就是变换矩阵的行列式。

看由「第一个基向量的落点」（也就是矩阵第一列）和「(x, y) 的像」张成的平行四边形。它正是前面那个面积等于 y 的平行四边形变换后的样子，所以它的面积是 det(A) · y。于是 y = 这个新平行四边形的面积 ÷ det(A)。

新面积可以直接算：(x, y) 的像是已知的，这正是方程组的右边。所以造一个新矩阵，第一列和 A 相同，第二列换成输出向量，求它的行列式。只用输出空间里的数据，也就是矩阵的列和输出向量，就恢复了未知输入的 y 坐标。

同理求 x：原来那个面积等于 x 的平行四边形（未知向量和 ĵ）变换后由输出向量和矩阵第二列张成，面积乘了 det(A)。所以 x = 第一列换成输出向量的新矩阵的行列式 ÷ det(A)。

这个求解公式就是克莱姆法则：

x = det(A₁) / det(A)，y = det(A₂) / det(A)，其中 Aₖ 是把 A 的第 k 列换成输出向量 v 得到的矩阵。

坐标系藏在基向量里

二维空间里一个向量，标准坐标是 (3, 2)：从起点到终点，右移 3、上移 2。更线性代数的说法是把两个数看成标量：第一个缩放 î（指向右、长度 1），第二个缩放 ĵ（指向上、长度 1），两个缩放后的向量首尾相加，就是坐标描述的向量。

可以把这两个特殊向量看成坐标系全部隐含假设的封装：第一个数表示向右、第二个数表示向上、单位长度到底有多长，全都绑在「选 î、ĵ 作为坐标缩放的对象」这件事上。向量与一组数之间的任何翻译方式都叫坐标系，î 和 ĵ 叫标准坐标系的基向量。

Jennifer 的基

朋友 Jennifer 用另一组基向量，叫 b₁ 和 b₂：b₁ 指向右上一点，b₂ 指向左上。刚才那个我们叫 (3, 2) 的向量，Jennifer 会描述为 (5/3, 1/3)：她到达这个向量的方式是 b₁ 乘 5/3，b₂ 乘 1/3，再相加。

一般地，Jennifer 用坐标描述向量时，第一个坐标缩放 b₁、第二个缩放 b₂，再相加，得到的通常和我们用同样坐标想到的向量完全不同。

更精确地说：她的 b₁ 我们描述为 (2, 1)，b₂ 我们描述为 (−1, 1)。但要意识到，从她的角度、在她的坐标系里，这两个向量的坐标是 (1, 0) 和 (0, 1)，正是它们定义了她世界里 (1, 0)、(0, 1) 的意思。我们看着空间里同样的向量，只是用了不同的词和数来描述，就像说不同的语言。

关于画法的一点说明：平时画的方形网格只是一种构造，用来可视化我们的坐标系，依赖于我们选的基。空间本身没有内在的网格。Jennifer 可以画她自己的网格，同样是人为的构造。

她的原点和我们的重合，因为所有人都同意 (0, 0) 的意思：任何向量乘 0 得到的东西。但她的坐标轴方向和网格间距不同，取决于她选的基。

从她的语言翻译到我们的

接下来要解决两个坐标系之间的翻译。比如 Jennifer 说一个向量是 (−1, 2)，要换成我们的坐标。她的坐标是说：这个向量是 −1 · b₁ + 2 · b₂。从我们的角度，b₁ = (2, 1)，b₂ = (−1, 1)，所以直接在我们的坐标里算 −1·(2, 1) + 2·(−1, 1) = (−4, 1)。这就是她口中 (−1, 2) 在我们这里的描述。

这个过程，用她的每个基向量乘以对应坐标再相加，就是矩阵向量乘法：矩阵的列是用我们的语言写的 Jennifer 的基向量。

如果把矩阵向量乘法理解为施加一个线性变换（作者说第 3 章是他认为整个系列最重要的一集），这里有个直观的理解：列为 Jennifer 基向量的矩阵，可以看成一个变换，把我们的基向量 î、ĵ（我们说 (1, 0)、(0, 1) 时想的东西）移到 Jennifer 的基向量（她说 (1, 0)、(0, 1) 时想的东西）。

拿我们认为坐标是 (−1, 2) 的那个向量施加这个变换：变换前它是 −1 · î + 2 · ĵ；线性变换的关键性质是，结果是新基向量的同一个线性组合，−1 × (î 的落点) + 2 × (ĵ 的落点)。所以这个矩阵做的事，是把「我们对 Jennifer 那句话的误解」变换成「她本来指的那个向量」。

为什么感觉是反的

作者第一次学的时候总觉得这是反的：几何上，这个矩阵把我们的网格变换成 Jennifer 的网格；数值上，它却把一个用她的语言描述的向量翻译成我们的语言。

让他终于想通的是：它接收的是「我们对 Jennifer 的误解」，也就是用同样的坐标、但在我们的坐标系里得到的那个向量，然后把它变换成她本来指的向量。

反过来翻译：用逆矩阵

反方向，也就是从开头那个我们叫 (3, 2) 的向量算出 Jennifer 的 (5/3, 1/3)：从「把她的语言翻译成我们的」那个基变换矩阵出发，求它的逆。逆变换就是把原变换倒着播放。

实际中，尤其高于二维时，用计算机算逆矩阵。这里，列为 Jennifer 基向量的基变换矩阵，它的逆矩阵两列是 (1/3, −1/3) 和 (1/3, 2/3)。用它乘 (3, 2)，得到 (5/3, 1/3)。

小结：列为「用我们的坐标写的 Jennifer 基向量」的矩阵 A，把向量从她的语言翻译成我们的语言；逆矩阵 A⁻¹ 反过来。

翻译一个变换：A⁻¹MA

用坐标描述的不只是向量。这部分需要熟悉用矩阵表示变换、矩阵乘法对应变换复合（第 3、4 章）。

取一个线性变换，比如逆时针旋转 90°。我们用矩阵表示它时，跟踪 î、ĵ 的去向：î 到 (0, 1)，ĵ 到 (−1, 0)，这些坐标成为矩阵的列。但这个表示深深绑定在我们对基的选择上：从跟踪 î、ĵ 开始，到用我们自己的坐标记录落点，都是。

换成 Jennifer 来描述同样的 90° 旋转，你可能想直接把我们旋转矩阵的两列翻译成她的语言，但这不对：那两列表示的是我们的基向量 î、ĵ 去了哪，而 Jennifer 要的矩阵应该表示她的基向量落在哪，而且要用她的语言描述落点。

常用的做法是这样：从任意一个用 Jennifer 语言写的向量出发。不要试图在她的语言里跟踪它，先用基变换矩阵 A 把它翻译成我们的语言；得到同一个向量、我们的语言。然后左乘变换矩阵 M，得到变换后的位置，仍是我们的语言。最后左乘逆基变换矩阵 A⁻¹，得到变换后的向量，但换回了她的语言。

对她语言里的任意向量都能这样做，所以这三个矩阵的复合 A⁻¹MA 就是用 Jennifer 的语言写的变换矩阵：输入她语言的向量，输出她语言的变换后的向量。

具体到这个例子：Jennifer 的基在我们的语言里是 (2, 1)、(−1, 1)，变换是 90° 旋转，三个矩阵乘出来两列是 (1/3, 5/3) 和 (−2/3, −1/3)。Jennifer 用这个矩阵乘她坐标系里的向量，就得到这个向量旋转 90° 后在她的坐标系里的坐标。

数学上的换位思考

一般来说，看到 A⁻¹MA 这样的表达式，它暗示着一种数学上的换位思考：中间的矩阵是你眼中的某个变换，外面两个矩阵代表视角的转换，整个乘积代表同一个变换在另一个人眼中的样子。

留在自己张成的直线上的向量

看一个二维线性变换：î 移到 (3, 0)，ĵ 移到 (1, 2)，矩阵是 3102。盯住某一个向量，看它张成的空间，也就是过原点和它终点的那条直线。变换中，多数向量会被「撞离」这条直线：如果它的落点恰好还在这条线上，就太巧了。

但有些特殊向量会留在自己的张成空间上，矩阵对它的作用只是拉伸或压缩，像一个标量。这个例子里，î 就是一个：它张成的是 x 轴，从矩阵第一列能看出 î 变成了自己的 3 倍，仍在 x 轴上。由线性，x 轴上其他向量也都只是被拉伸 3 倍，都留在自己的直线上。

稍隐蔽一点的是 (−1, 1)，它被拉伸 2 倍；同样由线性，它张成的那条对角线上的所有向量都被拉伸 2 倍。对这个变换，具有这种性质的只有这两条线上的向量：x 轴上的拉伸 3 倍，对角线上的拉伸 2 倍。其他所有向量都会被转一点，离开它张成的直线。

定义，以及为什么有用

这些特殊向量叫这个变换的特征向量 (Eigenvector)，每个特征向量对应一个特征值 (Eigenvalue)，就是它在变换中被拉伸或压缩的倍数。拉伸和压缩没有本质区别，特征值是正数也只是碰巧：特征值可以是 −1/2，表示向量被反向并压缩一半。重要的是它留在自己张成的直线上，没有被转离。

一个用处是三维旋转：如果能找到这个旋转的一个特征向量，也就是留在自己直线上的向量，你找到的就是旋转轴。用「一根轴加一个转角」来想三维旋转，比想那个 3×3 矩阵容易得多。顺便，这里对应的特征值必须是 1，因为旋转不拉伸也不压缩。

这个模式在线性代数里很常见：任何矩阵描述的线性变换，都可以通过把矩阵的列读成基向量落点来理解；但更抓住本质、更不依赖坐标系的办法，往往是求特征向量和特征值。

怎么算：det(A − λI) = 0

作者不讲全部计算细节，只讲对概念理解最重要的部分。用符号写，特征向量的意思是 Av = λv：A 是变换矩阵，v 是特征向量，λ 是对应的特征值。左边是矩阵乘向量，右边是数乘向量，形式不一样不好处理。

先把右边也改写成矩阵乘向量：一个把任何向量都乘 λ 的矩阵，每个基向量都被乘 λ，所以对角线上是 λ、其余是 0。通常把 λ 提出来写成 λI，I 是对角线为 1 的单位矩阵。两边都是矩阵乘向量了，移项、提出 v，得到 (A − λI)v = 0。

v 是零向量时这总成立，但那没意思，要的是非零特征向量。看过第 6、7 章就知道，矩阵乘一个非零向量得到零，唯一的可能是这个矩阵对应的变换把空间压到了更低维，也就是行列式为零。所以 λ 是特征值，当且仅当 det(A − λI) = 0。

具体例子：A 的两列是 (2, 1) 和 (2, 3)，从每个对角元素减去一个可变的 λ。想象转动旋钮改变 λ，矩阵跟着变，行列式也跟着变。要找的是让行列式为零、让调整后的变换把空间压扁的那个 λ，这个例子里恰好是 λ = 1。换一个矩阵，特征值就不一定是 1。

把这串推理理一遍：λ = 1 时，A − λI 把平面压成一条线，意味着存在非零向量 v 使 (A − λI)v = 0，也就是 Av = λv，v 是 A 的特征向量。这里特征值是 1，所以 v 原地不动。作者说，如果你没有牢固理解行列式、以及它和「方程组有非零解」的关系，这个式子会显得莫名其妙。

回到开头的例子

回到 3102：从对角线减去 λ 求行列式，得到关于 λ 的二次多项式 (3 − λ)(2 − λ)。只有它为零时 λ 才可能是特征值，所以特征值只能是 2 和 3。

找特征值为 2 的特征向量：把 λ = 2 代入矩阵，解哪些向量被这个调整过的矩阵送到零。像解任何线性方程组一样解，会发现解是 (−1, 1) 张成的那条对角线上的所有向量，对应原矩阵把这些向量拉伸 2 倍。

几个特殊情况

二维变换不一定有特征向量。比如旋转 90°：每个向量都被转离自己的直线，没有特征向量。真去算的话，矩阵两列是 (0, 1) 和 (−1, 0)，减去 λ 求行列式得到 λ² + 1，根只有虚数 i 和 −i。没有实数解，说明没有特征向量。

再看剪切：î 不动、ĵ 右移一格，矩阵两列是 (1, 0) 和 (1, 1)。x 轴上的向量都是特征值为 1 的特征向量，因为它们原地不动；而且只有这些。减去 λ 求行列式得到 (1 − λ)²，唯一的根是 λ = 1，和几何上看到的一致。

也可能只有一个特征值，却有不止一条线的特征向量。简单例子：把所有东西都放大 2 倍的矩阵。唯一的特征值是 2，但平面上每个向量都是属于它的特征向量。

特征基与对角化

最后一个话题是特征基，大量用到上一集的基变换。如果基向量恰好都是特征向量，比如 î 被乘 −1，ĵ 被乘 2。把新坐标写成矩阵的列，这两个倍数，也就是 î、ĵ 的特征值，落在对角线上，其余全是 0。

除对角线外都是零的矩阵叫对角矩阵 (Diagonal Matrix)，它的意思是：所有基向量都是特征向量，对角元素就是它们的特征值。

对角矩阵有很多好处，最大的一个是容易算它乘自己很多次：它做的只是把每个基向量乘上一个特征值，乘 100 次就是把每个基向量乘上特征值的 100 次方。反过来，试试算一个非对角矩阵的 100 次幂，真的试一下，那是一场噩梦。

基向量恰好是特征向量的情况很少见。但如果变换有足够多的特征向量，多到能选出一组张成整个空间（比如开头那个例子），就可以换一个坐标系，让这些特征向量当基向量。

按上一集的办法：把新基向量（这里是两个特征向量）的坐标作为列，得到基变换矩阵；把原变换夹在中间，右边放基变换矩阵、左边放它的逆，结果就是同一个变换在新基坐标系下的矩阵。

用特征向量做这件事的意义在于：新矩阵一定是对角的，对角线上是对应的特征值。因为在这个坐标系里，变换对基向量做的就只是缩放。由特征向量组成的一组基叫特征基 (Eigenbasis)。

所以要算这个矩阵的 100 次幂，更容易的办法是换到特征基、在那里算 100 次幂、再换回标准坐标系。不是所有变换都能这样：剪切就没有足够的特征向量张成整个空间。但只要找得到特征基，矩阵运算就变得很舒服。

思考题屏幕上的题：A = 0111。先手算 A²、A³，找规律；已知两个特征向量是 (2, 1 + √5) 和 (2, 1 − √5)，试着用特征基算 Aⁿ。

A 的各次幂里出现的是斐波那契数：Aⁿ = Fₙ₋₁FₙFₙFₙ₊₁（F₁ = F₂ = 1）。两个特征值用 det(A − λI) = λ² − λ − 1 = 0 求得 φ = (1 + √5)/2 和 ψ = (1 − √5)/2。取两个特征向量为列组成基变换矩阵 P，则 P⁻¹AP 是对角线为 φ、ψ 的对角矩阵，于是 Aⁿ = P · diag(φⁿ, ψⁿ) · P⁻¹。乘出来右上角就是 Fₙ = (φⁿ − ψⁿ)/√5，即斐波那契数的通项公式（Binet 公式）。「令人惊讶的结果」指的就是这个：一个全是整数的数列，通项里有 √5。

常规做法回顾

回顾：如果线性变换对某个向量的作用只是把它乘一个常数，这个向量叫特征向量，这个常数叫对应的特征值，常记作 λ。写成方程整理一下：λ 是 A 的特征值，意味着 A − λI 把某个非零向量（对应的特征向量）送到零向量，于是 det(A − λI) = 0。

常规做法：从对角线减去未知的 λ，令行列式为零来解。这总要多几步展开化简，才能得到干净的二次多项式，叫矩阵的特征多项式 (Characteristic Polynomial)。特征值是它的根，所以还要套二次求根公式，通常又得化简一两步。过程不算糟，但至少对 2×2 矩阵，有更直接的办法。

三个事实

要重新发现这个技巧，只需要三个事实，每个本身也常用。

事实一：矩阵的迹 (Trace)，也就是两个对角元素之和，等于特征值之和。对这里更有用的说法是：两个特征值的平均值，等于两个对角元素的平均值。

事实二：矩阵的行列式，也就是常见的 ad − bc，等于两个特征值的乘积。如果你理解特征值描述的是算子在某个方向上拉伸了多少、行列式描述的是整体上面积（或体积）缩放了多少，这就说得通。

这两个值几乎不用写什么就能从矩阵读出来。例：8426，特征值的平均值 = 8 和 6 的平均值 = 7；行列式 = 48 − 8，所以特征值的乘积是 40。

事实三：知道两个数的平均值和乘积，怎么快速求出这两个数。这个例子里，两个数以 7 为中心对称分布，写成 7 ± d。乘积 (7 + d)(7 − d) 是平方差，等于 7² − d² = 40，所以 d² = 49 − 40 = 9，d = 3。两个特征值是 4 和 10。

写成一般公式：对平均值 m、乘积 p，距离的平方总是 d² = m² − p。于是第三个事实：平均值为 m、乘积为 p 的两个数是 m ± √(m² − p)。忘了的话现推也很快，就是平方差公式换了个说法；作者还是建议记住它。作者的朋友、A Capella Science 频道的 Tim 为它写了首口诀歌。

两个例子

3141：先在心里想好公式，写的时候边写边填 m 和 p。平均值是 3 和 1 的平均 = 2，所以写下 2 ± √(2² − …)；乘积是行列式 3×1 − 1×4 = −1，填进去。特征值是 2 ± √5。这正是开头用常规方法算的那个矩阵，这次直接得多。

2718：平均值是 2 和 8 的平均 = 5；行列式是 2×8 − 7×1 = 9。所以特征值是 5 ± √16，化简为 9 和 1。几乎是盯着矩阵就能写出特征值，最后只需要一点点化简。

作者说他在记线性代数相关的草稿时经常用这个技巧。他在做一期关于矩阵指数的视频（后来的《微分方程》第 5 章），里面特征值频繁出现，如果学生能从小例子里直接读出特征值，就不会因为陷入另一个计算而丢掉主线。

泡利矩阵

另一个例子是量子力学里常出现的三个矩阵，叫泡利自旋矩阵 (Pauli Spin Matrices)：0110、0−ii0、100−1。懂量子力学的人知道矩阵的特征值和它描述的物理密切相关。

三个矩阵对角元素的平均值都是 0，所以特征值的平均值都是 0，公式特别简单。行列式：第一个是 0 − 1 = −1；第二个也是 0 − 1，因为 (−i)(i) = 1，要多想一下；第三个是 −1 − 0。

所以三个的特征值都是 ±1。在量子力学里，这三个矩阵描述沿 x、y、z 方向观测粒子自旋，特征值只有 ±1，对应观测到的自旋要么完全朝一个方向、要么完全朝另一个方向，不会连续地取中间值。

作者承认这个例子反而削弱了他的论点：对这几个特定矩阵，常规的特征多项式方法几乎一样快，甚至更快。第一个的特征多项式直接就是 λ² − 1；第二个也是；第三个已经是对角矩阵，对角元素就是特征值。

能感到提速的是更一般的情况：取三个矩阵的线性组合 aσₓ + bσy + cσz，量子力学里它描述沿方向 (a, b, c) 观测自旋，假设这个向量已归一化，a² + b² + c² = 1。一眼看出特征值的平均值仍是 0；可以暂停确认乘积仍是 −1；于是特征值是 ±1。用特征多项式做就麻烦得多，在脑子里更难算。

思考题验证 aσₓ + bσy + cσz 的行列式是 −1（已知 a² + b² + c² = 1）。

这个矩阵是 ca−bia+bi−c。行列式 = −c² − (a − bi)(a + bi) = −c² − (a² + b²) = −(a² + b² + c²) = −1。对角元素平均值为 0，所以特征值是 0 ± √(0 + 1) = ±1。

和特征多项式、求根公式的关系

用平均值-乘积公式和求特征多项式的根，没有区别，毕竟解的是同一个问题。可以这样看：平均值-乘积公式是一种解一般二次方程的好方法。求二次方程的根时，你知道两个根的和与积，要恢复这两个数，是同样的处境。

具体地，首项系数为 1 的二次多项式 x² + bx + c，两根的平均值是一次项系数的 −1/2（因为 b 是两根之和的相反数），例子 x² − 10x + 9 里平均值是 5；两根之积就是常数项，不用调整。然后套平均值-乘积公式得到根。

可以把它当作传统求根公式的轻量版。更有用的一点是每个符号都带着意义。这个特征值技巧的要点正在于此：平均值和乘积可以直接从矩阵读出来，所以不必经过「写出特征多项式」这一步，直接写出根。

想证明前两个事实的话，把一般矩阵的特征多项式展开，仔细想每个系数的含义：det(A − λI) = λ² − (a + d)λ + (ad − bc)，而它又等于 (λ − λ₁)(λ − λ₂) = λ² − (λ₁ + λ₂)λ + λ₁λ₂，对照系数就是「迹 = 特征值之和、行列式 = 特征值之积」。

这一集记住这几条

  • 2×2 矩阵的特征值：λ = m ± √(m² − p)，m = 对角元素的平均值，p = 行列式。
  • 迹 = 特征值之和，行列式 = 特征值之积；对照 det(A − λI) = λ² − (a+d)λ + (ad−bc) 的系数即得。
  • 这就是用「和与积」解二次方程，好处是 m、p 能直接从矩阵上读出来。

向量到底是什么

一方面，把向量定义为数字列表清晰明确：四维、一百维向量都成了可以实际操作的具体概念，而不然的话「四维」只是个说不清的几何概念。另一方面，经常用线性代数的人，尤其熟练做基变换之后，常有一种感觉：你面对的空间独立于你给它的坐标存在，坐标带有很大的随意性，取决于你选了哪组基。

线性代数的核心话题，比如行列式和特征向量，似乎并不在乎坐标系：行列式说的是变换把面积缩放多少倍，特征向量是变换中留在自己张成空间上的向量，两者都是空间本身的性质，换坐标系不影响它们的值。可如果向量的本体比实数列表更「空间」，那数学家说的「空间」又是什么意思？

函数也是向量

为了回答这个问题，作者用大半集讲一种既不是箭头也不是数组、却有向量特征的东西：函数。

两个向量能相加，两个函数 f、g 也能相加，得到新函数 f + g。这个新函数在任意输入处（比如 −4）的值，是 f 和 g 在同一输入处的值之和；一般地 (f + g)(x) = f(x) + g(x)。这和向量按坐标相加很像，只不过某种意义上有无穷多个坐标。

类似地，函数可以乘一个实数：把所有输出都乘这个数，同样类似按坐标数乘，只是坐标有无穷多个。

既然向量能做的只有相加和数乘，线性代数里原本针对空间箭头发展出来的那些构造和解题方法，应该也能用在函数上。比如函数也有线性变换：接收一个函数、变成另一个函数。熟悉的例子来自微积分：求导。在这个语境里，常把它叫作算子 (Operator) 而不是变换，意思相同。

线性的严格定义

函数的变换怎样才算线性，要用严格定义来判断。严格定义比第 3 章那种说法抽象、更依赖符号，好处是足够一般，函数和箭头都适用。满足两条性质的变换是线性的，通常叫可加性 (Additivity) 和成比例 (Scaling)：

可加性：L(v + w) = L(v) + L(w)，先相加再变换，和先变换再相加结果一样。成比例：L(cv) = cL(v)，先数乘再变换，和先变换再数乘结果一样。常听到的说法是：线性变换保持向量加法和数乘运算。

之前说的「网格线保持平行且等距」，只是这两条性质在二维点的特殊情况下的图示。这两条性质最重要的推论之一，也是矩阵向量乘法之所以成立的原因，是线性变换完全由它对基向量的作用决定：任何向量都能写成基向量的缩放再相加，变换后就是变换后的基向量以同样方式缩放再相加。这对函数和箭头同样成立。

学微积分的人一直在用求导的可加性和成比例，哪怕没这样叫过：两个函数相加再求导，等于分别求导再相加；函数乘一个数再求导，等于求导再乘这个数。

把求导写成矩阵

为了把类比做到底，看看怎么用矩阵描述求导。函数空间往往是无穷维的，这有点棘手，但作者觉得这个练习很有意思。

只考虑多项式，比如 x² + 3x + 5、4x⁷ − 5x²。每个多项式只有有限项，但整个空间包含任意高次的多项式。

先给这个空间坐标，也就是选一组基。多项式本来就写成 x 的各次幂的缩放之和，所以自然地选纯幂函数作为基函数：b₀(x) = 1，b₁(x) = x，b₂(x) = x²，b₃(x) = x³，以此类推。它们的角色和 î、ĵ、k̂ 在箭头世界里一样。次数可以任意高，所以基函数有无穷多个，多项式当作向量时有无穷多个坐标。

x² + 3x + 5 的坐标是 (5, 3, 1, 0, 0, …)：5 乘第一个基函数，加 3 乘第二个，加 1 乘第三个，之后都不加。4x⁷ − 5x² 的坐标是 (0, 0, −5, 0, 0, 0, 0, 4, 0, …)。一般地，每个多项式只有有限项，所以坐标是有限长的一串数，后面跟着无穷多个 0。

在这个坐标系里，求导由一个无穷矩阵描述，大部分是 0，但在主对角线上方那条斜线上依次是正整数 1, 2, 3, …。看它作用在 x³ + 5x² + 4x + 5 上，坐标是 (5, 4, 5, 1, 0, …)：

向量空间与八条公理

回到「什么是向量」。数学里有很多「向量式」的东西：只要是一组对象，有合理的数乘和相加，不管是空间里的箭头、数字列表、函数，还是别的什么奇怪东西，线性代数里关于向量、线性变换的所有工具都应该适用。

把自己想成正在建立线性代数理论的数学家。你希望所有定义和发现适用于所有向量式的东西，不只是某个特例。这些向量式的东西组成的集合，叫向量空间 (Vector Space)。你不想操心别人可能发明的各种奇怪向量空间，于是列一组向量加法和数乘必须遵守的规则。

这些规则叫公理 (Axioms)，现代线性代数里一共八条，任何向量空间都要满足，已经发现的理论和构造才适用。它基本上是一张检查清单，确认加法和数乘做的是你以为它们会做的事。以下对任意向量 u、v、w 和数 a、b：

公理是一个接口

这些公理与其说是自然的基本规律，不如说是一个接口：一边是发现结论的你（数学家），一边是想把结论用到新向量空间上的其他人。

比如有人定义了一种疯狂的向量空间，所有 π 小人组成的集合，配上某种 π 小人的加法和数乘，公理就是他们开始使用线性代数结论前要核对的清单。你不必考虑所有可能的奇怪向量空间，只要用公理证明结论，定义满足公理的人就能放心使用，哪怕你从没想过他们的情形。

因此结论都倾向于写得很抽象，只用公理表述，而不围绕某种具体的向量。这就是为什么几乎每本教科书都用可加性和成比例来定义线性变换，而不说网格线保持平行等距，哪怕后者更直观，作者认为对初学者也更有帮助，虽然它只适用于一种情况。

所以数学家对「向量是什么」的回答是：不管这个问题。在现代理论里，向量的形态无关紧要，箭头、数字列表、函数、π 小人都行，只要有满足这些规则的加法和数乘。

就像问「3 是什么」：它具体出现时总是某三个东西，但在数学里，它被当作所有三元组的抽象，让你用一个概念推理所有三元组。向量也一样，有很多化身，数学把它们抽象成一个无形的概念：向量空间。

但作者仍然认为，先在具体、可视化的环境里推理向量更好，比如二维空间里从原点出发的箭头。学得更多之后，要知道这些工具的适用范围宽得多，这也是教科书和课程往往写得很抽象的根本原因。

结语

系列到此结束。作者说看懂了这些视频，就有了线性代数底层直觉的扎实基础。这不等于学会了整门课，那只能靠做题；但有了正确的直觉，之后的学习可以高效得多。

这一集记住这几条

  • 函数能相加、数乘，所以函数也构成向量空间；多项式空间以 1, x, x², … 为基，坐标是有限个数加无穷个 0。
  • 线性的严格定义：可加性 L(v + w) = L(v) + L(w) 和成比例 L(cv) = cL(v)；「网格线平行等距」是它在二维里的样子。
  • 求导是线性算子，在多项式基下是斜线上为 1, 2, 3, … 的无穷矩阵。
  • 向量空间 = 满足八条公理的加法和数乘；向量具体是什么形态不重要。
