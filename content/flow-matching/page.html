Flow Matching 与 Rectified Flow 综述

这一页把两篇论文放在一起讲。它们在 2022 年秋天相隔一个月发布，出发点不同，核心却是同一个训练目标：在噪声和数据之间画一条插值路径，用最小二乘回归这条路径上的速度。前三节讲背景和预备知识，接下来四节讲 Flow Matching 的条件构造和路径选择，再四节讲 Rectified Flow 的因果化、理论保证和 reflow，最后几节比较两者，给出一个实际运行的二维实验，并介绍后续发展和常见误解。

扩散模型本身见 DDPM 专题；Stable Diffusion 3 把 Rectified Flow 和 DiT 结合起来，相关背景在那两页。

1概述：两篇论文，一个训练目标

Flow Matching 由 Meta AI (FAIR) 和 Weizmann 研究所的 Yaron Lipman、Ricky T. Q. Chen、Heli Ben-Hamu、Maximilian Nickel、Matt Le 提出，2022-10-06 发布在 arXiv。Rectified Flow 由 UT Austin 的 Xingchao Liu、Chengyue Gong、Qiang Liu 提出，2022-09-07 发布。两篇都发表于 ICLR 2023。

两篇论文都训练一个随时间变化的速度场 v(x,t)，生成时从噪声出发解常微分方程 dx/dt = v(x,t)。最常用的配置下，二者的训练目标逐字相同：抽噪声 x0、数据 x1 和时间 t，令 xt = (1−t)x0 + t x1，让网络回归 x1 − x0。

Flow Matching 的贡献是一套一般的构造：用逐样本定义的条件路径拼出边际路径，证明回归条件速度与回归边际速度梯度相同，并把扩散路径和最优传输路径放进同一族高斯路径里比较。Rectified Flow 的贡献是从传输映射的角度证明这样学到的流保持边际分布、降低所有凸传输代价，并提出 reflow：用学到的流重新配对数据，反复迭代使轨迹越来越直，从而用很少的步数甚至一步生成。

这个目标后来成为大规模生成模型的主流选择。Stable Diffusion 3（2024-03-05）的论文题目就是 《Scaling Rectified Flow Transformers》，Movie Gen、π0 等模型都用 Flow Matching 训练。

2来历：Continuous Normalizing Flow 为什么一直训练不动

用常微分方程做生成模型并不新。Neural ODE（2018-06-19）提出 Continuous Normalizing Flow (CNF)：用神经网络参数化速度场，把简单分布连续地变形成数据分布。它不受离散归一化流对结构的限制，也能算精确的似然。问题在训练：最大似然要在每个训练步里正向、反向各解一次 ODE，FFJORD（2018-10-02）等改进仍然很慢，扩展不到大图像。

扩散模型这边，Song 等人的 SDE 论文（2020-11-26）证明每个扩散 SDE 都对应一个边际分布相同的概率流 ODE，DDIM（2020-10-06）给出了离散时间的确定性采样。也就是说，扩散模型实际上已经在训练一种 CNF，而且不用模拟 ODE，靠的是去噪分数匹配。但这条路只能用扩散过程定义的路径，噪声调度是从 SDE 推出来的，而不是按 ODE 的需要设计的。

2022 年秋天，三组人几乎同时想到绕开扩散过程，直接规定插值路径：Rectified Flow（2022-09-07）、Stochastic Interpolants（Albergo、Vanden-Eijnden，2022-09-30）和 Flow Matching（2022-10-06）。Flow Matching 在相关工作中把另外两篇列为同期工作，Rectified Flow 后来的版本也与它们互相引用。

3预备知识：流、速度场与连续性方程

速度场 vt(x) 定义一个流 ψt：dψt(x)/dt = vt(ψt(x))，ψ0(x) = x。把源分布 p0 的样本沿流推到 t 时刻，得到的分布记为 pt，叫做概率路径。如果 pt 正好是我们想要的那条路径，就说 vt 生成 pt。

判断速度场是否生成某条概率路径，用连续性方程 (Continuity Equation)：

∂pt(x)/∂t + div(pt(x) vt(x)) = 0质量守恒：某处密度的变化等于流入减流出

它是两篇论文证明的共同工具。Flow Matching 用它证明条件速度的加权平均生成边际路径（定理 1）；Rectified Flow 用它的弱形式证明学到的流保持边际分布（定理 3.3）。

还要注意时间方向。扩散文献里 t=0 是数据、t=T 是噪声；这两篇论文都反过来，t=0 是噪声（或源分布），t=1 是数据。读扩散论文和这两篇对照时，公式里的 1−t 大多来自这个差别。

4Flow Matching 目标：想回归的速度算不出来

设 p0 是标准高斯，q 是只能拿到样本的数据分布。如果已经有一条从 p0 到 q 的概率路径 pt 和生成它的速度场 ut，训练目标就很简单：

LFM(θ) = Et, x∼pt ‖vt(x; θ) − ut(x)‖2论文式 (5)

困难有两个。第一，满足 p1 ≈ q 的路径有无数条，事先不知道选哪条。第二，即使选定了，ut 一般也没有闭式，它依赖整个数据分布。所以这个目标本身无法直接用。

5条件构造：逐样本的路径拼成边际路径

Flow Matching 的关键一步是先解决只有一个数据点的问题。给定一个数据样本 x1，设计一条条件概率路径 pt(x|x1)：t=0 时是 p0，t=1 时集中在 x1 附近，例如 N(x|x1, σ2min I)。生成它的条件速度 ut(x|x1) 很容易写出来，因为只涉及一个点。

再对数据分布取平均。条件路径的平均 pt(x) = ∫pt(x|x1) q(x1) dx1 是边际路径，t=1 时接近 q。速度也可以平均，但要按每一点的后验加权：

ut(x) = ∫ ut(x|x1) · pt(x|x1) q(x1) / pt(x) dx1论文式 (8)，即 E[ut(x|x1) | xt = x]

定理 1 说这样加权平均出来的 ut 生成边际路径 pt。证明只用连续性方程和积分换序：条件路径各自满足连续性方程，而连续性方程关于 p 与 p·u 是线性的。

边际速度还是算不出来，因为式里有对整个数据集的积分。定理 2 解决这个问题：改为回归条件速度

LCFM(θ) = Et, x1∼q, x∼pt(x|x1) ‖vt(x; θ) − ut(x|x1)‖2论文式 (9)

它与 LFM 只差一个与 θ 无关的常数，梯度相同。原因是最小二乘的最优解就是条件期望：在同一个 x 处，网络看到许多互相矛盾的目标方向，学到的是它们的平均，也就是边际速度。这和去噪分数匹配等价于分数匹配是同一个道理，Flow Matching 论文明确说受它启发。

这样，训练只需要两样东西：能从 pt(x|x1) 采样，能算 ut(x|x1)。不需要模拟 ODE，也不需要知道边际路径。

补充这个「对条件量取平均」的论证在后续工作里被一再推广：Generator Matching 把速度换成任意 Markov 过程的生成元，离散 Flow Matching 把它用到 token 序列上，见资料里 NeurIPS 2024 教程第 4 段。

6高斯条件路径：扩散路径是特例

论文考虑一族高斯条件路径 pt(x|x1) = N(x | μt(x1), σt(x1)2 I)，边界条件 μ0 = 0、σ0 = 1、μ1 = x1、σ1 = σmin。生成同一条路径的速度场有无穷多个（可以加任意无散度分量），论文取最简单的仿射流 ψt(x) = σt(x1) x + μt(x1)。定理 3 给出它的速度：

ut(x|x1) = σ't(x1)/σt(x1) · (x − μt(x1)) + μ't(x1)论文式 (15)，撇号表示对 t 求导

代入扩散路径，得到的就是概率流 ODE 的速度。反向的 VE 路径取 μt = x1、σt = σ1−t；反向的 VP 路径取 μt = α1−t x1、σt = \sqrt{1 − α21−t}。论文附录 D 验证了它们与 Song 等人概率流 ODE 的向量场一致。所以用 Flow Matching 训练扩散路径，得到的是和扩散模型相同的模型，只是回归的是速度而不是分数或噪声。

论文还指出一个细节：扩散路径是作为 SDE 的解推出来的，有限时间内到不了真正的高斯，实践中只能近似；Flow Matching 直接规定 μt、σt，可以精确满足边界条件。

7最优传输路径：直线、匀速、方向不变

最自然的选择是让均值和标准差随时间线性变化：μt = t x1，σt = 1 − (1 − σmin) t。代入定理 3：

ut(x|x1) = (x1 − (1 − σmin) x) / (1 − (1 − σmin) t)论文式 (21)
ψt(x0) = (1 − (1 − σmin) t) x0 + t x1论文式 (22)，条件流
L = E ‖vt(ψt(x0)) − (x1 − (1 − σmin) x0)‖2论文式 (23)，σmin = 0 时就是回归 x1 − x0

这个条件流恰好是两个高斯 p0(x|x1) 与 p1(x|x1) 之间的最优传输位移映射，论文因此称它为 OT 路径。在条件流下，粒子沿直线匀速运动；条件速度可以写成 g(t)h(x|x1)，方向不随时间变化，论文认为这让回归任务更简单（图 2）。扩散路径的条件分数方向随时间变化，采样轨迹还可能越过终点再折返（图 3）。

论文自己强调了一个限制，后来却常被忽略：条件流是最优传输，不等于边际流是最优传输。边际速度是许多条件速度的平均，在样本稀疏、模式分开的地方轨迹会弯。论文只说预期边际速度「仍然相对简单」。

9Rectified Flow：把线性插值因果化

Rectified Flow 的出发点是传输映射问题：给定两个只有样本的分布 π0、π1，找一个映射把一个推到另一个。生成建模（π0 是高斯）和域迁移（两个都是图像集合）是同一个问题。

取任意耦合 (X0, X1)，通常是独立配对，令 Xt = tX1 + (1−t)X0。这条线性插值满足 dXt = (X1 − X0) dt，但它是非因果的：更新 Xt 要先知道终点 X1。Rectified Flow 用一个只看当前位置和时间的速度场去拟合它：

minv ∫01 E‖(X1 − X0) − v(Xt, t)‖2 dtRectified Flow 式 (1)
vX(x, t) = E[X1 − X0 | Xt = x]式 (2)，精确最优解

这个目标和 Flow Matching 取 OT 路径、σmin = 0 时完全相同。两篇论文对它的解释不同：Flow Matching 把它看作条件速度的边际化，Rectified Flow 把它看作对插值过程的因果化，得到的流 dZt = vX(Zt, t)dt 无需预知未来就能模拟。

理解 Rectified Flow 的关键是流不会交叉。解存在且唯一的 ODE，两条轨迹不可能在同一时刻经过同一点却走向不同方向。线性插值的直线可以交叉，学到的流就在交叉点附近「重新接线」：每条轨迹在交叉处改走另一条线的后半段，整体描绘出的密度和插值完全相同（论文图 2b）。

10Rectified Flow 的理论保证

Rectified Flow 论文第 3 节给出三类结论，都在假设式 (1) 被精确求解的前提下成立。

保持边际分布（定理 3.3）：对每个 t，Zt 与 Xt 同分布，因此 (Z0, Z1) 是 π0 与 π1 的合法耦合。这一条对任意可微插值都成立，不要求直线。但整条轨迹的联合分布不同：Xt 是非因果、非 Markov 的随机过程，Zt 是确定性的。论文的说法是 Zt 把 Xt 因果化、Markov 化并去随机化。

降低凸传输代价（定理 3.5）：对任意凸函数 c，E[c(Z1 − Z0)] ≤ E[c(X1 − X0)]。证明只用两次 Jensen 不等式。取 c = ‖·‖ 时有直观的图示：重新接线后的折线长度不变，而连接端点的直线不长于折线。它同时对所有凸代价成立，是 Pareto 意义上的下降，所以反复 rectify 不针对任何一个特定的代价，也就不保证收敛到某个 c 的最优传输。

拉直（定理 3.7）：定义直度 S(Z) = ∫01 E‖(Z1 − Z0) − \dot{Z}t‖2 dt，S = 0 表示轨迹是匀速直线。记 Zk 为第 k 次 rectify 得到的流，则 \mink≤K S(Zk) = O(1/K)。直线流用一步 Euler 就能精确模拟：Z1 = Z0 + v(Z0, 0)。

直线与最优的关系（第 3.4 节）：如果一个耦合对某个严格凸代价最优，它一定是直的（定理 3.8），反过来不成立。一维时两者重合，直线耦合就是唯一的单调耦合，同时对所有凸代价最优；二维以上，reflow 得到的直线耦合一般不是最优传输。论文还指出，有人猜测 DDIM 给出二次代价下的最优耦合，这个猜测已被证伪。

11Reflow 与蒸馏：用自己生成的配对重新训练

Reflow 的做法很简单：用训练好的第一个流（1-Rectified Flow）从噪声 Z0 模拟出 Z1，得到一批确定性的配对，再用同样的目标在这些配对上训练第二个流（2-Rectified Flow）。新配对的插值线交叉更少，学到的流更直。CIFAR-10 的实验生成了 400 万对 (z0, z1)，再把前一个模型微调 30 万步。

蒸馏和 reflow 不同。蒸馏是让一个一步模型忠实地复现某个流的映射 Z0 → Z1k；reflow 得到的是另一个传输代价更低、更直的耦合。论文建议只在最后阶段蒸馏，取 \hat{T}(z0) = z0 + v(z0, 0) 时，蒸馏损失正好是式 (1) 在 t = 0 处的那一项。

12非线性扩展：概率流 ODE 和 DDIM 也是 Rectified Flow

把线性插值换成任意可微曲线 Xt，目标改为回归 \dot{X}t，得到非线性 Rectified Flow。它仍保持边际分布，但不再保证降低凸代价，reflow 也不再拉直。论文证明（命题 3.11）所有概率流 ODE 变体都是取 Xt = αt X1 + βt ξ 的特例：VP ODE（等价于 DDIM 的连续极限）、sub-VP ODE 和 VE ODE 只是 αt、βt 的选择不同。

从这个角度看，VP ODE 有两个问题（论文图 5、图 6）。一是路径不直：αt2 + βt2 = 1 而不是 αt + βt = 1，轨迹一般是弯的，reflow 也拉不直。二是速度不均匀：αt 是指数形式，前半段几乎不动，大部分更新挤在 t &gt; 0.5 之后。论文还指出，把 VP ODE 的 αt 换成线性的 t，连续时间的轨迹不变，但更新速度变得均匀。

由此得出论文的建议：学习 ODE 不必借道扩散和 SDE；插值曲线和初始分布可以各自独立地选；默认用典范的线性插值。

15后续发展

大规模生成模型。Stable Diffusion 3（2024-03-05）系统比较了多种扩散和流的公式，结论是 Rectified Flow 配 logit-normal 时间采样（把训练时的 t 集中在中段）效果最好，骨干是 DiT 的变体 MM-DiT。之后 FLUX.1（Black Forest Labs，2024-08）同样采用 Rectified Flow Transformer。Meta 的 Movie Gen（2024-10-17）用 Flow Matching 训练文生视频模型，并做了受控消融：同样设置下，人类偏好评测里 Flow Matching 在质量和文本对齐上都优于扩散损失。机器人领域的 π0（2024-10-31）用 Flow Matching 生成连续动作序列。

耦合与路径。小批量最优传输耦合（Tong 等人 2023-02-01，Pooladian 等人 2023-04-28）在每个批量内求最优配对，批量趋于无穷时学到真正的最优传输。Stochastic Interpolants 的统一框架（2023-03-15）和 SiT（2024-01-16）在同一个 DiT 骨干上比较了插值、预测目标和采样器的各种组合。

16局限与常见误解

  • 「Flow Matching 学到的是最优传输」不对。OT 路径只是条件流的最优传输，边际流一般不是。Rectified Flow 递归下去得到的是直线耦合，也不是最优传输（一维除外）。Flow Matching 论文和 Rectified Flow 论文都明确写了这一点。
  • 「Rectified Flow 的轨迹是直的」要看是第几个。1-Rectified Flow 就是普通的 Flow Matching，轨迹在模式之间明显弯曲，一步 Euler 的 FID 是 378。只有 reflow 之后才接近直线。
  • reflow 有代价。它需要先用前一个模型生成大量配对（CIFAR-10 用了 400 万对），完整求解时的 FID 还会变差。NeurIPS 2024 教程里 Ricky Chen 的解释是：强制直线要求速度场有更大的 Lipschitz 常数，弯曲的流反而更好拟合。
  • 和扩散并不对立。高斯源、独立耦合、高斯路径时，Flow Matching 的模型和扩散模型的概率流 ODE 是同一个对象，区别在参数化（速度、噪声、数据）和时间权重。Flow Matching 论文用 FM 训练扩散路径，Rectified Flow 论文把概率流 ODE 写成非线性 Rectified Flow，都在说明这一点。
  • 两篇论文的实验规模都不大。Flow Matching 最大到 ImageNet 128，Rectified Flow 的定量结果主要在 CIFAR-10。这个训练目标在大模型上的优势，是 Stable Diffusion 3、Movie Gen 这些后来的工作通过受控比较确认的。

两篇论文的关系

Flow Matching 和 Rectified Flow 是同一个方法吗？

最常用的配置下训练的是同一个模型：噪声和数据独立配对，线性插值 xt = (1−t)x0 + t x1，回归 x1 − x0。Flow Matching 的 OT 路径带一个很小的 σmin，取 σmin = 0 时两者的损失逐字相同。

不同的是论证方式和各自往外推广的方向。Flow Matching 从条件路径的边际化出发，覆盖整族高斯路径，扩散路径是特例；Rectified Flow 从传输映射出发，允许任意两个分布和任意耦合，并提出 reflow。所以说「SD3 用的是 Rectified Flow」和「SD3 用的是 Flow Matching」都对，只是沿用了不同论文的叫法。

Stable Diffusion 3 用的是哪一个？

SD3 论文题为 《Scaling Rectified Flow Transformers》，采用的前向过程是 zt = (1−t)x0 + tε，即线性插值，网络回归速度。注意 SD3 沿用扩散的时间方向：t=0 是数据、t=1 是噪声，和这两篇论文正好相反。

SD3 没有做 reflow。它的改进在时间采样：训练时用 logit-normal 分布抽 t，让中间时刻被采到得更多，这在它比较的多种公式里效果最好。

核心构造

每个位置都看到许多互相矛盾的目标方向，网络为什么还能学对？

因为最小二乘的最优解是条件期望。同一个 xt 可能来自很多对 (x0, x1)，网络在这一点上最小化平方误差，学到的是这些 x1 − x0 的平均，也就是 E[X1 − X0 | Xt = x]。Flow Matching 的定理 1 说明这个平均正好生成边际路径，Rectified Flow 的式 (2) 写的是同一个量。

这也是 CFM 损失本身降不到零的原因：矛盾的目标留下一个与参数无关的方差项。所以训练损失的绝对值不能用来判断模型好坏。

综述：条件构造 →教程第 1 段：条件损失与 Bregman 散度 →

既然叫 OT 路径，生成时走的就是最优传输吗？

不是。OT 指的是条件流：给定一个数据点，从高斯到这个点的那段映射是最优传输。边际流是许多条件速度的平均，一般不是最优传输，轨迹也不是直线。Flow Matching 论文第 4 节末尾明确说了这一点。

本页的二维实验里，1-Rectified Flow（即 OT 路径的 Flow Matching）一步 Euler 时所有样本都挤在圆心，到最近模式的平均距离 3.94；如果它是直线流，一步就该到位。NeurIPS 2024 教程第 1 段 23:31 也专门澄清了这个误解，并提到高维时路径会变直。

综述：最优传输路径 →综述：二维实验 →

Flow Matching 里的 σmin 有什么用？

它让 t=1 时的条件分布是一个以 x1 为中心、标准差 σmin 的窄高斯，而不是 delta 函数，这样条件路径在 t=1 处也有密度，定理的推导更干净。论文没有报告 σmin 的具体取值和消融。

实践中它小到可以忽略，很多实现直接取 0，此时损失就是回归 x1 − x0，与 Rectified Flow 相同。

用 Flow Matching 训练扩散路径，得到的和扩散模型是一回事吗？

在模型层面是一回事。论文附录 D 证明，VE、VP 路径代入定理 3 得到的条件速度，与 Song 等人概率流 ODE 的向量场一致。区别在于网络回归的是速度，而不是噪声或分数，等价于换了一种参数化和一种时间权重。

表 1 显示这种换法本身就有好处：同样是 VP 扩散路径，FM 训练在 ImageNet 64 上 FID 16.88、NFE 187，分数匹配是 19.74、441。教程第 1 段 25:05 起解释了原因之一：噪声预测和数据预测的换算系数在端点有奇点，速度参数化没有。

为什么这两篇论文的 t=0 是噪声？读别的论文时要注意什么？

两篇论文都从「把简单分布推成数据分布」的流出发，时间自然从源分布走向目标。扩散文献的习惯相反，t=0 是数据，时间越大噪声越多。Dieleman 的博客在「不守约定」一节专门提醒过 Flow Matching 的这个反转。

因此看到 Flow Matching 论文里的 α1−t、σ1−t，大多只是在把扩散的时间翻过来；SD3 和 diffusers 的实现又按扩散的方向写。对照公式时先确认哪一端是噪声。

Reflow 与少步生成

Reflow 和蒸馏有什么区别？

Reflow 用当前的流生成 (Z0, Z1) 配对，再在这些配对上重新训练一个流，得到的是一个新的、更直、传输代价不更高的耦合。蒸馏是让一个一步模型忠实地复现某个流的 Z0 → Z1 映射，不改变耦合。

Rectified Flow 论文建议先 reflow 把流拉直，最后再蒸馏：流已经接近直线时，一步模型很好近似。CIFAR-10 上 2-Rectified Flow 不蒸馏的一步 FID 是 12.21，蒸馏后 4.85。

综述：Reflow 与蒸馏 →

Reflow 之后为什么多步采样反而变差？

论文表 1 里 RK45 完整求解的 FID 从 2.58（1-Rectified Flow）变成 3.36、3.96，论文的解释是对速度场的估计误差在每次 reflow 中累积：第 k+1 个流学的是第 k 个流生成的配对，第 k 个流的误差被当成了数据。

本页的二维实验也看到了这一点：100 步时到最近模式的平均距离从 0.313 变成 0.325。NeurIPS 2024 教程第 3 段里 Ricky Chen 给了另一个角度：强制直线需要速度场有更大的 Lipschitz 常数，弯曲的流反而更好拟合。

综述：二维实验 →教程第 3 段：拉直流 →

反复 reflow 会收敛到最优传输吗？

不会，至少不保证。Rectified Flow 证明的是递归 rectify 使流越来越直（定理 3.7，O(1/K)），同时所有凸传输代价都不增（定理 3.5）。但直线耦合只是最优耦合的必要条件（定理 3.8），一维以外一般不是最优传输。论文另一篇工作提出把速度限制为梯度场，才能收敛到二次代价下的最优耦合。

教程第 3 段 3:00 讲者说反复迭代会得到最优传输解，这与论文第 3.4 节不符，笔记里标注了。

综述：理论保证 →教程第 3 段：拉直流 →

为什么 1-Rectified Flow 一步采样会完全失败？

一步 Euler 的结果是 x0 + v(x0, 0)。在 t=0，xt = x0 和终点几乎无关，边际速度 E[X1 − X0 | X0 = x0] 约等于 E[X1] − x0，所以一步走到的是数据的均值。论文表 1 里 1-Rectified Flow 一步 FID 是 378，图 5 里一步只生成了 π1 的均值。

本页二维实验的目标均值是圆心，1-Rectified Flow 一步的样本全部落在原点附近（平均距离 3.94）。reflow 后的配对是确定性的，t=0 的速度已经知道该去哪个模式。

读论文和资料时

Flow Matching 训练出来的模型还能算似然吗？

能。它就是一个 Continuous Normalizing Flow，可以用瞬时变量替换公式沿 ODE 反向积分速度场的散度，散度用 Hutchinson 迹估计做无偏估计，论文附录 C 给了完整推导。表 1 的 BPD 就是这样算的（dopri5，容差 1e-5）。训练时不需要这些，只有评估似然时才要解 ODE。

Rectified Flow 说 DDIM 也是它的特例，是什么意思？

Rectified Flow 的非线性扩展把插值换成 Xt = αt X1 + βt ξ，回归 \dot{X}t。命题 3.11 证明各种概率流 ODE 的训练目标都可以写成这种形式，VP ODE 就是 DDIM 的连续时间极限。区别只在 αt、βt：VP 满足 αt2 + βt2 = 1，路径是弯的；线性插值满足 αt + βt = 1，路径是直的。

扩散模型是自编码器Diffusion models are autoencoders原文 ↗

去噪自编码器 (Denoising Autoencoder) 是一类神经网络：输入被噪声破坏，任务是预测干净的输入，也就是去掉这种破坏。要把这个任务做好，就需要学到干净数据的分布。去噪自编码器在表示学习中非常流行，在深度学习早期还被用来对深度神经网络做逐层预训练1。

事实上，扩散模型中使用的神经网络通常解决的是一个非常相似的问题：给定一个被噪声破坏的输入样本，预测与数据分布相关的某个量。这个量可以是对应的干净输入（和去噪自编码器一样），可以是加入的噪声，也可以介于两者之间（后文详述）。当破坏过程是线性的（即噪声是加性的）时，这些做法在某种意义上都是等价的：把预测噪声的模型的输出从带噪输入中减掉，就得到一个预测干净输入的模型。用神经网络的语言说，就是从输入到输出加了一条残差连接。

二者有几点关键区别：

  • 去噪自编码器通常在中间某处有某种信息瓶颈 (Information Bottleneck)，以便学到容量受某种限制的有用输入表示。去噪任务本身只是手段，训练好之后我们真正要用的并不是它。扩散模型所用的神经网络通常没有这种瓶颈，因为我们更关心它的预测，而不是它为了做出预测而在中间构建的内部表示。
  • 去噪自编码器可以用各种类型的噪声训练。例如可以遮掉输入的一部分（掩码噪声），也可以加入从任意分布（通常是高斯分布）采样的噪声。扩散模型通常只用加性高斯噪声，因为它有很好的数学性质，能大大简化许多运算。
  • 另一个重要区别是，去噪自编码器通常只针对某个特定强度的噪声训练。扩散模型则必须能对噪声很多或很少的输入都做出预测。噪声水平作为额外的输入提供给神经网络。

前面说过，我已经在之前的一篇博客里详细讨论过这层关系，如果想更深入地了解，可以去看那篇。

扩散模型是深层隐变量模型Diffusion models are deep latent variable models原文 ↗

Sohl-Dickstein 等人在 2015 年的一篇 ICML 论文中首次提出：用扩散过程逐步破坏数据中的结构，再通过学习逆转这个过程来构造生成模型2。五年后，Ho 等人在此基础上提出了去噪扩散概率模型 (Denoising Diffusion Probabilistic Models, DDPM)3，它和基于分数的模型（见下文）一起构成了现代扩散模型的蓝本。

在这种表述中（见上面的概率图模型），𝐱T（隐变量）表示高斯噪声，𝐱0（观测变量）表示数据分布。两者之间由有限个中间隐变量 𝐱t 连接（通常 T=1000），它们构成一条 Markov 链，即 𝐱t−1 只依赖 𝐱t，不直接依赖链中更早的随机变量。

Markov 链的参数用变分推断 (Variational Inference) 拟合，目标是逆转一个扩散过程。这个扩散过程本身也是一条 Markov 链（方向相反，图中用 q(𝐱t|𝐱t−1) 表示），它逐步向数据中加入高斯噪声。具体来说，和变分自编码器 (Variational Autoencoder, VAE)45 一样，我们可以写出证据下界 (Evidence Lower Bound, ELBO)，即对数似然的一个下界，它可以在计算上可行地最大化。实际上这一节的标题也完全可以叫「扩散模型是深层 VAE」，但我已经把「扩散模型是自编码器」用在了另一种视角上，怕这样会有点混淆。

q(𝐱t|𝐱t−1) 按构造是高斯分布，但我们要用模型拟合的 p(𝐱t−1|𝐱t) 不一定是！不过事实表明，只要每一步足够小（即 T 足够大），就可以把 p(𝐱t−1|𝐱t) 当作高斯分布来参数化，近似误差小到这个模型仍能生成好的样本。仔细想想这有点出人意料，因为采样时任何误差都可能在 T 步中累积。

坦白说，在这篇博客的所有视角中，这大概是我理解得最少的一个。考虑到它这么流行，这有点讽刺，但变分推断对我来说一直有点神秘。我就讲到这里，主要推荐几位详细讲过这一视角的作者（当然还有 DDPM 原论文）：

扩散模型预测分数函数Diffusion models predict the score function原文 ↗

大多数基于似然的生成模型参数化输入 𝐱 的对数似然 log⁡p(𝐱|θ)，再拟合模型参数 θ 使它最大，要么近似地做（如 VAE），要么精确地做（如流模型或自回归模型）。由于对数似然代表概率分布，而概率分布必须归一化，这通常需要一些约束，保证参数 θ 的所有可能取值都给出合法的分布。例如，自回归模型用因果掩码保证这一点，大多数流模型需要可逆的神经网络结构。

其实还有另一种拟合分布的方法，巧妙地绕开了这个归一化要求，叫做分数匹配 (Score Matching)6。它基于这样一个观察：所谓的分数函数 (Score Function) sθ(𝐱):=∇𝐱log⁡p(𝐱|θ) 对 p(𝐱|θ) 的缩放不变。这一点很容易看出：

∇𝐱log⁡(α⋅p(𝐱|θ))=∇𝐱(log⁡α+log⁡p(𝐱|θ))
=∇𝐱log⁡α+∇𝐱log⁡p(𝐱|θ)=0+∇𝐱log⁡p(𝐱|θ).

作用在概率密度上的任意缩放因子都消失了。因此，如果模型直接参数化分数的估计 s^θ(𝐱)，就可以通过最小化分数匹配损失（而不是直接最大化似然）来拟合分布：

ℒSM:=(s^θ(𝐱)−∇𝐱log⁡p(𝐱))2.

不过这种形式的损失函数并不实用，因为对任意数据点 𝐱，我们都没有好办法算出真实的分数 ∇𝐱log⁡p(𝐱)。有几种技巧可以绕开这个要求，把它变成容易计算的损失函数，包括隐式分数匹配 (Implicit Score Matching, ISM)6、切片分数匹配 (Sliced Score Matching, SSM)7 和去噪分数匹配 (Denoising Score Matching, DSM)8。下面细看最后一种：

ℒDSM:=(s^θ(𝐱~)−∇𝐱~log⁡p(𝐱~|𝐱))2.

这里 𝐱~ 是给 𝐱 加上高斯噪声得到的。这意味着 p(𝐱~|𝐱) 服从高斯分布 𝒩(𝐱,σ2)，真实的条件分数函数可以写成闭式：

∇𝐱~log⁡p(𝐱~|𝐱)=∇𝐱~log⁡(1σ2πe−12(𝐱~−𝐱σ)2)
=∇𝐱~log⁡1σ2π−∇𝐱~(12(𝐱~−𝐱σ)2)=0−12⋅2(𝐱~−𝐱σ)⋅1σ=𝐱−𝐱~σ2.

这个形式有非常直观的解释：它就是为了得到 𝐱~ 而加到 𝐱 上的高斯噪声的缩放版本。因此，沿着分数方向使 𝐱~ 的可能性变大（即在对数似然上做梯度上升），恰好对应去掉（一部分）噪声：

𝐱~+η⋅∇𝐱~log⁡p(𝐱~|𝐱)=𝐱~+ησ2(𝐱−𝐱~)=ησ2𝐱+(1−ησ2)𝐱~.

如果取步长 η=σ2，一步就还原出干净数据 𝐱。

ℒSM 和 ℒDSM 是不同的损失函数，但妙处在于它们在期望意义下有相同的最小值点：𝔼𝐱[ℒSM]=𝔼𝐱,𝐱~[ℒDSM]+C，其中 C 是某个常数。Pascal Vincent 早在 2010 年就推出了这个等价关系（那时分数匹配还没流行起来！），如果想加深理解，强烈推荐读他关于这个问题的技术报告8。

这种方法引出的一个重要问题是：应该加多少噪声，即 σ 应该取多少？给这个超参数选一个固定值，实践中效果并不好。噪声水平低时，很难在低密度区域准确估计分数。噪声水平高时这个问题不那么严重，因为加入的噪声把密度往各个方向摊开了，但这样一来，我们建模的分布就被噪声严重扭曲。效果好的做法是在许多不同的噪声水平上建模密度。有了这样的模型，就可以在采样时对 σ 做退火：从大量噪声开始，逐步调小。Song 和 Ermon 在 2019 年的论文中详细描述了这些问题和他们优雅的解法9。

把多个噪声水平上的去噪分数匹配，和采样时对噪声的逐步退火结合起来，得到的模型本质上和 DDPM 等价，但推导方式完全不同，全程看不到 ELBO！想进一步了解这一视角，可以看 Yang Song 关于这个主题的精彩博客。

扩散模型求解反向 SDEDiffusion models solve reverse SDEs原文 ↗

前面两种视角（深层隐变量模型和分数匹配）考虑的都是离散、有限的一组步骤。这些步骤对应不同水平的高斯噪声，可以写出一个单调映射 σ(t)，把步骤编号 t 映射为该步噪声的标准差。

如果让步数趋于无穷，自然可以把离散的编号变量换成区间 [0,T] 上的连续值 t，它可以解释为时间变量，即 σ(t) 现在描述噪声标准差随时间的演化。在连续时间下，逐步向数据点 𝐱 加噪的扩散过程可以用随机微分方程 (Stochastic Differential Equation, SDE) 描述：

d𝐱=𝐟(𝐱,t)dt+g(t)d𝐰.

这个方程把 𝐱 的无穷小变化和 t 的无穷小变化联系起来，d𝐰 表示无穷小的高斯噪声，也就是 Wiener 过程。𝐟 和 g 分别叫做漂移 (drift) 系数和扩散 (diffusion) 系数。𝐟 和 g 取特定形式时，就得到 DDPM 所用 Markov 链的连续时间版本。

SDE 把微分方程和随机变量结合在一起，初看可能有点吓人。好在要理解这一视角对扩散模型有什么用，并不需要太多高深的 SDE 工具。不过有一个非常重要的结论可以利用：给定一个像上面那样描述扩散过程的 SDE，可以写出另一个 SDE，描述反方向的过程，即时间反转的过程10：

d𝐱=(𝐟(𝐱,t)−g(t)2∇𝐱log⁡pt(𝐱))dt+g(t)d𝐰‾.

这个方程同样描述一个扩散过程。d𝐰‾ 是反向的 Wiener 过程，∇𝐱log⁡pt(𝐱) 是随时间变化的分数函数。它随时间变化，是因为噪声水平随时间变化。

解释为什么会这样超出了这篇博客的范围，不过 Yang Song 等人为扩散模型引入 SDE 形式化的原论文11非常值得一读。

具体来说，如果有办法估计随时间变化的分数函数，就可以模拟反向扩散过程，从而从噪声出发采样数据分布。于是我们又一次可以训练一个神经网络来预测这个量，把它代入反向 SDE，得到一个连续时间扩散模型。

实践中，模拟这个 SDE 又要把时间变量 t 离散化，你可能会问这一切有什么意义。妙处在于，离散化现在可以在采样时决定，不必在训练分数预测模型之前就固定下来。换句话说，通过选择采样步数，可以在不改动模型的前提下，非常自然地在样本质量和计算开销之间权衡。

扩散模型是流模型Diffusion models are flow-based models原文 ↗

还记得流模型 (Flow-based Model) 吗1213？如今它们在生成建模中不太流行，我认为主要原因是它们要达到同等性能，往往比其他类型的模型需要更多参数。这源于它们有限的表达能力：流模型中的神经网络必须可逆，而且 Jacobian 的对数行列式必须容易计算，这对可用的计算形式施加了很大的限制。

至少离散的归一化流是这样。Continuous Normalizing Flow (CNF)1415 也存在，它通常的形式是一个由神经网络参数化的常微分方程 (Ordinary Differential Equation, ODE)，描述数据分布的样本与简单基分布（例如标准高斯分布）中对应样本之间的一条确定性路径。CNF 不受上述神经网络结构约束的影响，但按它最初的形式，训练时需要穿过 ODE 求解器做反向传播。虽然有一些技巧可以让这件事更高效，但这大概也是它难以广泛应用的一个障碍。

回到扩散模型的 SDE 表述，它描述的是一个随机过程，把简单基分布的样本映射为数据分布的样本。一个有意思的问题是：中间样本的分布 pt(𝐱) 是什么样的？它如何随时间演化？这由所谓的 Fokker-Planck 方程支配。想看它的具体形式，可以看 Song 等人 (2021)11 的附录 D.1。

下面是最出人意料的一点：存在一个 ODE，它描述一个确定性过程，其随时间变化的分布与 SDE 所描述的随机过程完全相同。这叫做概率流 ODE (Probability Flow ODE)。更妙的是，它有简单的闭式形式：

d𝐱=(𝐟(𝐱,t)−12g(t)2∇𝐱log⁡pt(𝐱))dt.

这个方程同时描述正向和反向过程（把符号反过来就是另一个方向），注意随时间变化的分数函数 ∇𝐱log⁡pt(𝐱) 又一次出现了。要证明这一点，可以分别写出 SDE 和概率流 ODE 的 Fokker-Planck 方程，做些代数运算证明它们相同，因此必然有相同的解 pt(𝐱)。

注意，这个 ODE 描述的并不是和 SDE 相同的过程：那是不可能的，因为确定性的微分方程不可能描述随机过程。它描述的是一个不同的过程，独特之处在于两个过程的分布 pt(𝐱) 相同。Yang Song 博客中概率流 ODE 那一节有一张很好的图，对比了这两个过程。

这件事的意义很深远：简单基分布中的特定样本与数据分布中的样本之间，现在有了一个双射。我们得到这样一种采样过程：全部随机性都包含在初始的基分布样本里，一旦采样了它，从它到数据样本的过程就是完全确定的。这也意味着，可以正向模拟 ODE，把数据点映射为对应的隐表示，对隐表示做操作，再反向模拟 ODE，把它们映射回数据空间。

概率流 ODE 描述的模型就是一个 Continuous Normalizing Flow，只不过我们训练它时不需要穿过 ODE 做反向传播，这让方法的可扩展性大大提高。

这一切都能实现，而且完全不需要改变模型的训练方式，至今在我看来仍像魔法一样。我们可以把分数预测器代入上一节的反向 SDE，也可以代入这一节的 ODE，得到两个以不同方式建模同一分布的生成模型。这真是太妙了。

另外，概率流 ODE 还使扩散模型可以计算似然（见 Song 等人 (2021)11 的附录 D.2）。这同样需要求解 ODE，所以开销和采样差不多。

由于上述种种原因，概率流 ODE 这一范式近来相当流行。例如，Karras 等人16以它为基础，研究了扩散建模中的各种设计选择；我和同事最近在扩散语言模型的工作中也用了它17。它还被推广到扩散过程之外，用来学习任意一对分布之间的映射，例如 Flow Matching18、Rectified Flow19 和 Stochastic Interpolants20。

附注：为扩散模型获得确定性采样过程的另一种方法是 DDIM21，它基于深层隐变量模型的视角。

扩散模型是循环神经网络Diffusion models are recurrent neural networks (RNNs)原文 ↗

从扩散模型采样，需要用神经网络反复做预测，并用这些预测更新一张画布，画布一开始填满随机噪声。如果考虑这个过程的完整计算图，它看起来很像一个循环神经网络 (Recurrent Neural Network, RNN)。RNN 中有一个隐状态，反复经过一个循环单元得到更新，单元由一个或多个带参数的非线性运算组成（例如 LSTM22 的门控机制）。在扩散模型里，隐状态就是画布，所以它位于输入空间，而单元就是我们为扩散模型训练的去噪器神经网络。

RNN 通常用沿时间反向传播 (Backpropagation Through Time, BPTT) 训练，梯度穿过循环传播。为了降低计算开销，反向传播穿过的循环步数常常限制在某个上限以内，这叫做截断 BPTT。扩散模型也用反向传播训练，但每次只穿过一步。在某种意义上，扩散模型提供了一种训练深层循环神经网络的方法，完全不需要穿过循环做反向传播，训练过程因此可扩展得多。

RNN 通常是确定性的，所以这个类比对上一节基于概率流 ODE 的确定性过程最说得通。不过，往 RNN 的隐状态里注入噪声作为正则化手段也并不罕见，所以我认为这个类比对随机过程同样适用。

以非线性层数计，这个计算图的总深度等于神经网络的层数乘以采样步数。可以把展开后的循环本身看作一个非常深的神经网络，可能有成千上万层。这个深度很大，但真实世界数据的生成建模这样有挑战性的任务需要如此深的计算图，也合乎情理。

还可以考虑：如果不在每个扩散采样步都用同一个神经网络，而是对不同的噪声水平范围用不同的网络，会怎样？这些网络可以分别、独立地训练，甚至可以有不同的结构。这实际上相当于在这个非常深的网络中「解绑权重」，把它从 RNN 变成普通的深度神经网络，但仍然不必一次性对整个网络做反向传播。Stable Diffusion XL23 的「Refiner」模型就用这种方法取得了很好的效果，所以我认为它可能会流行起来。

2010 年我开始读博时，训练超过两个隐藏层的神经网络是件苦差事：反向传播直接用效果不好，所以我们用无监督的逐层预训练124找一个好的初始化，让反向传播能够奏效。如今即使几百个非线性层也不再是障碍。因此，几年之后能用反向传播训练上万层的网络，并非不可想象。到那时，扩散模型提供的「分而治之」方法可能就失去光彩了，也许我们都会回去训练深层变分自编码器！（注意，同样的「分而治之」视角也适用于自回归模型，那样的话它们也会过时。）

这个视角引出的一个问题是：如果穿过采样过程的两步或更多步做反向传播，扩散模型是否真的会更好？这种做法并不流行，这大概说明它在实践中不划算。有一个重要的例外（算是吧）：使用自条件 (Self-conditioning)25 的模型，例如 Recurrent Interface Network (RIN)26，除了更新后的画布，还在扩散采样步之间传递某种形式的状态。为了让模型学会利用这个状态，训练时会额外做一次前向计算，提供它的一个近似值。不过并没有额外的反向计算，所以这不算真正的两步 BPTT，更像 1.5 步。

扩散模型是自回归模型Diffusion models are autoregressive models原文 ↗

对自然图像的扩散模型来说，采样过程往往先生成大尺度结构，再迭代地添加越来越精细的细节。事实上，噪声水平和特征尺度之间似乎存在几乎直接的对应关系，我在之前一篇博客的第 5 节详细讨论过。

为什么会这样？用空间频率来思考会有帮助。图像中的大尺度特征对应低空间频率，精细细节对应高频。可以用二维 Fourier 变换（或它的某种变体）把图像分解成各个空间频率分量。这常常是图像压缩算法的第一步，因为已知人类视觉系统对高频敏感得多，压缩时可以对高频比低频压得更狠。

自然图像和许多其他自然信号一样，在频域上表现出一个有意思的现象：各频率分量的幅值往往与频率成反比地衰减27：S(f)∝1/f（如果看的是功率谱而不是幅值谱，则与频率的平方成反比）。

另一方面，高斯噪声的频谱是平的：在期望意义下所有频率的幅值相同。由于 Fourier 变换是线性运算，给自然图像加高斯噪声得到的新图像，其频谱是原图频谱与噪声平坦频谱之和。在对数域中，两个频谱的叠加看起来像一个折线（铰链形状），说明加入噪声掩盖了较高空间频率中的所有结构（见下图）。噪声的标准差越大，受影响的空间频率就越多。

由于扩散模型是通过逐步给输入样本加更多噪声来构造的，可以说这个过程逐渐淹没越来越低频的内容，直到所有结构都被抹去（至少对自然图像是这样）。从模型采样时方向相反，实际上是在越来越高的空间频率上添加结构。这基本上就像自回归，只不过是在频率空间里！Rissanen 等人 (2023) 在用逆热耗散做生成建模（作为高斯扩散的替代）的论文第 2.2 节讨论了这一观察28，不过他们没有把它和自回归模型联系起来。那是我加上去的，为了让这一节有个挑衅性的标题。

一个重要的前提是，这种解释依赖于自然信号的频率特性，所以对其他领域中的扩散模型应用（例如语言建模，见我关于扩散语言模型的博客第 2 节），这个类比可能不成立。

扩散模型估计期望Diffusion models estimate expectations原文 ↗

考虑转移密度 p(𝐱t|𝐱0)，它描述在时刻 t、以原始干净输入 𝐱0 为条件时，（由它加噪得到的）带噪数据样本 𝐱t 的分布。基于这个分布的样本，扩散模型中的神经网络的任务是预测期望 𝔼[𝐱0|𝐱t]（或它的某个随时间变化的线性函数）。这看起来也许有点显然，但我想强调它的一些推论。

第一，它从另一个角度说明了为什么均方误差 (MSE) 是训练扩散模型的正确损失函数。训练时期望 𝔼[𝐱0|𝐱t] 是未知的，所以我们改用 𝐱0 本身来监督模型。由于 MSE 损失的最小值点恰好就是期望，尽管事先不知道 𝔼[𝐱0|𝐱t]，我们最终还是得到了它（的近似）。这和典型的监督学习问题有点不同：那里理想的结果是模型精确预测出用来监督它的目标（不考虑标注错误）。这里我们有意不希望如此。更一般地说，只通过样本提供监督、却能估计条件期望，这一点非常强大。

第二，它解释了为什么扩散模型的蒸馏29303132是如此有吸引力的方案：在这种设定下，我们可以直接用想让模型预测的目标期望 𝔼[𝐱0|𝐱t] 的近似来监督扩散模型，因为教师模型提供的正是这个。结果训练损失的方差比从零训练时低得多，收敛也快得多。当然，前提是手头已经有一个训练好的模型可以当教师。

离散与连续的扩散模型Discrete and continuous diffusion models原文 ↗

到目前为止，我们讲过几种考虑有限个离散噪声水平的视角，也讲过几种使用连续时间概念、再配合映射函数 σ(t) 把时间步映射为对应噪声标准差的视角。它们通常分别称为离散时间和连续时间。很妙的一点是，这主要是解释方式的问题：在离散时间视角下训练的模型，通常很容易改造到连续时间设定下使用16，反之亦然。

扩散模型可以是离散的或连续的，还有另一层含义，就是相对输入空间而言。我发现文献中有时不清楚「连续」或「离散」指的是时间还是输入。这一点尤其重要，因为有些视角只对连续输入真正有意义，它们依赖对输入的梯度（即所有基于分数函数的视角）。

离散与连续的四种组合都存在：

  • 离散时间、连续输入：最初的深层隐变量模型视角 (DDPM)，以及基于分数的视角；
  • 连续时间、连续输入：基于 SDE 和 ODE 的视角；
  • 离散时间、离散输入：D3PM33、MaskGIT34、Mask-predict35、ARDM36、Multinomial diffusion37 和 SUNDAE38 都是在离散输入上做迭代精化的方法。它们是否都该算作扩散模型并不完全清楚（取决于你问谁）；
  • 连续时间、离散输入：连续时间 Markov 链 (Continuous Time Markov Chain, CTMC)39、Score-based Continuous-time Discrete Diffusion Model40 和 Blackout Diffusion41 都把离散输入和连续时间结合起来。这种设定也常常这样处理：把离散数据嵌入欧氏空间，再在那个空间里做输入连续的扩散，例如 Analog Bits25、Self-conditioned Embedding Diffusion42 和 CDCD17。

其他表述Alternative formulations原文 ↗

最近有几篇论文借后见之明，从第一性原理出发重新推导这类模型，完全避开微分方程、ELBO 或分数匹配这些概念。这些工作为扩散模型提供了又一种视角，由于需要的背景知识更少，可能更容易入门。

Inversion by Direct Iteration (InDI)43 是一种源于图像复原的表述，目的是借助迭代精化提高感知质量。它不对图像退化的性质作任何假设，模型在成对的低质量与高质量样本上训练。Iterative α-(de)blending44 以两个不同分布的样本之间的线性插值为出发点，得到两个分布之间的确定性映射。这两种方法也都和前面讨论过的 Flow Matching18、Rectified Flow19 以及 Stochastic Interpolants20 密切相关。

一致性Consistency原文 ↗

最近文献中出现了几种关于扩散模型「一致性」的不同概念：

  • Consistency Model (CM)45 被训练成把概率流 ODE 任意轨迹上的点映射到该轨迹的起点（即干净数据点），从而可以一步采样。具体做法是间接的：在某条轨迹上取成对的点，要求模型对两者的输出相同（「一致性」由此得名）。它有一个从现成扩散模型出发的蒸馏版本，但也可以从零开始训练 Consistency Model。
  • Consistent Diffusion Model (CDM)46 用一个显式鼓励一致性的正则项训练，他们对一致性的定义是：去噪器的预测应当对应条件期望 𝔼[𝐱0|𝐱t]（见前文）。
  • FP-Diffusion47 取描述 pt(𝐱) 随时间演化的 Fokker-Planck 方程，引入一个显式的正则项来保证它成立。

对理想的扩散模型（即完全收敛、容量无限的极限情形），这些性质都平凡地成立。然而真实的扩散模型是近似的，这些性质在实践中往往不成立，所以加入显式强制它们的机制是合理的。

我把这一节放进来，主要是想推荐 Lai 等人 (2023) 最近的一篇论文48，它证明这三种不同的一致性概念本质上是同一件事的不同视角。我觉得这是个非常优雅的结果，也很契合这篇博客的主题！

不守约定Defying conventions原文 ↗

按我的经验，除了概念层面的这些不同视角，扩散文献在重新发明记号、不守约定方面也问题尤其多。有时候，对同一个概念视角的两种描述看起来毫无相似之处。这不利于理解，也抬高了入门门槛。（说清楚，我不是在指责谁。事实上，我怀疑这篇博客本身可能也在加剧这个问题。抱歉。）

还有一些看似无关紧要的细节和参数化选择，可能产生深远的影响。下面是三件需要留意的事：

  • 大体上大家都用 variance-preserving (VP) 扩散过程，即每一步除了加噪，还对当前画布重新缩放以保持总方差。不过 variance-exploding (VE) 表述也有一些追随者，它不做缩放，加入噪声的方差趋于无穷。最著名的是 Karras 等人 (2022)16 使用了它。有些对 VP 扩散成立的结论，对 VE 扩散可能不成立（反之亦然，除非做必要的修改），而论文未必会明说。读扩散论文时，务必弄清它用的是哪种表述，以及是否对它作了任何假设。
  • 扩散模型中的神经网络，有时被参数化为预测（标准化的）噪声，或者预测分数函数；有时则预测干净输入，甚至预测两者随时间变化的组合（例如 𝐯-prediction30）。这些目标在如下意义上等价：它们互为彼此以及带噪输入 𝐱t 的随时间变化的线性函数。但重要的是理解这如何与训练时不同时间步损失贡献的相对权重相互作用，这会显著影响模型性能。不加调整的话，对图像数据，预测标准化噪声似乎是个很好的选择。在建模其他一些量（例如隐空间扩散中的隐变量）时，人们发现预测干净输入效果更好。这主要是因为它隐含了不同的噪声水平权重，因而也隐含了不同的特征尺度权重。
  • 一般的理解是，破坏过程所加噪声的标准差随时间增大，即熵随时间增加，就像在我们的宇宙中那样。因此 𝐱0 对应干净数据，𝐱T（T 足够大）对应纯噪声。有些工作（例如 Flow Matching18）把这个约定反过来，如果没有立刻注意到，会非常困惑。

最后值得一提的是，生成建模语境下「扩散」的定义已经变得相当宽泛，现在几乎等同于「迭代精化」。很多针对离散输入的「扩散模型」其实并不基于扩散过程，但它们当然密切相关，所以这个标签的范围逐渐扩展到包括它们。界线该划在哪里并不清楚：如果任何通过逆转逐步破坏过程来实现迭代精化的模型都是扩散模型，那么所有自回归模型也都是扩散模型。在我看来，这会混乱到让这个术语失去意义。

结语Closing thoughts原文 ↗

现在学习扩散模型，体验想必相当混乱，但对所有这些不同视角的探索，造就了一个丰富的方法工具箱，这些方法都能结合使用，因为归根结底，底层模型始终是同一个。我还发现，了解不同视角之间的关系，大大加深了我的理解。有些在一种视角下很神秘的事，在另一种视角下一目了然。

如果你刚开始接触扩散模型，希望这篇文章能帮你找到接下来该学的东西。如果你已经是经验丰富的扩散研究者，希望我拓宽了你的视角，也希望你仍然学到了一点新东西。感谢阅读！

应用与一句话定义

开场先列应用：Movie Gen 的文生视频、Stable Diffusion 3 的文生图、蛋白质这类几何数据的生成，最近还有机器人动作策略学习。教程按线性顺序讲 Flow Matching 本身，到最后才回头和扩散对照。

生成建模问题：直接映射与逐步生成

整个讲座用一个方框表示全部可能状态（比如所有图像）。给定简单的源分布 p（通常是高斯）和复杂的目标分布 q，生成建模要找一个映射，把 X0∼p 推成 X1∼q。

GAN 这类方法直接学一个映射 X1=Φ(X0)，优点是一次前向就出样本，缺点是没有精确的概率模型，训练需要极小极大，比较脆弱。近年的范式改为逐步生成：用转移函数 Φt+h|t 把 t 时刻的样本推进到 t+h，每一步都比上一步好一点。

三类过程与边际概率路径

逐步生成的过程有三类：流 (Flow) 光滑地移动样本，扩散 (Diffusion) 连续但带局部噪声，跳跃 (Jump) 过程在某个位置停一段随机时间后直接跳到新位置。三者都是连续时间 Markov 过程 Xt，t∈[0,1]。

核心对象是<b>边际概率路径</b> pt：把时间冻结在 t，Xt 的分布就是 pt。构造算法时最关心的是 p0=p、p1=q，这样才能把源样本送进生成过程，推到 t=1 得到目标样本。前两段半都只讲流，因为它是最简单的连续时间 Markov 过程：确定、光滑，采样更快，还能构造似然的无偏估计。

流模型与速度场

流模型由两部分组成：一个微分同胚 (Diffeomorphism) ψt，即可逆、不折叠的空间变形；以及一个源样本 X0。流天然是 Markov 的，因为可逆，所以从 Xt 可以退回 X0 再推到 t+h。

难点在于可逆函数的线性组合一般不可逆，直接参数化流很难。改用速度场 ut(x)：它描述粒子的局部移动方向。两种表示等价，从速度到流要解 ODE \frac{d}{dt}ψt(x)=ut(ψt(x))，需要模拟；从流到速度只需求导。速度场是不受约束的向量场，可以随意相加，这一点贯穿整个教程。代价是训练完之后采样必须模拟 ODE。

训练目标与采样

若速度 ut 定义的流把 p 变形为 pt，就说 ut <b>生成</b> pt。Flow Matching 的目标就是训练一个生成满足 p0=p、p1=q 路径的速度。采样时从源分布抽样，沿速度积分到 t=1；求解器文献很丰富，Lipman 举的例子是二阶的中点法，对流模型效果很好。

最简版本的 Flow Matching

最简版本由三篇同期工作提出（Flow Matching、Rectified Flow、Stochastic Interpolants）。每个训练步：随机抽源样本 X0 和目标样本 X1，均匀抽 t∈[0,1]，算 Xt=(1−t)X0+tX1，把 Xt 送进网络，回归 X1−X0。写成代码只有几行。

这里有两个自由度：X0 和 X1 的分布几乎没有限制；而且二者的联合分布（耦合）可以不独立，比如黑白图和彩色图配对。Lipman 认为这个自由度今后会被越来越多地使用。

由条件流构造边际流

训练时网络在同一位置看到大量互相矛盾的方向，学出来的速度却恰好把 p 推到 q，Lipman 分两步解释。先假设数据集只有一个样本 x1，那么条件流 ψt(x0|x1)=(1−t)x0+tx1 把整个源分布推成 x1 处的 delta 函数，得到条件概率路径 pt|1(x|x1)，对应的条件速度在每一点都指向 x1。

再对所有 x1 求平均。条件概率路径的平均是边际概率路径，这一点比较直观；出人意料的是速度同样成立：在每一点对所有条件速度取条件期望 ut(x)=E[ut(Xt|X1)|Xt=x]，得到的就是生成边际路径的速度。Lipman 强调这里用到的正是速度的线性。

条件损失与 Bregman 散度

边际速度本身是一个对整个数据集的平均，直接回归它算不出来。但最小二乘学到的本来就是条件期望，所以只回归条件速度的 CFM 损失，与回归边际速度的 FM 损失梯度相同，而条件速度对单个样本就能算。

平方范数可以推广为任意 Bregman 散度；Holderrieth 等人的 Generator Matching 证明了 Bregman 散度既充分又必要。更一般地，扩散、分数匹配、Flow Matching 里学的都是某个条件期望 E[Y|X]，用 Y 的样本以 Bregman 散度回归即可，这是这些损失有效的共同原因。

为什么选线性路径

条件流的选择是一个自由度。最优传输里的动能 (Kinetic Energy) 是一个自然的代价，动能最小的路径是匀速直线。边际速度的动能没有闭式解，但由 Jensen 不等式，它被各条件流动能的平均从上方界住，而右边对固定的 x0,x1 显然在直线处取最小。所以线性条件流是在最小化这个上界。

由此得到几条结论：线性路径最小化该上界；它降低初始耦合的动能；数据集只有一个点时它就是最优传输。但对边际速度而言，它<b>不是</b>最优传输，路径不是直线，不能像真正的最优传输那样一步 Euler 采样，Lipman 说这一点常被误解。另一方面，Shaul 等人观察到维度越高路径越直，在约一万维时已经相当直。

仿射路径与几种预测目标

把系数推广为 ψt(x|x1)=αt x1+σt x，即仿射路径。利用条件期望的线性，速度可以改写成源预测（x0 预测）或目标预测（x1 预测）。这些参数化都合法，但换算系数带奇点：源预测在 t=0 附近、目标预测在 t=1 附近。网络不可能完美拟合，奇点处的误差会被放大；速度参数化没有这个问题，这是它更稳定的一个原因。

如果源分布是高斯、耦合独立，这些参数化与扩散里的概率流 ODE 完全重合，噪声预测 (ε) 的奇点在噪声端、x1 预测的奇点在数据端。指南里有一张各种表示之间的换算表。

与扩散模型对比

两者都在构造从 p 到 q 的边际概率路径，区别在构造方式。扩散先定义一个从数据到噪声的前向过程，再反转它；前向过程必须有闭式的条件概率，这通常把它限制在高斯源和独立耦合上，而且有限时间内到不了真正的高斯，这就是噪声预测在源端奇异的来源。Flow Matching 直接把已知如何生成的条件路径聚合起来，源、目标、耦合都可以任意，条件路径也可以更一般（例如下一段的流形情形）。

对高斯仿射路径，Flow Matching 的建议是速度参数化加线性调度；Lipman 提到有论文报告这在大规模生成上带来了性能和效率的提升。

注这里说的「扩散模型」指用确定性 ODE 采样的扩散模型。扩散模型的 v 预测对应余弦调度下的速度，讲者在 29:47 提到了这一点。

这一段记住这几条

  • 速度场是线性对象，可以对条件速度取平均，这是整套方法的根基。
  • CFM 与 FM 梯度相同，原因是最小二乘（更一般是 Bregman 散度）学到的是条件期望。
  • 线性条件路径最小化的是动能的上界，边际流并不是最优传输，低维时明显弯曲。
  • 源预测、目标预测在端点有奇点，速度参数化没有。

条件生成

给定带标签的数据 (X1,Y)，目标是从 q(x1|y) 采样。做法和无条件情形没有本质区别：条件概率路径的构造通常不显式依赖 y（给定 x1，整个源分布照样推向 x1），边际化在给定 y 的条件下进行。训练时同一个网络覆盖所有条件，额外接收标签作为输入，损失里多采样一个 Y。

用途包括类别条件、超分辨率这类逆问题（X1 是高分辨率图，Y 是低分辨率图），以及最常见的文本条件。

引导

每个条件对应很多样本时（类别条件）这种做法很好；但文本条件几乎不重复，一句话通常只对应一张图，模型很难在条件上泛化，生成结果常漏掉描述里的物体。常用的补救是引导：分类器引导由 Bayes 公式把条件分数写成无条件分数加分类器分数；无分类器引导用条件分数和无条件分数隐式地定义分类器。

对高斯路径训练的 Flow Matching 模型，两种引导的公式形式完全相同，只是把分数换成速度。Movie Gen 做过受控消融：同样设置下用 Flow Matching 和扩散损失训练文生视频模型，人类偏好评测中 Flow Matching 在质量（58.3% 对 41.7%）和文本对齐（53.5% 对 46.5%）上都占优。

讲者提出的开放问题：Flow Matching 不要求高斯源，那么非高斯路径的模型应当如何引导，目前还没有答案。

数据耦合

到目前为止都用独立耦合，足以把 p 变成 q。这一部分讨论非独立的耦合能带来什么，讲了两类：配对数据，以及在源和目标之间寻找某种最优耦合的多样本耦合。

配对数据：改源分布而不加条件

Liu 等人（I2SB）和 Albergo 等人（带数据依赖耦合的随机插值）提出另一种条件生成：不把 y 作为网络输入，而是改变源分布和耦合，令 X0=Y+ε，即标签加一点噪声。损失形式不变，只是采样 (X1,Y) 后用 Y 构造 X0。训练好的流从退化图像直接流向干净图像，在超分辨率和修补上比专门设计的扩散方法有明显提升。

多样本耦合：小批量最优传输

回到第 1 段的不等式：边际速度的动能被耦合代价 E\|X1−X0\|2 从上方界住，不同耦合对应不同的 ut，降低上界就可能降低动能。做法是分别从源和目标抽 k 个样本，求使 L2 代价最小的置换（一般是双随机矩阵），再从配对中取样。k=1 退回独立耦合；Pooladian 等人和 Tong 等人证明 k→∞ 时学到的速度生成最优传输映射。这再次说明独立耦合下的 Flow Matching 不是边际最优传输。

实验上耦合代价和学到的流的动能都随批量增大单调下降。但在高维图像上，可能因为轨迹本来就比较直，采样速度只有很小的改进，比不上专门的采样器；在维度较低的科学应用中更有前景，例如 Bose 等人的蛋白质主链设计。

对称数据

以分子为例：表示成张量时，交换原子顺序或整体旋转都不改变分子，这是置换和旋转对称。对称用群描述，我们希望生成模型的密度在群作用下不变，源分布也取不变的分布，概率路径同样要不变。Köhler 等人在 Flow Matching 之前就证明：等变的速度场生成不变的概率路径和等变的流。

因此网络结构要做成等变的，再用 CFM 训练。但独立耦合没有考虑对称性，学出的轨迹往往弯曲；两篇近期工作提出对齐耦合：对 X1 的所有群变换副本，选与 X0 最近的那个配对，降低损失的方差。

Riemann 流形

气候数据在球面上，蛋白质和机器人运动常用 SE(3)、SO(2) 这类流形上的不变表示。Riemann 流形需要两样东西：光滑结构（可以定义切空间）和内积（度量）。速度此时位于切空间，求解 ODE 时沿速度走一小步再投影回流形。损失里的 L2 范数换成 Riemann 度量，损失等价性照样成立。

条件流的构造：对球面、环面、双曲空间这类简单流形，用测地线推广直线，测地线有闭式，训练无需模拟。一般流形上测地线难算，而且会把概率质量堆在边界上（迷宫例子）。Chen 和 Lipman 提出用满足非负、仅在 x=y 处为零、非退化三个条件的预度量 (Premetric) 构造条件流，得到条件速度的闭式表达，代价是需要模拟；例子里用了双调和谱距离。

与 Riemann 分数匹配对比

Riemann Flow Matching 在简单流形上训练无需模拟，而 Riemann 分数匹配连从条件分布采样都没有闭式，必须先模拟 SDE 才能算损失；一般流形上前者只需解 ODE；回归目标上，Flow Matching 有精确的条件速度，分数匹配的条件分数只能近似，引入额外偏差。讲者认为这是 Flow Matching 在流形应用中被广泛采用的原因。

这一段记住这几条

  • 条件生成和引导与扩散一致，高斯路径下只是把分数换成速度；非高斯路径怎么引导还是开放问题。
  • 耦合是可设计的：配对数据可以直接当源分布，小批量最优传输能降低动能，但在高维图像上收益有限。
  • 流形上的 Flow Matching 用测地线或预度量构造条件流，比 Riemann 分数匹配少了模拟和近似。

拉直流：Rectified Flow

Chen 把 Rectified Flow 拆成两步。第一步就是 Flow Matching：随机配对数据和噪声，沿直线插值，学一个匹配同一边际路径的流。流的轨迹不能交叉，所以学出来的流在中间「反弹」，上面的模式去上面、下面的去下面。于是预训练流定义的耦合不再独立，而是把对应的模式连了起来。

第二步用这个模型耦合重新训练：不再从数据集采样，而是从模型自己采样噪声-数据对，再做同样的 Flow Matching。实践中通常只做一次，即先得 1-Rectified Flow，再训练 2-Rectified Flow。InstaFlow 的对比里，Stable Diffusion 配 DPM 求解器在 25 步时很好，1、2、4 步明显不行，8 步也能看出退化；2-Rectified Flow 在各步数下比较一致，25 步出现的铅笔在 1 步时没有出现，仍有一些损失。

主要缺点：强制直线会严重限制模型，常导致样本质量下降。弯曲的流反而更容易用速度建模，速度的 Lipschitz 常数更低；要直线就需要更大的 Lipschitz 常数，接近不连续。

注讲者在 3:00 说论文证明了反复迭代会得到完全直的流和最优传输解。Rectified Flow 论文证明的是递归 rectification 使流越来越直（定理 3.7，O(1/K) 速率），而直线耦合只是最优耦合的必要条件，一维以外不保证最优（第 3.4 节、定理 3.8）。

自一致损失：Shortcut 模型

Frans 等人 2024 年的 Shortcut 模型不拉直流。速度是 h→0 的极限量，Euler 法只是近似；Shortcut 模型多接收一个步长参数 h，直接预测 Xt+h=Xt+h st(Xt,h)，h→0 时退化为速度。训练 h&gt;0 的行为用自一致性：两步小步应当等于一步两倍大的步。训练的主体仍是 Flow Matching 损失，自一致损失只是稀疏地加上。

主要缺点：Shortcut 预测的是轨迹本身，是高度非线性的量，不能像速度那样做线性组合，所以无分类器引导不能直接用。他们的变通办法是训练前固定引导系数，让 Shortcut 直接匹配引导后的轨迹。

只改求解器

一个有用的事实：用某个调度 (αt,σt) 训练的模型，可以换算成另一个调度下的模型，两者只差一个尺度变换和一个按信噪比匹配的时间重参数化，而 (X0,X1) 的耦合完全不变。例子里把模型改成噪声标准差为 10 的调度再用普通求解器采样，不同步数下的结果一致得多。

Bespoke Solver（Shaul 等人）把这一点推进一步：模型不动，在求解器里引入少量参数并只优化它们，可以理解为训练后寻找最好的调度。由于只是数值求解器，步数趋于无穷时仍收敛到原 ODE 的解；在 CIFAR-10 上训练的求解器直接用于 ImageNet 模型，效果和在 ImageNet 上训练的一样。主要缺点：模型参数不更新，达不到完整蒸馏的效果，到不了 1 到 2 次函数求值。

逆问题：后验推断

只在干净图像上训练、不针对退化做任何训练，求解修补、超分辨率、JPEG 复原这类逆问题。把它写成后验推断：p1|Y(x1|y)∝p1(x1)pY|1(y|x1)，退化模型已知。生成后验的速度需要 p(y|xt) 的分数，相当于分类器引导，但不想为每种退化训练带噪分类器。ΠGDM 等方法用一个高斯近似这一项，效果出人意料地好。

主要缺点：要从速度得到分数，只能用高斯路径；而且这是启发式替换，说不清到底在从什么分布采样，偶尔会随机失败。

逆问题：优化源变量

另一种思路完全不依赖模型给的密度。Nalisnick 等人 2018 年的论文指出，生成模型给出的密度很不可靠，会给训练集外的数据更高的密度。而且大规模模型都在隐空间里，观测（图像）与 X1（隐变量）之间隔着解码器，是高度非线性的。

于是把逆问题写成纯优化 \minx1\|f(x1)−y\|2；为了留在数据流形附近，改为优化源变量：\minx0L(ψ1(x0))，预训练流是光滑可逆的微分同胚。这就是 Ben-Hamu 等人的 D-Flow。一张遮掉 90% 的鸟图，十步优化就收敛到合理的结果；同一方法用于文生图、文生音频和按性质生成分子。主要缺点：每步都要模拟并对流求导，开销大约是前一种方法的 10 到 20 倍。

微调：数据驱动与奖励驱动

部署的模型都经过多阶段微调。数据驱动的微调在精选的小数据集上继续训练，重点在数据筛选和防止过拟合。奖励驱动的微调只用一个奖励模型（人类偏好模型，或 CLIP 分数这类图文对齐指标），最朴素的做法是直接最大化 EX1∼pundefined[r(X1)]，可以用强化学习把奖励当黑箱，也可以在奖励可微时直接求梯度（Clark 等人、Xu 等人）。

主要缺点：目标里没有任何东西要求样本保持自然，容易发生奖励作弊。实践中用 LoRA 冻结原模型、只训练新增参数，作为一种启发式的约束。

KL 正则与倾斜分布

借鉴大语言模型的 RLHF，目标是倾斜分布 p^*(x1)∝pbase(x1)\exp(r(x1))。直觉是加一个让微调模型靠近预训练模型的 KL 正则，但对流和扩散模型，KL 只能在整条路径上定义，最优解不是倾斜分布，而是多出一个来自 X0 与 X1 相关性的价值函数偏置。原因是 t=1 的分布同时受初始噪声分布和模型影响。

两种解决办法：Uehara 等人同时学习最优的初始噪声分布；Domingo-Enrich 等人（Adjoint Matching）改用采样过程，使 X0 与 X1 独立，价值函数变成常数，边际就是倾斜分布。

无记忆 SDE

去掉依赖的采样过程是一个「无记忆」SDE：采样早期加入的噪声足以抵消初始噪声的影响。用它从预训练模型采样，图像色彩过于鲜艳，并不来自预训练分布，但理论上微调时应当用它。微调时用无记忆 SDE 采样、优化 KL 正则目标；它保持了分数与速度之间的关系，所以微调完还能换回 ODE 采样，得到自然的图像。

这一段记住这几条

  • 加速有三条路：拉直流（reflow）、预测一段轨迹（shortcut、consistency）、只优化求解器，各有代价。
  • 免训练逆问题可以走后验近似，也可以把预训练流当微分同胚去优化源变量。
  • 奖励微调若想得到 RLHF 式的倾斜分布，要先去掉初始噪声与样本的相关性，这就是无记忆 SDE 的作用。

连续与离散空间上的过程

连续空间上有流、扩散、跳跃三类过程；限制到离散空间（文本、代码），连续的生成过程不存在，流和扩散都不成立，只剩跳跃过程，也就是连续时间 Markov 链 (Continuous Time Markov Chain, CTMC)：时间连续，状态离散。

转移核与生成元

这些过程都可以用转移核 pt+h|t(·|x) 统一描述：输入当前状态，输出下一状态的分布。要推广 Flow Matching，首先要找到转移核的线性表示，因为速度的线性是规模化的关键。Generator Matching 的做法是对转移核按 h 做一阶展开：零阶项是 delta 函数（h=0 时原地不动），一阶项是一个总和为零的「概率导数」，称为<b>生成元</b> (Generator)。生成元不含 h，和速度一样描述瞬时变化。

采样

采样时从 X0 出发，丢掉 o(h) 项，用学到的生成元乘 h 加到 delta 函数上得到下一步分布，再从中抽样。Lipman 指出这类过程目前基本只有这种 Euler 式采样，没有流那样丰富的求解器。

Generator Matching

Holderrieth 等人证明，同一套「套路」在这种抽象下依然成立：以单个目标样本为条件，设计一条从源到 x1 处 delta 函数的条件概率路径，以及生成它的条件生成元。这是整个算法里唯一需要创造性的地方，要解 Kolmogorov 前向方程（指南里详细讨论了），不是总能做到。做到之后，条件路径的平均是边际路径，条件生成元的平均就是生成边际路径的生成元，因为生成元是线性的；训练仍是用 Bregman 散度回归条件期望。

离散 Flow Matching

按时间顺序，离散 Flow Matching（Campbell 等人、Gat 等人）其实早于 Generator Matching，这里为讲解方便倒过来讲。目标是做出能和自回归模型竞争的文本、代码生成，Lipman 坦言目前还差得远，但设计空间很大，希望其中有能胜过自回归的方案。状态是 token 序列，过程在每个状态停留一段时间后跳到另一状态，转移核写成单位阵加 h 乘一个列和为零的速率矩阵。

因子化速度

直接预测到所有状态的速率不可行：1000 个 token、5 万词表时需要 500001000 个输出。Campbell 等人 2022 年的办法是因子化速度：只允许一次改变一个 token（位置任意），输出量变成 1000×50000，与自回归模型同一量级。连续情形下的速度其实也是逐坐标的，只是连续空间里无穷小的变化彼此感知，离散空间里各 token 的跳变则较稀疏。

混合路径与损失

要学到因子化速度，条件概率路径也必须按 token 因子化。最常用的是混合路径 (Mixture Path)：每个 token 以概率 1−t 来自源分布（掩码或随机 token），以概率 t 取目标 token。对应的条件速度只指向正确的 token，系数在 t→1 时发散，保证最终一定跳到目标。训练只需要能采样带噪序列并算出条件速度；Bregman 散度取 KL 时，损失就是交叉熵。Lipman 提到其他路径还很少有人探索。

代码生成实验

Gat 等人把方法扩展到 1.7B 参数做代码任务。HumanEval pass@1 上，同规模自回归模型是 14.3%，离散 Flow Matching 是 6.7%；如果告诉模型答案的正确长度，提高到 11.6%，差距缩小了不少，这本身是个值得研究的问题。由于不是自回归，可以固定任意部分只补全其余部分。

离散流的开放问题

三个问题：如何超越因子化速度，一次预测多个 token 的联合变化；如何为非流的过程设计更好的采样器；以及如何在巨大的设计空间里搜索，包括过程类型、边际路径、可以任意叠加的无散度 (Divergence-free) 分量（得到边际相同的随机采样），以及 Generator Matching 提出的多个生成元的组合。最后一页把 Flow Matching 归结为一张蓝图：它能推广到这么多过程和模态，说明还有大量改进空间。

这一段记住这几条

  • 生成元是转移核的一阶项，是速度在任意连续时间 Markov 过程上的推广，同样是线性的。
  • 离散 Flow Matching 用因子化速度和混合路径，损失退化为交叉熵。
  • 代码生成上与自回归还有明显差距（6.7% 对 14.3%），已知长度时缩小到 11.6%。
