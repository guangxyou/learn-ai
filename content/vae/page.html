1概述：编码器输出分布的自编码器

变分自编码器 (Variational Autoencoder, VAE) 是一种带连续隐变量的生成模型，由 Diederik P. Kingma 和 Max Welling 在 2013 年提出。

结构上它和自编码器相同，由编码器和解码器组成，区别在中间层：编码器对每个输入 x 输出一个高斯分布 qφ(z|x) 的均值和方差，训练时从这个分布采样 z 再送进解码器；损失函数除了重建误差，还有一项 KL 散度，要求这些高斯分布接近标准正态分布 N(0, I)。

训练完成后，生成新样本只需要解码器：从 N(0, I) 采样一个 z，经解码器得到一张训练集里没有的图。编码器在训练时提供近似后验，训练后可以用来把数据映射到隐空间，做表示学习、插值或压缩。

名称里的「变分」来自 变分推断 (Variational Inference)：用一族简单分布去近似难以计算的后验分布，并把近似的质量写成一个可以优化的下界。

「自编码器」指的是这套推断方法在用神经网络实现时，形式上恰好是一个编码器接一个解码器。原论文把方法称为 Auto-Encoding Variational Bayes (AEVB)，VAE 是其中用多层感知机实现的那个例子。

2来历：变分推断与神经网络的结合

2013 年以前，和 VAE 相关的工作分在两条线上。

一条是神经网络里的 自编码器 (Autoencoder)。Hinton 和 Salakhutdinov 2006-07-28 在 Science 上发表的深层自编码器，用瓶颈结构把图像压缩为低维编码，再还原回去。它学到的是一个确定性映射，隐空间里编码点的分布没有任何约束，所以不能直接从隐空间采样来生成新图。

另一条是概率图模型里的 隐变量模型 (Latent Variable Model) 和变分推断。假设每个样本背后有一个看不见的隐变量 z，学习时需要后验 p(z|x)，而后验通常算不出来。

经典的平均场变分推断要求对近似后验解析地求期望，只适用于共轭指数族这类结构简单的模型；Hoffman 等人的随机变分推断 (Stochastic Variational Inference, arXiv 2012-06-29) 把它扩展到大数据集，但对模型形式的要求不变。

基于采样的方法（例如 Monte Carlo EM）对每个样本都要跑一段马尔可夫链，数据量大时代价太高。Hinton、Dayan、Frey 和 Neal 1995-05-26 在 Science 上提出的 wake-sleep 算法已经用一个识别网络来近似后验，但它交替优化的两个目标合起来并不对应边际似然或它的某个下界。

Kingma 和 Welling（阿姆斯特丹大学）2013-12-20 在 arXiv 上发表《Auto-Encoding Variational Bayes》，2014-04 在 ICLR 2014 报告。论文摘要里列了两点贡献：一是对变分下界做重参数化，得到一个可微、无偏、能用标准随机梯度法优化的估计量，称为 SGVB (Stochastic Gradient Variational Bayes)。

二是在独立同分布数据、每个样本一个连续隐变量的设定下，用一个识别模型（编码器）对所有样本统一给出近似后验，称为 AEVB。两点合起来，隐变量模型的推断和学习都可以用一个网络、一次反向传播完成。

DeepMind 的 Rezende、Mohamed 和 Wierstra 独立提出了几乎相同的方法，2014-01-16 发到 arXiv，题为《Stochastic Backpropagation and Approximate Inference in Deep Generative Models》，2014-06 在 ICML 2014 发表。文献里常把两篇并列引用。

VAE 之后成为生成模型和表示学习的基础方法之一。ICLR 2024（2024-05）把时间检验奖 (Test of Time Award) 授给了这篇论文。Kingma 和 Welling 2019-06-06 发表了一篇长综述《An Introduction to Variational Autoencoders》，系统整理了 VAE 及其扩展。

3要解决的问题：隐变量模型的计算难点

原论文的设定是一个有向隐变量模型：每个样本 xi 由一个连续隐变量 zi 生成，先从先验 p(z) 采样 z，再从条件分布 pθ(x|z) 生成 x。θ 是生成模型的参数。要学 θ，就要算数据的边际似然；要知道某张图对应什么样的 z，就要算后验：

pθ(x) = ∫ pθ(x|z) p(z) dz边际似然：对所有可能的 z 积分
pθ(z|x) = pθ(x|z) p(z) / pθ(x)后验：分母就是上面那个积分

当 pθ(x|z) 是一个神经网络时，这个积分没有解析解；z 是几十维的连续向量，数值积分也做不了。后验的分母是同一个积分，所以也算不出来。原论文第 2.1 节把这种情况称为 不可解 (Intractable)，并额外假设数据集很大，按全量数据更新一次参数的方法代价太高。

在这个设定下，论文要同时解决三件事：

  • 参数 θ 的近似最大似然或最大后验估计，用来学一个能生成数据的模型；
  • 给定 x 时隐变量 z 的近似后验推断，用来做表示和编码；
  • x 的近似边际推断，用于去噪、补全、超分辨率这类需要 p(x) 先验的任务。

已有方法在这个设定下各有缺陷：

方法需要什么在这个设定下的问题
EM 算法E 步要算真实后验后验不可解
平均场变分推断对近似后验解析地求期望模型含神经网络时期望不可解
Monte Carlo EM对每个样本跑一段 MCMC 采样后验每个样本都要迭代采样，大数据集上太慢

4整体结构：三个分布、两个网络

VAE 里有三个分布，其中两个由神经网络给出参数：

记号形式参数
先验 (Prior)p(z)N(0, I)无，固定
编码器，即近似后验qφ(z|x)对角高斯，均值和方差由网络输出编码器权重 φ
解码器，即似然pθ(x|z)伯努利或高斯，参数由网络输出解码器权重 θ

训练一步的流程（对应上面的架构图）：

  • 取一个小批量的样本 x；
  • 编码器对每个 x 输出 μ 和 log σ2；
  • 对每个样本独立采样 ε ∼ N(0, I)，计算 z = μ + σ ⊙ ε；
  • 解码器从 z 输出重建分布的参数，计算重建项 −log pθ(x|z)；
  • 用 μ、σ 按解析式计算 KL 项 KL(qφ(z|x) ‖ p(z))；
  • 两项相加取批量平均作为损失，反向传播，同时更新 θ 和 φ。

生成只用解码器：从 N(0, I) 采样 z，取解码器输出分布的均值作为生成结果。

编码器的做法叫 摊销推断 (Amortized Inference)。传统变分推断给每个样本单独维护一组变分参数 (μi, σi)，N 个样本就有 N 组，每来一个新样本都要重新优化。VAE 用一个网络 μφ(x)、σφ(x) 统一输出这些参数，推断一个新样本只需要一次前向计算，代价是网络给出的近似不一定是这一族里最好的那个。

5编码器：输出对角高斯的参数

编码器把 x 映射为一个对角协方差的高斯分布：

qφ(z|x) = N(z; μφ(x), diag(σφ2(x)))均值和方差都是 x 的函数
h = tanh(W3 x + b3)原论文附录 C 的编码器：一个隐藏层
μ = W4 h + b4, log σ2 = W5 h + b5两个线性输出头

输出 log σ2 而不是 σ，是因为方差必须为正，而网络输出可以取任意实数。取对数以后任何实数都对应一个合法的方差，使用时取指数即可；KL 项的解析式里本来就含 log σ2。

协方差取对角阵有三个原因：完整协方差矩阵有 d2 个参数，还要保证正定；对角高斯的采样和 KL 都只需要逐维计算；原论文第 3 节明确假设真实后验近似为高斯，协方差近似为对角。代价是给定 x 时各维隐变量被假设为条件独立，真实后验里维度之间的相关性无法表示。后来的标准化流 (Normalizing Flow) 和逆自回归流 (Inverse Autoregressive Flow) 就是为了放宽这一点。

每个样本有自己的 μi、σi。同一个编码器对不同的图给出不同位置、不同宽度的高斯，宽度反映编码器对这张图的 z 有多确定。

6重参数化：让采样操作可导

重建项是一个按 qφ 取的期望 Ez∼qφ(z|x)[log pθ(x|z)]，要对 φ 求梯度。困难在于期望所依赖的分布本身含有 φ，而「从分布中采样一个数」这个操作对分布参数没有导数，反向传播在采样节点处中断。

一种通用的做法是得分函数估计量 (Score Function Estimator，也叫 REINFORCE)：

∇φ Eq[f(z)] = Eq[f(z) ∇φ log qφ(z|x)]只需要能对 log q 求导，不需要 f 可导

它是无偏的，但方差很大。原论文第 2.3 节指出这个朴素估计量方差过高，实际上无法使用。

重参数化技巧 (Reparameterization Trick) 把随机性移到一个不依赖 φ 的辅助变量 ε 上，z 写成 ε 的确定性函数：

ε ∼ N(0, I), z = μφ(x) + σφ(x) ⊙ εz 的分布仍然是 N(μ, σ2)
Ez∼qφ[f(z)] = Eε∼N(0, I)[f(μφ(x) + σφ(x) ⊙ ε)]期望改为对 ε 取，ε 的分布不含 φ
∇φ Eε[f(z)] = Eε[∇φ f(μφ(x) + σφ(x) ⊙ ε)]梯度可以移进期望，按链式法则逐层计算

改写后 z 对 μ 的导数是 1，对 σ 的导数是 ε，梯度经 z 回传到编码器。这个估计量利用了 f 对 z 的导数信息，方差比得分函数估计量低得多。

原论文第 2.4 节给出了三类可以这样改写的分布：逆累积分布函数可解的分布（指数、柯西、Logistic 等），位置-尺度族（高斯、拉普拉斯、学生 t 等，取标准分布作 ε，z = 位置 + 尺度 × ε），以及可以写成辅助变量变换组合的分布（对数正态、Gamma、Dirichlet、Beta 等）。离散分布不在其中，后来 2016-11 的 Gumbel-Softmax 和 Concrete 分布用连续松弛解决了离散变量的重参数化。

7解码器与重建项

解码器输出的是一个分布 pθ(x|z) 的参数，重建项是这个分布下输入 x 的对数似然。分布按数据类型选，选定分布就确定了重建损失的形式：

解码器分布网络输出重建损失 −log pθ(x|z)原论文用在
伯努利每个像素为 1 的概率，sigmoid 输出二元交叉熵 (Binary Cross-Entropy)MNIST（像素接近二值）

高斯，方差固定为 σ2均值‖x − μ‖2 / (2σ2) 加常数，即 L2 损失后来的大多数实现
拉普拉斯，尺度固定中心L1 损失后来的部分实现

重建项按 q 取期望，用蒙特卡洛估计：采样 L 个 z，对 log pθ(x|zl) 取平均。原论文第 2.3 节指出，只要小批量足够大（M = 100），每个样本采样一次（L = 1）即可。单样本估计是无偏的，噪声在批量和训练步数上被平均掉。

生成和重建时，通常直接取解码器输出分布的均值（伯努利的概率、高斯的均值）作为图像，不再从这个分布里采样像素噪声。

固定方差的高斯解码器里，σ2 决定了重建项相对 KL 项的权重：σ2 越小，重建误差被放大得越多，结果越接近普通自编码器。这和下文 β-VAE 调 KL 系数是同一件事的两种写法。

8KL 项：两个高斯之间的解析式

近似后验和先验都是高斯时，KL 散度可以直接积分出来，不需要采样。原论文附录 B 给出了这个结果，J 是隐变量维数：

KL(N(μ, diag σ2) ‖ N(0, I)) = ½ Σj=1J (μj2 + σj2 − 1 − log σj2)各维独立，逐维相加

每一维的式子由两部分组成：μj2 惩罚均值偏离原点；σj2 − 1 − log σj2 在 σj = 1 时取最小值 0，方差变小或变大都会增加它。σ 趋于 0 时 −log σ2 趋于无穷，所以 KL 项阻止编码器把每张图映射为一个确定的点；没有这一项，VAE 会退化为普通自编码器。

原论文给出了两个版本的 SGVB 估计量：版本 A 对整个下界做蒙特卡洛估计；版本 B 解析地计算 KL 项，只对重建项采样。版本 B 的方差更小，是实际使用的版本。

9证据下界：这个损失为什么成立

上面两项损失并不是凭经验拼出来的，它们来自对 log p(x) 的一个恒等变形。对任意分布 q(z|x)：

log pθ(x) = Eq[log pθ(x)]log p(x) 和 z 无关，对 q 取期望不变
= Eq[log (pθ(x, z) / pθ(z|x))]贝叶斯公式
= Eq[log (pθ(x, z) / qφ(z|x))] + Eq[log (qφ(z|x) / pθ(z|x))]分子分母同乘 q 后拆开
= ELBO(θ, φ; x) + KL(qφ(z|x) ‖ pθ(z|x))第二项正好是 KL 的定义

第一项叫 证据下界 (Evidence Lower Bound, ELBO)。证据指 log p(x)；KL 散度非负，所以 ELBO ≤ log p(x)，等号在 q 等于真实后验时成立。ELBO 里只有 pθ(x|z)、p(z)、qφ(z|x) 这些能算的量，把联合分布拆开就得到 VAE 的两项：

ELBO = Eqφ(z|x)[log pθ(x|z)] − KL(qφ(z|x) ‖ p(z))重建项减去 KL 项，原论文式 (3)

训练损失取 −ELBO 的批量平均。同时对两组参数求梯度，效果不同：对 φ，log p(x) 是常数，增大 ELBO 只能通过减小间隙 KL(q ‖ pθ(z|x)) 实现，即让编码器给出的 q 更接近真实后验；对 θ，ELBO 是 log p(x) 的下界，增大它会把 log p(x) 一起推高。

同一个结果也可以用 Jensen 不等式一步得到：log pθ(x) = log Eq[pθ(x, z) / qφ(z|x)] ≥ Eq[log (pθ(x, z) / qφ(z|x))]。这种写法说明了 ELBO 是下界，但看不出间隙具体是什么。

10训练算法与最小实现

原论文的算法 1 是小批量版本的 AEVB：

  • 初始化参数 θ、φ；
  • 从完整数据集中随机取 M 个样本组成小批量；
  • 对每个样本采样噪声 ε ∼ p(ε)；
  • 计算小批量 ELBO 估计量对 θ、φ 的梯度；
  • 用随机梯度下降或 Adagrad 等随机优化方法更新 θ、φ；
  • 重复从取小批量到更新参数的步骤，直到收敛。

原论文第 5 节的实验设置：小批量 M = 100，每个样本 L = 1；所有参数从 N(0, 0.01) 随机初始化。

优化器用 Adagrad，全局步长从 {0.01, 0.02, 0.1} 中按前几轮的训练集表现选取；加一个小的权重衰减，相当于参数上的先验 N(0, I)。编码器和解码器各一个隐藏层，MNIST 用 500 个隐藏单元，Frey Face 用 200 个（数据集小，防止过拟合）；隐变量维数取 3、5、10、20、200 做对比。

原论文第 5 节有一处笔误：原文写「生成模型（编码器）和变分近似（解码器）」，两个括号里的词写反了，生成模型是解码器，变分近似是编码器。

下面是一个 MNIST 上的最小实现，结构和原论文一致（单隐藏层多层感知机、伯努利解码器、解析 KL、单样本重参数化），激活函数换成 ReLU，优化器换成 Adam：

import torch, torch.nn as nn, torch.nn.functional as F
from torchvision import datasets, transforms

class VAE(nn.Module):
    def __init__(self, d_in=784, d_h=400, d_z=20):
        super().__init__()
        self.enc = nn.Linear(d_in, d_h)
        self.mu, self.logvar = nn.Linear(d_h, d_z), nn.Linear(d_h, d_z)
        self.dec = nn.Sequential(nn.Linear(d_z, d_h), nn.ReLU(), nn.Linear(d_h, d_in))

    def forward(self, x):
        h = F.relu(self.enc(x))
        mu, logvar = self.mu(h), self.logvar(h)
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)   # 重参数化
        return self.dec(z), mu, logvar                            # 解码器输出 logits

def loss_fn(logits, x, mu, logvar):
    rec = F.binary_cross_entropy_with_logits(logits, x, reduction='sum')   # 伯努利解码器
    kl = 0.5 * torch.sum(mu.pow(2) + logvar.exp() - 1 - logvar)          # 附录 B 的解析式
    return (rec + kl) / x.size(0)                                         # −ELBO 的批量平均

11两项损失的平衡与隐空间的形状

两项损失对编码器的要求方向相反。重建项要求不同输入的 q 彼此分开、方差尽量小，这样解码器拿到 z 时能确定它来自哪张图；KL 项要求每个 q 都接近 N(0, I)，均值靠近原点、方差接近 1。训练的结果是一个折中：相似的图编码到相邻且部分重叠的区域，所有样本的 q 合起来大致覆盖先验的高概率区域。

这带来两个性质。一是连续性：隐空间里相邻的点解码出相似的图，两张图的编码之间做线性插值，中间点解码出来是平滑过渡。二是可采样性：从 N(0, I) 采样的 z 大多落在训练样本的 q 覆盖到的区域，解码器在这些位置受过训练。普通自编码器两者都没有保证，编码点之间的空白区域解码出来往往不像任何一张图。

原论文附录 A 用二维隐空间展示了这一点：在单位正方形上取等间距网格，经标准正态分布的逆累积分布函数映射成 z，再逐个解码。MNIST 的结果里，数字的类别和笔画粗细、倾斜在平面上连续变化。

二维是为了画图。原论文第 5 节的实验表明，隐变量维数从 3 增加到 200，下界没有出现过拟合，作者把这归因于变分下界自带的正则化作用。维数多余时，KL 项会使用不上的维等于先验（μ = 0、σ = 1），这些维不携带信息。

14后续发展

下界与后验改进。 Rezende 和 Mohamed 的标准化流（2015-05-21）用一串可逆变换把对角高斯变成更复杂的分布，近似后验不再限于对角高斯。Burda 等人的重要性加权自编码器 (Importance Weighted Autoencoder, IWAE，2015-09-01) 从 q 采样 K 个 z 做重要性加权，得到比 ELBO 更紧的下界，K = 1 时退化为 ELBO。

Kingma 等人的逆自回归流（2016-06-15）提出一种计算量随维数线性增长、能用于高维隐变量的流，同一篇还提出了缓解后验坍缩的 Free Bits。

条件生成与半监督。 Kingma 等人 2014-06-20 的半监督模型 M2 把类别标签当作一个部分观测的隐变量，在只有少量标注时做分类和按类生成。Sohn 等人的条件 VAE（NeurIPS 2015，2015-12）让编码器、解码器和先验都以条件 y 为输入，用于结构化输出预测。Bowman 等人 2015-11-19 把 VAE 用在句子生成上，描述了 KL 项降到 0、隐变量不起作用的问题（后来称为后验坍缩），并提出 KL 退火。

先验与解耦。 Higgins 等人的 β-VAE（ICLR 2017，2017-04）给 KL 项乘一个大于 1 的系数，换取各维隐变量对应可解释的独立变化因素，代价是重建质量下降。Tomczak 和 Welling 的 VampPrior（2017-05-19）把先验换成一组可学习伪输入的近似后验的混合，减小先验和聚合后验之间的差距。

层级隐变量。 Sønderby 等人的 Ladder VAE（2016-02-06）用多层隐变量自上而下地生成。Vahdat 和 Kautz 的 NVAE（2020-07-08）用深层残差结构和多尺度层级隐变量，第一次让 VAE 在 256×256 的人脸上生成清晰图像。Child 的 VDVAE（2020-11-20）把层级加深到几十层，在多个图像数据集的似然指标上超过了 PixelCNN 等自回归模型。

离散隐变量。 van den Oord 等人的 VQ-VAE（2017-11-02）把编码器输出替换为码本里最近的向量，先验改为在离散编码上训练的自回归模型；VQ-VAE-2（2019-06-02）加入两级层级。

Esser 等人的 VQGAN（2020-12-17）在此基础上加感知损失和对抗损失，压缩率更高、重建更清晰。OpenAI 的 DALL·E（2021-02-24）用离散 VAE（dVAE）把 256×256 的图压缩为 32×32 个编码，再让 Transformer 在文字和图像编码的序列上建模。

作为图像压缩器。 Rombach 等人的 Latent Diffusion（2021-12-20）训练一个自编码器把图像压到低维隐空间，KL 正则版本的 KL 权重约为 10−6，再加感知损失和图块判别器，然后在隐空间里训练扩散模型。

2022-08-22 发布的 Stable Diffusion 即采用这一结构，512×512×3 的图压缩为 64×64×4 的隐表示。此后的 SDXL（2023-07-04）重新训练了同结构的自编码器，Stable Diffusion 3（2024-03-05）把隐通道数从 4 增加到 16。视频生成模型沿用同样的思路，例如 Wan 2.1（2025-03-26）用一个因果三维 VAE 在时间和空间上同时压缩视频。

这条线上，VAE 的角色发生了变化。2013 年的 VAE 同时负责压缩和生成，KL 项保证隐空间可以采样。到 Latent Diffusion，KL 权重小到几乎可以忽略，隐空间的分布由扩散模型学习，VAE 只保留编码器加解码器的结构和一个很弱的正则项。

符号与概率

xi 指的是一张图，还是整个数据集？

一张图。数据集是 x1 … xN，xi 是其中第 i 张，下标只是编号。CS231n 课件写成上标 x(i)，也是这个意思。

所以 pθ(z|xi) 是这一张图的后验：看到这张图以后，它的 z 可能在哪。每张图有自己的一份后验，编码器也是一张一张地算，对第 i 张图输出它自己的 μi 和 σi。

和整个数据集有关的是两样东西。一是训练目标：样本独立时，数据集的对数似然是每张图的对数似然之和，实际训练时一个批次里每张图各算一份 ELBO，再取平均。二是「所有图的 q 合在一起」的那个分布：

q(z) = (1/N) Σi qφ(z|xi)所有训练图的近似后验取平均

单张图的 qφ(z|xi) 是一个偏离原点的小高斯，KL 项只是把它往 N(0, 1) 拉。所有图的小高斯合起来，整体才接近 N(0, 1)。视频里那三张二维隐空间图，每个点是一张图编码出的 z，画的就是这个合起来的分布。

z ∼ q 是什么意思？

读作「z 服从分布 q」：z 是一个随机变量，取各个值的概率由 q 决定；也可以理解成 z 是从 q 里抽出来的一个样本。∼ 就是「服从」或「从……采样」。

写在期望下标里，Ez∼q[f(z)] 的意思是 z 按 q 的概率取值，对 f(z) 求平均，常简写成 Eq。在变分自编码器里，q 是 qφ(z|xi) = N(μi, σi2)，z ∼ q 就是从编码器给第 i 张图算出的高斯里抽一个 z，具体做法是先抽 ε ∼ N(0, 1)，再算 z = μ + σε。

比如某张图编码得到 μ = 2、σ = 0.5，抽出来的 z 大多在 2 附近，约 95% 落在 1 到 3 之间。

KL 散度：期望 →

KL 散度为什么是积分的形式，为什么又能写成期望？

积分是因为 z 连续。z 只取有限几个值时，KL 散度是求和 Σz q(z) log [q(z)/p(z)]；z 是连续向量时，q(z) 变成概率密度，求和就换成积分。两者是同一个东西。

能写成期望，是因为期望的定义本身就是这个形状：Eq[f(z)] = ∫ q(z) f(z) dz，用 q(z) 当权重给 f(z) 加权平均。f 取 log(q/p)，就是 KL 的积分。

写成期望有两个用处。一是期望是线性的，减号能拆开，ELBO 的推导一路靠这个。二是积分算不出来时，可以从 q 里采样取平均来估计，重建项就是这么算的。两个高斯之间的 KL 恰好能积出解析式，所以 KL 项不用采样。

KL(q ‖ p) 衡量的是两个分布的相似度吗？为什么 q 在前？

衡量的是差异：两个分布一样时为 0，差得越多越大。它不对称，KL(q ‖ p) 和 KL(p ‖ q) 一般不等，所以不算距离，只叫散度。两枚硬币 q = (0.5, 0.5)、p = (0.9, 0.1)，一个方向 0.511，另一个方向 0.368。

q 在前是因为只有这个方向算得动。期望按 q 取，q 是编码器的高斯，能采样也能算密度；真实后验只出现在 log 里，可以拆成 log p(z, x) − log p(x)，后一项和 z 无关，成了常数。反过来要按真实后验取期望，得先能从后验采样，而这做不到。

副作用是 q 偏窄：KL(q ‖ p) 重罚「q 放到了 p 很小的地方」，所以 q 宁可缩在后验的一个峰里。

「变分」是什么意思？

来自变分法：优化的对象是一个函数，而不是一个数。变分推断 (Variational Inference) 里，要找的是一个分布 q，让它最接近算不出来的后验。

直接在所有分布里找没法做，所以限定在一族简单分布里，比如对角高斯，问题就变成优化这一族的参数 μ、σ。变分自编码器再进一步，不为每张图单独优化一组参数，而是训练一个网络，输入图、输出这张图的 μ 和 σ，这个网络就是编码器。

模型与训练

为什么不先训练一个普通自编码器，再给所有 z 拟合一个高斯？

能做，但效果一般。普通自编码器的隐空间没有约束，编码出来的点聚成形状不规则的几块，块之间有大片空白。用一个高斯去拟合，采样会大量落在空白处，解码出来不像图。视频里「只有重建损失」那张图就是这个样子。

变分自编码器的 KL 项在训练时就把隐空间往 N(0, 1) 上压，空白少得多。反过来，如果用一个足够强的模型去学隐空间的分布，这条路是走得通的：Latent Diffusion 就是先训练一个几乎不加约束的自编码器，再用扩散模型去学隐向量的分布。

为什么要重参数化？

重建项要按 qφ 取期望，而 qφ 依赖编码器的参数 φ。「从一个依赖 φ 的分布里抽一个样本」这个动作没有梯度，反向传播到这里就断了。

重参数化把它改写成先抽一个和 φ 无关的 ε ∼ N(0, I)，再算 z = μ + σ ⊙ ε。随机性全在 ε 里，z 是 μ、σ 的普通函数，梯度能照常传回编码器。

每张图每一步只采一个 z，够吗？

够。单个样本的估计没有偏差，只是噪声大；训练要跑几万步，每步又是一整个批次的图，噪声会被平均掉。原论文 (Kingma 和 Welling) 第 2.3 节说，批量取 100 时每个样本采一次就行。

多采几个 z 会让每一步的梯度更稳，但计算量成倍增加，一般不划算。

编码器为什么常输出 log σ2，而不是 σ？

方差必须是正数，网络的输出却可正可负。让网络输出 log σ2，任何实数都对应一个合法的方差，用的时候取指数就行。KL 公式 ½ Σ (μ2 + σ2 − 1 − log σ2) 里本来就有 log σ2，直接用。

解码器输出的是一个分布，还是一张图？

名义上是分布，实际上用的是图。解码器输出像素高斯的均值，方差固定为常数；训练时算这个高斯的对数似然，生成时直接拿均值当输出，从不在均值上再加噪声。

方差固定时，对数似然就是 −‖x − μ‖2/(2σ2) 加常数，最大化它等价于最小化 L2 损失。σ2 越小，重建项相对 KL 项越重。

CS231n：神经网络怎么输出一个分布 →

手写数字上为什么常用二元交叉熵当重建损失？

因为解码器换了一个分布。MNIST 的像素接近非黑即白，可以把每个像素当成伯努利分布，解码器输出它是白色的概率。伯努利分布的对数似然就是二元交叉熵 (Binary Cross-Entropy)。原论文在 MNIST 上用的就是伯努利解码器，在人脸数据上用高斯解码器。

规律是一样的：解码器假设什么分布，重建损失就是这个分布的负对数似然。高斯对应 L2，拉普拉斯对应 L1，伯努利对应二元交叉熵。

生成和重建的时候，用 μ 还是采样？

生成新图：从先验 N(0, I) 采 z，过解码器。

重建或者拿 z 当特征：一般直接用编码器输出的 μ，不采样，结果确定，也最能代表这张图。训练时才必须采样，因为重建项是对 q 取期望。

隐变量的维度怎么选？

太小，信息挤不过瓶颈，重建很差；太大，重建好了，但很多维用不上，KL 项会把这些维压回先验，也就是对这些维 μ = 0、σ = 1，它们不携带任何信息。实际看任务：画二维隐空间的演示用 2 维；MNIST 常用 10 到 50 维；Latent Diffusion 这类用的是空间形状的隐表示，比如 64×64×4。

一个实用的检查：训练完看每一维的 KL 贡献，接近 0 的维就是没用上的。

常见毛病与变体

变分自编码器生成的图为什么糊？

两个原因叠在一起。一是逐像素的重建损失：同一个 z 可能对应好几张不同的图（KL 项逼着不同图的 q 互相重叠），L2 损失下最优输出是这些图的平均，L1 是中位数，边缘和纹理都被平均掉。二是高斯解码器本身：它假设像素之间独立，没法表达「这条边要么在这儿要么在那儿」这种多种可能。

改进的方向：把重建损失换成感知损失加对抗损失（Latent Diffusion 的做法），或者换更强的解码器，或者减小 KL 权重，再用别的模型学隐空间的分布。

两种讲法对照：为什么糊 →视频：重叠处取平均 →

后验坍缩 (Posterior Collapse) 是什么？

编码器给所有图都输出和先验一样的 N(0, I)，KL 项降到 0，z 不携带任何信息，解码器完全不看 z 也能把重建做得不错。

它常出现在解码器很强的时候，比如用自回归的循环网络当解码器生成句子：解码器靠前面的词就能预测下一个词，用不着 z。这时 KL 项的「免费」最优解就是让 q 等于先验。

常见对策：训练初期把 KL 权重从 0 慢慢升到 1 (KL Annealing)；把解码器削弱一点，比如随机丢掉一部分输入词；给每一维的 KL 设一个下限，低于下限不罚 (Free Bits)。

β 变分自编码器是什么？

给 KL 项乘一个系数 β：损失变成「重建项 − β × KL」。β = 1 就是原版。

β > 1 时隐空间被更用力地压向先验，各维更独立，往往一维对应一个可解释的变化（姿态、大小、颜色），代价是重建更糊。β < 1 时重建更好、隐空间更乱。Latent Diffusion 的自编码器取 β ≈ 10−6，几乎就是普通自编码器。

前面说过，解码器方差 σ2 也起同样的作用，调 σ2 和调 β 是一回事。

Higgins 等，ICLR 2017：β 变分自编码器原论文 ↗

从 N(0, I) 采的 z，为什么有时会解码出很怪的图？

KL 项只是把每张图的 q 往先验拉，并不保证所有图的 q 合在一起正好铺满 N(0, I)。合起来的分布可能在某些区域很稀，先验在那里却有不小的概率。从先验采到这种区域的 z，解码器训练时几乎没见过，输出就不像样。

对策是换一个更贴合数据的先验，或者干脆用另一个模型学隐向量的分布：两阶段的做法、Latent Diffusion 都属于这一类。

Tomczak 和 Welling：可学习的 VampPrior 先验 ↗

ELBO 能当 log p(x) 用吗？真实的对数似然怎么估？

ELBO 只是下界，两者差一个 KL(q ‖ 后验)，这个差多大不知道。用 ELBO 比较两个模型可能不公平：一个模型的下界松，不代表它的真实似然低。

估真实的 log p(x) 用重要性采样 (Importance Sampling)：从 q 里抽 K 个 z，用 log (1/K) Σk pθ(x, zk) / qφ(zk|x) 估计。

K = 1 时它的期望就是 ELBO，K 越大越接近 log p(x)。论文里报告的对数似然通常取 K = 5000 左右。把这个更紧的界直接当训练目标，就是重要性加权自编码器。

向量量化变分自编码器是什么？

隐变量换成离散的：准备一本码本，几百到几千个向量；编码器的输出替换成码本里最近的那个向量，解码器从这些码本向量重建。全称 Vector Quantized Variational Autoencoder。

先验是均匀分布，KL 项变成常数，训练里实际不出现。生成时另外训练一个自回归模型，在码本编号的序列上建模。CS231n 第 14 讲结尾提到，除了扩散模型，另一条现代路线就是「离散变分自编码器 + 自回归模型」。

Stable Diffusion 里的变分自编码器和原版有什么不同？

结构还是编码器输出 μ、σ，解码器还原图。不同在训练目标：重建损失换成 L1 加感知损失，再加一个图块判别器做对抗训练；KL 项权重只有约 10−6。这正是 Latent Diffusion 论文里的 KL 正则版本。

形状上，512×512×3 的图压成 64×64×4 的隐表示，空间上 8 倍下采样。因为 KL 几乎不约束，隐表示的方差不是 1，Stable Diffusion 1.x 在送进扩散模型前会乘一个缩放系数 0.18215，把方差拉回 1 附近。

变分自编码器和生成对抗网络、扩散模型是什么关系？

CS231n 的家族树里，变分自编码器是显式但近似的密度模型，能算出 log p(x) 的下界；生成对抗网络只能采样、算不出密度；扩散模型通过逐步去噪采样。

它们并不互相取代。扩散模型本身可以看成隐变量模型，训练目标也是变分下界；现代的图像生成流程同时用三样：变分自编码器的编码器解码器负责压缩，判别器负责让解码清楚，扩散模型在隐空间里生成。

2先验、似然、后验、证据：贝叶斯公式里的四个名字

隐变量模型假设每张图是这样来的：先从先验 p(z) 抽一个 z，再从 pθ(x|z) 生成图。z 和 x 的联合分布就是两者相乘：

pθ(x, z) = p(z) pθ(x|z)先抽 z，再按 z 生成 x

同一个联合分布也能反过来拆：先有 x，再看 z。两种拆法相等，整理一下就是贝叶斯公式：

pθ(z|x) = pθ(x|z) p(z) / pθ(x)后验 = 似然 × 先验 / 证据
pθ(x) = ∫ pθ(x|z) p(z) dz证据：把所有 z 的可能性加起来

四个量里，先验是自己定的，似然由解码器算，都没问题。麻烦在证据：要对所有 z 积分，z 有上百维，解码器又是神经网络，这个积分没有解析解，也没法暴力数值积分。证据算不出来，后验的分母就没有，后验也就算不出来。变分自编码器后面的所有绕路都从这里开始。

例子z 只有两个取值时

假设 z 只有两个取值，「猫」的先验是 0.3，「狗」是 0.7。看到一张图 x，解码器说猫生成这张图的可能性是 0.8，狗是 0.1。

证据 p(x) = 0.3 × 0.8 + 0.7 × 0.1 = 0.31；后验 p(猫|x) = 0.24 / 0.31 ≈ 0.774，p(狗|x) = 0.07 / 0.31 ≈ 0.226。z 只有两个值时证据是两项求和，一下就算完；z 是 128 维的连续向量时，求和变成 128 重积分，就算不动了。

3期望：按概率加权的平均

随机变量 z 服从分布 q，记作 z ∼ q。函数 f(z) 的期望是按 q 的概率给每个取值加权再求和：

Eq[f(z)] = Σz q(z) f(z)z 只取有限个值
Eq[f(z)] = ∫ q(z) f(z) dzz 连续，q(z) 是概率密度

两行是一个意思。z 连续时没法逐个列出取值，只能对密度积分，求和号就换成了积分号。掷一个公平骰子，f(z) = z，期望是 (1 + 2 + … + 6) / 6 = 3.5；z ∼ N(0, 1)，f(z) = z2，期望就是方差 1。

期望的下标说的是「按哪个分布取平均」，换一个分布结果就不同。后面推导里同一个 log pθ(x|z)，按编码器的 q 取期望和按先验 p(z) 取期望是两回事，所以下标不能随手省。

推导 ELBO 时每一步都在用期望的两条性质：

  • 线性：Eq[a f + b g] = a Eq[f] + b Eq[g]。一个期望里的减号可以拆成两个期望相减。
  • 常数的期望是它自己：f 里没有 z 时 Eq[f] = f。log p(x) 不含 z，所以推导里可以随时给它套上或去掉对 z 的期望。

4KL 散度：log(q/p) 按 q 取平均

KL 散度 (Kullback-Leibler Divergence) 衡量两个分布差多少。q 相对 p 的 KL 散度定义为：

KL(q ‖ p) = Σz q(z) log [q(z) / p(z)]离散
KL(q ‖ p) = ∫ q(z) log [q(z) / p(z)] dz连续
= Eq[log q(z) − log p(z)]对照上一节：就是 log(q/p) 按 q 取期望

逐项看：对每个 z，log(q/p) 比较两个分布给它的概率，q 给得多就是正数，给得少就是负数；然后按 q(z) 加权平均。所以它关心的是：q 认为常见的那些 z，p 给的概率够不够。

它衡量的是差异：两个分布完全相同时为 0，差得越多越大，没有上限。用自然对数时单位是奈特 (nat)，以 2 为底时是比特。

例子两枚硬币

q 是一枚公平硬币，正反各 0.5；p 偏向正面，正面 0.9、反面 0.1。

KL(q ‖ p) = 0.5 × ln(0.5/0.9) + 0.5 × ln(0.5/0.1) = 0.5 × (−0.588) + 0.5 × 1.609 ≈ 0.511 奈特。正面那项是负的，q 给正面的概率比 p 少；反面那项是正的，而且大得多，因为 q 有一半时间出反面，p 却认为反面很少见。

补充信息论的读法：数据实际来自 q，却用为 p 设计的最优编码去压缩，平均每个样本多花 KL(q ‖ p) 奈特。所以 KL(q ‖ p) = 交叉熵 H(q, p) − 熵 H(q)。基础概念页「压缩即智能」第 2 部分讲的就是这件事。

5KL ≥ 0：扔掉它就得到下界

被积函数有正有负，加起来却总是 ≥ 0，当且仅当 q 和 p 处处相等时为 0。证明要用 log 是凹函数：琴生不等式 (Jensen's Inequality) 说凹函数的期望不超过期望的凹函数，E[log Y] ≤ log E[Y]。

−KL(q ‖ p) = Eq[log (p(z) / q(z))]把 log(q/p) 翻成 log(p/q)，前面加负号
≤ log Eq[p(z) / q(z)]琴生不等式
= log ∫ q(z) · p(z) / q(z) dz = log ∫ p(z) dz按期望的定义展开，q 约掉
= log 1 = 0p 是概率分布，积分为 1

所以 KL(q ‖ p) ≥ 0。等号要求 p/q 是常数，两个分布都积分为 1，这个常数只能是 1，也就是 q = p。

这一条在变分自编码器里用了两次。CS231n 推导时 log p(x) 拆出一项算不出的 KL，它 ≥ 0，扔掉以后剩下的就是 log p(x) 的下界。视频的推导里，同一项 KL 是「近似后验离真实后验多远」，它 ≥ 0 保证 ELBO 永远不超过 log p(x)。

6两个方向不一样：为什么用 KL(q ‖ p)

交换两个分布，KL 一般会变。还是两枚硬币：KL(q ‖ p) ≈ 0.511，反过来 KL(p ‖ q) = 0.9 × ln(0.9/0.5) + 0.1 × ln(0.1/0.5) ≈ 0.368。不对称，所以它算不上距离，只叫散度。

变分自编码器要用 q 去近似真实后验，写成 KL(qφ(z|x) ‖ pθ(z|x))，q 在前。选这个方向是因为只有它算得动：

  • 期望按 q 取。q 是编码器给的高斯，能从里面采样，也能算 log q。
  • 真实后验只出现在 log 里，可以拆成 log p(z, x) − log p(x)：前一项能算，后一项和 z 无关，从期望里提出来就是常数。两种推导都靠这一步。
  • 反过来的 KL(pθ(z|x) ‖ q) 要按真实后验取期望，得先能从后验里采样，而这正是做不到的事。

KL(q ‖ p) 罚的是 q 放错地方：p 几乎为 0 的地方 q 还有概率，log(q/p) 会非常大。所以 q 宁可缩在 p 的一个峰里，漏掉另一个峰也无所谓，这叫寻找众数 (Mode-Seeking)。

KL(p ‖ q) 罚的是 q 漏掉地方：p 有概率的地方 q 不能太小，q 就会摊开盖住所有峰，叫覆盖质量 (Mass-Covering)。代价是两峰之间那片 p 几乎为 0 的地方，q 也给了不少概率。

放到变分自编码器里：编码器给出的高斯往往比真实后验更窄。后验如果有几种可能的解释，q 通常只抓住其中一种。

7两个高斯之间的 KL 有解析解

q 和 p 都是高斯时，KL 可以直接积出来，不用采样。先看一维，设 q = N(μ1, σ12)，p = N(μ2, σ22)。高斯密度取对数：

log N(z; μ, σ2) = −½ log(2πσ2) − (z − μ)2 / (2σ2)

代进 KL = Eq[log q(z) − log p(z)]，只需要两个期望：Eq[(z − μ1)2] = σ12，这是方差的定义；Eq[(z − μ2)2] = σ12 + (μ1 − μ2)2，离另一个中心远了一段，多出均值差的平方。

KL(q ‖ p) = Eq[−½ log(2πσ12) − (z − μ1)2/(2σ12) + ½ log(2πσ22) + (z − μ2)2/(2σ22)]两个对数密度相减
= log(σ2/σ1) − ½ + [σ12 + (μ1 − μ2)2] / (2σ22)代入两个期望

变分自编码器里 p 是标准正态 N(0, 1)，代入 μ2 = 0、σ2 = 1，μ、σ 换成编码器的输出：

KL(N(μ, σ2) ‖ N(0, 1)) = ½ (μ2 + σ2 − 1 − log σ2)一维
KL(N(μ, diag(σ2)) ‖ N(0, I)) = ½ Σj (μj2 + σj2 − 1 − log σj2)z 有 d 维、各维独立，逐维相加

例子代几个数

上面那张图里 q = N(0, 1)、p = N(1, 1.52)：ln 1.5 − 0.5 + (1 + 1) / 4.5 ≈ 0.350，和数值积分一致。

μ = 0.5、σ = 0.8：½ × (0.25 + 0.64 − 1 + 0.446) ≈ 0.168。μ = 0、σ = 1：0，正好就是先验。

对 μ 求导是 μ，对 σ 求导是 σ − 1/σ。梯度下降把 μ 往 0 推；σ < 1 时导数为负，σ 会变大，σ > 1 时为正，σ 会变小。CS231n 说「先验项希望均值都是 0、标准差都是 1」，指的就是这两个导数。

σ 趋于 0 时 −log σ2 趋于正无穷。编码器想把每张图的 z 压成一个确定的点，KL 项就会无限大，这是它和重建项拉扯的地方。

补充实现时编码器一般输出 log σ2，不直接输出 σ：网络的输出可正可负，log σ2 取任何实数都对应一个合法的方差，KL 公式里本来也要用 log σ2。

8积不出来就采样：蒙特卡洛估计与重参数化

重建项 Eq[log pθ(x|z)] 里有解码器，没有解析解。这时用蒙特卡洛估计 (Monte Carlo Estimation)：从 q 里抽 S 个样本，取平均。

Eq[f(z)] ≈ (1/S) Σs=1S f(z(s)), z(s) ∼ q样本平均

这个估计没有偏差，平均起来等于真值，只是带噪声，样本越多噪声越小。比如 z ∼ N(0, 1)、f(z) = z2，真值是 1；在一次模拟里，抽 10 个样本估出 0.72，抽 100 个估出 1.29，抽 10000 个估出 0.998。

变分自编码器训练时每张图每一步只抽一个 z（S = 1）。单次估计噪声很大，但每一步换图、换样本，几万步平均下来就够了。原论文第 2.3 节说批量取 100 时，每个样本抽一次就行。

还有一个问题：训练要对 φ 求梯度，可期望 Eqφ 的分布本身依赖 φ，「抽一个 z」这个动作没法求导。重参数化技巧 (Reparameterization Trick) 把随机性挪到外面：

ε ∼ N(0, 1), z = μ + σ · ε先抽一个和 φ 无关的 ε，再用编码器的输出变换它
Eqφ[f(z)] = Eε[f(μ + σε)]期望改按 ε 取，分布里不再有 φ
∇ Eε[f(μ + σε)] = Eε[∇ f(μ + σε)]梯度可以挪进期望里，采样以后照常反向传播

例子验证一下

取 f(z) = z2，q = N(μ, σ2)。精确结果是 E[z2] = μ2 + σ2，对 μ 的导数 2μ，对 σ 的导数 2σ。

出发点：最大似然

生成模型的目标是学一个分布 pθ(x)，让训练数据在它下面尽量可能。θ 是神经网络的权重，网络输入一张图，输出它的概率密度。最大似然估计 (Maximum Likelihood Estimation) 就是找让训练数据概率最大的 θ。

训练数据 x1 … xN 假设独立同分布，联合概率是各自概率的乘积。乘积不好优化，取对数变成求和，log 单调，最大值的位置不变：

θ* = argmaxθ Πi pθ(xi)让整个数据集的概率最大
= argmaxθ Σi log pθ(xi)取对数，乘积变求和

这就是后面所有推导的目标：让每张训练图的 log p(x) 变大。自回归模型能精确算出 log p(x)，直接最大化；变分自编码器算不出来，只能最大化它的一个下界。

放弃精确密度，换来隐向量

自回归模型把数据拆成序列，用概率的链式法则逐个预测，log p(x) 是精确的。变分自编码器仍然是显式密度方法，但它算的只是一个近似，准确说是真实密度的下界。

有精确的方法，为什么要换成近似的。他的回答是：换来的东西是隐向量 (Latent Vector)。训练过程中，每张图自然得到一个表示它的向量，这些向量本身就有用，值得拿精确密度去换。

注课上这里插了一个问答：自回归为什么要拆成序列。V 个词的词表上，长度为 T 的序列有 VT 种，直接建模联合分布，参数量随长度指数增长；拆成「已知前面预测下一个」，每一步只要一个 V 维的分布。实际都在对数空间里算，数值更稳。

自编码器：通过瓶颈学特征

先去掉「变分」，讲普通的自编码器 (Autoencoder)。它是无监督方法：编码器从输入 x 提取特征 z，希望 z 装着有用的信息，比如图里有什么物体、有几个、什么颜色。编码器可以是多层感知机、卷积网络、Transformer，什么结构都行。

没有标签怎么训练。最简单的办法是让模型重建输入：再接一个解码器，输入 z、输出 x̂，损失是 x̂ 和 x 的 L2 距离 ‖x̂ − x‖2。他说这是「史上最蠢的损失函数」，等于在训练一个恒等函数，而恒等函数谁都会写。

关键在于加约束，最常见的是瓶颈 (Bottleneck)：z 比 x 小得多。1024×1024 的彩色图有三百多万个数，z 可能只有 128 维。要把三百万个数挤过 128 维再还原回来，模型只能学到数据里真正的结构。

训练完以后，自监督的用法是扔掉解码器，拿编码器给下游任务初始化，和上一讲讲的自监督学习一样。

想生成，就得会采样 z

如果想拿自编码器生成数据，做法正好反过来：扔掉编码器，留下解码器。只要能采样出「像模型编码出来的那种 z」，送进解码器就是一张新图。

问题是这只是把难题往后推了一步。原来要生成 x，手上有一堆 x；现在要生成 z，手上有一堆 z，难度一点没减。普通自编码器对 z 的分布没有任何约束，编码出来的点散成什么形状都有可能，没法从里面采样。

隐变量模型：每张图背后有一个 z

变分自编码器的想法：如果能强制 z 服从一个已知的分布，比如高斯，训练完就能从这个分布采样，再送进解码器。它是自编码器的概率化版本，「变分」这个名字有很长的历史，课上没展开。

具体的假设是：训练数据 x(i) 的每一张，背后都有一个看不见的隐向量 z(i)。生成数据的过程是先生成 z，再由 z 生成 x，生成这张图需要的全部信息都在 z 里。上标 i 只是编号，表示不同的独立样本。

z 永远观测不到，没有它的数据集。另一个约束是 z 来自一个已知的先验 (Prior) p(z)，几乎总是取单位高斯 N(0, I)。训练好以后：从先验采一个 z，过解码器，就是一个样本。

注「变分」来自变分推断 (Variational Inference)：真实后验算不出来时，在一族简单分布（比如所有对角高斯）里挑一个最接近的去近似，把「求一个分布」变成「优化分布族的参数」。白板推导视频就是从这个角度讲的。

第一次尝试：把 z 积掉

怎么训练。z 看不到，似乎无从下手。他的办法是回到最大似然：如果手上有 (x, z) 成对的数据集，直接最大化 log p(x|z) 就能训练一个条件生成模型。可是没有 z。

没有 z，可以把它积掉。x 和 z 一定有一个联合分布，哪怕看不到；对 z 积分就得到 x 的边缘分布，这叫边缘化 (Marginalization)：

pθ(x) = ∫ pθ(x, z) dz = ∫ pθ(x|z) p(z) dz联合分布用链式法则拆成似然乘先验

积分里两项都能算：pθ(x|z) 是解码器，p(z) 是自己选的高斯。但积分本身算不了：z 是高维向量，pθ(x|z) 是一个神经网络，没有解析解。

用有限个样本近似这个积分呢。他说一般不行：z 维度很高，在训练的内层循环里做数值积分不是个好主意。

注为什么从先验里采样估这个积分行不通，补一个直观的理由。pθ(x) ≈ (1/S) Σs pθ(x|zs)，zs ∼ p(z)。对一张具体的图 x，先验里随便抽的 z 绝大多数解码出来和 x 毫不相干，pθ(x|z) 几乎为 0；只有极小一片 z 能生成这张图。要碰到那一片，需要的样本数随 z 的维度指数增长。

如果知道「哪一片 z 能生成 x」，只在那一片里采样就高效多了。这一片正是后验 pθ(z|x)，也就是下一步要用编码器去近似的东西。

第二次尝试：贝叶斯公式，再加一个网络

概率里另一个常用工具是贝叶斯公式，它给出 p(x) 的另一种写法，里面没有积分：

pθ(x) = pθ(x|z) p(z) / pθ(z|x)对任何一个 z 都成立

分子两项都能算。分母的后验 (Posterior) pθ(z|x) 算不出来，因为算它同样需要那个积分，又卡住了。

变分自编码器的办法是：算不出来的那一项，就再放一个神经网络去算。另一个网络 q，权重 φ，学习条件分布 qφ(z|x)，希望它近似真实后验 pθ(z|x)。课件写的是：如果能保证 qφ(z|x) ≈ pθ(z|x)，就有

pθ(x) ≈ pθ(x|z) p(z) / qφ(z|x)分母换成编码器

于是要联合训练两个网络，各有独立的权重。解码器输入 z，输出 x 上的分布；编码器输入 x，输出 z 上的分布。他也承认，q 能不能近似好后验，一般没法强制保证。

神经网络怎么输出一个分布

网络输出的是一组数，怎么能是一个分布。办法是把所有分布都定成正态分布，让网络输出它的参数。

编码器：输入 x，输出两个和 z 同样形状的向量，一个是均值 μz|x，一个是对角协方差的对角线 Σz|x。合起来 qφ(z|x) = N(μz|x, Σz|x)。

为什么一定要对角。完整协方差矩阵要描述每两维之间的相关性，d 维就有 d2 个数。用在图像上，h×w 的图就是 h2w2 个数，大到没法输出。只取对角线，就等于假设各维互相独立，协方差变成一个和数据本身一样大的向量。

解码器：输入 z，输出像素上的对角高斯的均值 μx|z，方差固定成一个常数 σ2：pθ(x|z) = N(μx|z, σ2)。他说这里其实「作了点弊」：名义上输出一个分布，实际从不从里面采样，总是直接拿均值当输出图。

解码器的方差为什么不学。如果每个像素各学一个方差，又没有像素间的协方差，从这个分布采样就等于在均值图上每个像素各自加独立噪声，得到的只是一张带雪花的图，没有意义。

方差固定以后，最大化高斯的对数似然就等价于最小化 L2 距离：

log N(x; μx|z, σ2 I) = −‖x − μx|z‖2 / (2σ2) − (D/2) log(2πσ2)D 是像素数
max log pθ(x|z) ⇔ min ‖x − μx|z‖2σ2 固定，后一项是常数

所以「解码器输出一个高斯」和「自编码器用 L2 重建损失」其实是一回事，σ2 只决定重建项相对 KL 项的权重。

注有学生问像素平移这类不变性怎么办。他说那是网络结构的事，比如卷积天然对平移等变，损失函数这一层不管。

推导：把 log p(x) 拆成三项

现在有了编码器和解码器，训练目标是什么。他说这是整节课唯一一张推导的幻灯片，原则还是最大似然：最大化 log p(x)。

第一步，用贝叶斯公式写出 log p(x)，这是精确的等式。第二步做一件看起来多余的事：分子分母同乘 qφ(z|x)。第三步用对数的性质，按一个特定的顺序拆成三项：

log pθ(x) = log [pθ(x|z) p(z) / pθ(z|x)]贝叶斯公式
= log [pθ(x|z) p(z) qφ(z|x) / (pθ(z|x) qφ(z|x))]分子分母同乘 q，值不变
= log pθ(x|z) − log [qφ(z|x) / p(z)] + log [qφ(z|x) / pθ(z|x)]重新分组：p(x|z)，q 配 p(z)，q 配后验

课件上三种颜色标出了每一项来自哪里。到这一步，右边还带着 z，左边却没有。

关键观察：log p(x) 不依赖 z。上面三项各自含 z，加起来以后 z 全部消掉。一个不依赖 z 的量，可以在外面套上对 z 的期望，按任何分布取都成立。这里选按编码器 qφ(z|x) 取：

log pθ(x) = Ez∼qφ(z|x)[log pθ(x)]常数的期望是它自己
= Ez[log pθ(x|z)] − Ez[log (qφ(z|x) / p(z))] + Ez[log (qφ(z|x) / pθ(z|x))]期望是线性的，分别作用到三项上
= Ez[log pθ(x|z)] − KL(qφ(z|x) ‖ p(z)) + KL(qφ(z|x) ‖ pθ(z|x))后两项按定义就是 KL 散度

他说熟悉概率的话会认出后两项是 KL 散度，衡量两个分布有多不同。这一串都是精确的等式，没有任何近似。

注为什么偏偏选按 q 取期望，课上没说。按别的分布取，等式同样成立，但只有按 q 取，后两项才正好是 KL 散度的定义（KL(q ‖ ·) 的期望就是按 q 取的），第一项也才能用编码器采样来估计。期望和 KL 的定义见「KL 散度」资料。

「三项各自含 z、加起来不含 z」可以直接验证：把三项的 log 合并回去，就是 log [pθ(x|z) p(z) / pθ(z|x)]，这正是贝叶斯公式里的 log p(x)，和 z 无关。

三项各是什么

式子看着吓人，每一项都能读出含义。

第一项，重建项 Ez∼qφ(z|x)[log pθ(x|z)]。读法：拿一张图 x 过编码器，得到 z 上的分布；从这个分布里采一个 z，过解码器，看还原出 x 的对数概率有多大。对所有这样的 z 取平均，所以叫数据重建项。

第二项，先验项 KL(qφ(z|x) ‖ p(z))。编码器对每张图预测一个 z 上的分布，p(z) 是事先选好的先验，通常是对角高斯。这一项衡量模型学到的隐空间和先验有多像，要它们尽量一致。

第三项 KL(qφ(z|x) ‖ pθ(z|x))。编码器的分布和真实后验有多像。这一项算不出来：当初引入 q，就是因为后验算不出来，现在它又出现了。

扔掉第三项：证据下界

第三项怎么办。扔掉。KL 散度总是 ≥ 0，这两个分布虽然算不出来，KL 一定不小于 0。扔掉以后左边只会更大：

log pθ(x) ≥ Ez∼qφ(z|x)[log pθ(x|z)] − KL(qφ(z|x) ‖ p(z))重建项减先验项

右边就是训练变分自编码器用的目标，叫变分下界 (Variational Lower Bound)，也叫证据下界 (Evidence Lower Bound, ELBO)，「证据」指的就是 log p(x)。联合训练编码器 q 和解码器 p 去最大化它。

他的说法是：这是真实对数似然的一个近似，准确说是下界；最大化下界，希望真实对数似然也跟着变大，虽然并不精确。

注「希望」可以说得更具体。扔掉的第三项正好是下界和真实值之间的差：log pθ(x) − ELBO = KL(qφ(z|x) ‖ pθ(z|x))。

对编码器 φ 来说，log p(x) 和 φ 无关，抬高 ELBO 只能靠缩小这个差，也就是让 q 更贴近真实后验，下界越来越紧。对解码器 θ 来说，抬高 ELBO 是在抬高 log p(x) 的一个下界。两者一起更新，下界既在变紧，又在被往上推。白板推导视频就是从「缩小这个差」这一侧讲起的，见「两种讲法对照」。

训练一步

那一大页数学落到训练上，流程并不复杂：

  • 编码器输入 x，输出 z 上的分布：μ 和 σ。
  • 对这个分布算 KL 项，它鼓励预测的均值为 0、标准差为 1。
  • 从预测的分布里采一个 z，用重参数化技巧 (Reparameterization Trick)，梯度才能穿过采样传回编码器。
  • 把 z 过解码器，得到解码器预测的分布（其实就是均值图），对它算重建项。

注两项损失写成公式（课上没写）。z 有 d 维，编码器输出 μ 和 σ，先验是 N(0, I)，KL 项有解析解，不用采样：KL = ½ Σj (μj2 + σj2 − 1 − log σj2)。推导见「KL 散度」资料的「两个高斯之间的 KL」。

重参数化：先抽 ε ∼ N(0, I)，再算 z = μ + σ ⊙ ε。随机性全在 ε 里，z 对 μ、σ 可导。重建项用这一个 z 估计期望，解码器方差固定时就是 ‖x − μx|z‖2 / (2σ2)。每张图每一步只采一个 z，原论文说批量够大时这样就够了。

所以一个批次的损失是：每张图的 L2 重建误差（乘一个由 σ2 决定的系数）加上 KL 项，再对批次取平均。

两项损失互相拉扯

他觉得变分自编码器最有意思的地方在于两项损失在隐空间上互相拉扯。模型被迫把信息挤过 z，而两项对 z 的要求不一样。

重建项希望 σ 为 0，每个 x 有一个各不相同的均值向量。那样每张图有一个独一无二的 z，没有任何随机性，就能完美重建。

先验项希望所有 σ 都是 1、所有均值都是 0，也就是每张图的分布都和单位高斯一模一样。这和重建项想要的正好相反。

训练就是在两者之间找平衡：既要把数据重建好，又要让隐空间接近先验。

注两个极端都能用公式看出来。σ 趋于 0 时 KL 项里的 −log σ2 趋于正无穷，所以 z 不可能被压成一个点；q 如果完全等于 N(0, I)，z 和 x 就毫无关系，解码器只能对所有图输出同一张平均图，重建项很差。

平衡点的位置取决于两项的相对权重，也就是解码器的 σ2。σ2 越小，重建项越重，图越清楚、隐空间越不规整；越大则相反。给 KL 项单独乘一个系数 β 的做法叫 β 变分自编码器，见「常见问题」。

训练好以后：采样与隐空间

训练好以后，从先验采 z，过解码器，就得到一个样本。

另一个好处：隐空间是对角高斯，各维之间统计独立，可以分别改变。不同维度常常对应数据里某种有意义、互相独立的变化。在手写数字上训练的变分自编码器，沿隐空间两个维度改变 z，数字会平滑地从一类变到另一类，这是变分自编码器很常见的性质。

最后的小结：有监督与无监督；三种概率生成模型；家族树的一半，自回归和变分自编码器。下一讲讲另一半，生成对抗网络和扩散模型。

注「各维统计独立」严格说只对先验成立。编码器给每张图的 q 是对角高斯，但把所有训练图的 q 合在一起，整体分布未必各维独立，也未必正好是 N(0, I)。生成时从 N(0, I) 采到的 z，如果落在训练数据很少覆盖的区域，解码出来就不太像样。

这一段记住这几条

  • 目标始终是最大似然：最大化每张训练图的 log p(x)。变分自编码器算不出它，只能最大化一个下界。
  • 自编码器靠瓶颈学特征，但 z 的分布没有约束，不能拿来生成；变分自编码器要求 z 服从先验 N(0, I)。
  • 把 z 积掉要算高维积分，用贝叶斯公式又要算后验，都算不了；于是加一个编码器 qφ(z|x) 去近似后验。
  • 编码器输出对角高斯的 μ 和 σ；解码器输出像素的均值、方差固定，最大化它的对数似然就是最小化 L2。
  • log p(x) = Eq[log p(x|z)] − KL(q ‖ p(z)) + KL(q ‖ p(z|x)) 是精确的；最后一项 ≥ 0 又算不出，扔掉得到证据下界。
  • 训练一步：编码器出 μ、σ，算 KL，重参数化采 z，解码，算重建；两项在隐空间上互相拉扯，平衡点由两者的权重决定。

在隐空间里做扩散

现在多数扩散模型都在隐空间里做，分两个阶段训练。第一阶段训练一个编码器和一个解码器，把图像转成隐表示：H×W×3 的图变成 H/D × W/D × C 的隐张量。

第二阶段训练扩散模型：取一张图，过编码器得到隐表示，加噪，让扩散模型去噪。这时编码器是冻结的，梯度不传回去，它只负责提取隐表示。

推理时，随机取一个隐表示，用扩散模型反复去噪，得到干净的隐表示，最后过解码器变成图。

编码器解码器是变分自编码器，再加一个判别器

编码器解码器怎么训练。他问学生见过什么编码器解码器，答案是变分自编码器：实际训练 Latent Diffusion 时，这个编码器解码器通常就是一个变分自编码器，而且 KL 先验项的权重非常小。

可是上一讲刚说过变分自编码器的输出发糊。解码器的重建质量是整个系统的上限：重建都是糊的，下游扩散模型生成得再好也没用。

怎么在解码器后面把图变清楚。答案是让它同时是一个生成对抗网络：再训练一个判别器，区分真图和解码器重建的图。所以现代的生成流程同时要训练变分自编码器、生成对抗网络和扩散模型，他自嘲说「一团乱」。

他举的例子是开源的 FLUX.1 [dev]：文本编码器用 T5 和 CLIP，编码器做 8 倍下采样，扩散模型是 120 亿参数的 Transformer。

注这就是白板推导视频最后那个问题的答案，课上一句话，原论文写得更细。Latent Diffusion 的自编码器用感知损失加基于图块的对抗损失训练，论文说这样能保证局部真实感，避免只用 L1、L2 像素损失带来的模糊；KL 项权重约 10−6（附录 G），另一个版本用向量量化代替 KL。

把 KL 权重压到 10−6，等于几乎不要求隐空间服从 N(0, 1)，这个自编码器很接近普通自编码器，重建自然清楚；隐向量服从什么分布交给扩散模型去学，不再从 N(0, 1) 里直接采 z。两边加起来，糊的问题就没了。

扩散模型也是隐变量模型

讲扩散模型的几种理解时，第一种就和变分自编码器有关：每个干净样本背后，都对应一串加了噪声的版本，这串噪声版本看不到，是隐变量。

这和变分自编码器的设定一样：有 z 和 x，z 观测不到，要想办法训练。可以用非常相似的数学技巧，最大化数据似然的一个变分下界。课件写的是「优化变分下界，和变分自编码器一样」。

注区别在于：扩散模型的「编码器」，也就是加噪的前向过程，是固定的，不用学；只学「解码器」，也就是一步步去噪的反向过程。DDPM 的损失就是从这个变分下界化简出来的。

  • 这个编码器解码器是 KL 权重很小的变分自编码器，再加一个判别器把重建变清楚。
  • 扩散模型本身也是隐变量模型，训练目标和变分自编码器一样是变分下界。

Latent Diffusion：先压缩，再在隐空间里扩散

近两年的扩散模型基本都换成了 Latent Diffusion 的做法。Diffusion Transformer 也是，它只是把去噪网络从 U-Net 换成了 Transformer。普通的扩散模型直接在像素上加噪、去噪，所有计算都在像素空间 (Pixel Space) 里做。

像素空间很大：256×256 的三通道图有 196,608 个数，每一步去噪都在这么大的张量上算，而且要走很多步。Latent Diffusion 先用编码器把图压进一个小得多的隐空间 (Latent Space)，扩散只在隐空间里做，最后由解码器还原成图。板书上举的隐空间大小是 32×32。

压缩一定丢信息。Latent Diffusion 论文把压缩分成两种：感知压缩 (Perceptual Compression) 去掉高频细节，语义压缩 (Semantic Compression) 去掉的是图里有什么、怎么组成。作者认为细节之间相关性强，比较容易学回来，难学的是整体语义。

于是分工是：编码器和解码器负责感知层面的压缩和还原，中间的扩散模型在隐空间里学语义。整个系统分两步训练，先训练编码器和解码器，再在它们给出的隐空间上训练扩散模型。

注原论文 (Rombach 等，arXiv 2021-12-20) 用下采样倍数 f 描述压缩程度，主要用 f = 4 和 f = 8。f = 8 时 256×256 的图压成 32×32，另有若干通道，Stable Diffusion 用 4 个，总数 32×32×4 = 4,096，比像素少 48 倍。

编码器和解码器来自变分自编码器

Latent Diffusion 里的编码器和解码器来自变分自编码器 (Variational Autoencoder)。它从普通的自编码器 (Autoencoder) 出发，用一套概率上的办法把自编码器变成了生成模型，2013 年提出（Kingma 和 Welling，arXiv 2013-12-20）。

讲者的疑问：变分自编码器作为生成模型效果一般，很多生成结果都比较糊，这是它出了名的缺点。可是把编码器和解码器之间的部分换成扩散模型，图就变得非常清晰。这说明编码器和解码器的能力是够的，问题出在中间。

要回答它，先得把变分自编码器的原理弄清楚。他说网上的博客要么讲得笼统、跳过了细节，要么前后对不上，所以做了这期。Latent Diffusion 本身概念不复杂，变分自编码器牵涉贝叶斯推断，值得单独讲。

注「沿用 2013 年的编码器和解码器」要打个折扣。Latent Diffusion 的自编码器结构和变分自编码器一样，训练目标却改了不少，这正是它重建清晰的主要原因之一，见倒数第二节的注。

自编码器：能学特征，不能生成

自编码器是一种自监督的图像特征学习方法。输入 xi，编码器把它压成 zi，解码器再从 zi 还原出 x̂i，用 x̂i 和 xi 之间的重建损失同时训练编码器和解码器。

训练好以后，只给 zi 就能还原出很像 xi 的图，说明 zi 装下了 xi 的大部分信息，所以 z 可以当特征用。这是自编码器能做特征提取的原因。它为什么不能直接当生成模型，是下一节的内容。

想生成新图，就要一个新的 z

设数据集里有 N 张图 x1 … xN，编码后得到 z1 … zN。生成模型要生成数据集里没有的新图，所以需要一个新的 zN+1。它不能从已有的 z1 … zN 里取，那样解码出来的都是见过的图；也不能随便取，随手一个点解码出来多半不像图。

所以希望 z 服从某个已知的分布，这样就能从分布里采样新的 z。自编码器做不到：训练时没有对 z 的分布做任何约束，编码出来的点散成什么形状都有可能，找不到一个合理 (reasonable) 的新 z。

直接的想法是给 z 规定一个分布，比如标准正态分布 p(z) ∼ N(0, 1)，训练完让所有 zi 整体服从它。讲者说这很难做，原因有两个：

  • 不知道 x1 应该落在这个分布的哪个点上，没有目标值，也就没法监督编码器把点放到该放的位置。
  • 解码器也难训：从 N(0, 1) 里随便采一个 z 去解码，这个 z 对应哪张 xi 是不确定的，拿它和某张图算重建损失没有意义。

换个问题：去找后验 pθ(z|xi)

变分自编码器换了个角度：给定 xi 以后，z 的条件分布 pθ(z|xi) 是什么样。这个分布叫后验 (Posterior)。它是不是高斯、参数是多少，都不知道。

先假设它已知，往后看一步：从 pθ(z|xi) 里采一个 z，送进解码器得到 x̂i，和 xi 算重建损失来训练解码器。这个损失是合理的，因为 z 就是从 xi 的条件分布里来的，和 xi 对得上。上一节的第二个难处就这样解决了。

于是任务从「给每个 xi 找一个确定的 zi」变成了「给每个 xi 找 z 的一个分布」。讲者认为这是整个推导里最关键的一步转换。

他在这里回顾了一遍：自编码器学到了特征，但没有约束特征的分布，所以采不到新的隐向量；隐变量本来就观测不到，先验可以自己假设，但假设了先验，又找不到数据点和分布里的点怎么对应，编码器没法训。现在不找确切的 z，改为找后验。

注p(z) 是先验 (Prior)，看到 x 之前对 z 的假设；pθ(z|xi) 是后验，看到 xi 之后 z 的分布。θ 是解码器的参数，后验由先验和解码器一起决定：pθ(z|x) = pθ(x|z) p(z) / pθ(x)。分母 pθ(x) 要对所有 z 积分，算不出来，这就是第 13 讲说后验不可算的原因。

变分贝叶斯：在高斯分布族里找离后验最近的那个

后验算不出来，就找一个近似。变分贝叶斯 (Variational Bayes) 是贝叶斯推断里的一种近似方法。讲者说不必非要掌握它，讲它是为了说明「变分」这个名字从哪来。

板书上的大圆代表所有分布构成的集合，真实后验 pθ(z|xi) 是其中一个点。里面的小圈是一族我们会算的分布，比如高斯分布族。做法是在这一族里找一个和后验最接近的分布 qφ(z|xi) 去近似它：从族里某个分布出发，通过优化一步步挪到离后验最近的位置。

这样问题就变成了优化 φ。φ 是这个高斯分布的参数，也就是均值 μ 和标准差 σ。

注讲者说 qφ(z|xi) 里写不写 xi 无所谓，为了形式统一才写上。在变分自编码器里这个 xi 很要紧：每张图有自己的后验，近似也得每张图一个。

变分自编码器不为每张图单独优化一组 μ、σ，而是训练一个网络，输入 xi、输出这张图的 μ 和 σ，这个网络就是编码器，这种做法叫摊销推断 (Amortized Inference)。所以「优化 φ」就是训练编码器。

用 KL 散度衡量「最近」

「最近」要有一个度量，这里用 KL 散度 (Kullback-Leibler Divergence)，目标是最小化 KL(qφ(z|xi) ‖ pθ(z|xi))。KL 散度不对称，两个分布交换位置结果就不同，严格说它不是距离，但可以当作衡量近似程度的标准。用 KL 散度做这件事，就是变分贝叶斯法。

难点在于 pθ(z|xi) 本身不知道，这个 KL 写不出表达式，没法直接算。下一节的推导绕开它，得到一个能算的替代目标，叫变分下界，也就是 ELBO。

注定义：KL(q ‖ p) = ∫ q(z) log [q(z) / p(z)] dz = Eq[log q(z) − log p(z)]。后面要用到两条性质。KL ≥ 0，当且仅当两个分布处处相等时为 0。KL(q ‖ p) 和 KL(p ‖ q) 一般不相等，变分推断用 q 在前的这个，期望按 q 取，只需要能从 q 里采样。

展开 KL：log p(xi) = KL + ELBO

从 KL 散度的定义出发，只用两个工具：对数的性质 log(a/b) = log a − log b，以及条件概率的定义 p(z|xi) = p(z, xi) / p(xi)。下面的期望 Eq 都按 z ∼ qφ(z|xi) 取。

KL(qφ(z|xi) ‖ pθ(z|xi)) = ∫ qφ(z|xi) log [qφ(z|xi) / pθ(z|xi)] dzKL 散度的定义
= Eq[log qφ(z|xi)] − Eq[log pθ(z|xi)]对数拆成相减，积分写成期望
= Eq[log qφ(z|xi)] − Eq[log pθ(z, xi)] + Eq[log pθ(xi)]代入 p(z|xi) = p(z, xi) / p(xi)，前面的减号让最后一项变成加
= Eq[log qφ(z|xi)] − Eq[log pθ(z, xi)] + log pθ(xi)log pθ(xi) 里没有 z，期望就是它本身
= −ELBO + log pθ(xi)前两项记作 −ELBO

其中 ELBO = Eq[log pθ(z, xi)] − Eq[log qφ(z|xi)]。移项得到一个恒等式：

log pθ(xi) = KL(qφ(z|xi) ‖ pθ(z|xi)) + ELBO

log pθ(xi) 叫边际似然 (Marginal Likelihood)，也叫证据 (Evidence)，做生成模型时说的最大似然就是最大化它。这个式子对任何 q 都成立，中间没有任何近似。

注板书和这里有两处不同。期望的下标写成了 Eq(z)，省掉了 xi，和上一节「写不写 xi 无所谓」一致，但 q 实际依赖 xi；θ 和 φ 也时写时不写。推导本身没有错。

为什么最大化 ELBO 就是最小化 KL

回到最初的目标：用 q 近似后验，也就是最小化上面那个 KL。恒等式左边的 log pθ(xi) 里没有 z，和 q 也无关，调 φ 改变 q 的时候它是一个常数。

常数等于 KL 加 ELBO，两项此消彼长，ELBO 涨多少 KL 就降多少。所以最小化那个算不出来的 KL，等价于最大化能算出来的 ELBO。讲者强调这一步是整件事的核心，不少博客没讲明白为什么要最大化 ELBO。

名字也从这里来。KL ≥ 0，所以 ELBO ≤ log pθ(xi)，ELBO 是证据（对数边际似然）的一个下界，Evidence Lower Bound。只有 q 恰好等于真实后验时等号才成立。

注和CS231n 的推导对照。课上从最大似然出发：想最大化 log pθ(x)，写出同样的三项，扔掉算不出的 KL 得到下界，再最大化下界。这个视频从近似后验出发，固定 θ 只看 φ。

实际训练时编码器 φ 和解码器 θ 一起更新：对 φ 来说，抬高 ELBO 就是让 q 贴近后验；对 θ 来说，抬高 ELBO 会把 log pθ(x) 一起往上推。两种讲法优化的是同一个式子。

把 ELBO 拆成两项

接着把 ELBO 化成能直接当损失用的形式。这次换一种方式拆联合分布：pθ(z, xi) = p(z) pθ(xi|z)，先验乘解码器给出的似然。

ELBO = Eq[log pθ(z, xi)] − Eq[log qφ(z|xi)]
= Eq[log p(z) + log pθ(xi|z)] − Eq[log qφ(z|xi)]联合分布拆成先验乘似然，乘积的对数变成相加
= Eq[log pθ(xi|z)] − (Eq[log qφ(z|xi)] − Eq[log p(z)])把含 q 和 p(z) 的两项放到一起
= Eq[log pθ(xi|z)] − Eq[log (qφ(z|xi) / p(z))]对数相减变成对数里相除
= Eq[log pθ(xi|z)] − KL(qφ(z|xi) ‖ p(z))按 KL 散度的定义

ELBO 由此分成两项。第一项：从 q 里采 z，解码器还原出 xi 的对数似然，取期望。第二项：近似后验 q 和先验 p(z) 之间的 KL 散度。最大化 ELBO 就是同时最大化第一项、最小化第二项。

注板书倒数第二行写的是 −Eq[log q(z) / log p(z)]，应为 log (q(z) / p(z))，两个对数相除和对数里面相除是两回事。下一行写成 KL 的结果是对的。

两个目标：贴近先验，重建得好

损失函数到这里就出来了。先验 p(z) 一开始就假设好了，是标准正态分布 N(0, 1)；q 从高斯分布族里取，qφ(z|xi) = N(μ, σ2)。于是训练要做两件事：

  • 最小化 KL(qφ(z|xi) ‖ p(z))：编码器给每张图输出的高斯，要靠近标准正态分布。
  • 最大化 Eq[log pθ(xi|z)]：给定 z 时 xi 的似然要大。生成模型里这个似然由网络来学，这个网络就是解码器。

讲者把整条链又走了一遍：想找和 xi 对应的 z 来训练解码器，所以要后验；后验算不出，用变分贝叶斯取一个高斯 q 去近似；近似得好不好用 KL 量；这个 KL 算不出，转成最大化 ELBO；ELBO 再拆成上面两项。按原论文这条推导，q 往 N(0, 1) 靠是推出来的结论，出发点是近似后验。

注讲者有一句说，q 和真实后验越近越好，等价于 q 和先验越近越好。这句说过头了。KL(q ‖ p(z)) 只是 ELBO 里的一项，它和重建项互相牵制：q 如果完全等于 N(0, 1)，z 里就不带任何关于 xi 的信息，重建项会很差。最大化的是两项之和，最终的 q 落在两者之间。

训练流程：编码器输出 μ 和 σ，采样，解码

第一项前面有一个按 q 取的期望。所以每次编码得到 q 以后，都要从 q 里重新采一个 z（蒙特卡洛方法），希望每次采到的 z 都能把 xi 还原好。训练一步是这样：

  • 输入 x，编码器输出 μ 和 σ，确定一个高斯分布 N(μ, σ2)。
  • 从这个高斯里采一个 z。
  • 解码器把 z 还原成 x̂，和 x 算 L1 或 L2 重建损失。
  • 同时算 KL(N(μ, σ2) ‖ N(0, 1)) 这一项损失，把每张图的高斯往标准正态分布拉。

回头对照推导：编码器输出的 N(μ, σ2) 就是 q，在近似真实后验 pθ(z|xi)；N(0, 1) 是先验 p(z)。从 q 里采出的 z 可以看作来自 xi 的后验，和 xi 对得上，所以拿它重建 xi 是合理的。

两项损失具体怎么算，讲者没有展开，这里补上。KL 项在两个高斯之间有解析解，不用采样。z 有 d 维、各维独立时：

KL(N(μ, σ2) ‖ N(0, 1)) = ½ Σj (μj2 + σj2 − 1 − log σj2)对 d 个维度求和

比如某一维 μ = 0.5、σ = 0.8，这一维的 KL 是 ½ × (0.25 + 0.64 − 1 + 0.446) ≈ 0.168；μ = 0、σ = 1 时是 0，正好就是先验本身。

重建项取决于解码器假设的分布。假设 pθ(x|z) 是均值为 x̂、方差固定为 s2 的高斯，那么 log pθ(x|z) = −‖x − x̂‖2 / (2s2) + 常数，最大化它就是最小化 L2 损失；假设成拉普拉斯分布，就对应 L1 损失。讲者说的「L1 或 L2 重建损失」就是这么来的。

注还有一处讲者没提：z 是采样得到的，采样这一步没法直接对 μ、σ 求梯度。变分自编码器用重参数化技巧 (Reparameterization Trick)：先从 N(0, 1) 采 ε，再算 z = μ + σ ε。随机性都放进 ε，z 对 μ 和 σ 可导，梯度就能传回编码器。

CS231n 的训练一步讲过这一步，公式推导见 KL 散度资料。

为什么每次都重新采样

每次都从 q 里重新采样，是因为重建项是一个期望，期望一般用蒙特卡洛估计。讲者的说法是，希望从 q 里采到的每一个 z 都能把 xi 还原好，所以不断采、不断重建。

他还提到另一种看法：从同一个 xi 的高斯里采出 z1、z2 等好几个点，都要求还原成 xi，相当于在隐空间里做数据增强，解码器会更鲁棒，泛化更好。

最后他把主线收拢了一遍：变分自编码器的出发点是找一个和 xi 对应的 z 去做重建，为此用变分贝叶斯假设了一个 q，最小化 KL，推成最大化 ELBO，再推出两项损失。网上有的讲法直接规定隐空间要服从正态分布，出发点不同，结论一样。

注实际训练中通常每张图每一步只采一个 z，靠大量迭代把期望平均出来。原论文第 2.3 节说，只要批量够大（他们用 100），每个样本采一次就够了。

隐空间长什么样：只有重建、只有 KL、两者都有

板书上贴了三张图：在 MNIST（0 到 9 的手写数字）上训练，把隐空间画成二维，十种颜色对应十个数字。讲者说实际的隐空间维度可能很高，这是投影到二维的样子。

  • 只有重建损失，也就是普通自编码器：同一个数字聚成一块，有区域性；但整体没有规则，各块的形状和位置很随意，块之间有大片空白，很难找到一个合理的新 z。这就是自编码器不能当生成模型的原因。
  • 只有 KL 散度、不做重建：所有点挤成一个中间密、四周疏的圆，明显是正态分布，有规则；但不同数字混在一起，没有区域性。
  • 两者都用，即变分自编码器：既有区域，又有规则。

讲者的对应关系是：重建损失管区域性，KL 散度管规则。后者好理解，KL 本来就是把隐空间往假设的标准正态分布上拉。前者是因为隐空间也是特征空间，自编码器学的就是特征，相似的图特征相近，投影以后也挨在一起。

图上还能看到数字之间的过渡是连续的：从「1」的区域往「2」的区域走，中间的点解码出来会从 1 慢慢变成 2。讲者把解码器的作用概括为在 KL 给出的那团正态分布上做了一次聚类，特征相近的图聚到一起，又没有打破整体分布，所以能从里面采新的 z 来生成新图。

注三张图标题是 Only reconstruction loss、Only KL divergence、Combination，出自 Irhum Shafkat 的博客文章 Intuitively Understanding Variational Autoencoders。

讲者口头说的「L1 损失对应区域性」指的是重建损失，用 L1 还是 L2 不影响这个结论。

Latent Diffusion 为什么更清晰：第一个猜想

回到开头的问题。两者结构差不多，都是一个编码器加一个解码器，Latent Diffusion 只是中间多了扩散。讲者说网上没找到相关的讨论，下面是他自己的思考，可能有错。

第一个猜想和变分贝叶斯有关。两者都假设先验 p(z) 是 N(0, 1)。变分自编码器靠最小化 KL(q ‖ p(z)) 让数据的隐向量服从先验，而 q 是从高斯族里取来近似后验的，真实后验未必是高斯。这一步近似本身就带来偏差，最后拟合出来的正态分布不如想象中好，生成效果也跟着打折。

扩散模型学的是噪声到任意分布的映射

先看普通的像素扩散：一张图一步步加噪，最后变成服从标准正态分布的噪声；生成时随便取一个噪声，就能一步步还原成图。它学到的是标准正态分布和真实数据分布 p(x) 之间的映射，而且真实分布不需要是高斯。

变分自编码器的问题出在用高斯 q 去假设后验 p(z|xi)。既然扩散模型能学任意未知分布和标准正态分布之间的映射，这个假设就可以不做：隐向量服从什么分布不用知道，交给扩散模型去学它和 N(0, 1) 之间的映射。

生成时从 N(0, 1) 取一个 ε，扩散模型把它变成一个服从隐空间分布的 z，解码器再把 z 解成图。少了一步高斯假设，效果可能就更好。这是他的第一个思考。

注对照 Latent Diffusion 原论文第 3.1 节和附录 G：猜想的方向大体对，但还有一个更直接的原因讲者没提。

原论文的自编码器用感知损失 (Perceptual Loss) 加基于图块的对抗损失 (Patch-based Adversarial Objective) 训练，论文说这样能保证重建的局部真实感，避免只用 L1、L2 这类像素损失带来的模糊。

隐空间的正则也很弱：KL 版本的 KL 项权重只有约 10−6，另一个版本用向量量化代替 KL，隐空间几乎不被拉向 N(0, 1)，接近一个普通自编码器，所以重建清楚。

隐向量的分布交给扩散模型去学，这一点和讲者的猜想一致。所以 Latent Diffusion 的清晰来自两处：解码器本身用感知和对抗损失训练；生成时 z 由扩散模型给出，不再直接从 N(0, 1) 里采。

第二个原因：重叠处取平均，图就糊了

第二个思考是变分自编码器的老毛病，讲者说这个说法是别人提过的。两张图各自的高斯 q 可能有重叠，两张图都可能采到重叠区域里的同一个 z，虽然概率很小。解码器面对这个 z，不知道该还原成哪一张，为了让重建损失最小，训练中就会取两者的平均。平均的结果是高频细节变差，图就糊了。

举个数字的例子：同一个 z 在一张图里对应某个像素值 0（黑），在另一张里对应 1（白）。用 L2 损失时最优输出是均值 0.5，一片灰；用 L1 时最优输出是中位数，只有两个样本时 0 到 1 之间任何值损失都一样，同样给不出一条清楚的边。边缘、纹理这些高频部分在不同样本之间最容易对不齐，也最容易被平均掉。

讲者最后的总结：Latent Diffusion 比变分自编码器好，主要因为它利用了扩散模型的长处，能学到任意未知的复杂分布和标准正态分布之间的关系。隐空间的后验正好是一个未知分布，扩散模型绕开了用变分贝叶斯去近似它这一步，所以效果更好。

注第二个原因也解释了为什么改训练目标有用：只要重建损失是逐像素的 L1、L2，多个可能答案之间就会被平均。Latent Diffusion 的自编码器加了对抗损失，判别器会惩罚看起来模糊的重建，解码器就不能靠取平均来压低损失。

这个视频记住这几条

  • 自编码器能学特征但不能生成：隐空间没有约束，采不到合理的新 z。
  • 变分自编码器把「给每张图找一个 z」换成「给每张图找 z 的后验分布」。后验算不出，就用一个高斯 qφ(z|xi) 去近似，这是变分贝叶斯；编码器输出的 μ、σ 就是这个高斯的参数。
  • 恒等式 log pθ(xi) = KL(q ‖ pθ(z|xi)) + ELBO 对任何 q 都成立。左边和 q 无关，所以最小化算不出的 KL 等价于最大化能算的 ELBO；又因为 KL ≥ 0，ELBO 是对数似然的下界。
  • ELBO = Eq[log pθ(xi|z)] − KL(qφ(z|xi) ‖ p(z))：前一项是重建损失（高斯解码器对应 L2），后一项把每张图的高斯拉向 N(0, 1)，有解析解；采样那一步靠重参数化技巧传梯度。
  • 二维隐空间上，重建损失让同类聚成区域，KL 让整体成为规则的正态分布，两者缺一不可。
  • 变分自编码器发糊，是因为逐像素重建损失在重叠的后验之间取平均。Latent Diffusion 的自编码器改用感知加对抗损失、KL 权重压到约 10−6，隐向量的分布交给扩散模型去学。

2合起来看：编码器和解码器一起更新

实际训练时 θ（解码器）和 φ（编码器）同时更新，同一个 ELBO 对两者的作用不一样：

  • 对 φ：log p(x) 和 φ 无关，是常数。抬高 ELBO 只能靠缩小间隙 KL(q ‖ 后验)，也就是让编码器给出的 q 更贴近真实后验。这是视频讲的那一半。
  • 对 θ：ELBO 是 log p(x) 的下界，抬高它会把 log p(x) 一起往上推。这是 CS231n 讲的那一半。θ 变了，真实后验也跟着变，间隙不一定保持不变。

所以最大化 ELBO 一举两得：下界在变紧，同时在被往上推。两种讲法各自固定了一个参数在看，视频固定 θ 只看 φ，CS231n 没区分两者，一句「希望」带过。

3拆 ELBO 的两种写法

两边最后都要把 ELBO 写成「重建项减先验项」，拆法略有不同。

CS231n 是一步到位：贝叶斯公式里的分子本来就是 pθ(x|z) p(z)，乘上 q/q 以后直接按「p(x|z)、q 配 p(z)、q 配后验」分组，三项一次出来。

视频是两步：先把 KL(q ‖ 后验) 展开，用条件概率把后验换成联合分布 p(z, xi)，得到 ELBO = Eq[log p(z, xi)] − Eq[log q]；再把联合分布拆成 p(z) pθ(xi|z)，合并出 KL(q ‖ p(z))。

ELBO = Eq[log pθ(z, x)] − Eq[log qφ(z|x)]视频的第一种形式：联合分布减 q 的熵项
= Eq[log pθ(x|z)] − KL(qφ(z|x) ‖ p(z))两边共同的最终形式

第一种形式在论文里也常见，它的好处是不需要先认出 KL：−Eq[log q] 就是 q 的熵，所以 ELBO 也可以读成「联合分布的期望对数概率，加上 q 的熵」。

  • 为什么不直接把 z 积掉：高维积分算不动。
  • 神经网络怎么输出分布：对角高斯，为什么必须对角，为什么解码器方差固定。
  • 解码器是高斯时，重建项就是 L2 损失。
  • 重参数化技巧：采样那一步怎么传梯度。
  • 隐空间各维独立，可以分别改变；在手写数字上沿两维平滑变形。
  • Latent Diffusion 的自编码器加了判别器（第 14 讲）。

视频讲到、CS231n 没讲的：

  • 「变分」这个名字从哪来：变分贝叶斯，在分布族里找最近的那个。
  • 为什么最大化 ELBO 能让 q 贴近后验：log p(x) 对 q 是常数。
  • 二维隐空间里只用重建、只用 KL、两者都用的对比图。
  • 变分自编码器为什么糊，以及和 Latent Diffusion 的比较。

两边都没讲的，补在「KL 散度」资料、「综述」和「常见问题」里：KL 散度的定义和 ≥ 0 的证明，两个高斯之间 KL 的解析解，KL 方向带来的偏窄，后验坍缩，β 变分自编码器。

6建议的读法

没学过 KL 散度的话，先看「KL 散度」资料里的定义、≥ 0 和方向三节，十分钟能看完。

然后看 CS231n 的讲法，它把问题的来龙去脉交代得最清楚：为什么要隐变量，为什么积分和贝叶斯公式都走不通，网络怎么输出分布。推导那一节对着课件截图一行行看。

再看视频，从另一头把同一个恒等式推一遍，重点看「为什么最大化 ELBO 就是最小化 KL」和后半段的隐空间对比、糊的讨论。

最后看这一页和常见问题，把两种讲法合起来。
