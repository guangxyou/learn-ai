1概述：用一个分类器训练生成器

生成对抗网络 (Generative Adversarial Network, GAN) 是一种生成模型，由蒙特利尔大学的 Ian Goodfellow、Jean Pouget-Abadie、Mehdi Mirza、Bing Xu、David Warde-Farley、Sherjil Ozair、Aaron Courville 和 Yoshua Bengio 提出。论文 2014-06-10 发布在 arXiv，发表于 NIPS 2014。

它训练两个网络。生成器 G 把一个随机噪声 z 映射成样本。判别器 D 接收一个样本，输出它来自真实数据的概率。D 的目标是分清真假，G 的目标是让 D 判错。两者交替更新，形成一个极小极大博弈。

和 VAE、DDPM 不同，GAN 从不写出 p(x)，也不优化似然。损失完全由另一个网络给出。生成时只需一次前向计算，不需要马尔可夫链，也不需要迭代。

从 2015 年到 2021 年前后，GAN 是高质量图像生成的主要方法。此后它的主导地位被扩散模型取代，但判别器作为一种损失函数保留了下来：Stable Diffusion 的自编码器就用它合成局部纹理。

2来历：不用马尔可夫链，也不用近似推断

2014 年的深度学习成就主要在判别模型，比如图像分类和语音识别，依靠的是反向传播、Dropout 和分段线性单元。深度生成模型的影响小得多，因为它们常常要面对难以计算的概率量。

当时的主要生成模型有几类。受限玻尔兹曼机和深度玻尔兹曼机要处理配分函数及其梯度，只能用马尔可夫链蒙特卡洛估计，混合困难。深度信念网络同时继承了有向和无向模型的计算困难。生成随机网络 (GSN) 不需要写出密度，但采样仍要运行马尔可夫链。几个月前的 VAE（2013-12-20）用反向传播训练生成网络，代价是优化证据下界，并且需要一个推断网络。

Goodfellow 的想法是把密度估计问题改写成分类问题。分类已经是深度学习最擅长的事，分类器能告诉生成器它的样本哪里不像真实数据。这样既不需要配分函数，也不需要马尔可夫链，还能直接使用分段线性单元。

论文致谢里写着感谢「Les Trois Brasseurs」激发创造力，这是蒙特利尔的一家酒吧。Goodfellow 在 DeepLearning.AI 的访谈中说，想法来自和朋友在那里的一次讨论，他当晚回家写了第一版代码。

思路本身有更早的来源。噪声对比估计（Gutmann、Hyvärinen）已经用判别准则训练生成模型，但判别的对象是一个固定的噪声分布，所以模型一旦学到近似分布，学习就会变慢。GAN 让判别器和生成器一起变化，避开了这个问题。论文在相关工作里讨论了这一点。

对抗模型的特点是：放弃密度，换来采样和模型设计上的自由。代价有两个，一是算不出 pg(x)，二是训练时两个网络要保持同步。第二个代价在此后几年里成为这个领域的主要问题。

4整体结构：一个采样器和一个分类器

生成器 G(z; θg) 是一个可微函数，输入来自先验 pz(z) 的噪声，输出一个数据空间中的样本。先验是固定的，通常取高斯或均匀分布。G 的结构没有特别要求，它和先验一起隐式地定义了一个分布 pg：从 pz 采样 z，经过 G 得到的样本服从 pg。

这个分布只能采样，不能求值。这也是把 GAN 称为隐式生成模型 (Implicit Generative Model) 的原因。如果 z 的维度低于数据维度，pg 集中在一个低维流形上，在数据空间中甚至没有密度函数。

判别器 D(x; θd) 是一个普通的二分类网络，输出一个标量，表示 x 来自数据而不是 pg 的概率。两个网络的联系只有一处：G 的输出是 D 的输入，所以梯度可以从 D 一直传回 G。

论文用一个比喻说明它们的关系：生成器相当于制造假币的团伙，判别器相当于警察，竞争促使双方不断改进，直到假币和真币无法区分。

一旦训练结束，判别器就被丢弃，生成图像只用 G。这和 VAE 的结构形成对比：VAE 的解码器也是一次前向生成，但训练它的是一个推断网络和重建损失，而 GAN 的生成器从未直接接触数据。

5目标函数：极小极大博弈

两个网络优化同一个价值函数 V(G, D)，方向相反：

minG maxD V(G, D) = 𝔼x∼pdata [log D(x)] + 𝔼z∼pz [log(1 − D(G(z)))]论文式 (1)
  • 对判别器： 第一项让真实样本的输出接近 1，第二项让生成样本的输出接近 0。这正是二分类的交叉熵，标签是「真实样本为 1，生成样本为 0」，只差一个符号。
  • 对生成器： 第一项与 G 无关，只有第二项起作用。G 要最小化 log(1 − D(G(z)))，也就是让 D(G(z)) 变大。

V 的数值不能当作损失来看。一般的训练有一条下降的曲线，这里的 V 同时取决于两个网络：判别器强时 V 大，生成器强时 V 小，同样的数值可以对应完全不同的训练状态。这一点直接导致 GAN 难以判断是否在变好，后面的训练难点一节会再谈。

6训练算法：交替更新

把内层的最大化做到收敛，既算不起，也会在有限数据上过拟合。所以算法 1 交替进行：k 步判别器，一步生成器。论文的实验取 k = 1，这是最省计算的选择。只要 G 变化得足够慢，D 就能保持在最优解附近。

∇θd (1/m) Σi=1m [ log D(x(i)) + log(1 − D(G(z(i)))) ]判别器：做梯度上升
∇θg (1/m) Σi=1m log(1 − D(G(z(i))))生成器：做梯度下降

下面是完整可运行的代码（PyTorch）。数据是一个二维玩具分布：半径为 2 的圆上 8 个高斯，这样在笔记本的 CPU 上几十秒就能跑完，也容易看出覆盖了几个模式。后面非饱和目标一节的实验结果就是这段代码跑出来的。

import math, torch, torch.nn as nn

def real_batch(n):                 # 真实分布：圆上 8 个高斯，标准差 0.05
    k = torch.randint(0, 8, (n,))
    centers = torch.stack([2 * torch.cos(k * math.pi / 4), 2 * torch.sin(k * math.pi / 4)], 1)
    return centers + 0.05 * torch.randn(n, 2)

def mlp(i, o):
    return nn.Sequential(nn.Linear(i, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, o))

z_dim, m = 16, 256
G, D = mlp(z_dim, 2), mlp(2, 1)    # D 输出 logit，sigmoid 放进损失函数
opt_g = torch.optim.Adam(G.parameters(), 2e-4, betas=(0.5, 0.999))
opt_d = torch.optim.Adam(D.parameters(), 2e-4, betas=(0.5, 0.999))
bce = nn.functional.binary_cross_entropy_with_logits
one, zero = torch.ones(m, 1), torch.zeros(m, 1)

for step in range(20001):
    # 判别器一步（k = 1）：真实样本标 1，生成样本标 0。detach 使梯度不进入 G
    fake = G(torch.randn(m, z_dim)).detach()
    loss_d = bce(D(real_batch(m)), one) + bce(D(fake), zero)
    opt_d.zero_grad(); loss_d.backward(); opt_d.step()

    # 生成器一步：梯度穿过 D 回到 G，但只更新 G 的参数
    logit = D(G(torch.randn(m, z_dim)))
    loss_g = -bce(logit, zero)     # 式 (1) 的原始目标：最小化 log(1 − D(G(z)))
    # loss_g = bce(logit, one)     # 非饱和目标：最大化 log D(G(z))
    opt_g.zero_grad(); loss_g.backward(); opt_g.step()

补充更新生成器时梯度也流过 D，D 的 .grad 会累积，但下一步判别器更新前的 zero_grad 会把它清掉，所以不影响结果。

7理论结果一：最优判别器

接下来的理论分析在函数空间中进行：假设 G 和 D 的容量无限，直接讨论 pg 和 D，不讨论网络参数。第一步固定 G，求最优的 D。

用期望的换元（把对 z 的期望写成对 pg 的期望），价值函数变成对 x 的积分：

V(G, D) = ∫x [ pdata(x) log D(x) + pg(x) log(1 − D(x)) ] dx论文式 (3)

积分可以逐点最大化。对固定的 x，记 a = pdata(x)，b = pg(x)，y = D(x)，函数 a log y + b log(1 − y) 对 y 求导并令其为零，得到 y = a / (a + b)。于是：

D^*G(x) = pdata(x) / ( pdata(x) + pg(x) )论文式 (2)，命题 1

这个结果很直观：D^* 在每一点给出样本来自数据的后验概率，先验是真假各一半。它还说明判别器其实在估计一个密度比：D^*(x) / (1 − D^*(x)) = pdata(x) / pg(x)。后来的很多方法，比如 f-GAN，都从这个角度推广。

8理论结果二：全局最优是 pg = pdata

把 D^* 代回价值函数，得到一个只关于 G 的训练准则：

C(G) = maxD V(G, D) = 𝔼x∼pdata [ log( pdata(x) / (pdata(x) + pg(x)) ) ] + 𝔼x∼pg [ log( pg(x) / (pdata(x) + pg(x)) ) ]论文式 (4)

分母乘 2 再除以 2，就能凑出两个 KL 散度：

C(G) = −log 4 + KL( pdata ‖ (pdata + pg) / 2 ) + KL( pg ‖ (pdata + pg) / 2 )论文式 (5)
C(G) = −log 4 + 2 · JSD( pdata ‖ pg )论文式 (6)，JSD 是 Jensen–Shannon 散度

JS 散度非负，且只在两个分布相同时为零。所以 C(G) 的全局最小值是 −log 4，当且仅当 pg = pdata 时取到（定理 1）。此时 D^*(x) = 1/2，判别器只能随机猜测。

这个定理给了 GAN 理论上的依据：博弈的唯一全局最优就是生成分布等于数据分布，判别器并不是一个随意选择的损失。

9理论结果三：收敛结论的前提

命题 2 说：如果 G 和 D 容量足够，每一步都把 D 训练到最优，并且 pg 按更新后的准则改进，那么 pg 收敛到 pdata。证明依据的是 V 关于 pg 是凸的，而凸函数族上确界的次梯度包含取到上确界那一个函数的梯度。

这个结论的前提和实际算法有三处差别：

  • 优化的对象不同。 证明直接更新函数 pg，实际优化的是网络参数 θg，关于参数并不是凸的。论文承认这一点，并说多层感知机在实践中的出色表现说明它仍是合理的选择。
  • 判别器不是最优的。 证明要求每一步都把 D 训练到最优，算法只更新一步。
  • 目标也换了。 实际使用的通常是下面的非饱和目标，它已经不是这个极小极大博弈。

后来的研究确实发现了问题。Mescheder 等人（2018-01-13）构造了一个只有两个参数的简单例子，证明未加正则化的 GAN 在分布不连续时不一定收敛，并提出了 R1 梯度惩罚。Arjovsky 和 Bottou（2017-01-17）指出，如果 pdata 和 pg 位于不重合的低维流形上，最优判别器能完美区分，生成器的梯度就会消失。

10非饱和目标：实践中的第一个修改

论文第 3 节末尾给出了一个实践上的修改。训练初期 G 很差，D 能高置信度地拒绝生成样本，D(G(z)) 接近 0，此时 log(1 − D(G(z))) 饱和，几乎提供不了梯度。所以不让 G 最小化 log(1 − D(G(z)))，而是最大化 log D(G(z))：

minθg 𝔼z [ log(1 − D(G(z))) ]原始目标，导数大小为 1 / (1 − D)，D → 0 时趋于 1
minθg 𝔼z [ −log D(G(z)) ]非饱和目标，导数大小为 1 / D，D → 0 时趋于无穷

这里说的饱和还要算上 D 内部的 sigmoid：若 D = σ(ℓ)，ℓ 是 logit，则原始目标对 ℓ 的导数大小是 D 本身，D 接近 0 时趋于 0，非饱和目标对 ℓ 的导数大小是 1 − D，趋于 1。

我们实际测了这一点。用前面代码中的网络，固定 G 为初始状态，单独把 D 训练若干步，再计算两种目标对 θg 的梯度范数（5 个种子的平均）：

但这个修改是有代价的，它不再是原来的博弈。Goodfellow 在 NIPS 2016 教程中说，这个版本完全出于启发式考虑，唯一的动机是保证生成器有足够强的梯度。Arjovsky 和 Bottou 算出，判别器最优时，非饱和目标的梯度等于下面这个量的梯度：

KL( pg ‖ pdata ) − 2 · JSD( pg ‖ pdata )Arjovsky、Bottou（2017-01-17），定理 2.5

这个式子里的 KL 方向是反的：生成了数据中不存在的样本，代价很大；漏掉数据中的模式，代价很小。负的 JS 项还在把两个分布推开。这与模式坍缩的现象是一致的。

这个玩具实验的结果和通常的印象相反，原始目标反而更好：5 个种子中，原始目标在第 20000 步全部覆盖 8 个模式，非饱和目标只覆盖 2、3、3、4、3 个。原因是两种目标解决的问题不同。在二维玩具数据上，判别器不容易压倒生成器，梯度消失并没有发生，于是非饱和目标的模式丢失问题就显现出来了。图像这样的高维数据上，D 很容易把生成样本分开，原始目标在训练初期得不到梯度，所以实践中仍然常用非饱和目标。不应把这一个玩具实验推广到图像。

11原论文的实验

实验用了 MNIST、Toronto Face Database (TFD) 和 CIFAR-10。生成器混合使用 ReLU 和 sigmoid 激活，判别器使用 maxout 激活，训练判别器时使用 Dropout。噪声只输入生成器最底层。

论文没有办法直接计算似然，于是对生成样本拟合高斯 Parzen 窗，用测试集在这个密度下的对数似然作为指标，窗宽 σ 用验证集交叉验证。

论文自己也说，这种估计方差较大，在高维空间表现不好，只是当时能用的最好方法。Theis 等人后来指出（2015-11-05），Parzen 窗估计和样本质量之间可能相差很远，这个指标很快被放弃。

样本质量以今天的标准看很低：32×32 的 CIFAR-10 只能看出模糊的轮廓。论文的态度也很克制，只说这些样本至少可以和当时较好的模型竞争，并显示了对抗框架的潜力。它在图 2 的说明中特意指出，这些图是真实样本，而其他深度生成模型的可视化往往展示的是条件均值。这也说明 GAN 样本清晰的特点从一开始就存在。

12评估：没有似然之后怎么比较

放弃似然带来一个长期问题：怎么判断模型好不好。后来形成的两个指标都依赖预训练的 Inception 网络。

  • Inception Score（2016-06-10）： IS = exp( 𝔼x KL( p(y|x) ‖ p(y) ) )。每张图的类别分布 p(y|x) 越集中，整体的类别分布 p(y) 越均匀，分数越高。缺点是不使用真实数据的统计量，也看不出类内多样性。
  • FID（2017-06-26）： 用高斯分布拟合真实图像和生成图像的 Inception 特征，计算两个高斯之间的 Fréchet 距离，FID = ‖μr − μg‖2 + Tr( Σr + Σg − 2 (Σr Σg)1/2 )。越低越好，同时反映质量和多样性，这是此后最常用的指标。

Lucic 等人（2017-11-28）用大规模实验比较了多种损失，结论是：充分调参并多次随机初始化后，大多数 GAN 变体的 FID 没有显著差异，很多报告的改进可能来自算力和调参。这个结果提醒大家，单次结果的比较并不可靠。

13训练难点

论文第 6 节列出的两个缺点就是此后几年的主要课题：没有 pg(x) 的显式表示，以及 D 要和 G 保持同步。

  • 不收敛。 这是一个博弈，梯度下降要寻找鞍点，而不是最小值。参数可能围绕平衡点振荡，甚至发散。
  • 模式坍缩 (Mode Collapse)。 生成器把很多 z 映射到少数几个样本。论文称之为「Helvetica 场景」。交替更新时，内外层的顺序其实是 maxD minG 和 minG maxD 的混合，对前者来说，生成器把所有质量放到当前判别器最认可的点上就是合理的，判别器随后转向，生成器又转到另一个点。
  • 梯度消失。 判别器太强时，原始目标饱和。当 pg 和 pdata 的支撑集几乎不重叠时，JS 散度保持常数 log 2，提供不了方向。
  • 没有可信的指标。 判别器和生成器的损失不说明训练进展。CS231n 第 14 讲对此有详细说明，并对比了扩散模型：后者至少有一条平滑下降的损失曲线。
  • 大量技巧。 训练结果对结构和超参数非常敏感。DCGAN 的准则、特征匹配、小批量判别、单侧标签平滑等都是这一时期的产物。

资料：CS231n 第 14 讲 →

14改进一：换目标函数

2016 年到 2018 年，大量工作在修改目标函数。f-GAN（2016-06-02）说明可以估计任意 f 散度，原始 GAN 只是其中一例。LSGAN（2016-11-13）把交叉熵换成最小二乘。

影响最大的是 WGAN（2017-01-26）。它指出 JS 散度的问题：两个支撑集不重叠的分布，无论相距多远，JS 散度都等于 log 2，梯度没有方向。Wasserstein-1 距离没有这个问题，它会随分布的距离连续变化。

根据 Kantorovich-Rubinstein 对偶，Wasserstein 距离可以写成对所有 1-Lipschitz 函数的上确界，于是判别器（WGAN 称作 critic）变成一个不带 sigmoid 的打分函数：

minG max‖f‖L ≤ 1 𝔼x∼pdata [f(x)] − 𝔼z∼pz [f(G(z))]WGAN 的目标

关键在于怎么保证 Lipschitz 约束。WGAN 把权重裁剪到 [−0.01, 0.01]，作者自己也称这是一种很糟糕的做法。WGAN-GP（2017-03-31）改为惩罚梯度范数偏离 1，默认 λ = 10，每步生成器更新 5 步判别器。谱归一化（2018-02-16）则直接约束每层权重的谱范数，后来被 SAGAN 和 BigGAN 采用。

Mescheder 等人（2018-01-13）提出的 R1 惩罚只惩罚真实样本上的判别器梯度，StyleGAN 系列一直在用。R3GAN（2025-01-09）则认为很多技巧是不必要的，它用一个带正则化的相对论损失加上现代网络结构，去掉了此前大部分技巧。

WGAN ↗WGAN-GP ↗Spectral Normalization ↗R3GAN ↗

15改进二：换网络结构

样本质量上的大幅进步主要来自结构。

  • DCGAN（2015-11-19）： Alec Radford 等人给出一组稳定训练的准则：用带步长的卷积替换池化，使用 Batch Normalization，去掉全连接层，生成器用 ReLU，判别器用 LeakyReLU。输入是 100 维噪声，批量 128，学习率 0.0002，Adam 的 β1 取 0.5。它还显示隐空间存在语义方向，比如「戴眼镜的男人 − 不戴眼镜的男人 + 不戴眼镜的女人」得到戴眼镜的女人。
  • Progressive GAN（2017-10-27）： 从低分辨率开始训练，逐层增加分辨率，第一次生成了 1024×1024 的高质量人脸。
  • SAGAN（2018-05-21）和 BigGAN（2018-09-28）： SAGAN 加入自注意力。BigGAN 把批量和通道数放大，并引入截断技巧，采样时把 z 限制在较小范围内，用多样性换取质量。ImageNet 128×128 上 IS 166.5、FID 7.4，此前最好是 52.52 和 18.65。
  • StyleGAN（2018-12-12）： 不再把 z 直接输入生成器，而是先经过 8 层映射网络得到 512 维的 w，再通过自适应实例归一化逐层调制，从而把粗结构和细节分开控制。StyleGAN2（2019-12-03）消除了水滴状伪影，把 FFHQ 的 FID 从 4.40 降到 2.84。StyleGAN3（2021-06-23）解决了混叠问题，消除了纹理粘在屏幕坐标上的现象。

StyleGAN-ADA（2020-06-11）用自适应的判别器数据增强解决小数据集上的过拟合。Projected GAN（2021-11-01）把判别器放到预训练网络的特征空间中。StyleGAN-XL（2022-02-01）把这条路线扩展到 ImageNet。

DCGAN ↗Progressive GAN ↗BigGAN ↗StyleGAN ↗StyleGAN2 ↗StyleGAN3 ↗

16条件生成和图像翻译

原论文的结论部分列出的第一个扩展就是条件生成：把条件 c 同时输入 G 和 D。Mirza 和 Osindero 在 2014-11-06 就实现了这个想法。

判别器本质上是一个可学习的损失函数，这个视角催生了图像翻译。pix2pix（2016-11-21）用 U-Net 生成器加 L1 损失和图块判别器，把语义图、线稿转成照片。它的图块判别器 (PatchGAN) 只判断局部是否真实，和 L1 损失互补：L1 负责整体结构，判别器负责高频细节。CycleGAN（2017-03-30）进一步去掉配对要求，用循环一致性约束两个方向的映射。

图块判别器后来成为 VQGAN 和 Latent Diffusion 自编码器的标准组件。

cGAN ↗pix2pix ↗CycleGAN ↗

17后续发展：被扩散模型超过，以判别器的形式留下

2021-05-11，ADM 在 ImageNet 256×256 上取得 FID 4.59，BigGAN-deep 为 6.95，这篇论文的标题就是 Diffusion Models Beat GANs。Recall 指标上差距更明显：BigGAN-deep 为 0.28，ADM-G 为 0.52，扩散模型覆盖数据分布的能力更好。

文本生成图像把这个差距进一步拉大。GAN 难以覆盖 LAION 这样多样的数据，在 2021 年以后的文本生成图像中，扩散模型成为主流。主要原因有三：扩散模型的目标是简单的回归，有平滑可信的损失曲线；不需要对抗平衡，方便扩展到很大的模型和数据集；覆盖分布的能力更好。

但 GAN 并没有消失，至少有三处保留了下来：

  • 作为感知损失。 VQGAN 和 Stable Diffusion 的自编码器用图块判别器合成局部纹理。这是如今使用最广的 GAN 组件，见 Latent Diffusion 综述。
  • 用于加速扩散。 SDXL Turbo 所用的对抗扩散蒸馏（2023-11-28）在蒸馏损失外加一个判别器，把生成压缩到 1 至 4 步。Denoising Diffusion GAN（2021-12-15）更早把两者结合。
  • 继续作为生成模型。 GigaGAN（2023-03-09）在文本条件下生成 512 像素图像约需 0.13 秒，R3GAN（2025-01-09）说明简单的现代结构也能取得有竞争力的结果。单步生成的速度优势仍然存在。

ADM ↗Denoising Diffusion GAN ↗Adversarial Diffusion Distillation ↗GigaGAN ↗

基本概念

生成器的损失从哪里来？它连真实数据都没见过。

来自判别器。生成器看到的只有 D(G(z)) 对自身参数的梯度。判别器学到了「真实样本长什么样」，这个信息通过梯度传给生成器。

论文认为这可能还是统计上的一个优点：输入的成分不会直接复制到生成器的参数中。见第 6 节。

综述：整体结构 →

GAN 是概率模型吗？

是，但它是隐式的。pz 和 G 确实定义了一个分布，可以从中采样，只是写不出密度 pg(x)，也算不出一个具体样本的似然。这和 VAE、DDPM 不同，它们至少能给出似然的下界。

这样的代价是评估困难，也是 IS、FID 这类指标出现的原因。

综述：评估 →

训练 GAN 时损失曲线不下降，是不是出了问题？

不一定。理想状态下 D(x) = D(G(z)) = 1/2，此时 V = −log 4 ≈ −1.386，交叉熵形式的判别器损失约为 2 log 2 ≈ 1.386，并不是零。损失稳定在某个值附近可能是正常的。

反过来，判别器损失趋于零常常说明判别器压倒了生成器。判断训练进展要看样本和 FID，不能只看这条曲线。

综述：目标函数 →CS231n：V 不是损失函数 →

算法里的 k 该取多少，为什么论文取 1？

论文取 k = 1，是因为这个选择计算量最小，实验中也够用。理论要求 D 接近最优，直觉上 k 大一些更好，但有限数据上训练过头的 D 会过拟合，也可能导致梯度饱和。

WGAN 系列默认每步生成器更新 5 步判别器，因为它的目标函数希望 critic 接近最优，且不会饱和。StyleGAN2 和多数现代实现用 k = 1。

综述：训练算法 →

目标函数

原始目标和非饱和目标不是优化同一件事吗？

不是。两者的不动点相同，但一般情况下不等价。原始目标对应一个真正的零和博弈，非饱和目标则不再是零和：判别器和生成器的目标不再互为相反数。

判别器最优时，非饱和目标的梯度等于 KL(pg ‖ pdata) − 2 JSD(pg ‖ pdata) 的梯度（Arjovsky、Bottou，定理 2.5）。这个方向的 KL 对丢失模式惩罚很小，负的 JS 项还有推开两个分布的作用。

综述：非饱和目标 →

本页的圆环实验里原始目标反而更好，那为什么大家都用非饱和目标？

这是一个二维玩具实验，判别器没有明显压倒生成器，所以梯度饱和这个主要问题没有出现，非饱和目标的代价（丢失模式）反而显现出来。5 个种子的结果都如此：第 20000 步时，原始目标全部覆盖 8 个模式，非饱和目标覆盖 2 至 4 个。

高维图像上，判别器分辨生成样本容易得多，这正是论文提出修改的原因。梯度实验也支持这一点：当 D(G(z)) 降到 0.0019 时，原始目标的梯度范数只有 0.0041，非饱和目标是 1.9。

这个实验没有在图像上重复，所以不能据此说明图像上哪个更好。一个结果也可能受学习率和网络结构的影响，这里没有做参数搜索。

综述：非饱和目标 →

为什么最优时是 −log 4，而不是 0？

−log 4 就是 D = 1/2 代入 V 的结果：log(1/2) + log(1/2) = −log 4。只有减去这个常数，才得到非负的 JS 散度：C(G) − (−log 4) = 2 JSD ≥ 0。

综述：全局最优 →基础：JS 散度 →

WGAN 解决了什么，又没解决什么？

WGAN 解决的是支撑集不重叠时 JS 散度不提供方向的问题，同时 critic 的目标值与样本质量的相关性更好。权重裁剪是它的主要弱点，WGAN-GP 和谱归一化修正了这一点。

它没有解决 GAN 的全部问题。Lucic 等人的大规模比较显示，调参充分时，各种损失的 FID 没有显著差异。CS231n 的 Johnson 也认为可解读损失曲线的问题没有真正解决。

论文里的「Helvetica 场景」是什么？

就是后来所说的模式坍缩 (Mode Collapse)：G 把太多 z 映射到同一个 x，没有足够的多样性。Goodfellow 在 NIPS 2016 教程中明确写着 mode collapse 也称 Helvetica scenario。

综述：训练难点 →

模式坍缩为什么会发生？

常见的解释有两个。第一，交替更新没有规定内外层的先后，如果 G 相对 D 更新过多，博弈更接近 maxD minG，生成器的最优响应就是把质量放到当前 D 最认可的一点。第二，非饱和目标对丢失模式的惩罚很小。

圆环实验展示了第二种情况。常用的缓解方法包括小批量判别、WGAN 系列的目标、R1 正则化和数据增强。

基础：极小极大博弈 →

为什么 GAN 的样本比 VAE 清晰？

VAE 的解码器通常用高斯似然，也就是像素 L2 损失，细节不确定时最优解是平均，表现为模糊。GAN 不做逐像素比较，模糊的图像很容易被判别器识别为假，所以生成器必须选择一种具体的细节。

论文从另一个角度说明了这一点：GAN 能表示非常尖锐甚至退化的分布，而基于马尔可夫链的方法要求分布有一定的模糊。

生成器会不会只是记住了训练集？

论文用最近邻检查了这一点：图 2 最右一列是相邻样本在训练集中的最近邻，二者不同。但有判别器无法发现的情况：如果生成器输出的是训练样本本身，判别器确实分不出来，这在理论上也是合法的解。

有限样本下，真实分布就是训练集的经验分布，所以严格的全局最优其实是记住训练集。实际没有发生，是网络结构和优化过程带来的泛化能力所致。这部分理论至今并不完整。

基础：散度和博弈

论文第 4 节的证明只用到几个工具：期望的换元、逐点优化、KL 散度和 JS 散度。这里按证明用到的顺序整理，并补上极小极大博弈和 Parzen 窗。

1期望的换元：从 z 到 x

价值函数的第二项是对 z 的期望，𝔼z∼pz [log(1 − D(G(z)))]。pg 的定义就是 G(z) 的分布，所以这个期望可以写成对 x 的期望，𝔼x∼pg [log(1 − D(x))]。

这一步不要求 G 可逆，也不需要 pg 的解析形式，它只是同一个随机变量的两种写法。但要把它写成积分 ∫ pg(x) … dx，就要求 pg 有密度。如果 z 的维度低于 x，pg 集中在低维流形上，严格说并没有密度函数。论文的证明默认密度存在。

2逐点优化：对每个 x 分别求最优

要最大化 ∫ f(x, D(x)) dx，而 D 可以是任意函数时，每一点的 D(x) 可以独立选择，所以逐点最大化被积函数就行。这是非参数假设带来的便利：实际网络的 D 不能在每一点独立取值。

对固定的 x，要最大化 a log y + b log(1 − y)，其中 a, b ≥ 0。求导得 a / y − b / (1 − y) = 0，解出 y = a / (a + b)。二阶导数为负，所以这是最大值。

例子数字例子

某一点 pdata(x) = 0.3，pg(x) = 0.1，则 D^*(x) = 0.3 / 0.4 = 0.75，意思是在先验各一半时，这个点来自数据的后验概率是 75%。

3KL 散度

KL(p ‖ q) = 𝔼x∼p [ log( p(x) / q(x) ) ]，它衡量用 q 代替 p 的代价，非负，只在 p = q 时为零，且不对称。更详细的性质见 VAE 专题的 KL 散度部分。

方向决定了惩罚哪种错误。KL(pdata ‖ pg) 中，pg 在数据有质量的地方接近零时代价很大，所以它惩罚丢失模式，这是最大似然对应的方向。KL(pg ‖ pdata) 中，pg 把质量放在数据没有的地方时代价很大，所以它惩罚生成不真实的样本，丢失模式几乎没有代价。这正是非饱和目标的主要成分。

4JS 散度

Jensen–Shannon 散度是对称化的 KL 散度。记 m = (p + q) / 2：

JSD(p ‖ q) = (1/2) KL(p ‖ m) + (1/2) KL(q ‖ m)

它的取值范围是 [0, log 2]。p = q 时为 0。p 和 q 的支撑集完全不重叠时，m 在 p 有质量的地方等于 p / 2，每个 KL 项都等于 log 2，所以 JSD 等于 log 2。这一点就是 WGAN 的出发点：只要不重叠，距离再远也是同一个值。

例子从 C(G) 推到 JS 散度

式 (4) 的第一项是 𝔼p_{data} [ log( pdata / (pdata + pg) ) ]。分母写成 2 · (pdata + pg) / 2 = 2m，得到 𝔼p_{data} [ log( pdata / m ) ] − log 2 = KL(pdata ‖ m) − log 2。第二项同理得到 KL(pg ‖ m) − log 2。

两项相加，C(G) = −2 log 2 + KL(pdata ‖ m) + KL(pg ‖ m) = −log 4 + 2 · JSD(pdata ‖ pg)。

5极小极大博弈和纳什均衡

二人零和博弈中，一方的收益是另一方的损失。minG maxD V 的含义是：G 先选，D 看到后做出最优响应，G 选择使这个最优响应下 V 最小的策略。

纳什均衡指任何一方都不能单方面改变策略而获益。GAN 的全局最优 (pg = pdata, D = 1/2) 就是这样的点：D 只能猜，G 任何改动都会让 D 有机可乘。

minG maxD 和 maxD minG 一般不同。前者让 G 必须覆盖分布，因为 D 能看到 G 的选择。后者中 D 先选，G 把全部质量放到当前 D 认为最真实的点上就是最优响应，这对应模式坍缩。交替的梯度更新并没有规定内外层的先后。

寻找鞍点比寻找最小值难。最简单的例子是 V(x, y) = xy，鞍点在原点，但同时做梯度下降和上升，(x, y) 会绕原点转圈甚至发散，这就是 GAN 训练会振荡的原因之一。

6Parzen 窗：只有样本时怎么估计密度

论文表 1 的指标是这样算的：在每个生成样本 xi 上放一个高斯，p̂(x) = (1/n) Σi N(x; xi, σ2 I)，再计算测试集在 p̂ 下的平均对数似然。

它的问题是高维下几乎没有意义。Theis 等人（2015-11-05）指出，这个估计需要的样本数随维度快速增长，而且分数高低与样本视觉质量可以几乎无关。MNIST 这样的低维数据上它尚能给出一些信息，图像变大后就不能用了。这也是 IS 和 FID 出现的背景。

隐式密度模型的设定

自回归模型和 VAE 都写下参数化的 p(x) 或它的近似，再最大化。GAN 放弃直接建模 p(x)，只保证能采样。

设定是：有限个样本来自真实分布 pdata；引入隐变量 z，服从自己定的先验，通常是单位高斯；采样 z，经生成器 G 得到 x = G(z)，这些样本服从 pG。目标是让 pG 接近 pdata。

判别器：两个网络对抗

前两种模型自己写目标函数来逼近数据分布，GAN 把这件事交给另一个网络：判别器 D 输入一张图，判断它是真是假。判别器按分类模型训练，生成器的训练目标是让判别器判错。

有学生问生成器能否得到判别器的反馈。可以，这正是方法成立的关键：反馈就是梯度。两个网络通过生成的图像连接，从判别器一路反向传播到生成器。

极小极大博弈的每一项

固定生成器看判别器：第一项希望真实样本的 log D(x) 大，第二项希望生成样本的 log(1 − D(G(z))) 大，合起来就是真假二分类。

固定判别器看生成器：第一项与生成器无关，只剩第二项。生成器希望生成样本被判为真，所以要最小化它。整个式子记作 V(G, D)，判别器最大化，生成器最小化。

交替梯度上升和下降

优化在一个循环里交替进行：对 V 关于判别器参数求导，做一步梯度上升；再对 V 关于生成器参数求导，做一步梯度下降。

V 不是损失函数

V 的绝对值说明不了 pG 和 pdata 匹配得多好，因为它取决于判别器有多强。判别器弱时生成器容易占优，判别器强时生成器必须很强，不同的 (G, D) 组合可以得到相同的 V。

所以难点有两个：目标本身不稳定，要对同一个量分别关于两组参数求最大和最小；没有任何数值能说明是否在接近好的解。一般网络的训练有一条下降的曲线可看，这里画出生成器和判别器的损失基本没有意义。

训练初期的梯度问题

训练刚开始时生成器输出接近噪声，判别器几轮迭代就能分清真假，D(G(z)) 接近 0。把 log(1 − D(G(z))) 画成 D(G(z)) 的函数，它在 0 附近几乎是平的，所以生成器恰好在训练初期得不到梯度。

常用的修正是让生成器最小化 −log D(G(z))，新曲线在训练初期有更大的梯度。这也意味着生成器和判别器其实并不优化同一个 V。

注综述里实测了这两种目标的梯度差距，并讨论了非饱和目标的代价，见非饱和目标。

问答：训练集、损失曲线、非平稳分布

训练集里没有的东西能否生成：pdata 由训练集决定，毫不相似的东西生成不了。希望在于泛化，比如见过马、圣诞帽和独角兽的图画后，也许能把它们组合起来。

能否分别画两个网络的损失曲线：可以画，但基本没用。Johnson 说，成百上千篇论文试图通过替换对数、改用 Wasserstein 距离等办法让曲线可解读，他认为没有人真正解决这个问题，很多人最后还是用原始形式。

判别器面对的是非平稳分布。ImageNet 分类的数据集是固定的，这里判别器要区分的生成样本随生成器变好而不断变化，学习动态非常复杂。生成器的梯度也只能经由判别器传来，这是不稳定的原因之一。

最优判别器与全局最优

这是一个嵌套优化问题。里层可以解出来，给定 G 时最优判别器是 D^*(x) = pdata(x) / (pdata(x) + pG(x))。这个式子写得出来却算不了，因为它依赖 pdata。代入外层后可以证明，外层目标当且仅当 pG = pdata 时取到最小。

但前提很多：假设网络容量无限，而实际网络大小固定；结论完全没有说明梯度上升下降能否收敛到这个点，何况只有有限样本。理论上有一定依据，实际给不了多强的保证。

DCGAN 与 StyleGAN

DCGAN 用五层卷积网络，是第一个给出像样结果的 GAN。Johnson 特意提到第一作者 Alec Radford，后来在 OpenAI 做了 GPT-1、GPT-2。

想了解 GAN 的最佳实践可以读 StyleGAN，结构复杂得多，效果也很好。GAN 的一个优点是隐空间往往是平滑的：在两个隐向量之间插值，生成的图像是平滑的过渡。StyleGAN3 论文中动物之间的平滑变形说明模型发现了有用的结构，并把它放进了隐空间。

优缺点

优点是形式相当简单，调得好时能生成分辨率很高的漂亮图像。缺点是训练不稳定，没有损失曲线可看，可能出现模式坍缩、NaN 或判别器失控，而且没有曲线能帮助诊断。必须仔细控制归一化、采样等细节才能得到好结果，所以很难扩展到很大的模型和数据。

他说从 2016 年前后到 2020、2021 年，GAN 是生成模型的首选。

问答：模式坍缩、没有从 x 到 z 的映射

平滑的隐空间不是必然出现的。生成器可能忽略 z，只记住训练集里的 10 个样本，无论输入什么都输出其中之一。这些样本可以和真图逐位相同，判别器分不出来，这是合法的解，但完全没有平滑的隐空间。

生成器只给出 z 到 x 的映射，一般没有办法从 x 回到 z，这是它和 VAE 很不同的地方。可以用梯度下降做数值求逆，但 x 和 z 之间没有显式的约束，判别器做的只是分布层面的对齐，没有逐样本的监督。

和变分自编码器比较

有学生问：VAE 用密度换来隐向量，GAN 连可控的隐向量也放弃了，换来了什么。回答是好得多的样本：VAE 的样本总是模糊的，GAN 能给出清晰的样本，代价是调参困难。推理时不再需要判别器，从先验采样 z 输入生成器即可，非常高效。
