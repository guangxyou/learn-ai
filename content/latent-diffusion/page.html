1概述：先压缩，再在压缩后的空间里扩散

隐空间扩散模型 (Latent Diffusion Model, LDM) 是一种图像生成方法，由慕尼黑大学和海德堡大学的 Robin Rombach、Andreas Blattmann、Dominik Lorenz、Björn Ommer 以及 Runway ML 的 Patrick Esser 提出。论文 2021-12-20 发布在 arXiv，发表于 CVPR 2022。Stable Diffusion 是这种方法的大规模版本。

方法分两个阶段。第一阶段训练一个自编码器，把图像压缩成一个仍保留空间结构的小张量，比如把 512×512×3 的图像压缩成 64×64×4，数据量降到约 1/48。第二阶段冻结自编码器，在这个隐空间 (Latent Space) 里训练扩散模型。生成时，扩散模型在隐空间迭代去噪，解码器只在最后运行一次，把结果还原成图像。

论文的另一个贡献是条件机制。它在 U-Net 中加入交叉注意力 (Cross-Attention) 层，文本、类别、布局都可以先编码成一串 token，再由交叉注意力接入去噪网络。这个结构后来成为文本生成图像的标准做法。

2来历：两阶段生成和扩散模型在 2021 年汇合

2021 年的高分辨率图像生成主要有三条路线，各有明显的短板。生成对抗网络 (GAN) 采样快、图像清晰，但难以覆盖复杂数据的全部模式。自回归 Transformer 建模能力强，但参数量达到数十亿，采样要逐个 token 进行。扩散模型的样本质量已经超过 GAN，但直接在像素上运算，训练和采样都非常昂贵。

两阶段生成此前已经发展了几年。VQ-VAE（2017-11-02）和 VQ-VAE-2（2019-06-02）先把图像压缩成离散 token，再用自回归模型学习 token 的分布。VQGAN（2020-12-17）在自编码器的损失里加入感知损失和图块判别器，下采样 16 倍仍能得到较好的重建。DALL·E（2021-02-24）把这条路线用到文本生成图像。VQGAN 的三位作者 Patrick Esser、Robin Rombach、Björn Ommer 都是 LDM 的作者。

这条路线的限制来自第二阶段。自回归模型的计算量随 token 数量快速增长，所以第一阶段必须压缩得很狠。VQGAN 的 16 倍下采样会丢失细节，LDM 论文图 1 显示它的 PSNR 只有 19.9。

另一方面，扩散模型在 2020 年以后进展很快。DDPM（2020-06-19）给出了简单的训练目标，DDIM（2020-10-06）把采样缩短到几十步，ADM（2021-05-11）在 ImageNet 上超过了 BigGAN。把扩散模型放进隐空间的想法也已经出现：LSGM（2021-06-10）联合训练变分自编码器和隐空间扩散先验，D2C（2021-06-12）把隐空间扩散用于少样本条件生成。

LDM 的做法是把这两条路线直接组合起来：沿用 VQGAN 的第一阶段，把第二阶段换成扩散模型。扩散模型的 U-Net 是卷积结构，计算量随隐变量尺寸增长较慢，而且能利用隐变量的二维结构，所以第一阶段只需要下采样 4 到 8 倍，重建质量明显提高。两阶段分开训练，也避开了 LSGM 需要在重建和生成之间精细加权的困难。

同一天 arXiv 上还出现了 GLIDE（2021-12-20），它在像素空间用文本条件扩散模型，加上一个上采样模型。论文 v2（2022-04-13）把文本模型扩大到 14.5 亿参数，并加入了无分类器引导，这才有了正文中与 GLIDE 的对比结果。

3要解决的问题：大部分计算花在察觉不到的细节上

论文引用的成本数字来自 ADM：最强的扩散模型要训练 150 至 1000 个 V100 日，在一块 A100 上生成 5 万个样本大约要 5 天。成本来自两处。训练时，梯度要在全部像素上计算。采样时，同一个网络要在完整分辨率上运行 25 至 1000 次。

论文进一步分析了这些计算花在哪里。图 2 取一个训练好的 DDPM，横轴是率 (Rate)，即已传输的信息量，纵轴是失真 (Distortion)，即重建误差。曲线在很低的率上就达到了较低的失真，此后要把失真进一步降到接近零，率会急剧上升。

也就是说，图像的大部分比特对应感知上几乎无法分辨的高频细节。论文把学习分成两段：前一段是感知压缩 (Perceptual Compression)，处理这些细节，几乎不涉及语义；后一段是语义压缩 (Semantic Compression)，学习数据的语义和构图，这才是生成模型的主要任务。

DDPM 的简化损失已经通过权重降低了这部分细节的影响，但这只改变损失的分配，每一步的计算量没有减少。LDM 的思路是用一个单独的模型处理感知压缩，扩散模型只在压缩后的空间里处理语义压缩，这样计算量才真正下降。

完整模型由三个网络组成，训练时分两个阶段。

两阶段分开训练有三个实际好处。第一，自编码器只需训练一次，可以用于很多个扩散模型。第二，自编码器和扩散模型的目标不同，分开训练不需要调两者之间的权重。第三，生成图像的成本大幅下降，因为迭代都在小张量上进行，解码只运行一次。

5第一阶段：感知压缩自编码器

自编码器沿用 VQGAN 的设计，编码器和解码器都是卷积网络。给定图像 x ∈ ℝH×W×3，编码器输出 z = ℰ(x) ∈ ℝh×w×c，解码器输出重建 x = 𝒟(z)，下采样倍数 f = H/h = W/w，取 2 的整数次幂。

只用 L1 或 L2 重建损失，结果会偏模糊：在细节不确定时，像素损失的最优解是所有可能结果的平均。所以论文用三项损失：

  • 重建损失： L1 加上 LPIPS 感知损失。LPIPS 比较的是预训练 VGG 网络的特征，它对高频纹理的位置不敏感，更接近人的判断。
  • 对抗损失： 一个基于图块的判别器 Dψ，逐块判断真假。它不判断整张图，所以只约束局部的真实感。官方 KL 配置 autoencoder_kl_32x32x4.yaml 中，判别器从第 50001 步起才参与训练。
  • 正则化损失 Lreg： 限制隐变量的尺度，有两种形式，下面详述。
LAutoencoder = minℰ,𝒟 maxψ ( Lrec(x, 𝒟(ℰ(x))) − Ladv(𝒟(ℰ(x))) + log Dψ(x) + Lreg(x; ℰ, 𝒟) )论文式 (25)

判别器的作用值得单独说明。图像压缩后信息已经丢失，解码器无法还原原有的每一根毛发。判别器迫使解码器生成看起来真实的纹理，这些纹理并非从隐变量中解码而来，而是解码器自己合成的。所以这个自编码器的 PSNR 不算很高，但视觉效果很好。教程第一部分用一张松鼠尾巴的对比说明了这一点：没有判别器时毛发糊成一片，加上判别器后毛发清晰，但并不是原来的那些毛发。

这也说明了为什么生成图像的质量上限由自编码器决定：无论扩散模型生成什么隐变量，最后都要经过同一个解码器。

例子两种正则化

KL 正则化： 编码器输出高斯分布的均值和方差，z = ℰμ(x) + ℰσ(x) · ε，对标准正态分布加 KL 惩罚，权重约 10−6。这个权重小到不会让隐变量接近标准正态，KL 项只起到防止方差过大的作用。

VQ 正则化： 使用一个包含 |𝒵| 个向量的码本，把隐变量量化到最近的码本向量，但量化层被并入解码器：扩散模型工作在量化之前的连续 z 上，解码时才量化。码本选得很大（如 8192、16384），因此正则化同样很弱。

两种都能用。论文发现 VQ 正则化的重建略差，但有时样本质量更好。文本生成图像模型和后来的 Stable Diffusion 用的是 KL 正则化。

6隐空间的尺度：为什么要乘 0.18215

扩散模型的噪声表默认数据的方差约为 1。KL 权重只有 10−6 时，编码器输出的方差并不受约束，隐变量的标准差可能明显大于 1。此时信噪比 Var(z) / σt2 偏高，同样的噪声水平对这些数据的破坏不够，模型会在逆向过程的早期就决定大量语义细节。

论文附录 G 的处理方式很简单：用第一个批量估计隐变量的标准差 σ̂，把隐变量除以它：

σ̂2 = (1 / bchw) Σb,c,h,w (zb,c,h,w − μ̂)2在第一个批量上估计，所有通道共用一个值
z ← z / σ̂ = ℰ(x) / σ̂缩放后标准差为 1

Stable Diffusion v1 配置里的 scale_factor: 0.18215 就是这个 1/σ̂，对应的 σ̂ 约为 5.49。编码后乘以它，解码前除以它。使用预训练自编码器时，这是最容易遗漏的一步。VQ 正则化的隐空间方差本来就接近 1，不需要缩放。

7压缩倍数：怎么选下采样倍数 f 和通道数 c

压缩比由 f 和 c 共同决定，等于 3f2/c。f 决定空间分辨率，也决定了 U-Net 的计算量；c 决定每个位置保留多少信息。下图用论文表 8 的全部数据作图。

图上能看出三点。第一，压缩比越大，重建越差，这条关系相当稳定。第二，压缩比相同时，只要通道数相应增加，f 可以取得更大：f=8, c=4 和 f=16, c=16 的 PSNR 和 R-FID 几乎相同。第三，KL 正则化的重建一般好于 VQ 正则化。

第一阶段不是压缩得越少越好。论文比较了 f 从 1 到 32 的类别条件模型，所有模型参数量相近，都在一块 A100 上训练 200 万步。结果有两个失败方向：

  • f = 1, 2 时训练很慢。感知压缩仍由扩散模型承担，算力大部分用于高频细节。训练 200 万步后，LDM-1 与 LDM-8 的 FID 相差 38。
  • f = 32 时很早就停滞。第一阶段丢失了太多信息，后面的扩散模型无法弥补。

f = 4 到 16 取得较好的平衡，其中 f = 4 和 8 最好。ImageNet 这样复杂的数据集需要更低的压缩率。

计算量的差异可以从批量大小直接看出。表 13 中，参数量都在 3.9 亿左右的模型，在同一块 A100 上，LDM-1 的批量只有 7，LDM-4 是 40，LDM-8 是 64。图 1 则对比了同一张图的重建：f = 4 的自编码器 PSNR 27.4、R-FID 0.58；DALL·E 的 f = 8 自编码器 PSNR 22.8、R-FID 32.01；VQGAN 的 f = 16 自编码器 PSNR 19.9、R-FID 4.98。

之所以能用这么温和的压缩，是因为第二阶段换成了卷积网络。VQGAN 和 DALL·E 要把隐变量排成一维序列交给自回归 Transformer，token 增加时计算量增长很快，也丢掉了二维结构。U-Net 直接在二维隐变量上卷积，归纳偏置和图像一致，可以处理 64×64 这样大的隐变量。

8第二阶段：在隐空间训练扩散模型

自编码器冻结后，每张图像都可以编码成隐变量 z0 = ℰ(x)。第二阶段就是在这些隐变量上训练一个普通的扩散模型，前向过程、预测噪声的目标都和 DDPM 相同，只是把 x 换成 z：

LDM = 𝔼x, ε∼N(0,1), t [ ‖ε − εθ(xt, t)‖2 ]论文式 (1)，像素空间，即 DDPM 的简化损失
LLDM = 𝔼ℰ(x), ε∼N(0,1), t [ ‖ε − εθ(zt, t)‖2 ]论文式 (2)，隐空间
LLDM = 𝔼ℰ(x), y, ε∼N(0,1), t [ ‖ε − εθ(zt, t, τθ(y))‖2 ]论文式 (3)，加上条件 y

前向过程没有可学习参数，所以 zt 可以一步算出：zt = √αt z0 + √(1 − αt) ε。训练时编码器不参与反向传播，图像甚至可以预先编码存好，只读取隐变量。

损失是在隐空间度量的。这相当于把「哪些差异重要」的判断交给了自编码器：感知上不重要的差异已被压缩掉，隐空间的 L2 距离比像素空间的 L2 距离更接近语义差异。

10条件机制一：交叉注意力

LDM 之前，扩散模型的条件主要是两种：类别标签（通过嵌入加到时间向量上）和模糊图像（拼接到输入）。文本这样可变长度、含有多个概念的条件，需要一种能让图像的不同位置关注不同词的机制。

论文用的是 Transformer 里的交叉注意力。图像特征作为查询 (Query)，条件序列作为键 (Key) 和值 (Value)：

Q = WQ(i) · φi(zt)φi(zt) 是 U-Net 第 i 层展平后的特征
K = WK(i) · τθ(y), V = WV(i) · τθ(y)τθ(y) ∈ ℝM×dτ 是条件序列
Attention(Q, K, V) = softmax(QKT / √d) · V每个图像位置在 M 个 token 上算一组权重

这个结构有两个重要性质。第一，条件的长度和模态都不受限制，只要有一个编码器 τθ 把条件变成 token 序列即可。论文用它做了三种条件：文本（BERT 分词器加 Transformer）、布局（每个框编码成左上角、右下角和类别三个 token）、类别（一个 512 维嵌入，即长度为 1 的序列）。第二，注意力图有明确的空间含义，每个词对应一张权重图，后来的 Prompt-to-Prompt 正是通过修改这些图做图像编辑。

τθ 不以时间步 t 为条件，这样每次采样只需编码一次。论文中 τθ 和 εθ 联合训练，这一点与 Stable Diffusion 不同。

# ldm/modules/attention.py，CrossAttention.forward（省略掩码）
q = self.to_q(x)                 # x: 图像特征，b × N × dim
context = default(context, x)    # 没有条件时退化为自注意力
k = self.to_k(context)           # context: 条件序列，b × M × context_dim
v = self.to_v(context)
q, k, v = map(lambda t: rearrange(t, 'b n (h d) -> (b h) n d', h=h), (q, k, v))
sim = einsum('b i d, b j d -> b i j', q, k) * self.scale   # N × M 的相似度
attn = sim.softmax(dim=-1)
out = einsum('b i j, b j d -> b i d', attn, v)

12引导：用无分类器引导换取保真度

论文 v2 的文本模型和类别条件模型都使用了无分类器引导 (Classifier-Free Guidance)。训练时以一定概率丢弃条件，让同一个网络同时学会有条件和无条件的预测。采样时每步计算两次，再做外推：

ε̂ = εθ(zt, t, ∅) + s · ( εθ(zt, t, τθ(y)) − εθ(zt, t, ∅) )s = 1 时等于普通的条件预测，s &gt; 1 时更强调条件

引导对指标影响很大。表 2 中，文本模型不用引导时 FID 23.31，s = 1.5 时降到 12.63，与 GLIDE（12.24，60 亿参数）和 Make-A-Scene（11.84，40 亿参数）基本相当，而模型只有 14.5 亿参数。表 10 中，LDM-4 在 ImageNet 上从 FID 10.56 降到 3.60（s = 1.5）。

指标最好的 s 和视觉效果最好的 s 并不相同。评估 FID 时用 s = 1.5，但图 5 展示的样本用 s = 10。较大的 s 使图像更符合提示，但样本多样性下降，FID 变差。Stable Diffusion 后来的常用值是 7.5 左右。

论文附录 C 还给出另一种引导：训练后用任意可微的目标引导采样，比如用 L2 或 LPIPS 让解码结果在下采样后接近一张目标图像。这种方法可以在不改模型的情况下提高超分辨率的 PSNR。

13采样：在隐空间迭代，解码一次

生成时不需要编码器。从标准正态分布采样 zT，用 DDIM 等采样器迭代调用 U-Net，最后把 z0 除以缩放系数，交给解码器。

# 采样（diffusers 接口的示意，未在本页环境运行）
ctx  = text_encoder(tokens).last_hidden_state
null = text_encoder(empty_tokens).last_hidden_state
z = torch.randn(n, 4, 64, 64, device=device)
scheduler.set_timesteps(50)

for t in scheduler.timesteps:
    pred = unet(torch.cat([z, z]), t, encoder_hidden_states=torch.cat([null, ctx])).sample
    pred_u, pred_c = pred.chunk(2)
    eps = pred_u + 7.5 * (pred_c - pred_u)    # 无分类器引导
    z = scheduler.step(eps, t, z).prev_sample

image = vae.decode(z / 0.18215).sample        # 解码器只运行这一次

单步的计算量由隐变量尺寸决定。像素空间的 DDPM 要在 256×256 上运行 1000 次，LDM-8 只在 32×32 上运行，且常用 50 至 250 步。表 18 给出单块 A100 上的吞吐量：LSUN Bedrooms 上，ADM（1000 步）每秒 0.03 个样本，LDM-4（200 步）每秒 1.07 个样本。

隐空间的轨迹也比较平滑。教程第二部分引用 Vahdat 等人 2021 年的结果：在 CelebA-HQ 上，隐空间的黑盒 ODE 求解器只需约 23 次函数计算，明显少于像素空间。

14卷积采样：生成比训练时更大的图像

U-Net 主要由卷积构成，隐变量的空间尺寸可以在采样时改变。论文利用这一点，用 2562 上训练的模型直接生成更大的图像。条件是空间对齐的任务（语义合成、超分辨率、图像修复）效果最好，因为条件图给出了每个位置该有的内容，模型可以生成 5122 到 10242 的图像。

这种方式能否成功取决于信噪比。第 6 节提到，不缩放的 KL 隐空间信噪比偏高，卷积采样会出现不连贯的结构；缩放后明显改善。缩放再加上无分类器引导，文本模型也能直接合成 2562 以上的图像，但由于注意力层只见过训练时的序列长度，全局结构可能变差。

16局限

论文自己列了两点。采样仍然是顺序的，比 GAN 慢。需要像素级精度的任务上，自编码器的重建能力可能成为瓶颈，超分辨率已经受到一定影响。

后来的实践和讨论又补充了几点：

  • 解码器会编造细节。 对抗训练让解码器合成看起来真实的局部纹理。一般图像生成可以接受，但 Rombach 在教程圆桌里提到，医学图像这类应用就不合适。
  • 小尺度结构容易失真。 人脸、手、文字在 8 倍下采样后占的隐变量很少，扩散模型和解码器都难以准确还原。后来的模型通过增加隐变量通道数来缓解，比如 Stable Diffusion 3 把通道数从 4 增加到 16。
  • 隐空间的统计特性不够理想。 只有一个全局缩放系数，各通道方差并不相同，噪声表也是沿用像素空间的。Stable Diffusion v1 的噪声表在最后一步 αT ≈ 0.0047，zT 中仍残留少量信号，而采样从纯噪声开始，两者并不一致。
  • 存在先后依赖。 Sander Dieleman 在圆桌里指出，扩散模型依赖固定的隐空间。自编码器一旦要改，已经训练几周的扩散模型只能从头开始。像素空间的级联模型没有这个问题。
  • 文本理解有限。 用一个 77 token 的序列和交叉注意力表达复杂的组合关系并不容易，比如多个物体各自的属性和位置。教程圆桌上，吴英年和 Rombach 都把组合性列为主要的开放问题。

18后续发展

几年来，大多数图像和视频生成模型都保留了「先压缩、在隐空间生成」的骨架，但每个部件都被替换过。

开放模型。 Stable Diffusion 2.0（2022-11-24）把文本编码器换成 OpenCLIP ViT-H。SDXL（2023-07-04）把 U-Net 扩大到 26 亿参数，使用 CLIP ViT-L 和 OpenCLIP ViT-bigG 两个文本编码器，分辨率提高到 10242。FLUX.1（2024-08-01）由 Stable Diffusion 的原作者们在 Black Forest Labs 发布。

去噪网络。 DiT（2022-12-19）把隐变量切成图块，用 Transformer 替换 U-Net，在 ImageNet 2562 上 FID 达到 2.27。Stable Diffusion 3（2024-03-05）让文本和图像 token 在同一个注意力中联合计算，并改用 Rectified Flow 训练。在这类模型里，联合注意力取代了 U-Net 的交叉注意力。

采样加速。 隐空间扩散模型特别适合蒸馏，因为教师模型已经公开且足够好。Latent Consistency Models（2023-10-06）把生成压缩到 2 至 4 步，SDXL Turbo 所用的对抗扩散蒸馏（2023-11-28）和分布匹配蒸馏（2023-11-30）进一步减少到 1 步。

控制和编辑。 ControlNet（2023-02-10）复制一份预训练编码器，用零初始化的卷积接回原模型，加入边缘、姿态等条件，不需要重新训练主模型。Prompt-to-Prompt（2022-08-02）和 InstructPix2Pix（2022-11-17）则在已有模型上实现文字编辑。这些工作的共同前提是公开权重。

视频。 Align your Latents（2023-04-18）冻结图像 LDM 的空间层，在每层后插入时间层。Stable Video Diffusion（2023-11-25）把这个做法扩大到大规模数据。Sora（2024-02-15）把视频压缩到隐空间，再切成时空图块，用扩散 Transformer 生成。Rombach 在 2023 年的圆桌里提到，逐帧编码的隐变量仍有大量冗余，更好的视频分词器是值得做的方向，后来的视频模型普遍使用同时压缩时间和空间的自编码器。

压缩器。 第一阶段也在改进。Stable Diffusion 3 把隐变量通道从 4 增加到 16。DC-AE（2024-10-14）把下采样提高到 32 倍以上，让高分辨率生成更便宜。EQ-VAE（2025-02-13）在隐空间加入等变性约束，让隐变量对空间变换的表现更规律。

回到像素。 也有研究质疑自编码器是否必要。Imagen（2022-05-23）用像素空间的级联模型。simple diffusion（2023-01-26）通过调整噪声表和损失权重，在高分辨率上做端到端的像素空间扩散。Back to Basics（2025-11-17）让网络直接预测干净图像，在高维像素空间中用 Transformer 训练。隐空间方案的优势主要是成本，这些工作说明它并不是唯一的选择。

整体思路

Latent Diffusion、LDM、Stable Diffusion 是什么关系？

Latent Diffusion Model (LDM) 是方法的名字，也是这篇论文提出的模型类别。Stable Diffusion 是这种方法的一个具体模型，由同一批作者与 Stability AI、Runway 合作，用 LAION-5B 的子集和更大的算力训练，并公开权重。

所以 Stable Diffusion 一定是 LDM，LDM 不一定是 Stable Diffusion。Meta 的 Emu 也是 LDM。Stable Diffusion 3 和 FLUX.1 换成了 Transformer 和 Rectified Flow，但仍在隐空间工作，属于这个思路的延续。

综述：从 LDM 到 Stable Diffusion →

隐变量已经加了 KL 正则，为什么不能直接从标准正态采样再解码？

因为 KL 权重只有约 10−6，隐变量的分布远离标准正态。这里的 KL 项只是防止方差失控，不要求聚合后的分布接近先验。从标准正态采样后解码，得到的基本是没有结构的纹理。

普通 VAE 把这个权重取得较大，生成可以直接从先验采样，代价是重建模糊。LDM 选择把重建做好，把「隐变量的分布长什么样」交给第二阶段的扩散模型来学习。

综述：第一阶段 →

为什么分两阶段训练，联合训练不是更优吗？

两个阶段的目标不同。第一阶段追求逼真，用感知损失和判别器；第二阶段是基于似然的扩散目标，追求覆盖数据分布。联合训练要在重建和生成之间设置权重，很难调。

圆桌上 Dieleman 的说法是，联合训练只有在两部分优化同一个损失时才有意义，而那样恰好失去了这个结构的主要好处。Rombach 说 LDM 论文的审稿人也问过这个问题，他们试过联合训练，在复杂数据上效果并不好。吴英年补充了反方向的情况：需要结构化先验，或者分布在优化中持续变化（如分子设计）时，联合训练更合理。

综述：整体结构 →教程：圆桌 →

为什么隐变量要保留空间结构，压成一个向量不是更紧凑吗？

扩散模型的优势来自卷积 U-Net 的归纳偏置，而卷积需要二维结构。隐变量保持 h×w×c 的形状后，每个位置主要对应图像的一块局部区域，U-Net 可以像处理小图一样处理它。

这还带来两个实际好处：空间对齐的条件可以直接拼接，采样时也可以改变尺寸来生成更大的图。如果压成一维向量，这两点都做不到，VQGAN 和 DALL·E 排成一维序列后也丢失了大部分结构信息。

综述：压缩倍数 →

隐空间的扩散和像素空间的扩散，算法上有区别吗？

几乎没有。损失的形式相同，噪声表和采样器都可以照用。第二阶段可以当成在一个 64×64×4 的「图像」数据集上训练 DDPM。

区别在数据统计特性。隐变量的尺度和相关性都与像素不同，所以需要缩放，最合适的噪声表也可能不同。Chenlin Meng 在圆桌上提到，同一个噪声表换一个隐空间，效果可能明显变差。

自编码器

代码里的 0.18215 是什么，换一个自编码器还能用吗？

它是 Stable Diffusion v1 的自编码器算出的缩放系数，等于隐变量标准差的倒数，σ̂ 约为 5.49。论文附录 G 给出了方法：取第一个批量算标准差，把隐变量除以它，使缩放后的标准差约为 1。

这个数字绑定特定的自编码器。换一个自编码器就要重新估计，比如 SDXL 的配置用的是 0.13025。训练和采样都要用相同的系数：编码后乘，解码前除。

综述：隐空间的尺度 →

判别器生成的细节是「真的」吗？

不是。这些细节没有编码在隐变量里，是解码器根据局部上下文合成的，所以看起来真实，却和输入不一样。这也是 PSNR 不算高但 FID 很低的原因。

对一般图像生成这没有问题，但如果要做精确重建，比如医学影像，这是需要避免的。论文也说明了超分辨率模型在这方面已经受到限制。

综述：第一阶段 →教程：判别器 →

f 和 c 怎么选？为什么 Stable Diffusion 是 f = 8、c = 4？

f 决定 U-Net 的计算量，c 决定每个位置保留的信息。论文的结论是 f = 4 或 8 最好。文本模型在 2562 上训练时选 f = 8，隐变量 32×32×4，压缩比 48 倍，R-FID 0.90；5122 时隐变量是 64×64，计算量仍然可以接受。

后来 4 个通道被认为偏少，小尺度细节容易丢失。Stable Diffusion 3 改成 16 个通道，代价是第二阶段的建模难度增加，它的论文显示 d = 16 的模型需要更大的网络才能发挥优势。

KL 和 VQ 两种正则化怎么选？

论文的实验没有绝对的胜者：VQ 的重建指标略差，但有些 LDM 反而在 VQ 隐空间上样本质量更好，比如 CelebA-HQ、FFHQ 和 LSUN-Bedrooms 都用 VQ。文本模型选的是 KL。后来的主流模型基本都用 KL，一个原因是连续隐空间不需要量化，结构更简单。

无论哪种，论文都在 VQ 情形下让扩散模型工作在量化之前的连续隐变量上，所以扩散部分的代码相同。

什么时候用交叉注意力，什么时候用拼接？

开场：为什么讲这个主题

Kreis 的判断是，视觉领域近期的突破主要来自扩散模型，其中最突出的一类就是隐空间扩散模型。Stable Diffusion XL、Meta 的 Emu 都属于这一类，它们也用于视频、三维、分子，还有语义分割、关键点检测这些下游任务。

教程分四部分：Kreis 讲基础框架，Vahdat 讲端到端训练、加速采样和控制，Gao 讲图像以外的数据，最后是圆桌。圆桌嘉宾原定 Durk Kingma、Chenlin Meng、Robin Rombach、Sander Dieleman、吴英年，Kingma 当天因病缺席。

回顾：离散和连续的扩散过程

离散形式就是 DDPM：前向过程每一步把信号略微缩小并加一点噪声，βt 称为噪声表 (Noise Schedule)，一千步后信息被完全破坏。逆向过程也取条件高斯，均值由神经网络预测，方差通常作为超参数。

连续形式把这个过程写成随机微分方程 (SDE)。Anderson 的结果说明，前向 SDE 对应一个沿时间反向运行的 SDE，方程中唯一未知的量是分数函数 (Score Function)，即加噪后边际分布的对数密度梯度 ∇x log qt(x)。训练扩散模型就是学习这个函数的神经网络近似。

回顾：训练目标和网络结构

边际分布的分数算不出来，所以用去噪分数匹配：随机取时间 t 和一张图，只加噪这一张图。条件分布 qt(xt|x0) 是高斯，分数有解析式，可以作为回归目标。同一个 xt 可能来自很多不同的 x0，训练时这些目标被平均，网络收敛到的正是边际分布的分数。变分下界的推导最后也得到相同的形式。

网络通常是 U-Net：残差块加跳跃连接，配自注意力层捕捉长距离相关；时间经正弦嵌入或随机傅里叶特征后，用相加或自适应归一化接入。Kreis 提到 2023 年纯 Transformer 结构已有研究，但最成功的模型大多仍用 U-Net 的变体。

LDM 框架：两阶段

第一步不是训练扩散模型，而是训练自编码器。编码器把 512×512 的图像压缩到例如 64×64×4 的隐空间。隐空间仍保留空间结构，近似于逐块的局部编码。解码器大体是编码器的镜像，用来重建图像。

第二步把数据都编码成隐变量，在这些隐变量上做常规的扩散模型训练。生成时，先采样隐变量，再经过解码器。

历史方面，Kreis 把这个框架追溯到 Vahdat 等人的 LSGM，同期还有 D2C 和符号音乐生成的工作。Kreis 认为 Rombach 等人的论文是真正把这类模型推广开来的工作，这一部分也基本沿用它的形式。

LDM 的优点和结构

优点有两类。第一是效率：隐空间分辨率低，正则化后也更平滑，扩散模型的任务更容易，有时还能减少采样步数。第二是灵活：自编码器可以针对数据定制，比如输入多视角图像、输出辐射场，或者把离散数据嵌入连续空间，隐空间里的扩散模型不需要改动。

隐空间的网络结构和像素空间几乎一样。值得强调的是条件接入：Rombach 等人把 U-Net 中的自注意力层扩展成同时对文本 token 做交叉注意力。Kreis 说，到 2023 年几乎所有扩散模型都采用了这个机制。

判别器：解码器补出细节

要达到高性能，只有重建损失是不够的。自编码器通常还要加一个基于图块的判别器。压缩会损失信息，判别器迫使解码器像一个小型 GAN 那样，把丢失的纹理重新合成出来。

松鼠尾巴的对比很直观。没有判别器时，语义和形状都对，但细节全部模糊。加上判别器后，毛发看起来完美。Kreis 特意指出这并不是完美重建：这些毛发是解码器新生成的，看起来真实，但并未编码在隐空间中。

率失真：容量花在哪里

这是这一部分的核心。一张好图需要两种东西：正确的全局结构（老虎的眼睛、耳朵的位置和条纹模式）和真实的局部细节（每一根毛的形态）。用户主要在意前者，但模型也必须生成后者。

率失真曲线上每个点对应一个噪声水平。横轴是率，即加噪图中保留的关于原图的信息量，单位是比特每维；纵轴是失真，即从这张加噪图一步重建原图的误差。曲线显示，只需较低的率就能把失真降到较低水平，这一段编码的是大尺度结构。要把失真继续降到零，率会急剧上升，这部分信息是察觉不到的局部细节。

结论是，如果在像素空间直接训练，模型几乎所有容量都用来编码这些细节。LDM 的做法是把它们交给判别器和解码器，隐变量不再编码这些细节，扩散模型就能集中处理语义压缩。Kreis 认为这是理解 LDM 高性能的关键。

隐空间正则化：KL 和 VQ

除了下采样倍数和通道数，还可以用正则化控制隐空间的信息量。KL 正则化让编码器输出一个窄高斯，再加上一个指向标准正态的惩罚项，权重越大，隐变量携带的信息越少。追求感知质量时权重取得很小；Vahdat 接下来讲的最大似然训练则要用大权重。

VQ 正则化用一个可学习的有限码本把隐变量离散化。码本很大时相当于弱正则化，码本很小时相当于强正则化。

LDM 配方

第一步，训练强的自编码器：下采样 4 倍或 8 倍，精心调整隐空间的正则化，保证重建的视觉质量。这是生成质量的上限，因为无论扩散模型生成什么，都要经过同一个解码器，扩散模型无法修复解码器的问题。

第二步，训练高效的隐空间扩散模型。人们通常以为压缩和重建之间存在取舍，但判别器让高压缩下仍能得到好的视觉重建，因为局部细节是重新生成而不是编码的。

图像生成的现状

Stable Diffusion 和 Emu 都是 LDM，也有证据表明 DALL·E 3 是 LDM。Kreis 的观察是，这项技术用于实际图像生成已经相当成熟，近期的进展主要依靠数据标注、过滤和微调。

Vahdat：端到端训练

这里讲的是 LSGM 的做法：变分自编码器加一个隐空间扩散先验，联合优化。先把自编码器在正态先验下预训练，使隐变量分布接近正态，再联合训练。

优点：隐变量接近正态，扩散动力学平滑，采样容易；引入隐变量提高了表达能力；图、文本、三维这些难以直接扩散的数据也能处理。缺点是要同时维护两个结构，有规模上的问题。

目标仍是证据下界。把 KL 拆成熵和交叉熵后，前两项和普通 VAE 相同，可以用重参数化优化。关键是交叉熵项，它可以写成一个加权的去噪分数匹配。隐变量接近正态这一点还可以作为先验知识，用于重要性采样和分数函数的参数化。

加速采样和蒸馏

反向 SDE 可能要调用网络一千次。对应的概率流 ODE 没有噪声注入，轨迹是确定的，可以用成熟的数值求解器。由于隐变量接近正态，隐空间的轨迹更平滑，步数更少：2021 年的实验中，在 CelebA 上用现成的 ODE 求解器，隐空间只需约 23 次函数计算。

ODE 的确定性映射还可以用神经网络直接学习，这就是蒸馏。渐进蒸馏 (Progressive Distillation) 让学生网络的一步模仿教师网络的两步，学生再作为下一轮的教师，步数逐轮减半。Meng 等人在 CVPR 2023 上把隐空间的文本生成图像做到了 2 至 4 步。

一致性蒸馏 (Consistency Distillation) 利用同一条轨迹上的点都到达同一个终点这一性质，训练一个让它们输出相同 x0 的函数，隐空间版本可以做到约 4 步。对抗方向也重新受到关注。分布匹配蒸馏 (Distribution Matching Distillation) 把回归损失和反向 KL 结合，反向 KL 的梯度是真实分数和虚假分数之差，一步采样约 90 毫秒。

逆问题

逆问题指的是从退化的观测（低分辨率、缺失像素、模糊）恢复干净信号。线性情形下 y = Hx0 + n，退化模型已知。有了扩散先验，就可以从后验采样，用贝叶斯公式把条件分数拆成数据分数和似然分数两项。

数据分数已有，似然分数算不出来。重建引导 (Reconstruction Guidance) 的近似是：每一步用去噪网络预测 x0，代入退化模型，以它与 y 的距离的梯度作为引导。

另一种思路是变分推断。假设变分分布是狄拉克分布，就得到 MAP 估计，目标函数是重建损失加一项类似分数蒸馏的损失。

控制和编辑

控制方面：ControlNet 复制预训练模型的编码部分，原模型锁定，副本可训练，两者通过零初始化的卷积连接，所以初始时输出和原模型完全相同，之后逐渐学会调制。GLIGEN 的思路相近，在自注意力和交叉注意力之间加入门控自注意力，初始化时相当于跳跃连接，用它能控制物体的位置和大小。

编辑方面：SDEdit 利用「两个分布扩散后会靠近」这一事实，给笔画图加噪后反向采样，得到真实图像，不需要额外训练。Prompt-to-Prompt 发现图像布局主要由交叉注意力图决定，所以修改提示词时固定其他词的注意力图，只替换改变的词。InstructPix2Pix 没有现成的编辑前后数据集，就先用 GPT-3 生成成对的文本，再用 Prompt-to-Prompt 生成成对的图像，最后训练一个以指令为条件的扩散模型。

现场提问

有人问蒸馏出来的采样器为什么是正确的。Vahdat 的回答是没有保证：它们和 ODE 求解一样有累积误差，只要能很好地模拟 ODE 轨迹，就能近似数据分布。

另一个问题是编辑里的注意力图怎么在隐空间得到。回答是这些操作本来就在隐空间进行：隐变量是卷积得到的，和图像有一一对应的空间关系，展示时只是把 64×64 的图放大了。

Gao：视频

从这里开始是 Ruiqi Gao 的部分。LDM 不依赖具体的数据模态，只要有一个把数据映射到连续隐空间的自编码器。

视频最常见的结构是在每帧上重复 2D U-Net，中间加入时间注意力或时间卷积。Align your Latents 冻结图像 LDM 的空间层，只训练新增的时间层；编码器保持不变，解码器加入时间层和时间判别器微调，这一步对消除闪烁很关键。长视频用级联方式：关键帧模型、时间上采样、空间上采样。

Stable Video Diffusion 把这个框架放大，强调三点：先做图像预训练、再做视频预训练和高质量微调；数据筛选非常重要；要平移噪声表，保证最高噪声处没有残留信息。Emu Video 把任务拆成文本生成单帧、再由单帧生成其余帧。

开放问题包括：如何生成长的高分辨率视频、能否在时间上压缩、如何准确捕捉运动（当前模型的容量大部分仍用于单帧质量）、如何保持角色和场景一致、如何评估运动质量。

三维

三维有两类做法。第一类是直接在三维表示上做 LDM，关键是设计自编码器。LION 用点云和点体素 CNN，隐空间有形状和点两层。Diffusion-SDF 输入查询点，输出符号距离函数。Shap-E 把点云和渲染视图编码，解码成 NeRF 的 MLP 权重，扩散模型生成这些权重的隐变量。NeuralField-LDM 用体素网格表示场景，并在隐空间做分层扩散。

第二类用 2D 模型作为先验，因为高质量三维数据远少于图像。DreamFusion 提出分数蒸馏采样，用预训练的文本生成图像模型作为评判器，梯度经可微渲染回传到 NeRF。问题是只看单个视角，不同视角可能给出不一致的结果。

后续工作减少这种不确定性。Zero-1-to-3 微调 Stable Diffusion，让它以一张图和相对相机位姿为条件。ReconFusion 以多张图为条件，更接近三维重建。MVDream 把模型改造成多视角模型，加入类似视频的跨视角注意力。

文本、分子和感知任务

文本领域仍以自回归模型为主。两者都把生成拆成迭代细化，都用监督式目标。自回归模型训练效率高（一次前向得到所有时间步的训练信号），但结构受限、采样慢；扩散模型结构更灵活，采样也能用求解器、蒸馏和引导。Diffusion-LM 用最简单的嵌入层作为自编码器，好处是能用分类器引导控制生成。CDCD（Dieleman 的工作）在连续扩散中使用交叉熵，分数可以写成条件分数的加权和，权重正是需要学习的 p(x0|x)。

分子方面，几何 LDM 用等变图神经网络作为编码器和解码器，保证旋转、平移后概率不变。冷冻电镜工作用 VAE 编码二维投影，隐空间的扩散模型用来学习分子构象的分布。

预训练 LDM 的特征也可用于感知任务：在冻结的 LDM 上学习掩码生成器做分割；把深度图也编码进隐空间，以图像隐变量为条件做单目深度估计。

圆桌讨论

主持人是 Kreis，到场的有吴英年 (UCLA)、Chenlin Meng (Pika)、Robin Rombach (Stability AI)、Sander Dieleman (Google DeepMind)，Durk Kingma 因病缺席。下面按问题整理。发言人是按座次和上下文判断的。

为什么成功。 Rombach 认为有两个原因：框架通用，领域专家可以设计自编码器，生成模型专家再在隐空间训练扩散；感知数据可以大幅压缩，训练和推理都快。Dieleman 补充说这是有损压缩，图像中有大量感知上无关的熵。他举的例子是：把草地纹理整体平移一个像素，人根本看不出差别。

隐空间和像素空间。 隐空间的代价是解码器会编造局部细节，医学图像这类应用不合适。Dieleman 还指出一个工程问题：隐空间造成两次训练之间的先后依赖，改动自编码器后，训练了几周的扩散模型要从头开始，像素级联没有这个问题。

端到端还是两阶段。 Dieleman 明确选两阶段：学习隐变量时要追求逼真而不是多样性，这也是 GAN 能以这种形式留下来的原因；有了隐空间后，扩散模型的损失就应该在隐空间度量。如果两部分优化同一个损失，反而失去了这种结构的优势。Rombach 说 LDM 论文的第一批审稿问题就包括这一点，他们试过但效果不好。吴英年承认自己可能就是那位审稿人，并补充了联合训练合理的两种情形：需要结构化先验，或者分布在优化过程中不断变化。

图像之外。 吴英年看好语言：可以一次生成整段文字，类似系统二的慢思考。Rombach 看好视频分词器。Dieleman 提醒自编码器的做法不能照搬到文本：自编码器倾向于忽略熵最高的部分，在图像中那是噪声，而在语言中，名字、地点这些最难预测的词恰恰承载了最多信息。

和其他生成模型的关系。 Dieleman 说扩散模型在不同视角下可以看作自回归模型、流模型或 VAE 的特例，它的特别之处是迭代细化。他的一个说法是，这或许只是因为我们还不知道怎么训练 10 万层的网络；如果反向传播不成问题，也许十年后只用 VAE 就够了。Rombach 指出，实际表现好的系统本来就是组合：VAE 加对抗损失，隐空间扩散，再加判别器做蒸馏。

控制和组合性。 吴英年认为组合性是大问题，词之间的结构没有被好好利用。Rombach 提议用大语言模型先设计场景布局，再以布局为条件生成。Meng 指出控制方法依赖隐空间的结构，同样的噪声表换一个隐空间也可能失效。

给研究者的建议。 Dieleman 提到 NVIDIA 芬兰组的工作，最大的实验也只到 ImageNet 5122，说明不需要大量算力也能写出好论文。他自己在思考：扩散模型是在寻找噪声和数据之间的双射，当前的损失方差很高，能否找到更高效的方法。Rombach 建议研究视频编码器：LDM 的自编码器只用一块 GPU 训练，现在被 DALL·E 3 使用；从预训练模型提取判别知识也不需要太多资源。

开放权重的影响。 吴英年和 Meng 都认为 Stable Diffusion 改变了研究的基础条件：没有它，学术界接触不到大规模模型，三维生成和轻量的控制方法都无从做起。
