DiT 综述：来历、结构与后续发展

这一页按前向计算的顺序讲 DiT。前四节说明它是什么、从哪里来、要解决什么问题、整体结构如何；中间七节依次讲 patchify、四种条件块、adaLN-Zero、解码、模型配置、训练和引导；后面五节讲缩放实验、实验结果、局限、后续发展和相关模型。

扩散模型本身不在这里重复，见 DDPM 专题；隐空间和自编码器见 Latent Diffusion 专题。

1概述：用 Transformer 替换扩散模型的 U-Net

扩散 Transformer (Diffusion Transformer, DiT) 是一种扩散模型的去噪网络，由 UC Berkeley 的 William Peebles 和纽约大学的 Saining Xie 提出。论文 2022-12-19 发布在 arXiv，发表于 ICCV 2023。工作是 Peebles 在 Meta FAIR 实习期间完成的。

从 DDPM 到 Stable Diffusion，扩散模型的去噪网络几乎都是 U-Net。DiT 保留了 Latent Diffusion 的框架，也就是先用自编码器把图像压缩到隐空间，只把 U-Net 换成一个接近标准 Vision Transformer 的网络：把隐变量切成图块，变成 token 序列，经过一串 Transformer 块，再还原成噪声预测。

论文有两个主要结论。第一，U-Net 的归纳偏置对扩散模型并非必要。第二，模型的计算量 (Gflops) 和样本质量有很强的相关性：只要加深、加宽或增加 token 数，FID 就持续下降。最大的 DiT-XL/2 在 ImageNet 256×256 上取得 FID 2.27，超过了当时所有扩散模型。

这篇论文的影响主要在后面：PixArt、Stable Diffusion 3、FLUX.1 和 Sora 等模型都以 Transformer 为骨干。论文最后说 DiT 可以作为 Stable Diffusion 这类模型的替换骨干，这个判断后来成为现实。

2来历：Transformer 进入图像扩散模型的时机

U-Net 进入扩散模型是从 DDPM（2020-06-19）开始的。它继承自 PixelCNN++，主要由残差卷积块组成，在低分辨率层穿插自注意力。此后 ADM（2021-05-11）调整了通道数、注意力层和自适应归一化，但整体结构没有变。Latent Diffusion（2021-12-20）把它用到隐空间，并加入交叉注意力。两年多里，大家改进的主要是采样器、引导和级联，骨干网络几乎没人动。

另一边，Transformer 已经取代了很多领域的专用结构。Vision Transformer（2020-10-22）把图像切成图块后直接用 Transformer 分类，并且表现出很好的扩展性。在生成模型中，Transformer 用得最多的是自回归模型，比如 VQGAN 的第二阶段和 DALL·E。DALL·E 2 用 Transformer 做扩散先验，但生成的是 CLIP 嵌入，不是图像。

在隐空间中做这件事有一个明显的便利：隐变量只有 32×32，序列长度可控。如果在像素空间直接切 2×2 的图块，256×256 的图像会产生 16384 个 token，注意力的计算量无法接受。

同时也有其他研究者在尝试。U-ViT（2022-09-25）比 DiT 早近三个月，它把时间、条件和图块都当作 token，并保留了 U-Net 式的长跳跃连接。Jabri 等人（2022-12-22）几乎同时提出了基于注意力的高效结构，DiT 论文把它列为同期工作。DiT 的取向更彻底：不要跳跃连接，尽量贴近标准 Transformer，然后专门研究它的扩展规律。

3要解决的问题：结构选择到底有多重要

论文提出的问题是：U-Net 的归纳偏置对扩散模型是否关键？如果不关键，扩散模型就可以使用 Transformer 这类标准结构，继承其他领域的训练经验，也能和它们共享研究成果。

第二个问题是怎么衡量模型的复杂度。图像生成论文习惯报告参数量，但参数量不考虑图像分辨率。论文改用理论 Gflops，也就是一次前向计算的浮点运算量。下面会看到，这个选择直接决定了结论：改变图块大小时，参数量几乎不变，FID 却变化很大。

结构统一带来的好处是扩展规则简单。U-Net 要决定每个分辨率的通道数、注意力放在哪几层，组合很多；DiT 只有三个旋钮：图块大小 p、层数 N、宽度 d。论文用这三个旋钮加上条件方式组成一个设计空间，并测试了其中的主要组合。

4整体结构：隐空间里的 Vision Transformer

整条流水线和 Latent Diffusion 相同。自编码器直接用 Stable Diffusion 预训练好的版本，下采样 8 倍，256×256×3 的图像变成 32×32×4 的隐变量，共 8400 万参数，不参与训练。DiT 只替换中间的去噪网络。

t 和 y 分别嵌入成 d 维向量后直接相加，得到条件向量 c。时间步先经过 256 维的频率编码，再经过两层 MLP；类别是一个可学习的嵌入表，多出一个类别用于无分类器引导的空条件。

5Patchify：图块大小决定计算量

第一层把空间输入 I × I × C 切成 p × p 的图块，每块线性投影成 d 维 token，得到长度 T = (I / p)2 的序列。官方代码用一个步长等于 p 的卷积实现。然后加上正余弦位置编码，这是不可学习的，和 ViT 的频率编码相同。

论文测试了 p = 2, 4, 8。p 减半，token 数变成 4 倍，Transformer 的计算量至少变成 4 倍。参数量却几乎不变，因为 Transformer 块的权重和序列长度无关，只有首尾的投影层随 p 变化。

我们用官方代码统计了 12 个配置的可训练参数量，确实如此，而且 p 越小，参数量还略有下降：DiT-XL/8 是 6.757 亿，DiT-XL/4 是 6.750 亿，DiT-XL/2 是 6.748 亿。原因是首尾投影层的权重数量和 p2 成正比。这也是后面「参数量不能决定质量」这一结论的来源。

从表中可以读出两点。条件方式的影响很大，同样的计算量下 FID 能差近一倍。初始化也很重要，adaLN 和 adaLN-Zero 的结构几乎相同，只多了一组缩放系数和零初始化，FID 就从 25.21 降到 19.47。交叉注意力的表现还不如 adaLN，却多出约 15% 的计算量。此后论文所有实验都用 adaLN-Zero。

adaLN 有一个限制，论文也提到了：它对所有 token 应用相同的函数，所以条件只能是一个向量，无法表达「这个词对应图像的这个位置」。类别标签没有这个问题，文本条件就不够了，这也是后来的文本模型要把交叉注意力加回来的原因。

7adaLN-Zero：从恒等映射开始训练

自适应归一化最早来自 GAN 和带条件的 U-Net。在 DiT 里，LayerNorm 本身不带可学习参数，缩放和平移系数由条件向量回归，然后作用到归一化后的 token 上。adaLN-Zero 又多回归了一组系数 α，在残差连接之前缩放子层的输出。

一个块的计算可以写成：

x ← x + α1 · MSA( LN(x) · (1 + γ1) + β1 )子层 1：自注意力
x ← x + α2 · MLP( LN(x) · (1 + γ2) + β2 )子层 2：前馈网络
(γ1, β1, α1, γ2, β2, α2) = Linear( SiLU(c) )线性层的权重和偏置都初始化为零

「Zero」指的是这个线性层初始化为零。此时 α = 0，子层的输出被完全屏蔽，每个块都是恒等映射。网络的最后一层也初始化为零，所以模型一开始输出全零，相当于什么都没有预测。这和 ResNet 中把每个残差块最后的 Batch Normalization 缩放系数初始化为零是同一个思路，论文引用了这个做法，扩散模型的 U-Net 也有类似处理。

这件事用官方代码很容易验证。我们构造了一个 DiT-S/8，输入随机噪声、时间步和类别，第一个 DiT 块的输出和输入之差的最大绝对值是 0，整个网络的输出也全部是 0。

# 官方 models.py 的 DiTBlock，这段代码就是上面三个式子
class DiTBlock(nn.Module):
    def __init__(self, hidden_size, num_heads, mlp_ratio=4.0, **block_kwargs):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_size, elementwise_affine=False, eps=1e-6)
        self.attn = Attention(hidden_size, num_heads=num_heads, qkv_bias=True, **block_kwargs)
        self.norm2 = nn.LayerNorm(hidden_size, elementwise_affine=False, eps=1e-6)
        mlp_hidden_dim = int(hidden_size * mlp_ratio)
        approx_gelu = lambda: nn.GELU(approximate="tanh")
        self.mlp = Mlp(in_features=hidden_size, hidden_features=mlp_hidden_dim, act_layer=approx_gelu, drop=0)
        self.adaLN_modulation = nn.Sequential(nn.SiLU(), nn.Linear(hidden_size, 6 * hidden_size, bias=True))

    def forward(self, x, c):
        shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = self.adaLN_modulation(c).chunk(6, dim=1)
        x = x + gate_msa.unsqueeze(1) * self.attn(modulate(self.norm1(x), shift_msa, scale_msa))
        x = x + gate_mlp.unsqueeze(1) * self.mlp(modulate(self.norm2(x), shift_mlp, scale_mlp))
        return x

def modulate(x, shift, scale):
    return x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)

注意 adaLN_modulation 的代价。线性层输入 d 维、输出 6d 维，每个块就多出约 6d2 个参数。这解释了前面的表格：DiT-XL/2 中 adaLN-Zero 的参数比 in-context 多 2.26 亿，几乎全部来自这里，但它们只作用在一个向量上，所以 Gflops 几乎不变。

8解码：线性层还原成噪声和方差

最后一个块之后，再做一次自适应 LayerNorm，用一个线性层把每个 token 映射成 p × p × 2C 的张量，最后按原来的空间位置重排，得到 I × I × 2C 的输出。这里没有 U-Net 那样的上采样和跳跃连接，每个图块的输出只由对应的 token 决定。

输出通道是输入的两倍，因为它同时预测噪声和对角协方差。这沿用了 Improved DDPM 和 ADM 的做法：噪声用简化损失 Lsimple 训练，协方差用完整的变分下界 L 训练。对 DiT-XL/2 来说，每个 token 输出 2 × 2 × 8 = 32 维，序列长度 256，重排后是 32 × 32 × 8。

计算量的规律可以直接从结构算出来：MLP 部分和 T · d2 成正比，T 变成 4 倍时这部分正好变 4 倍；注意力部分和 T2 · d 成正比，T 变 4 倍时这部分变 16 倍。表中 DiT-XL 从 p = 4 到 p = 2 只增加了 4.08 倍，说明此时注意力的计算量占比还很小；token 再增加，注意力的占比才会上升。

10训练：几乎不调参

训练配置很简单，大部分超参数直接沿用 ADM：

  • 优化器 AdamW，学习率恒定为 10−4，无权重衰减，批量 256。
  • 唯一的数据增强是水平翻转。
  • 权重做指数滑动平均 (EMA)，衰减 0.9999，所有结果都来自 EMA 模型。
  • 扩散参数：1000 步，β 从 10−4 线性增加到 2 × 10−2。
  • 框架是 JAX，用 TPU v3 训练。DiT-XL/2 在 TPU v3-256 上约每秒 5.7 次迭代。官方开源的是 PyTorch 重写版本。

论文特别指出，它不像很多 ViT 工作那样需要学习率预热和正则化，也没有观察到 Transformer 训练中常见的损失尖峰。所有规格和图块大小用同一套超参数，没有专门调整。

官方代码的训练循环只有几行，和前面 DDPM、Latent Diffusion 的循环几乎一样：

11无分类器引导：只引导三个通道

论文的最好结果使用无分类器引导。训练时以 10% 的概率把类别替换成空嵌入（官方代码 class_dropout_prob=0.1），采样时外推：

ε̂ = εθ(xt, ∅) + s · ( εθ(xt, c) − εθ(xt, ∅) )s = 1 时等于普通采样

有一个实现细节容易让人意外：论文和官方代码默认只对隐变量的前三个通道做引导，第四个通道不引导。论文附录说明了这个实际做法，并测试了差别：三通道 s = 1.5 的 FID 是 2.27，四通道 s = 1.375 的 FID 是 2.20。三通道系数 1 + x 大致相当于四通道系数 1 + 3x / 4。官方代码的注释也说明，这样写是为了能精确复现论文结果。

这意味着用四个通道复现时，要把系数相应调小。至于为什么只引导一部分通道还能有好的效果，论文留作了开放问题。

12缩放实验：计算量决定质量

这是论文最核心的实验。在 S、B、L、XL 四种规格和 p = 8、4、2 三种图块的组合上训练 12 个模型，每个训练 40 万步。

图上有三个结论：

  • 加大规格和减小图块都有效。 固定图块大小，规格越大 FID 越低；固定规格，图块越小 FID 越低。
  • 参数量不能决定质量。 同样是约 6.75 亿参数，DiT-XL/8 的 FID 是 106.41，DiT-XL/2 是 19.47。
  • 计算量相近时，FID 也相近。 比如 DiT-S/2（6.06 Gflops）和 DiT-B/4（5.56 Gflops）的 FID 分别是 68.40 和 68.38，尽管它们的参数量相差 4 倍。

论文还考察了两个相关问题。第一，大模型的计算效率也更高：按总训练算力比较（Gflops × 批量 × 步数 × 3），小模型即使训练更久，最终也会落后于大模型。第二，增加采样步数不能弥补模型规模的不足。DiT-L/2 用 1000 步采样，每张图 80.7 Tflops，FID-10K 是 25.9；DiT-XL/2 只用 128 步，每张图 15.2 Tflops，FID-10K 是 23.7。把算力花在训练更大的模型上，比花在采样时更划算。

14局限

论文只研究了类别条件，下面几点是后来的工作暴露出来的，或者从结构上可以看出来：

  • adaLN 不能处理序列条件。 全局向量足以表达类别，表达不了文本的细节。文本模型要么把交叉注意力加回来，要么把文本和图像放进同一个注意力。
  • 算力需求高。 最好的结果用了 TPU v3-256 训练 700 万步。论文说明大模型效率更高，但前提是有足够的算力。
  • 没有多尺度结构。 分辨率翻倍时 token 数变成 4 倍，注意力的计算量变成约 16 倍。U-Net 可以只在低分辨率层放注意力，DiT 没有这个选择。后来的模型通过更大的下采样倍数和更大的图块来控制 token 数。
  • 依赖自编码器。 这是继承自 Latent Diffusion 的特点，解码器的质量同样决定了上限，上面的解码器实验已经显示了这一点。
  • 参数里有一部分只作用在一个向量上。 adaLN 的线性层占比不小，所以后来 PixArt-α 提出 adaLN-single，让所有块共享这组参数，以减少参数量。

另外，U-Net 并没有被证明不如 Transformer。EDM2（2023-12-05）只改善 U-Net 的训练动态，就把 ImageNet-512 的最好 FID 从 2.41 降到 1.81。论文证明的是 U-Net 并非必要，不是 Transformer 一定更好。Transformer 后来胜出，更多是因为容易扩展和复用其他领域的经验。

EDM2 ↗

15后续发展

论文结尾建议继续扩大模型和 token 数，并把 DiT 用到文本生成图像上。这两件事很快都发生了。

文本生成图像。 PixArt-α（2023-09-30）是较早的开放模型，它在每个块中加入交叉注意力接收文本，并提出 adaLN-single 处理时间步。Stable Diffusion 3（2024-03-05）的 MMDiT 让文本 token 和图像 token 在同一个注意力中计算，两路各有独立的权重，并改用 Rectified Flow 训练。FLUX.1（2024-08-01）先用双流块再用单流块，这种设计后来也被 HunyuanVideo 采用。

视频。 Sora（2024-02-15）把视频压缩到隐空间，切成时空图块，用 DiT 处理。DiT 的第一作者 Bill Peebles 后来担任 Sora 负责人。Latte（2024-01-05）把空间和时间块交替排列，HunyuanVideo（2024-12-03）的参数量超过 130 亿。这条路线的逻辑和 DiT 的结论一致：token 变多，模型变大，质量随之提高。

训练框架。 SiT（2024-01-16）使用完全相同的 DiT 骨干，把扩散过程换成随机插值框架，说明骨干和训练目标是可以分开研究的。MDT（2023-03-25）加入掩码辅助训练。今天很多模型都是「DiT 骨干 + Rectified Flow」的组合。

仍用 U-Net。 这条线并没有消失。SDXL（2023-07-04）是 26 亿参数的 U-Net，EDM2 也继续使用 U-Net。CS231n 2025 第 14 讲的说法是，相当普通的 Transformer 用在扩散模型上效果很好，没有什么特别的秘方，这也是目前多数大型模型的选择。

基本概念

DiT 是一种新的生成模型吗？

DiT 是去噪网络的一种结构，生成框架仍是 DDPM 加 Latent Diffusion：同样的前向加噪过程，同样的预测噪声和方差，同样的自编码器。论文替换的只是 U-Net 这一个部件。

所以同一个骨干可以配不同的训练目标。SiT 使用完全相同的骨干，把扩散过程换成随机插值框架。

综述：和 U-Net、LDM、ViT 的关系 →综述：后续发展 →

DiT-XL/2 的「2」是下采样倍数吗？

「2」是隐变量上的图块大小 p。整条路径上有两次尺寸缩小：自编码器的下采样倍数是 8，256×256 变成 32×32；patchify 再以 p = 2 切块，32×32 变成 16×16 个 token，共 256 个。

因此一个 token 对应原图 16×16 个像素的区域。DiT-XL/8 的一个 token 对应 64×64 个像素，序列只有 16 个 token。

综述：Patchify →

为什么论文用 Gflops，而不用参数量衡量复杂度？

参数量不反映序列长度。Transformer 块的权重和 token 数无关，同一个规格改变 p，参数量几乎不变，计算量却相差约 16 倍。DiT-XL/8 和 DiT-XL/2 都约有 6.75 亿参数，FID 分别是 106.41 和 19.47，只看参数量无法解释这个差距。

反过来，DiT-S/2 和 DiT-B/4 的参数量相差约 4 倍，Gflops 相近（6.06 和 5.56），FID 也相近（68.40 和 68.38）。

论文只写了「理论 Gflops」，没有说明统计工具，也没有说明一次乘加算一次还是两次。不同论文之间的 Gflops 数字未必可以直接比较。

综述：缩放实验 →基础：Gflops 怎样随结构变化 →

为什么 p 越小，参数量反而略有下降？

和 p 有关的只有首尾两个投影层。输入投影把 p × p × 4 映射到 d 维，输出投影把 d 维映射到 p × p × 8，这两层的权重都和 p2 成正比。位置编码是固定的，不计入可训练参数。

以 DiT-XL 为例：p 从 8 减到 2，两层的权重从约 88.5 万减到约 5.5 万，少了约 83 万。官方代码统计的可训练参数从 675,664,640 减到 674,834,720，也少了约 83 万。

综述：Patchify →

条件和初始化

adaLN 和 AdaIN、FiLM 是什么关系？

三者形式相同：由条件回归一组缩放和平移系数，作用在归一化之后或中间的特征上。差别在作用范围和位置。AdaIN（2017-03-20）用于风格迁移，按通道统计量做实例归一化；FiLM（2017-09-22）把这种调制写成通用的条件层；StyleGAN（2018-12-12）和 ADM（2021-05-11）分别把它用在 GAN 和扩散 U-Net 中。adaLN 用在 Transformer 的 LayerNorm 上，归一化沿 token 的特征维度进行。

基础：自适应归一化 →综述：adaLN-Zero →

adaLN-Zero 比 adaLN 只多了什么？

结构上多回归一组 α，乘在两个子层的输出上；线性层的输出从 4d 维变成 6d 维。初始化上把这个线性层的权重和偏置全部置零，所以 γ = β = α = 0，每个块开始时都是恒等映射。

因为多了 2d 维输出，每个块多出约 2d2 个参数。DiT-XL/2 中 adaLN 是 6.00 亿参数，adaLN-Zero 是 6.75 亿，FID 从 25.21 降到 19.47。论文没有分别测试「多一组 α」和「零初始化」各自的贡献。

网络一开始输出全零，对应什么样的预测？

噪声部分预测为 0。方差部分的输出 v 按 (v + 1) / 2 映射成插值系数，v = 0 时系数是 0.5，方差取 βt 和 βt 在对数域的中点。这是官方 gaussian_diffusion.py 中 LEARNED_RANGE 的做法，来自 Improved DDPM。

既然 adaLN-Zero 最好，为什么文本模型又用回交叉注意力？

论文比较的是类别条件。t 和 y 嵌入后相加成一个向量，这个向量足以表达类别，adaLN 又对所有 token 应用同一个函数，计算量最低。

文本是一个序列，不同的词要作用到图像的不同位置。把整段文本压成一个向量会丢掉这种对应关系。所以后来的模型通常用 adaLN 接收时间步，用交叉注意力或联合注意力接收文本，CS231n 第 14 讲也是这样总结的。

没有跳跃连接，细节不会丢吗？

U-Net 需要跳跃连接，是因为下采样路径丢失了空间分辨率，要把高分辨率特征送回解码路径。DiT 没有下采样，序列长度在所有块中保持不变，每个 token 始终对应同一个图块，所以不存在这类分辨率损失。

图块内部的信息是另一回事：一个 token 的 d 维向量要表示 p × p × 4 的隐变量，p 越大越难重建细节，这和 FID 随 p 增大而变差的现象一致。U-ViT 保留了长跳跃连接，DiT 论文没有比较有无跳跃连接的差别。

综述：解码 →U-ViT 论文 ↗

损失函数到底是什么？方差那一项会影响噪声预测吗？

官方代码的损失是两项之和，L = Lsimple + Lvb。Lsimple 是预测噪声的均方误差；Lvb 是变分下界，单位是比特。计算 Lvb 时，噪声输出被 detach，所以这一项只训练方差输出，不影响噪声预测。

论文正文写的是 Lsimple 训练 εθ，完整的 L 训练 Σθ，和代码一致。代码里 Lvb 没有再乘系数（RESCALED_MSE 默认关闭）。

这篇论文证明了 Transformer 比 U-Net 好吗？

「总训练算力」里的系数 3 是什么？

基础：ViT、自适应归一化和方差学习

论文默认读者了解 ViT、自适应归一化和 Improved DDPM 的方差学习。这里按论文用到的顺序整理这些内容。扩散过程本身见 DDPM 专题，自编码器和隐空间见 Latent Diffusion 专题。

1Vision Transformer：把图像变成序列

Vision Transformer (ViT, 2020-10-22) 把图像切成不重叠的图块，每块线性投影成一个向量，加上位置编码后送入标准的 Transformer 编码器。DiT 沿用了这个做法，差别在于输入是隐变量，并且不需要分类用的 cls token。

图块的线性投影等价于一个卷积核大小和步长都等于 p 的卷积层，官方代码就是这样实现的。设输入为 I × I × C，序列长度 T = (I / p)2。这个序列长度在所有块中保持不变，这是它和 U-Net 最大的结构差别。

每个 Transformer 块由两个子层组成，都带残差连接。多头自注意力让所有 token 相互交换信息，MLP 则对每个 token 单独变换。DiT 的 MLP 隐藏层是宽度的 4 倍，激活函数是用 tanh 近似的 GELU。

ViT 论文 ↗综述：Patchify →

2Gflops 怎样随结构变化

Gflops 是一次前向计算的浮点运算量，以 109 为单位。对 Transformer，可以按层估算：

MLP：∝ T · d2每个 token 过两个线性层，宽度 d 到 4d 再回到 d
自注意力的 Q、K、V 投影：∝ T · d2每个 token 一次线性变换
自注意力的点积：∝ T2 · d每对 token 算一次，头数只改变分组，不改变总量级
N 个块：以上各项 × N总量和层数成正比

由此可以读出论文的结果。d 加倍时，T · d2 这部分变成 4 倍；T 变成 4 倍（p 减半）时，T · d2 这部分变成 4 倍，T2 · d 这部分变成 16 倍。序列较短时前者占主导，所以 p 减半时总量接近 4 倍；序列较长时后者的比重才明显上升，所以高分辨率的代价增长更快。

参数量只和 N、d 有关，基本不含 T。这是「参数量相同、计算量相差 16 倍」的来源。

3自适应归一化：用条件控制特征的缩放和平移

普通归一化的最后一步是乘一个可学习的 γ，再加一个可学习的 β。自适应归一化把这两个系数改成由条件回归，使同一个网络在不同条件下对特征做不同的变换。

做法日期归一化条件来自用途
AdaIN2017-03-20Instance Normalization风格图的特征统计量风格迁移
FiLM2017-09-22不要求归一化任意条件的线性回归视觉问答
StyleGAN 的 AdaIN2018-12-12Instance Normalization隐变量 w 的线性回归GAN 生成器
ADM 的 AdaGN2021-05-11Group Normalization时间步和类别的嵌入扩散 U-Net
DiT 的 adaLN2022-12-19Layer Normalization时间步和类别的嵌入之和扩散 Transformer

LayerNorm 对每个 token 沿特征维度做归一化，不依赖批量。官方 DiT 块的 LayerNorm 设置了 elementwise_affine=False，自身没有参数，γ 和 β 完全由条件给出。调制的写法是 x · (1 + γ) + β，所以 γ = β = 0 时特征不变，这也是零初始化能得到恒等映射的前提。

同一组系数作用到所有 token 上，每个块只回归一个 6d 维的向量，所以 adaLN 几乎不增加 Gflops，只增加参数。

4把残差块初始化为恒等映射

残差块写成 x + F(x)。如果让 F 在初始化时输出 0，整个块就是恒等映射，深层网络在训练开始时等价于一个浅层网络，信号和梯度都更容易传播。

Goyal 等人（2017-06-08）在 ImageNet 大批量训练中，把每个残差块最后一个 Batch Normalization 的 γ 初始化为 0，发现这有助于加速大规模训练。扩散模型的 U-Net 把残差连接前的最后一个卷积层初始化为 0，目的相同。DiT 的做法是把 α 回归层初始化为 0，效果和这两种相同，只是实现位置在条件调制上。

6为什么还要预测方差

DDPM 把反向过程的方差 Σθ 固定为 βt 或 βt，只学习均值。Improved DDPM（2021-02-18）发现，学习方差可以提高对数似然，并允许用更少的采样步数。它让网络多输出一组 v，在两个固定值之间做对数域插值：

Σθ = exp( f · log βt + (1 − f) · log βt )对数域插值
f = (v + 1) / 2官方代码中的 LEARNED_RANGE

方差项无法用噪声的均方误差训练，只能用变分下界 Lvb。为了不影响噪声预测，计算 Lvb 时噪声输出被 detach。DiT 的总损失是 Lsimple + Lvb，这也是输出通道数是输入两倍的原因。

论文的采样步数是 250。图 10 还测试了 16 到 1000 步。步数较少时，学到的方差更有价值；这一点来自 Improved DDPM，DiT 论文没有单独做固定方差的对比。

7FID 和其他指标

FID (Fréchet Inception Distance) 用 Inception 网络提取真实图像和生成图像的特征，分别拟合成高斯分布，再计算两个高斯之间的 Fréchet 距离。数值越低越好，FID-50K 表示用 5 万张生成图计算：

FID = ‖μr − μg‖2 + Tr( Σr + Σg − 2 (Σr Σg)1/2 )r 为真实图像，g 为生成图像

FID 对实现细节敏感，缩放方式不同就可能改变结果，所以论文明确所有数字都用 ADM 的 TensorFlow 工具计算。

sFID 用 Inception 中间层的空间特征，对空间结构更敏感。Inception Score (IS) 只看生成图，同时要求单张图的分类明确、整体类别分布均匀，越高越好。Precision 大致衡量生成图中有多少落在真实分布范围内，反映样本质量；Recall 衡量真实分布有多少被生成图覆盖，反映多样性。

引导系数增大时，通常 Precision 上升、Recall 下降。DiT-XL/2 从无引导到 s = 1.5，Precision 从 0.67 升到 0.83，Recall 从 0.67 降到 0.57，符合这个规律。论文附录也观察到，系数越大，保真度越高，多样性越低。

潜在扩散模型

实际到处使用的是潜在扩散模型，分多个阶段。先训练编码器和解码器：编码器把图像映射到隐空间，空间下采样 D 倍，通道从 3 变成 C。然后在隐空间训练扩散模型：图像经编码器得到隐变量，加噪，训练模型去噪。编码器是冻结的，梯度不传回去。推理时采样一个随机隐变量，多次去噪得到干净的隐变量，再由解码器变成图像。

课件写的常见设置是 8 倍下采样、16 个通道。

注DiT 论文使用 Stable Diffusion 的自编码器，同样是 8 倍下采样，通道数是 4。把通道数增加到 16 是后来的做法，Stable Diffusion 3 就是 16 通道。

编码器解码器怎么训练

编码器和解码器用变分自编码器训练。但变分自编码器的输出模糊，解码器的重建质量会成为后面扩散模型生成质量的上限。解决办法是在解码器后接一个判别器，加入生成对抗损失。

于是总共要训练编码器、解码器、判别器和隐空间中的扩散模型。Johnson 的说法是，现代生成建模流水线要训练一个变分自编码器、一个生成对抗网络和一个扩散模型，并且为此道歉说这很混乱。

注这解释了 DiT 论文的解码器实验：只换解码器，FID 就从 2.46 变成 2.27。详见综述的实验结果。

扩散 Transformer

结构上的主要问题是怎样注入条件。扩散模型要接收三样输入：加噪图像、时间步 t、条件信号（比如文本）。注入方式有两类。

  • 由条件预测缩放和平移系数，用来调制块内的中间激活。时间步通常这样注入，这就是 DiT 的 adaLN。
  • 利用 Transformer 处理序列的特点，把时间步、文本等都放进序列，通过交叉注意力或联合注意力处理。

他的总结是：现代扩散 Transformer 通常用缩放平移注入时间步，用序列拼接（多为交叉注意力，有时是联合注意力）注入文本等条件。

注课件这张图取自 DiT 论文。DiT 论文只做了类别条件，四种方案中 adaLN-Zero 最好。Johnson 讲的这种组合是后来面向文本的做法，见常见问题为什么文本模型又用回交叉注意力。

文本生成图像

文本提示经过预训练的文本编码器（通常是 T5、CLIP 这类，一般冻结）得到文本嵌入，和加噪隐变量、时间步一起送入扩散 Transformer，迭代得到干净的隐变量，再经变分自编码器的解码器得到图像。所以除了前面几个模型，还需要一个语言模型。

他给出的具体数字是开源模型 FLUX.1 dev：T5 和 CLIP 作文本编码器，自编码器 8 倍下采样，隐变量是 128×128×16，Transformer 有 120 亿参数。课件写明它在隐变量上再做 2×2 patchify，得到 64×64 = 1024 个图像 token。

注Johnson 口头说的「再做一层下采样」就是 patchify，和 DiT-XL/2 的 p = 2 相同。和 DiT-XL/2 比较：参数量从 6.75 亿到 120 亿，约 18 倍；序列长度从 256 到 1024，正好 4 倍。这和 DiT 论文建议的方向一致，继续扩大模型和 token 数。

文本生成视频

流程基本相同，区别是隐变量多一个时间维度，解码器换成时空自编码器，在空间和时间上都做上采样。示例来自 Meta 的 Movie Gen（2024-10-04）。

视频模型训练昂贵，主要原因是序列长度。文本生成图像的 Transformer 处理 1024 个 token；这个视频模型的整体结构相近，却要处理约 7.6 万个视频 token。

注这和基础一节的估算相符：自注意力的点积部分和 T2 成正比，序列长度变成约 74 倍时，这部分的计算量变成约 5500 倍。实际的视频模型会用因子化注意力等办法控制这个代价，这里只是量级比较。

视频扩散模型这一年半

他说过去一年基本是视频扩散模型的时代，几乎每周都有新模型，有开源的，有发技术报告的，也有只提供商业服务、不透露细节的。

OpenAI 的 Sora 影响很大，它不是第一个视频扩散模型，却是第一个效果非常好的，最早把扩散 Transformer 真正扩展上去。上课当天（2025-05-20）Google 发布了 Veo 3，他认为这几乎可以肯定是当时最好的视频生成模型，它还能联合生成声音。
