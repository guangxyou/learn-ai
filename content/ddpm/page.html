先补基础：马尔可夫链和高斯

DDPM 的推导看着长，用到的工具其实就那几样：马尔可夫链、高斯分布的几条运算规则、贝叶斯公式、两个高斯之间的 KL 散度，再加一个变分下界。两个视频都默认你会这些，讲到「这一步用了马尔可夫性」「两个高斯相乘还是高斯」就一笔带过，没跟上的话后面全是天书。

这一页按 DDPM 用到的先后顺序补齐，每条都配一个能手算的小例子。变分自编码器页已经讲过的期望、KL 散度定义、ELBO 来历，这里只写 DDPM 要的那一部分，细节链过去。

1先认符号：DDPM 公式里的字母

DDPM 的字母不多，但下标 t 到处都是，α 和 β 还带一个累乘的版本 α。先列一张表，后面几个 tab 都按这个写法，和原论文 (Ho 等，arXiv 2020-06-19) 一致。

写法读作是什么
x0原图一张真实图片，像素归一化到 [−1, 1]。下标 0 表示还没加噪
xt第 t 步的图加了 t 步噪声以后的图，和 x0 形状完全一样。t 从 1 到 T
xT纯噪声T 一般取 1000，加满以后 xT 几乎就是标准正态分布 N(0, I)
x0:T一整条链x0, x1, …, xT 这 T + 1 个变量放在一起
βt第 t 步的噪声方差每一步加多少噪声，人为定好的一张表，原论文从 10−4 线性涨到 0.02
αt第 t 步保留多少αt = 1 − βt，一个比 1 略小的数
αt累乘的 ααt = α1 α2 ⋯ αt，从 x0 一路到 xt 原图还剩多少
ε标准噪声从 N(0, I) 抽的一个样本，形状和图一样
q(·)前向过程加噪那一侧的分布，全是人定的，没有参数
pθ(·)逆向过程去噪那一侧的分布，由神经网络算，θ 是网络参数
εθ(xt, t)噪声预测网络DDPM 真正训练的东西：输入带噪图和步数，输出它猜的噪声
N(x; μ, σ2 I)x 服从的高斯均值 μ、每个像素方差都是 σ2、像素之间独立。分号前面写的是这个分布描述的变量

最后一行的写法初看最容易卡住。q(xt|xt−1) = N(xt; √αt xt−1, βt I) 读作：已知 xt−1 时，xt 服从均值 √αt xt−1、方差 βt 的高斯。分号前的 xt 是变量，分号后是参数。

2马尔可夫链：下一步只看当前这一步

一串随机变量 x0, x1, x2, …，如果每一个只依赖紧挨着的前一个，和更早的无关，就叫马尔可夫链 (Markov Chain)。写成条件概率：

p(xt | xt−1, xt−2, …, x0) = p(xt | xt−1)马尔可夫性：知道了现在，过去就不提供额外信息

p(xt | xt−1) 叫转移概率 (Transition Probability)，离散状态时是一张表，连续状态时是一个条件分布，也叫转移核。马尔可夫性最大的用处是让整条链的联合分布可以拆成连乘：

p(x0, x1, …, xT) = p(x0) p(x1|x0) p(x2|x1, x0) ⋯任何联合分布都能这样按链式法则拆
= p(x0) p(x1|x0) p(x2|x1) ⋯ p(xT|xT−1)马尔可夫性把每一项的条件砍到只剩前一个
= p(x0) ∏t=1T p(xt|xt−1)写成连乘号

没有马尔可夫性，第 t 项要以前面全部 t 个变量为条件，T = 1000 时根本没法建模。有了它，整条链只需要一个起点分布加 T 个「一步怎么走」。DDPM 的前向过程和逆向过程都是这样一条链，论文里的 q(x1:T|x0) = ∏ q(xt|xt−1) 和 pθ(x0:T) = p(xT) ∏ pθ(xt−1|xt) 就是上面第三行。

补充天气链每天用同一张表，叫时齐 (Time-Homogeneous) 马尔可夫链。DDPM 每一步的 βt 不一样，转移核随 t 变，是非时齐的，马尔可夫性照样成立：马尔可夫性只要求「只看前一个」，不要求每步规则相同。

3连续状态的马尔可夫链：每一步加一点高斯噪声

状态换成一个实数，转移规则换成「把上一步缩小一点，再加一点高斯噪声」：

xt = √(1 − β) xt−1 + √β εt, εt ∼ N(0, 1)每一步抽一个新的、独立的噪声
q(xt|xt−1) = N(xt; √(1 − β) xt−1, β)同一件事写成转移核

xt 只用到了 xt−1 和一个新抽的噪声，所以这是马尔可夫链。系数为什么是 √(1 − β) 而不是 1：如果 xt−1 的方差是 1，缩小后方差变成 1 − β，再加方差 β 的噪声，合起来还是 1。方差一直守在 1，链既不会炸开也不会缩成一点，这叫保方差 (Variance Preserving)。

只加噪不缩小的话，方差每步加 β，走 1000 步就到了 1 + 1000β，终点分布取决于 T，没法事先定好从哪采样。

4高斯分布的三条运算规则

DDPM 的推导几乎每一行都在用下面三条。记住它们，前向过程「一步到位」和逆向过程的「后验均值」就都只是代数。

规则一，线性变换还是高斯。 x ∼ N(μ, σ2)，那么 ax + b ∼ N(aμ + b, a2 σ2)。反过来，任何 N(μ, σ2) 都可以写成 μ + σε，ε 是标准正态。这就是重参数化 (Reparameterization)：采样变成「抽一个标准噪声，再做一次乘加」，梯度能穿过 μ 和 σ 传回去。

规则二，独立高斯相加，均值相加、方差相加。 ε1, ε2 独立且都是 N(0, 1)，那么 aε1 + bε2 ∼ N(0, a2 + b2)，可以合成一个 √(a2 + b2) ε。注意相加的是方差，不是标准差。

规则三，看到指数里是 x 的二次式，就是高斯。 高斯密度正比于 exp(−(x − μ)2 / 2σ2)。把指数展开成 −(Ax2 − 2Bx)/2 + 常数，就能读出方差 σ2 = 1/A、均值 μ = B/A。

两个关于 x 的高斯密度相乘，指数相加，还是二次式，所以乘积（归一化以后）还是高斯。这一步叫配方 (Completing the Square)，DDPM 求后验 q(xt−1|xt, x0) 就是这么算的。

例子两步合成一步

设 x1 = √α1 x0 + √(1 − α1) ε1，x2 = √α2 x1 + √(1 − α2) ε2。把第一行代进第二行：

x2 = √(α2 α1) x0 + √α2 √(1 − α1) ε1 + √(1 − α2) ε2展开
噪声部分的方差 = α2 (1 − α1) + (1 − α2) = 1 − α1 α2规则二：方差相加
x2 = √(α1 α2) x0 + √(1 − α1 α2) ε两个噪声合成一个

取 α1 = 0.9、α2 = 0.8：原图系数 √0.72 ≈ 0.849，噪声方差 0.8 × 0.1 + 0.2 = 0.28 = 1 − 0.72。一路合并下去，t 步就是 √αt x0 + √(1 − αt) ε。

这是 DDPM 能随机抽一个 t、一步算出 xt 的原因，训练时用不着真的走 t 步。

5链能倒着走吗：贝叶斯公式和「多知道 x0」

马尔可夫链有一个对称的性质：把一条马尔可夫链倒过来读，xT, xT−1, …, x0，它仍然是马尔可夫链。马尔可夫性等价于「给定现在，过去和未来条件独立」，这句话把过去和未来对调还是成立。所以逆向过程也只需要一步一步的 p(xt−1|xt)。

倒着走一步的概率由贝叶斯公式给出：

q(xt−1|xt) = q(xt|xt−1) q(xt−1) / q(xt)正向一步 × 前一步的边际分布 / 后一步的边际分布

分子第一项是自己定的高斯，没问题。麻烦的是 q(xt−1) 和 q(xt)：它们是「所有真实图片加了 t 步噪声以后」的分布，要对整个数据分布积分，算不出来。这就是 DDPM 需要神经网络的地方：pθ(xt−1|xt) 去学这个算不出来的倒退一步。

换个条件就能算了。如果额外知道这条链的起点 x0：

q(xt−1|xt, x0) = q(xt|xt−1) q(xt−1|x0) / q(xt|x0)每一项都条件在 x0 上；第一项因为马尔可夫性，多写一个 x0 不影响

右边三项全是已知的高斯：一项是正向一步，两项是上一节的一步到位公式。按规则三配方，结果还是高斯，均值和方差都有闭式解。

DDPM 训练时手里正好有 x0，所以每一步都有一个精确的「标准答案」让网络去对，这是整个训练目标能写出来的关键。

例子天气链倒着看

天气链走到平稳状态后，晴 2/3、雨 1/3。已知今天下雨，昨天是晴天的概率：

P(昨晴|今雨) = P(今雨|昨晴) P(晴) / P(雨) = 0.2 × (2/3) / (1/3) = 0.4

倒着走一步要用到边际分布 P(晴)、P(雨)。天气链的边际分布能算，图像的边际分布算不出，这就是两者的区别。

补充为什么 β 要小：β 很小时，正向一步只挪了一点点，倒着走一步的真实分布 q(xt−1|xt) 也近似是一个高斯（Feller 1949 年的结论，Sohl-Dickstein 等 2015 年把它用到扩散模型上）。所以 DDPM 才敢把 pθ(xt−1|xt) 也设成高斯，只让网络输出均值。步子迈大了，倒退一步的分布可能是多峰的，一个高斯装不下，后来的各种加速采样都要面对这个问题。

6KL 散度：两个高斯之间有闭式解

KL 散度的定义和性质在变分自编码器页讲过：KL(q ‖ p) = Eq[log q − log p] ≥ 0，两个分布相同时才等于 0。DDPM 只用到一个特例，两个一维高斯之间的 KL：

KL(N(μ1, σ12) ‖ N(μ2, σ22)) = log(σ2/σ1) + (σ12 + (μ1 − μ2)2) / 2σ22 − 1/2一般情形
KL(N(μ1, σ2) ‖ N(μ2, σ2)) = (μ1 − μ2)2 / 2σ2两边方差相同时，log 项和常数项抵消

第二行是 DDPM 损失的来源。逆向过程的方差是固定的，和真实后验的方差取同一个值（或者接近），那么两者的 KL 就只剩「两个均值差的平方」除以一个常数。最小化 KL 变成了最小化均值的均方误差，网络要学的只是一个均值。

多维高斯每个像素独立，KL 是各维相加，平方换成向量的长度平方 ‖μ1 − μ2‖2。

例子方差相同的两个高斯

N(1, 0.52) 和 N(1.3, 0.52)：KL = 0.32 / (2 × 0.25) = 0.18。均值差翻倍到 0.6，KL 变成 0.72，翻了四倍，和均方误差的行为一样。

7变分下界：最大似然算不动时的退路

生成模型想做最大似然：让模型生成真实图片 x0 的概率 pθ(x0) 尽量大。DDPM 的模型是一条链，pθ(x0) 要把中间 1000 个隐变量全积掉：

pθ(x0) = ∫ pθ(x0:T) dx1:T对 x1 到 xT 所有可能取值积分，算不出来

变分自编码器碰到的是同一个问题，解法也一样：找一个能采样的分布 q 当「向导」，把积分写成期望，再用 Jensen 不等式把 log 挪进期望里：

log pθ(x0) = log Eq(x_{1:T|x0)}[pθ(x0:T) / q(x1:T|x0)]乘一个 q 再除一个 q，积分变成按 q 取期望
≥ Eq[log (pθ(x0:T) / q(x1:T|x0))]Jensen：log 是凹函数，平均的 log ≥ log 的平均

右边就是证据下界 (Evidence Lower Bound, ELBO)，最大化它就是在抬高似然的下界。DDPM 和变分自编码器只差在 q 上：变分自编码器的 q 是编码器，要训练；DDPM 的 q 就是前向加噪过程，完全固定，不用学。所以 DDPM 常被看成一个编码器固定、有 1000 层隐变量的变分自编码器。

论文里写的是负的版本，叫负对数似然的上界 L，训练时最小化它。符号反过来，内容是同一个。

例子Jensen 不等式的数

一个随机变量一半概率取 1、一半取 4。先平均再取 log：log 2.5 ≈ 0.916；先取 log 再平均：(log 1 + log 4) / 2 ≈ 0.693。后者小，符合「平均的 log ≤ log 的平均」。两者的差就是变分自编码器页说的那个 KL 缺口。

8期望用采样估：一张图只抽一个 t

DDPM 的损失是一个对 t、x0、ε 三样东西取的期望：

L = Et, x0, ε[‖ε − εθ(xt, t)‖2]t 均匀取 1 到 T，x0 来自数据集，ε 来自 N(0, I)

没人真去对 1000 个 t 求和。训练时每张图只随机抽一个 t、一个 ε，算出一个平方误差，一个批次里的样本平均起来就是这个期望的无偏估计，这叫蒙特卡洛估计 (Monte Carlo Estimation)。期望里面的东西只要能采样、能求梯度，就可以用随机梯度下降去优化。

代价是方差大：同一张图这次抽到 t = 3，下次抽到 t = 900，损失差别很大，所以扩散模型要训练很多步（原论文 CIFAR-10 训了 80 万步）。后来的工作专门研究怎么抽 t 能让方差小一点。

9分数：概率密度往哪个方向涨得最快

最后一个概念两个视频都提到了，原论文也专门讲了它和 DDPM 的关系。概率密度取对数后对 x 求梯度，叫分数 (Score)：∇x log p(x)。它是一个和 x 同形状的向量，指向密度上升最快的方向，也就是「往更像真实数据的地方走」。

一维高斯 N(μ, σ2) 的分数是 −(x − μ)/σ2，永远指回均值，离得越远推力越大。把它套到 DDPM 的 q(xt|x0) 上：

∇xt log q(xt|x0) = −(xt − √αt x0) / (1 − αt)高斯分数的公式
= −ε / √(1 − αt)代入 xt − √α_t x0 = √(1 − α_t) ε

预测噪声和预测分数只差一个已知的系数 −√(1 − αt)。DDPM 训练出的 εθ 换个系数就是一个分数估计器，它的采样公式也和朗之万动力学 (Langevin Dynamics) 那种「沿着分数走一步再加点噪声」的形式一样。

原论文第 3.2 节说的就是这件事：预测噪声的 DDPM 等价于多噪声尺度的去噪分数匹配 (Denoising Score Matching)。

补充去噪分数匹配是 Vincent 2011 年的结论：给数据加噪声，训练网络从带噪样本预测「指回原样本」的方向，学到的就是加噪后分布的分数。Song 和 Ermon (arXiv 2019-07-12) 用多个噪声尺度加朗之万采样做出了 NCSN，DDPM 从另一条路得到了几乎相同的算法，Song 等 (arXiv 2020-11-26) 后来用随机微分方程把两者统一了起来。

1一句话：把加噪的过程倒过来学

去噪扩散概率模型 (Denoising Diffusion Probabilistic Model, DDPM) 是一种图像生成模型。思路只有一句：给真图一点一点加高斯噪声，加 1000 步变成纯噪声；再训练一个网络学会每一步怎么把噪声去掉一点。生成新图时，从一张随机噪声出发，让网络去噪 1000 次，最后得到一张数据集里没有的图。

加噪是人定的，谁都会做，不用学；去噪是难的那一半，交给神经网络。网络每次只需要回答一个小问题：「这张带噪的图里，噪声是什么样的」。1000 个小问题串起来，就从噪声走回了图像。

名字里三个词分别对应：Denoising 是网络做的事（去噪），Diffusion 是加噪的过程（像墨水滴进水里慢慢散开，结构越来越模糊），Probabilistic 指整个模型是一个概率模型，每一步都是在描述一个分布，生成时每一步都会随机采样。

2来历：2015 年提出，2020 年做出效果

扩散模型的框架最早是 Sohl-Dickstein 等人在 2015 年提出的（arXiv 2015-03-12，《Deep Unsupervised Learning using Nonequilibrium Thermodynamics》），灵感来自非平衡热力学：一个慢慢扩散的物理过程，如果每一步都足够小，它的逆过程也能写成同样形式的一步步小变化。那篇论文已经有了前向加噪链、逆向高斯链和变分下界，但生成质量远不如当时的 生成对抗网络 (Generative Adversarial Network)，没引起多少注意。

2019 年 Song 和 Ermon 从另一条路做出了 NCSN（arXiv 2019-07-12）：训练网络估计加噪数据的分数（对数密度的梯度），再用朗之万动力学一步步采样，在 CIFAR-10 上第一次让这类方法接近 生成对抗网络。

DDPM 是 UC Berkeley 的 Jonathan Ho、Ajay Jain、Pieter Abbeel 在 2020 年发的（arXiv 2020-06-19，NeurIPS 2020）。它沿用 2015 年的框架，做了两处关键改动：网络改成预测噪声，损失改成一个去掉权重的均方误差。结果 CIFAR-10 无条件生成的 FID 到了 3.17，超过了当时所有无条件 生成对抗网络；256×256 的 LSUN 和 CelebA-HQ 样本质量和 ProgressiveGAN 相当。

之后两年是扩散模型的爆发期：DDIM 把采样从 1000 步压到几十步，引导 (Guidance) 让条件生成可控，Latent Diffusion 把扩散挪进压缩后的隐空间，2022 年的 Stable Diffusion、DALL·E 2、Imagen 都建在这条线上。第 15 节有时间线。

3全貌：两条马尔可夫链，训练和生成各做什么

DDPM 由两条方向相反的马尔可夫链组成，共享同一组变量 x0, x1, …, xT：

前向过程 (Forward Process)逆向过程 (Reverse Process)
方向x0 到 xT，加噪xT 到 x0，去噪
每一步q(xt|xt−1) = N(√αt xt−1, βt I)pθ(xt−1|xt) = N(μθ(xt, t), σt2 I)
参数没有，βt 是人定的表网络参数 θ，只学均值
起点数据集里的真图xT ∼ N(0, I)
什么时候用训练时造「题目」生成时一步步走

训练只做一件事：从数据集取一张图 x0，随机挑一个步数 t，随机抽一份噪声 ε，按公式一步算出 xt，让网络从 xt 和 t 猜出 ε，用猜的和真的之间的均方误差更新网络。整个训练不需要真的走一遍链。

生成要真的走一遍链：从 N(0, I) 抽一张噪声 xT，然后 t 从 T 数到 1，每一步用网络猜出噪声，按公式算出去掉一点噪声后的均值，再加一点新的随机噪声得到 xt−1。走完 1000 步得到 x0。

训练快、生成慢，这是 DDPM 的基本特点。训练时每张图只过一次网络；生成一张图要过 1000 次网络。原论文在 TPU v3-8（论文说相当于 8 块 V100）上，一批 256 张 32×32 的图要采样 17 秒，一批 128 张 256×256 的图要 300 秒。

4第一步：前向过程，以及一步跳到任意 t

前向过程每一步把上一张图缩小一点，再加一点独立的高斯噪声：

q(xt|xt−1) = N(xt; √(1 − βt) xt−1, βt I)论文式 (2) 里的一步
xt = √αt xt−1 + √βt εt, εt ∼ N(0, I)同一件事的采样写法，αt = 1 − βt
q(x1:T|x0) = ∏t=1T q(xt|xt−1)马尔可夫链，联合分布是各步连乘

βt 叫方差表 (Variance Schedule)。原论文取 T = 1000，β1 = 10−4，线性涨到 βT = 0.02。β 都很小，所以每一步只动一点点；乘 √(1 − βt) 是为了保方差：如果像素的方差是 1，加噪以后还是 1，见基础 tab 的高斯马尔可夫链一节。

前向过程最有用的性质是可以从 x0 一步跳到任意 xt。用高斯「独立噪声相加、方差相加」的规则把 t 步合并：

αt = α1 α2 ⋯ αt定义累乘
q(xt|x0) = N(xt; √αt x0, (1 − αt) I)论文式 (4)
xt = √αt x0 + √(1 − αt) ε, ε ∼ N(0, I)训练时就用这一行造 xt

xt 是原图和噪声的加权和，两个系数的平方和恒等于 1。√αt 随 t 从 1 掉到接近 0，原图越来越淡；√(1 − αt) 从 0 涨到接近 1，噪声越来越浓。线性方差表下的几个数：

5第二步：逆向过程，网络只学均值

逆向过程从标准正态分布出发，每一步是一个高斯，均值由网络给出：

p(xT) = N(xT; 0, I)起点：和前向过程的终点对上
pθ(xt−1|xt) = N(xt−1; μθ(xt, t), σt2 I)论文式 (1) 里的一步
pθ(x0:T) = p(xT) ∏t=1T pθ(xt−1|xt)也是马尔可夫链

这里有两个设计。第一，每一步都设成高斯。理由是基础 tab 说过的：前向每步的 β 很小时，真正倒退一步的分布 q(xt−1|xt) 也接近高斯，所以用高斯去拟合不会差太多。第二，方差 σt2 不学，直接定死。原论文试了 σt2 = βt 和 σt2 = βt（第 7 节的后验方差）两种，生成质量差不多；也试过让网络学对角方差，训练不稳定、效果更差。

于是网络的任务被压缩成：输入一张带噪图 xt 和步数 t，输出这一步该往哪去的均值 μθ(xt, t)，形状和图一样。这个均值怎么学、学成什么形式，是后面五节的内容。

为什么要学分布、每一步还要再采样，而不是直接输出一张确定的 xt−1：确定的映射会让每个 xT 只对应一张图，更要紧的是，均方误差训练出来的确定性预测会落在所有可能答案的平均上，图就糊了。每一步保留一点随机性，让链能在多个合理的方向里挑一个走下去。Nik_Li 视频最后一个问题讲的就是这个。

6第三步：训练目标从变分下界来

生成模型的标准目标是最大似然：让模型给真图的概率 pθ(x0) 尽量大。pθ(x0) 要把 x1 … xT 全积掉，算不出，于是和变分自编码器一样，用前向过程 q 当近似后验，写出负对数似然的上界（论文式 (3)）：

E[−log pθ(x0)] ≤ Eq[−log (pθ(x0:T) / q(x1:T|x0))]Jensen 不等式，见基础 tab
= Eq[−log p(xT) − Σt≥1 log (pθ(xt−1|xt) / q(xt|xt−1))] =: L把两条链的连乘代进去，log 把连乘变成求和

L 能算，但不好用：每一项都要从 q 里把整条链采出来，方差很大。论文附录 A 把它改写成一串 KL 散度。关键一步是用贝叶斯公式把前向的一步「倒过来」，并且多条件一个 x0：

q(xt|xt−1) = q(xt|xt−1, x0) = q(xt−1|xt, x0) q(xt|x0) / q(xt−1|x0)马尔可夫性让第一个等号成立，第二个等号是贝叶斯公式

代回 L，q(xt|x0) / q(xt−1|x0) 这些比值从 t = 2 连乘到 T，中间全部约掉，只剩 q(xT|x0) / q(x1|x0)。整理以后 L 拆成三类项（论文式 (5)）：

L = Eq[ KL(q(xT|x0) ‖ p(xT)) LT：前向终点和逆向起点差多少
+ Σt&gt;1 KL(q(xt−1|xt, x0) ‖ pθ(xt−1|xt)) Lt−1：每一步的逆向，和「知道原图时的真实倒退」差多少
− log pθ(x0|x1) ]L0：最后一步还原出真图的似然

三类项的处境不同。LT 里没有可学的参数：q 是固定的，p(xT) 是标准正态，它就是个常数，训练时直接忽略；论文的方差表让它小到约 10−5 比特每维。L0 只管最后一步，论文用一个离散解码器处理（第 11 节）。真正的主体是中间 T − 1 个 Lt−1，每一个都是两个高斯之间的 KL，有闭式解。

这一步把「最大似然」变成了「让每一步的逆向，去贴一个算得出来的目标分布」。目标分布 q(xt−1|xt, x0) 就是基础 tab 里说的「多知道 x0 就能倒着走」。

7第四步：知道原图时的倒退一步，有闭式解

q(xt−1|xt, x0) 叫前向过程的后验 (Forward Process Posterior)。贝叶斯公式里三个分布都是已知的高斯：

q(xt−1|xt, x0) ∝ q(xt|xt−1) · q(xt−1|x0)分母 q(xt|x0) 和 xt−1 无关，是归一化常数

两个高斯密度相乘，指数相加。只看和 xt−1 有关的部分（每个像素独立，按一维写）：

指数 = −½ [ (xt − √αt xt−1)2 / βt + (xt−1 − √αt−1 x0)2 / (1 − αt−1) ]两个高斯的指数
= −½ [ A xt−12 − 2B xt−1 ] + 常数展开，按 xt−1 的次数整理
A = αt / βt + 1 / (1 − αt−1) = (1 − αt) / (βt (1 − αt−1))二次项系数；通分时用到 αt + βt = 1 和 αt α_{t−1} = α_t
B = √αt xt / βt + √αt−1 x0 / (1 − αt−1)一次项系数

按配方规则，方差是 1/A，均值是 B/A（论文式 (6)(7)）：

βt = (1 − αt−1) / (1 − αt) · βt后验方差，只和方差表有关
μt(xt, x0) = √αt−1 βt / (1 − αt) · x0 + √αt (1 − αt−1) / (1 − αt) · xt后验均值，是 x0 和 xt 的加权和

两个结论。后验方差 βt 是个定数，和图无关；它比 βt 略小，t = 2 时只有 βt 的 45%，t = 100 时是 98%，t 越大越接近 βt。所以逆向方差取 βt 还是 βt 差别不大，前者是方差的上限，后者是下限（论文这么解释两种选择）。

后验均值是「原图」和「当前带噪图」的加权平均。可它要用到 x0，生成时偏偏没有 x0。这就是网络要补的那一块：给它 xt，让它把 x0 的信息估出来。

8第五步：从「学均值」改成「学噪声」

两个方差相同的高斯，KL 只剩均值差的平方。pθ 的方差固定为 σt2，于是每一项 Lt−1 化成（论文式 (8)）：

Lt−1 = Eq[ ‖μt(xt, x0) − μθ(xt, t)‖2 / (2σt2) ] + CC 是和 θ 无关的常数

最直接的做法是让网络直接输出 μθ 去拟合 μt。DDPM 换了一种参数化。先把 x0 用 xt 和 ε 表示出来，代进后验均值：

x0 = (xt − √(1 − αt) ε) / √αt由 xt = √α_t x0 + √(1 − α_t) ε 反解
μt = 1/√αt · ( xt − βt / √(1 − αt) · ε )代入后验均值化简，论文式 (10)

化简后 μt 里只有一个未知量 ε，其余的 xt、αt、βt、αt 都是已知的。那就让网络 εθ(xt, t) 去猜 ε，均值按同一个公式算：

μθ(xt, t) = 1/√αt · ( xt − βt / √(1 − αt) · εθ(xt, t) )论文式 (11)
Lt−1 − C = Ex0, ε[ βt2 / (2σt2 αt (1 − αt)) · ‖ε − εθ(√αt x0 + √(1 − αt) ε, t)‖2 ]代回式 (8)，论文式 (12)

均值差变成了噪声差乘一个常数。网络从「输出一张图的均值」变成了「输出它认为混在 xt 里的噪声」。这里的 ε 是从 x0 一步加到 xt 用的那份总噪声，不是 xt−1 到 xt 那一步的噪声，Nik_Li 特意强调了这一点。

同一个 μθ 有三种等价的参数化：直接预测 μt、预测 x0、预测 ε。论文都试了，预测 x0 效果最差，预测 ε 配上下一节的简化损失最好。数学上三者可以互相换算，差别在网络学起来难不难：ε 永远是标准正态，各步的输出尺度一致；x0 在 t 很大时几乎看不出来，网络只能猜一个平均，误差大。

9第六步：去掉权重，得到 Lsimple

式 (12) 前面有一个随 t 变的权重 βt2 / (2σt2 αt (1 − αt))。DDPM 的第二个改动是把它直接扔掉，t 均匀抽，得到简化损失（论文式 (14)）：

Lsimple(θ) = Et, x0, ε[ ‖ε − εθ(√αt x0 + √(1 − αt) ε, t)‖2 ]t ∼ Uniform{1, …, T}

扔掉的权重长什么样：取 σt2 = βt 时它等于 βt / (2αt(1 − αt))，t = 1 时约 0.5，t = 10 时 0.074，t = 100 时 0.010，之后一直在 0.005 到 0.01 之间。原来的下界把大部分力气花在 t 很小的那几步上，那几步噪声极弱，任务是去掉肉眼几乎看不见的细节。

去掉权重相当于把小 t 的项调轻、大 t 的项调重，网络把更多力气花在噪声大、更难的去噪任务上。论文的解释就是这句，实验结果也支持它：用 Lsimple 训练的样本质量最好，代价是对数似然变差了一点（3.75 对 3.70 比特每维）。

这是 DDPM 和 2015 年那篇的关键区别之一：它不再严格优化似然的下界，而是优化一个重新加权过的版本，换来了样本质量。后来的工作（Improved DDPM、EDM）专门研究怎么设这个权重。

补充和分数匹配的关系就在这一步。ε 和分数只差一个系数：∇ log q(xt|x0) = −ε / √(1 − αt)，所以 Lsimple 等于在每个噪声尺度上做去噪分数匹配，和 NCSN 的目标形式相同。采样公式 xt−1 = μθ + σt z 也和朗之万动力学「沿分数走一步再加噪声」一个样子。论文 3.2 节把这层关系当作一个发现写了出来。

训练循环里没有任何链式的东西，每次抽一个 t，一步造出 xt，一次前向一次反向。采样循环才真的沿链走 T 步，每一步先用网络算均值，再加 σt z 这份新噪声。最后一步不加噪声，直接输出均值。

下面是一个能跑的最小 PyTorch 实现，网络 model(x, t) 可以是任何输入输出形状相同、能接收步数的网络：

import torch
T = 1000
beta = torch.linspace(1e-4, 0.02, T)            # β_1 … β_T
alpha = 1 - beta
abar = torch.cumprod(alpha, 0)                   # ᾱ_t

def train_step(model, opt, x0):                  # x0: [B, C, H, W]，像素在 [-1, 1]
    t = torch.randint(0, T, (x0.shape[0],))      # 下标 0 … T-1 对应 t = 1 … T
    eps = torch.randn_like(x0)
    a = abar[t].view(-1, 1, 1, 1)
    xt = a.sqrt() * x0 + (1 - a).sqrt() * eps    # 一步跳到 x_t
    loss = ((eps - model(xt, t)) ** 2).mean()    # L_simple
    opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

@torch.no_grad()
def sample(model, shape):
    x = torch.randn(shape)                       # x_T
    for i in reversed(range(T)):
        t = torch.full((shape[0],), i)
        eps = model(x, t)
        mean = (x - beta[i] / (1 - abar[i]).sqrt() * eps) / alpha[i].sqrt()
        x = mean + beta[i].sqrt() * torch.randn_like(x) if i > 0 else mean   # σ_t² = β_t
    return x

训练函数里没有循环，采样函数里有一个 T 步的循环，和上面的表一一对应。σ 取的是 √βt；换成 √βt 只要把那一行的 beta[i] 换掉。

11网络和训练设置

εθ 是一个 U-Net，结构沿用 PixelCNN++ 的骨干（基于 Wide ResNet 的残差块），归一化从权重归一化换成了组归一化 (Group Normalization)。输入输出都是和图一样大的张量，所以用分割任务常见的 U-Net：先下采样提取全局信息，再上采样还原分辨率，同分辨率之间有跳连。

  • 分辨率：32×32 的模型有四级特征图（32、16、8、4），256×256 的有六级；每级两个残差块。
  • 自注意力：在 16×16 那一级加了自注意力块。
  • 步数 t 的输入：用 Transformer 的正弦位置编码把 t 变成一个向量，加到每个残差块里。同一个网络要处理所有 1000 种噪声强度，它必须知道当前是第几步。
  • 参数量：CIFAR-10 模型 3570 万，LSUN 和 CelebA-HQ 模型 1.14 亿；另训了一个 2.56 亿参数的大 LSUN Bedroom 模型。
  • 训练：Adam，学习率 32×32 用 2 × 10−4、256×256 用 2 × 10−5，批量 128 和 64；CIFAR-10 训了 80 万步，用了随机水平翻转和 0.1 的 dropout；参数做 0.9999 衰减的指数移动平均 (EMA)。

数据预处理：像素从 {0, …, 255} 线性缩放到 [−1, 1]。这样 x0 的尺度和 xT ∼ N(0, I) 相当，前向过程的方差保持才有意义。

12细节：最后一步的离散解码器

扩散模型和 DDPM 的来历

AI 绘画背后是生成模型，常见的有 生成对抗网络 (Generative Adversarial Network)、变分自编码器，Stable Diffusion、Midjourney 这些产品底层用的都是扩散模型。

扩散模型的概念 2015 年就有人提出，直到 2020 年 DDPM (Denoising Diffusion Probabilistic Model) 发表、效果做上去以后才受到重视。

讲者说这篇论文偏数学，网上一些讲解写得太难，他想讲得入门一点，顺便自己复习。

注2015 年那篇是 Sohl-Dickstein 等人的《Deep Unsupervised Learning using Nonequilibrium Thermodynamics》（arXiv 2015-03-12）；DDPM 是 Ho、Jain、Abbeel，arXiv 2020-06-19，NeurIPS 2020。

Midjourney 没公开过模型结构，说它基于扩散模型是业内的普遍看法。

定义问题：前向加噪，逆向去噪

有一张输入图 x0，不断往上加随机噪声，加 T 次后得到 xT，希望 xT 服从标准正态分布。从 x0 到 xT 的加噪叫前向过程 (Forward Process)，从 xT 回到 x0 的去噪叫逆向过程 (Reverse Process)。

推理时从标准正态分布里随机取一个 xT，如果学会了 xt 和 xt−1 之间的去噪关系，就可以一步步去噪，最后得到一张全新的 x0。

要学的是分布，不是一张确定的图

更一般地，假设有了 xt（x0 加了 t 次噪声的结果），要做的是从 xt 推出 xt−1 的分布 p(xt−1|xt)，而不是推出一张确定的 xt−1。讲者认为这一点必须先说清楚。

原因是有了分布就能从里面随机抽一个 xt−1，这个样本和前向过程里那张 xt−1 不一定是同一张。每一步都这样采样，从 xT 一直推到 x0，每次生成的结果都不一样。生成模型需要这种随机性，不能像分割任务那样一张输入对应一张固定的输出。他认为这是扩散模型多样性比 生成对抗网络 好的原因，不少论文也这么说。

所以后面会看到网络输出的是噪声，那只是重参数化以后的结果，任务的本质一直是预测分布。他也提前说明：网络学到的噪声不是 xt 和 xt−1 之间的噪声。

用贝叶斯公式改写要学的分布

要学的分布用贝叶斯公式改写成三项：

q(xt−1|xt) = q(xt|xt−1) q(xt−1) / q(xt)

右边第一项是加噪的一步，加噪过程是我们自己定义的，它的分布当然也能写出来。另外两项是 xt−1 和 xt 各自的分布，直接求不出来。

注板书上这几项都写成 p，这里按论文的习惯写成 q：前向过程和由它推出的分布用 q，网络要学的逆向分布用 pθ。视频里 p、q 混用，看板书时留意这一点。

加噪公式：xt = √αt xt−1 + √βt ε

加噪不是直接加 ε，而是先把 xt−1 乘一个系数 √αt，再加上 √βt 乘一个标准正态噪声 ε：

xt = √αt xt−1 + √βt εt, εt ∼ N(0, I)两个系数满足 βt = 1 − αt，原因留到问题二
√βt εt ∼ N(0, βt I)标准正态乘一个数，方差乘这个数的平方
q(xt|xt−1) = N(xt; √αt xt−1, βt I)于是加噪一步是一个高斯

βt 就是这一步所加噪声的方差。它必须很小、接近 0：只有每一步扰动都很小，前向和逆向的每一步才都能当作正态分布。相应地 αt 接近 1 但小于 1。

注「β 小时逆向一步也近似高斯」是 Feller 1949 年关于扩散过程的结论，Sohl-Dickstein 等 2015 年把它当作扩散模型的理论依据，见基础 tab 的「倒着走」一节。

另外两项算不出：多条件一个 x0

xt−1 是从 x0 一步步加噪来的，每一步的公式都知道，所以用 x0 能把 xt−1 表示出来，q(xt−1|x0) 是能求的，q(xt|x0) 同理。于是给要学的分布多加一个条件 x0，再用贝叶斯公式改写：

q(xt−1|xt, x0) = q(xt|xt−1, x0) q(xt−1|x0) / q(xt|x0)每一项都多一个 x0 条件
= q(xt|xt−1) q(xt−1|x0) / q(xt|x0)马尔可夫性：xt 只和 xt−1 有关，第一项的 x0 可以去掉

有人会问：既然 xt 只跟前一时刻有关，后两项为什么还留着 x0？讲者的解释是两种条件不一样。第一项的条件里已经有了 xt−1，再给 x0 没有意义；后两项的条件里只有 x0，要靠一步步的加噪公式从 x0 推到 xt−1 或 xt，x0 正是这条推导的起点。

注马尔可夫性说的是「给定前一个，更早的不提供额外信息」，见基础 tab 的马尔可夫链一节。q(xt|xt−1, x0) 的条件里有 xt−1，所以 x0 能去掉；q(xt−1|x0) 的条件里只有 x0，中间隔着 t − 1 步，这时 x0 当然有用。

从 x0 一步跳到 xt

讲者说计算比较繁，只给思路：把 xt−1 用 xt−2 展开，xt−2 再用 xt−3 展开，一直写到 x0。x0 前面的系数一定是 √αt √αt−1 ⋯ √α1 连乘；后面是一串 ε 的加权和，每个 ε 都服从标准正态，独立正态分布相加还是正态分布，所以这一串可以合成一个 ε。

结论是论文里的式 (4)，他用 αt（α 上面加一横）表示连乘：

αt = α1 α2 ⋯ αt
q(xt|x0) = N(xt; √αt x0, (1 − αt) I)方差 1 − α_t 讲者没算，留作练习
xt = √αt x0 + √(1 − αt) ε采样写法

把 t 换成 t − 1 就得到 q(xt−1|x0)。贝叶斯公式右边三项至此都有了。

注方差为什么是 1 − αt，基础 tab「高斯运算」一节有两步合并的例子：噪声部分方差是 α2(1 − α1) + (1 − α2) = 1 − α1 α2，一路合并下去就是 1 − αt。这里用到了 βt = 1 − αt；讲者在问题二里用另一种写法把这件事又推了一遍。

后验是高斯：均值待定，方差固定

右边三项都是高斯，把均值方差代进去做初等运算，得到的 q(xt−1|xt, x0) 还是高斯。讲者不想牵扯太多计算，直接给结论：均值是 xt 和 x0 的函数，方差是一个只由 αt、βt 决定的定值，可以当超参数。

q(xt−1|xt, x0) = N(xt−1; μt(xt, x0), βt I)
μt = √αt−1 βt / (1 − αt) · x0 + √αt (1 − αt−1) / (1 − αt) · xt讲者没写出的均值，论文式 (7)
βt = (1 − αt−1) / (1 − αt) · βt方差，只和方差表有关

他回顾了一遍思路：用贝叶斯公式列出式子；其中两个分布不好求，于是引入条件 x0；靠定义好的加噪过程和马尔可夫性求出这两个分布；三项都已知后解高斯，得到想要的分布。方差固定，问题就从预测一个分布变成了预测一个均值。

注跳过的「初等运算」是配方：两个高斯密度相乘，指数里是 xt−1 的二次式，二次项系数的倒数是方差，一次项系数除以二次项系数是均值。完整过程在综述 tab 第 7 节，规则在基础 tab「高斯运算」的规则三。

有了均值就能采样：重参数化

有了均值，就能得到一个 xt−1：

xt−1 = μt + √βt · ε, ε ∼ N(0, I)方差带小波浪线，和前向的 βt 区分

讲者给了两个理由。第一，这是合理的，就是把高斯标准化的过程反过来用。第二，这种写法可导：直接说「从分布里取一个 xt−1」在数学上不可导，而反向传播需要求导，所以要一个能求导的式子来表达「取样」这个动作。

注第二个理由放在 DDPM 里不太准。DDPM 训练时不会从 pθ 里采 xt−1，损失只用到前向一步算出的 xt（见 28:29 的伪代码一），采样阶段又不需要求导。

重参数化在 DDPM 里真正派上用场的是前向那一步：xt = √αt x0 + √(1 − αt) ε 把随机性挪到了 ε 上，网络的损失对 θ 可导。这个理由在变分自编码器里成立，那里编码器的采样结果要送进解码器、梯度要穿过去。

生成时没有 x0：改成预测噪声

均值 μt 要用到 xt 和 x0。这里的 x0 是训练时的条件，是数据集里那张真图；生成时只有 xt，没有 x0。补上这个缺口就是模型的任务：本来想让模型去预测 x0。

注意前面有 xt = √αt x0 + √(1 − αt) ε，反过来可以用 xt 和 ε 表示 x0。这样就不用去预测不太好预测的 x0，改为预测比较好预测的 ε。

这就解释了 U-Net 为什么输入 xt、输出噪声。而且这份噪声是从 0 时刻加到 t 时刻的那份，不是 t − 1 到 t 那一步的。

为什么不能一步预测出 x0

既然网络等于在间接预测 x0，能不能直接一步把图生成出来？讲者说不行：后验右边那些式子都是靠马尔可夫性得到的，从 xt 直接推 x0 不符合马尔可夫性。x0 在这里只是一个零件，用来算这一步分布的均值，最终还是要一步步采样回到 x0。

注「不符合马尔可夫性」不是真正的原因。从 xt 一步估计 x0 在数学上完全可以：网络预测出 ε，代进反解公式就有一个 x̂0，论文图 6 就是把每一步的 x̂0 画出来看。

问题在于质量：t 很大时，同一个 xt 可能来自很多张不同的原图，均方误差训练出来的 x̂0 是它们的平均，一张模糊的图。一步步走，每一步只需要往前挪一点，再加一点噪声重新采样，模糊的平均就不会累积下来。

讲者在 44:29 的问题三里也提到，DDIM 用非马尔可夫的过程照样能用同一个网络跳步采样，说明马尔可夫性并不是限制步数的根本原因。

代入化简：均值里只剩 ε 未知

把 x0 = (xt − √(1 − αt) ε) / √αt 代进后验均值。讲者分两部分化简：

x0 那一项：√αt−1 βt / (1 − αt) · (xt − √(1 − αt) ε) / √αtα_{t−1} / α_t 约成 1/αt，只剩不带横杠的 αt
xt 的系数合并：[βt + αt(1 − αt−1)] / ((1 − αt) √αt) = 1/√αt通分，用 βt = 1 − αt 和 αt α_{t−1} = α_t
ε 的系数：−βt / (√αt √(1 − αt))√(1 − α_t) 和分母约掉一次
μt = 1/√αt · ( xt − βt / √(1 − αt) · ε )论文式 (10)

式子里 xt 是输入，αt、βt、αt 都是事先定好的，唯一要预测的就是 ε。论文里把它写成 εθ，θ 是模型参数。

注板书化简过程中有几处少写了 √αt 和 ε，讲者边写边口头补了。上面按正确的结果誊清。

εθ(xt, t)：步数 t 为什么也要输入

模型 εθ(xt, t) 的输入是 xt 和 t。输入 xt、得到 ε，再按上面的式子得到均值、得到分布、采样出 xt−1，一步步推回去，这就是扩散模型的整个流程。

t 也要作为输入，是因为训练时的 xt 都是从 x0 一步加噪得到的，模型自己不知道送进来的这张图是第几步的。t = 1 和 t = 500 的噪声强度完全不同，所以讲者说 t 不只是时间，也是噪声强度，必须告诉模型，它才能估计出合理的 ε。

注原论文用 Transformer 的正弦位置编码把 t 变成向量，加到 U-Net 的每个残差块里。所有步数共用同一组参数，见综述 tab 的网络一节。

伪代码一：训练

对着论文的 Algorithm 1 讲。外层是一个循环，论文按迭代次数 (iteration) 计，一次迭代是一个批次，和把整个数据集过一遍的轮次 (epoch) 不同。讲者为了简单设批量为 1：

  • 从数据集里取一张图 x0。
  • 从 1 到 T 之间均匀地取一个 t，T 是超参数，一般取 1000。
  • 从标准正态分布取一个噪声 ε。
  • 用 √αt x0 + √(1 − αt) ε 一步得到 xt。各个 α 都是事先设好、算好存着的。
  • 把 xt 和 t 送进 U-Net，预测出 ε̂，和刚才抽的 ε 算均方误差。

讲者说这写法有点反直觉。按「一步步加噪」的理解，代码应该是两层循环，外层遍历图片、内层 t 从 1 走到 T 逐步加噪、每步预测一次。实际是直接一步到位，理论依据就是前面用马尔可夫性推出的 q(xt|x0)。也正因为抽的噪声直接作用在 x0 和 xt 之间，网络预测的才是 0 到 t 的噪声。

伪代码二：采样

生成从服从标准正态分布的 xT 开始。训练可以一步到位，生成不行：往回走时只能用上面推出的「倒退一步」公式，没有从 xT 直接到 x0 的式子，所以 t 要一个一个取。

xt−1 = 1/√αt · ( xt − (1 − αt)/√(1 − αt) · εθ(xt, t) ) + σt zAlgorithm 2 的第 4 行，1 − αt 就是 βt

括号外那一大块就是均值 μ；σt 是标准差，取的就是前面带波浪线的 √βt；z 是新抽的标准正态噪声。这一步就是「均值加标准差乘噪声」的采样。每一步都得到一个全新的 xt−1，最后得到的 x0 也是新的，这保证了多样性。

注论文里 σt2 取 βt 或 βt 都试过，结果差不多，并不只取 βt。最后一步 t = 1 时 z 取 0，直接输出均值。

问题一：T 为什么要取那么大

回到加噪公式。βt 要小，所以 αt 接近 1，同时又必须小于 1。

  • 接近 1：如果 αt 是 0，xt 一步就变成纯噪声，上一时刻的信息一点都没留下。希望每一步都保留上一步的大部分信息。
  • 小于 1：如果 αt 等于 1，x0 会一直原样保留，永远变不成标准正态分布。

再看一步到位的公式：希望最后 xT 里原图的系数 √αT 趋近 0、噪声的方差趋近 1，两者都等价于连乘 αT 趋近 0。每个 αt 都很接近 1，要连乘到接近 0，T 就必须很大。

注讲者举例时说每个 α「可能都是 0.9 左右」，实际 DDPM 的 αt 在 0.9999 到 0.98 之间。

按原论文的线性方差表，α1000 ≈ 4 × 10−5，√α1000 ≈ 0.0064；如果只走 100 步，α100 ≈ 0.90，原图几乎还在。论文说选方差表时的约束就是让 LT（前向终点和标准正态的差距）接近 0。

问题二：为什么 βt = 1 − αt

换个说法：为什么要让均值系数的平方加方差等于 1。讲者用一般的系数推一遍：设 xt = kt xt−1 + bt εt，k 是均值系数，b 是标准差。一路展开到 x0：

xt = kt kt−1 ⋯ k1 x0 + (kt ⋯ k2 b1 ε1 + kt ⋯ k3 b2 ε2 + ⋯ + bt εt)前面是原图，括号里是 t 个独立噪声的加权和
噪声方差 = kt2 ⋯ k22 b12 + kt2 ⋯ k32 b22 + ⋯ + bt2独立正态相加，方差相加
令 bi2 = 1 − ki2，方差 = 1 − kt2 kt−12 ⋯ k12代进去以后相邻项正负抵消（裂项相消）

于是均值系数是 kt ⋯ k1，方差是 1 减去它的平方。当均值系数趋于 0 时，方差自动趋于 1，正好是标准正态。加了这个约束，最后的形式简单，而且有这个好性质。令 kt = √αt，bt = √βt，约束就是 βt = 1 − αt。

注裂项相消可以用两项验证：k22 b12 + b22 = k22(1 − k12) + 1 − k22 = 1 − k12 k22。

这个约束的另一种说法是保方差 (Variance Preserving)：如果 xt−1 每个像素方差是 1，加噪后还是 1。不加约束的另一种选择是只加噪不缩小（kt = 1），方差会一直涨，NCSN 和后来 Score SDE 里的「方差爆炸」(Variance Exploding) 就是这种，终点分布的方差取决于加了多少噪声。

问题三：能不能跳步采样

能不能从 xt 跳到 xt−5，甚至一步回到 x0？毕竟公式都有了，ε 也能预测出来。讲者说 DDPM 这样做不行：采样用的后验公式和 q(xt|x0) 都是靠马尔可夫性推出来的，目标函数本身就建立在马尔可夫性上，用完就丢掉是「过河拆桥」。

但有办法：去马尔可夫化。让过程不再是马尔可夫的，同时依然满足 q(xt|x0) 这个边界条件，再把新过程的分布写出来。他指出训练的伪代码里根本没用到「一步一步」的那个转移公式，只用了 q(xt|x0)，所以那个公式是可以绕开的。

这就是 DDIM，与其说是一个新模型，不如说是一种采样方法。DDPM 采样太慢，现在的主流模型基本都用 DDIM 这类采样。

注DDIM 是 Song、Meng、Ermon 的论文（arXiv 2020-10-06）。

它构造了一族非马尔可夫的前向过程，边际分布 q(xt|x0) 和 DDPM 完全相同，所以 DDPM 训练好的网络不用重训就能拿来用；采样时可以只走一个子序列（比如 1000 步里每隔 20 步取一步），还可以把随机性完全去掉。Nik_Li 合集的第二期专门讲这个。

问题四：为什么不直接预测 xt−1

U-Net 本来是做分割的，输入输出一样大，为什么不直接用 xt 预测 xt−1，任务岂不是更简单？讲者的回答还是回到「预测分布」：如果去预测一张确切的 xt−1，任务就退化成了类似分割的任务，每一步都是确定的 (Deterministic)。

这时随机性只剩起点：xT 是随机抽的，但每个 xT 对应一张固定的 x0，两个一模一样的 xT 一定得到两张一模一样的 x0，有点像 生成对抗网络 了。

DDPM 刚提出时采样很慢，效果也不如最好的 生成对抗网络，如果只是这样，这篇文章不会有那么大影响力。它的优势是多样性，远超 生成对抗网络：每一步都在预测分布、重新采样，同一个 xT 输入两次会得到两张不同的图，1000 步每步都重新采样，随机性非常好。

注「每一步确定」本身不会让模型失去多样性。DDIM 把随机性去掉以后，每个 xT 也对应一张固定的图，可不同的 xT 照样生成各不相同的图，样本质量也很好；生成对抗网络 一个噪声对应一张图，问题在于训练时容易只覆盖一部分模式，和确定性无关。

直接用均方误差预测 xt−1 的真正毛病是糊：同一个 xt 可能来自很多个 xt−1，均方误差的最优解是它们的平均。把它当成高斯的均值、再加上一份噪声去采样，才是一个合法的概率模型。DDPM 预测的 ε 换算成均值以后，做的正是这件事。

总结：变分下界去哪了

论文里还有变分下界 (Variational Lower Bound) 这个概念，前面一直没提。讲者的解释是：论文的出发点是最大似然估计，取负号变成求最小值来定义损失；引入变分下界后取负号变成上界，化成一串 KL 散度，KL 的两边就是要学的 pθ(xt−1|xt) 和前面推出的后验。

所以这一套推导是在给「用 pθ 去拟合后验」这个做法正名；视频把「拟合后验」直接当成了已知的目标，就省掉了前面这些。

最后把整条链串了一遍：想要 xt−1 的分布，这个分布是高斯，方差已知，只缺均值；均值是 xt 和 x0 的函数，x0 不知道，转成预测 x0；x0 又可以写成 xt 和 ε 的函数，于是转成预测 ε。

推理时给定 xT，模型算出 ε，算出均值，得到分布，采样出 xT−1，再继续往回推，最终得到生成结果。扩散模型不是简单地「去噪」，全程都是在用概率分布做优化和推导。

注变分下界不只是「正名」。它决定了每一步的损失该乘多大的权重（论文式 (12)），DDPM 的 Lsimple 是把这个权重扔掉以后的版本，这个改动是它效果好的原因之一；后来的 Improved DDPM 又把一部分真正的下界加回来，换取更好的似然。综述 tab 第 6、9 节讲这两步。

这个视频记住这几条

  • 模型要学的是 xt−1 的条件分布，每一步都重新采样；网络输出噪声只是把均值换了个写法。
  • 直接倒着走一步要用到算不出的边际分布；多条件一个 x0，三项都是已知高斯，后验 q(xt−1|xt, x0) 有闭式解。
  • 后验均值里的 x0 用 (xt − √(1 − αt) ε) / √αt 换掉，唯一的未知数就是 ε；这份 ε 是从 x0 一步加到 xt 的总噪声。
  • 训练一步到位，靠的是 q(xt|x0)；采样必须一步步走，靠的是后验那一步。
  • βt = 1 − αt 让方差保持为 1，T 取大是为了让 αT 足够接近 0。

开场：这篇论文没有发明扩散模型

扩散模型现在几乎用在所有领域：图像、视频、音乐、三维模型，甚至新分子的发现。结果很惊艳，理论却很密，细节多，数学乍看也不友好。这一期跟着让扩散模型走红的那篇论文一步步走。

那篇论文是 Jonathan Ho 等人 2020 年的 DDPM。作者先澄清：它既不是第一个提出扩散模型的，也不是它起的名字，最早的出处是 Sohl-Dickstein 等人 2015 年的《Deep Unsupervised Learning using Nonequilibrium Thermodynamics》。

2015 年图像生成是 生成对抗网络 (Generative Adversarial Network) 的天下，扩散模型没人注意；2020 年的 DDPM 很快走红，视频里说到 2025 年引用已经超过两万次，是这个领域引用最多的论文。

论文的主要贡献，是把扩散模型从一个只在玩具数据集上验证过的理论概念，做成了最先进的图像生成技术。技术上，它主要提出了一个比 2015 年版本简单得多的训练目标，让方法更容易上手，也揭示了它和早先去噪模型之间的联系。

基本思路：加噪，再学会去噪

数据生成里，训练数据来自一个概率分布 p(x)。图像的话，可以把它想成「所有自然图像」的分布，或者只包含人脸的那一部分。这个分布复杂到写不出一个完整的表达式，很可能根本没有这样的表达式。

可我们仍然想生成新图，也就是从这个分布里采样新的点。难处在于：要在不知道分布长什么样的情况下造出新样本。

扩散模型用一个看似无关的过程来解决：先给图像逐步加高斯噪声，每步加一点，图像的结构慢慢被抹掉，加足够多步后变成纯噪声；然后训练一个模型学会把这些步骤慢慢倒回去，一点点去掉噪声。模型学得好的话，就能从随机噪声出发，一步步细化出一张有意义的图。

前向过程：先看一个会爆炸的版本

从一张没有噪声的图 x0 开始。下一张 x1 由条件分布 q(x1|x0) 产生：给 x0 加一份高斯噪声 ε，噪声大小由一个标量 β 控制。等价地说，x1 就是从「以 x0 为中心、方差为 β」的高斯里抽的一个样本。

下一步照做，q(x2|x1) 是以 x1 为中心、方差为 β 的高斯。噪声项是直接相加的，所以可以从 x0 一步跳到 x2：相当于加了两倍的噪声，以 x0 为中心、方差 2β。一直到第 t 步，q(xt|x0) = N(x0, tβ)。

问题来了：我们要的是一个能把数据逐渐变成标准正态分布的过程，这个过程做不到。均值永远停在 x0，方差无限增长，不可能收敛到标准正态分布。文献里管这叫方差爆炸 (Variance Exploding) 扩散。

注动画里写的 xt = x0 + tβ·ε 不严格，按方差 tβ 应该是 x0 + √(tβ) ε，前面「乘 β」也应该是乘 √β。作者口头说的「方差为 β」是对的。

方差爆炸并不是错的做法，只是终点分布随噪声总量变，不是固定的标准正态分布。Song 和 Ermon 的 NCSN 用的就是这一类，Score SDE 把它和 DDPM 的保方差版本当作两种并列的选择。

保方差的前向过程

要收敛到标准正态分布，得满足两个条件：均值趋于 0，方差趋于 1。所以每一步都要动均值，在前面乘一个系数让它衰减。DDPM 用的系数是 √(1 − β)。为什么是这个数：作者坦言还有别的合法选择，论文选它多半因为简单，这个选择能让任意一步的条件分布有一个简洁的表达式。推导他跳过了，说挺无聊。

q(xt|xt−1) = N(xt; √(1 − β) xt−1, β)每一步
q(xt|x0) = N(xt; √αt x0, (1 − αt)), αt = (1 − β)tβ 固定时的一步到位

只要 β 严格在 0 和 1 之间，t 趋于无穷时 αt 趋于 0，均值趋于 0、方差趋于 1，这就得到了一个真正的保方差 (Variance Preserving) 扩散过程。

一维例子：原始数据分布是两个峰。走一步，分布几乎不变；走 100 步左右，效果就明显了，均值靠向 0，分布宽度稳定下来。而且可以从输入分布直接跳到任意一步，不用一步步迭代。

论文里 α 的定义稍有不同，因为实际中每一步的噪声量不一样，不是固定的 β。只要每个 β 都在 0 和 1 之间，方差表可以随便选。这时 αt 变成每一步 1 − β 的连乘，就是论文里的写法。

注跳过的推导在基础 tab「高斯运算」的两步合并例子里，Nik_Li 视频的问题二也用一般系数推了一遍：要求均值系数的平方加方差等于 1，t 步合并后方差正好是 1 − αt。

逆向过程和负对数似然

前向过程用概率密度 q 把干净的图 x0 带到高斯噪声 xT。假设有办法把每一步倒回去，用概率密度 p(xt−1|xt) 表示。前向过程的参数全部固定；逆向过程的目标是找到最好的参数 θ 来有效去噪，这些参数就是神经网络的权重。

训练用贝叶斯统计里很标准的做法：最小化模型生成样本的负对数似然。意思是找一组 θ，让网络生成真实样本 x0 的概率尽可能大；不直接最大化 pθ(x0)，而是最小化 −log pθ(x0)，实际上更好算。

先定义记号。前向过程的联合分布 q(x1:T|x0) 用贝叶斯公式拆成条件分布的连乘；因为前向过程是马尔可夫链，每一步只依赖前一步，所以每个条件分布只剩 q(xt|xt−1)。

逆向过程同样写成连乘 pθ(x0:T) = p(xT) ∏ pθ(xt−1|xt)。注意逆向过程不以任何东西为条件，它从纯噪声出发，不需要先知道什么；前向过程则需要一张输入图 x0。

注「用贝叶斯公式拆成连乘」严格说是链式法则（概率的乘法公式），马尔可夫性再把每一项的条件砍到只剩前一个，见基础 tab 的马尔可夫链一节。

变分下界

处理联合分布时，第一步通常是把其他变量边际化掉：pθ(x0) = ∫ pθ(x0:T) dx1:T。可这个式子算不了。它的意思是：要算网络生成 x0 的概率，得把所有能生成它的路径都加起来。

动画把它画成两团：左边是自然图像的密度，右边是纯高斯噪声的密度。从图到噪声的路径是存在的，前向过程就是一条；我们也假设从噪声到图的路径存在。公式要求把所有这些路径加起来，路径太多，算不出来，这叫不可解 (Intractable)。

不能精确算不等于完全没办法。第一个常用技巧：乘一个、再除一个前向过程的密度，积分就写成了按 q 取的期望。第二个技巧是 Jensen 不等式：负对数是凸函数，可以把 log 挪进期望里，代价是等号变成不等号。

−log pθ(x0) = −log ∫ q(x1:T|x0) · pθ(x0:T) / q(x1:T|x0) dx1:T乘除同一个 q
= −log Eq(x_{1:T|x0)}[pθ(x0:T) / q(x1:T|x0)]写成期望
≤ −Eq[log (pθ(x0:T) / q(x1:T|x0))]Jensen 不等式

得到的是负对数似然的一个上界，通常叫证据下界 (Evidence Lower Bound, ELBO)。叫「下界」是因为它对负对数似然是上界，对似然本身就是下界。

化简变分下界：KL 和真实后验

用一些代数和贝叶斯公式，变分下界可以改写成更有用的形式。推导作者跳过了，说在论文附录 A 里写得很详细：

Eq[ KL(q(xT|x0) ‖ p(xT)) + Σt&gt;1 KL(q(xt−1|xt, x0) ‖ pθ(xt−1|xt)) − log pθ(x0|x1) ]论文式 (5)

里面的 KL 散度是衡量两个分布有多接近的量，可以粗略当成概率空间里的一种距离：两个分布均值或方差差得多，KL 就大；很像时 KL 就小；只有两个分布完全相同时才为 0。所以这个损失衡量的是几对分布离得有多远。

再化简。左边第一项和模型参数无关，优化时忽略。右边最后一项依赖网络，衡量模型从稍带噪声的 x1 还原干净 x0 的能力。可扩散模型通常有上千步，到 x1 时几乎没噪声了，模型已经恢复了大部分图像，这一项很小，提供不了多少学习信号，实际中加不加几乎没区别，通常直接去掉。

剩下的主体是一大串 KL。pθ(xt−1|xt) 是逆向一步，另一个 q(xt−1|xt, x0) 叫真实后验 (True Posterior)：前向过程 q(xt|xt−1) 存在一个反过程，我们就是在用 p 去近似它；如果再以原图 x0 为条件，就能精确算出这个反过程，而且有闭式解。

作者顺带回答了一个疑问：既然有闭式解，还要神经网络做什么。答案是用真实后验等于「作弊」：它要求知道 x0，而推理时的目标恰恰是从纯噪声生成 x0。训练时 x0 是知道的，所以可以用。这个损失做的事，就是训练网络去匹配那个「如果知道 x0 就能算出来」的真实后验，尽管网络自己只看得到 xt。

注「最后一项通常直接去掉」和论文的做法不完全一样。论文的 Lsimple 里 t = 1 那一项保留着，对应 L0 的一个近似（论文 3.4 节：离散解码器的积分近似成高斯密度乘区间宽度），并没有单独扔掉。实际效果上作者说得对：它只是 1000 项里的一项。

第一项不依赖参数是因为方差表 βt 固定。Improved DDPM 等工作如果去学方差表，这一项就不能忽略了。

从 KL 到均值的平方距离

真实后验的表达式作者又跳过了（代数加贝叶斯公式），结论是：它是一个高斯，均值 μ、方差 β。

近似后验也设成高斯，理由有两个：有一个定理说高斯马尔可夫链的逆过程也是高斯，选高斯合情合理；而且高斯什么都好算。于是网络本来要预测这个高斯的两个参数：均值 μθ 和方差 Σθ。论文进一步简化，把方差固定成不学习的常数 σt，网络只学均值。

要让两个高斯接近，又只能动其中一个的均值，能做的最好的事就是让它的均值尽量靠近真实后验的均值，也就是最小化两个均值之间的距离。KL 散度在这种情况下正好就是这样：方差固定时，它化简为两个均值之间的平方距离。

从整体看，最小化这一串 KL，就是让每一步的近似后验去贴它对应的真实后验；而每一个都只能调均值，所以就是缩小每一步与真实后验均值的距离。

L = Eq[ Σt&gt;1 ‖μt − μθ(xt, t)‖2 / (2σt2) ]论文式 (8)，省掉了常数

注「高斯马尔可夫链的逆过程也是高斯」要加条件：只在每一步噪声很小（β 很小）时近似成立，这是 Feller 1949 年关于扩散过程的结论。步子迈大了，真实的逆向一步可能是多峰的。DDPM 的 β 最大 0.02，所以用高斯没问题，见基础 tab「倒着走」一节的补充。

动画在 17:30 前后把近似后验写成 N(μθ, σθ)，那是还没固定方差时的写法；固定以后（18:58 的画面）就换成了 σt。论文里 σt2 取 βt 或 βt，两者效果差不多。

化成预测噪声

每一项 KL 都化成了平方距离，所以整体是在最小化一串 L2 距离：预测均值 μθ 离真实后验均值 μ 有多远，再乘一个取决于 σt 的权重。

μ 有闭式解，但有点复杂，是 x0 和 xt 的加权组合，用起来不方便。用重参数化技巧（视频开头用过、变分自编码器里也用的那个），xt 可以写成 x0 和纯高斯噪声 ε 之和；反过来稍做代数，x0 也能只用 xt 和 ε 表示。代进 μ，它就只依赖 xt 和 ε。

关键的一步：去噪网络也看得到 xt，所以对网络预测的 μθ 用同一个写法，写成 xt 和一个预测噪声 εθ 的函数。两个均值都换成「xt 加噪声」的形式，代回损失，xt 的项抵消掉，剩下 ε 和 εθ 之间的平方距离：

μt = 1/√αt · (xt − βt / √(1 − αt) · ε)真实后验均值
μθ(xt, t) = 1/√αt · (xt − βt / √(1 − αt) · εθ(xt, t))网络的均值用同一个形式
L = Eq[ Σt&gt;1 βt2 / (2σt2 αt (1 − αt)) · ‖ε − εθ(xt, t)‖2 ]代回，xt 抵消

于是 εθ 就是网络对「加到 x0 上、得到 xt 的那份噪声」的估计，最小化损失就是让这个估计尽量准。

作者在这里回顾了整条链：想优化 x0 的负对数似然，算不出，换成变分下界；用贝叶斯公式和大量计算写成几项之和，一项和参数无关、一项可以忽略，都扔掉，剩下一串 KL；近似后验选高斯，KL 化成真实和预测后验均值之间的 L2 距离；再用重参数化把均值写成真实噪声 ε 和预测噪声 εθ，得到最终的损失。

最后一个简化：每个样本都对几百上千个时间步求和太贵了。改成每个样本随机挑一个 t，样本足够多时会收敛到原来的目标。

注这里得到的损失还带着每一步的权重。DDPM 实际用的 Lsimple 把权重也扔掉了（视频在 26:46 的代码部分才提到），这一步对样本质量很关键，见综述 tab 第 9 节。

训练代码（续）：常数和训练循环

接着定义扩散用到的所有常数。先是方差表，描述每一步加多少噪声，和原论文一样从小的 βstart 线性插值到大的 βend；也可以换成余弦方差表，这里先用最常见的线性。然后算出 α、累乘 α，以及 √α 和 √(1 − α) 这些常用量。

训练循环每一步：随机挑一个 0 到 1000 之间的时间步 t，从标准正态分布抽一个噪声 ε，用前面推出的保方差公式算出带噪图像。代码里的式子和理论上的公式一模一样。带噪图像和 t 一起送进网络，网络输出对图中噪声的估计，和 ε 算损失。

代码里用的不是刚才推出的带权重的损失，而是更简单的版本：所有时间步的权重都设成 1，原论文也是这么做的，而且这样往往比随时间变化的权重效果更好。重复「加噪、算均方误差」直到训练完，这里大约 100 个轮次，最后保存权重。

训练中均方误差降得很快，很快稳定在一个很低的值。每个轮次结束时显示几张去噪结果：左边原图，然后是不同时间步的带噪版本和网络给出的去噪估计。训练初期，噪声大时输出很差，噪声小时已经不错；随着训练，各个时间步都越来越好，但噪声非常大时仍然认不出是哪个数字。作者说这完全没关系，用来生成新样本时照样表现很好。

beta_start, beta_end, timesteps = 1e-4, 0.02, 1000
betas = torch.linspace(beta_start, beta_end, timesteps)
alphas = 1.0 - betas
alphas_cumprod = torch.cumprod(alphas, dim=0)
sqrt_alphas_cumprod = torch.sqrt(alphas_cumprod)
sqrt_one_minus_alphas_cumprod = torch.sqrt(1.0 - alphas_cumprod)

for epoch in range(epochs):                  # epochs = 100, lr = 1e-4, batch_size = 32
    for imgs, _ in train_loader:
        noise = torch.randn_like(imgs)
        t = torch.randint(0, timesteps, (imgs.size(0),))
        noised_imgs = (sqrt_alphas_cumprod[t, None, None, None] * imgs
                       + sqrt_one_minus_alphas_cumprod[t, None, None, None] * noise)
        optimizer.zero_grad()
        loss = mse(model(noised_imgs, t, type_t="timestep"), noise)
        loss.backward()
        optimizer.step()

采样代码

推理代码写在另一个文件里。重新导入库，用刚保存的权重实例化网络，再把所有扩散常数重新定义一遍，包括线性方差表。这些参数必须和训练时完全一致，否则推理时某一步的噪声量就和训练时同一步见过的对不上。

采样循环：先抽纯高斯噪声作为初始的 xT；把它和时间步 t 送进网络，预测出 εθ，即对图中噪声的估计；把噪声估计代进后验均值公式，再加一点噪声，就从近似后验里采出了 xt−1。代码里的式子又和理论公式一模一样。然后把新图送进网络、算均值、采下一张，通常重复 1000 次。

x = torch.randn(n_samples, 1, image_size, image_size)
for t in reversed(range(timesteps)):
    t_tensor = torch.ones(n_samples).long() * t
    predicted_noise = model(x, t_tensor, type_t="timestep")
    alpha, alpha_cumprod, beta = alphas[t], alphas_cumprod[t], betas[t]
    noise = torch.randn_like(x) if t > 0 else 0
    x = (1 / torch.sqrt(alpha)) * (
        x - (beta / torch.sqrt(1 - alpha_cumprod)) * predicted_noise
    ) + torch.sqrt(beta) * noise

看几个样本在迭代中怎么变：扩散一开始几乎看不出变化，噪声还太多；到最后几百步，细节才从噪声里浮现出来，最终得到一组干净、互不相同的样本。只用一个去噪器和几条扩散公式就从零生成了高质量的手写数字，核心的采样循环不到 30 行。

整体思路

为什么要先加噪再去噪，直接学一个从噪声到图的映射不行吗？

直接学「一个噪声对应一张图」就是生成对抗网络和变分自编码器解码器做的事：一步跨过去，网络要一次学会把高斯分布整个搬到图像分布上，这件事很难，前者训练不稳，后者生成的图偏糊。

扩散模型把这一大步拆成 1000 个小步。每一步只需要去掉一点噪声，两端的分布几乎一样，用一个高斯描述就够了，网络的任务从「凭空画一张图」变成「这张带噪图里的噪声长什么样」，这是一个有标准答案的回归问题，好训练。代价是生成时要走 1000 步。

马尔可夫性在 DDPM 里到底用在哪几处？

三处。第一，前向和逆向的联合分布都能拆成一步一步的连乘，模型只需要定义「一步怎么走」。第二，求后验时 q(xt|xt−1, x0) = q(xt|xt−1)，条件里多出来的 x0 能直接去掉，三项都成了已知高斯。第三，变分下界拆成一串 KL 时，相邻项能约掉，也是靠这一条。

训练时一步跳到 xt 的公式 q(xt|x0) 本身不需要马尔可夫性，只需要每一步的噪声相互独立。DDIM 正是利用这一点：只保住 q(xt|x0)，把链改成非马尔可夫的，同一个网络照样能用。

q 和 p 有什么区别？视频里有时都写成 p。

前向过程

加噪为什么要先乘 √αt，不能直接加噪声吗？

直接加噪声，方差每步加 β，走 T 步后是 1 + Tβ，终点分布取决于加了多少步，均值也永远停在 x0，不会收敛到一个固定的分布。Deepia 视频把这个叫方差爆炸。

先乘 √(1 − βt) 再加方差 βt 的噪声，系数平方加方差恰好是 1，像素方差一直保持在 1，原图的成分则每步衰减一点，最终收敛到标准正态分布。这样采样时才知道从哪出发。

T 为什么取 1000？取 10 行不行？

两个要求互相拉扯。每一步的 βt 要小，逆向一步才近似高斯；所有步加起来又要让 αT 足够接近 0，xT 才和标准正态分布分不出来。β 小就只能靠步数多来凑。

按原论文的线性方差表，α1000 ≈ 4 × 10−5。如果只走 10 步又要冲干净，每步的 β 就得很大，倒退一步的真实分布会是多峰的，单个高斯拟合不了，生成质量很差。

前向过程不是一步一步加噪吗，为什么训练代码里一步就得到了 xt？

每一步加的是独立的高斯噪声，独立高斯相加还是高斯，t 步的噪声能合并成一份：xt = √αt x0 + √(1 − αt) ε。数学上和真的走 t 步得到的分布完全一样，所以训练时随机挑一个 t，一行算出 xt 就行。

生成时没有这种捷径：逆向的每一步都依赖网络当前的输出，只能一步步走。

训练目标

为什么后验要多条件一个 x0？生成时根本没有 x0。

不加 x0，倒退一步 q(xt−1|xt) 要用到「所有图片加噪后的分布」，算不出来；加了 x0，三项都是已知高斯，有闭式解。

训练时手里正好有 x0，这个闭式解就当成标准答案，让网络的 pθ(xt−1|xt) 去贴它。网络自己只看得到 xt，所以它学到的是对所有可能的 x0 取平均以后的那个「倒退一步」，生成时就用它。Deepia 管直接用真实后验叫「作弊」，说的就是这层。

网络预测的噪声，是 xt−1 到 xt 那一步加的噪声吗？

不是。它预测的是从 x0 一步加到 xt 用的那份总噪声 ε，也就是 xt = √αt x0 + √(1 − αt) ε 里的 ε。训练代码里抽的就是这份 ε，损失也是拿网络输出和它比。

生成时把这个 ε 的估计代进后验均值公式 μ = (xt − βt / √(1 − αt) · εθ) / √αt，得到的才是往 xt−1 走一步该到的位置。从式子能看出，每一步只减掉了 ε 估计的一小部分（系数 βt / √(1 − αt) 很小）。

预测 ε、预测 x0、预测均值，既然能互相换算，为什么偏偏预测 ε？

三者确实一一对应，区别在网络学起来的难度。ε 永远是标准正态，不管 t 是多少，输出的尺度都一样；x0 在 t 很大时几乎被噪声淹没，网络只能给出一个模糊的平均；均值则随 t 的尺度变化很大。

论文表 2 的对比：预测均值配真实下界 FID 13.22，预测 ε 配真实下界 13.51，两者差不多；预测 ε 配去掉权重的 Lsimple 降到 3.17。预测 x0 在早期实验里就效果更差，没放进表里。

为什么把损失前面的权重扔掉，效果反而更好？

真实下界里每一步的权重是 βt2 / (2σt2 αt (1 − αt))，t = 1 时约 0.5，t = 100 时只有 0.01，大部分权重压在 t 很小的那几步上。那几步噪声极弱，学的是去掉肉眼几乎看不见的细节。

全部设成 1 以后，相对来说大 t 的项变重了，网络把力气花在噪声大、更难的去噪上，生成的图更好。代价是对数似然变差一点（3.75 对 3.70 比特每维）。所以 DDPM 实际优化的不再是严格的似然下界。

采样

去噪的时候为什么还要再加噪声 σt z？

因为每一步要做的是从 pθ(xt−1|xt) 这个高斯里采样，网络给的只是均值，加上 σt z 才是一次真正的采样。不加的话，每一步都走到均值上，多次「取平均」叠起来，生成的图会偏平滑、细节少。

最后一步 t = 1 时不加噪声，直接输出均值。想要完全确定的采样也可以，但要换成 DDIM 那套公式，不能在 DDPM 的公式里简单地把 z 设成 0。

采样能不能跳步，或者从 xt 直接一步回到 x0？

用 DDPM 原本的公式不行：后验公式是按相邻两步推的，跳步就对不上了。一步回到 x0 数学上可以算出一个估计 x̂0 = (xt − √(1 − αt) εθ) / √αt，但 t 大时它是很多可能原图的平均，一张糊图。

换成 DDIM 就能跳步：它构造的非马尔可夫过程和 DDPM 有相同的 q(xt|x0)，训练目标完全一样，所以同一个网络可以只走几十步。

同一个 xT 采两次，会得到同一张图吗？

DDPM 不会。1000 步里每一步都抽一份新的 z，两次走出来的路径不同，最后的图也不同；固定 xt 再采，t 越大得到的图差别越大（论文图 7）。

DDIM 的确定性采样会：同一个 xT 永远对应同一张图。但不同的 xT 照样生成不同的图，多样性来自起点，所以「确定性就没有多样性」这个说法不成立，见 Nik_Li 问题四的注。
