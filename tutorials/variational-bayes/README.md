# 看见变分贝叶斯

一部中文交互教程，8 幕，建议约 20 分钟。

直接用浏览器打开 `index.html` 即可。无需安装，无需构建，无需网络，不会上传数据。

内容依次是：未知量与分布、贝叶斯更新、归一化积分、变分家族、ELBO、KL 的方向、平均场、自测。

- 黄色滑块和曲线上的圆点可以操作。
- “让它自己寻找”运行带回溯的梯度下降。
- ELBO 幕下方有逐行推导，其他各幕有可展开的补充说明。
- 左右方向键切换章节（焦点不在控件内时）。

`app.js`、`style.css` 和 `page.template.html` 为可编辑源文件。运行 `node build.mjs` 将样式和脚本内联，生成可单独复制的 `index.html`。

## 数学与计算

正态后验例子使用解析公式。双峰目标是两个正态分布的混合，权重 0.72/0.28，均值 −1.7/1.6，标准差均为 0.62。反向 KL 使用标准正态坐标下的数值求积；正向 KL 使用 z 网格求积。显示值四舍五入。优化限制参数范围，展示局部优化，不保证全局最优。

ELBO 幕以已知后验构造可验证的一维示意，固定 log p(x) = −2.30。实际 VI 不需要精确后验或证据数值；页面中两者用于展示恒等式。平均场例子使用单位边缘方差的相关二维正态，独立最优近似方差为 1 − ρ²。

已核对：概率密度归一化、KL 非负性、单峰 KL 零点、ELBO 恒等式、双峰局部解、正向 KL 的矩匹配解及平均场方差公式。浏览器交互另行检查。

主要参考：[Blei, Kucukelbir & McAuliffe, Variational Inference: A Review for Statisticians](https://arxiv.org/abs/1601.00670)。图形与讲解为原创；视觉采用深色画布、连续曲线和逐步推导，不属于 3Blue1Brown 官方作品。
